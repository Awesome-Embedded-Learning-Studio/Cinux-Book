# 从您敲下的那行字,到一根连着别处的线

您手头电脑上跑出来的每一件事,都是真的。咱们没有在谁的肚子里另造一台机器,也没有替您摆一台样子货。全部现场就在您眼皮底下,只是咱们挑的位置比较别扭:笔者在这一侧敲,您在那一侧看,而这一侧跟您的那一侧,有几处不一样。

那几处不一样,咱们在这里摊开讲清,一共三条。往后哪一篇里冒出一个看着不对劲的数字,您都可以回到这里,跟上面那几条对一对。

## 七个词,七个观察口

咱们平时说的命令行,说到底围着七个词转。七个词里没有一个是笔者的发明,它们都是您每天敲的那几行字背后真正在干活的东西。麻烦在于,它们全都藏在屏幕后面:您敲下回车,字流出来了,至于中间过了谁的手,平时一点都看不见。

咱们的办法是给每个词配一个观察口。观察口不解释任何东西,它只把那个词摆到明面上,让您亲眼看见一次。

就拿笔者此刻敲东西的这层壳来说。它叫 `shell`,平时您叫它命令行。同一个名字在它手里有两个身份,一个住在它自己里面,一个躺在磁盘上。大部分名字,它自己就能办,办不了的才交给磁盘上那个。还有一小组动作,压根交不出去,只能在它自己的进程里做完。您敲的每一条命令,都要过这一道分派。

再往下是三个小数字,`0`、`1`、`2`。程序启动的时候,手里就攥着它们。它们各自指着哪儿,咱们当天就能看见,而且不用懂任何机制。

两个数字也能成一对。内核把一个读端、一个写端交到一个程序手里,那就是一根管道。您平时写的那根竖线,左边要有一根管道,再让两边的进程各占一头,最后才轮到程序上场。

一行代码能变成两支。同一句 `fork` 在父亲那里和在孩子那里,回来两个不同的数,咱们看到两支都能自己往下走。跑起来之后,系统手里有一份花名册,上面是六个身份加一个名字:它自己的号、它父亲的号、它所在的组、它所在的会话、终端前台那一组是谁、它此刻在干什么,末尾还跟着它叫什么名字。父亲跑完还得回头收一次尾,才知道孩子是正常退场还是被什么东西打断了。

信号走的是另一条路。产生、挂着、送到,这三件事前后发生,平时挤在一瞬间里,看不成一段。有一个小程序的输出,咱们能把这三拍一行一行留住。

咱们再来看一个更怪的字节。同一个 `\003`,从终端敲进去,它会变成递给某个进程的信号。同样的字节从管道里送进去,它就只是一个普通的数据字节。一样的东西,两种命运。

终端这边咱们要跑两次同一份脚本,一次没有终端,一次有。还是那几个身份格,有四个格子两次跑出两套值:组、会话、终端前台那一组,还有状态。

最后是 `socket`,中文叫套接字。它给咱们留了两扇门。一扇是一根本机的连接,两头各有一个进程,一头还得报上一个没人占着的端口号。另一扇在文件系统里占一个位置,`ls -l` 看过去第一个字母写着 `s`,隔着它照样说得上话。

往后各篇讲自己的词,都会回到对应的口子上来,咱们到那一篇再进去看。

## 这七个词各自管着什么

有一个区分,您要是现在就带上,后面几篇会轻松不少。七个词里,只有一部分在办正事的时候真的去搬字节,另一部分管的是别的事。

`shell` 干的是翻译。它把您敲的那行字拆成几段,认出哪个是命令、哪个是参数,再决定这次由谁来执行。

管道、终端、普通文件、套接字,咱们数出来的这几样是真的在搬字节,而且都能用同一套调用去读写。文件描述符不在这个名单里:它是程序手里攥着的那几个号,每个号指向上面某一样。同一段数据从一个进程出去、进到另一个进程里,走的往往是这四样里的某一个。

进程和信号不搬字节。进程是那个干活的单位,您敲下的每一个命令,最后都以某个进程的样子存在过一小段时间。信号更干脆,它不携带数据,它只是通知。

这四类分工,后面每一篇都会落到具体的屏上,咱们到时候一屏一屏看。

## 同一套调用,套在所有东西上

七个口子,咱们各看各的,可它们看的是同一条线。

它有很多名字,咱们听得最多的一句是一切皆文件。这句话不是比喻,它说的是一个非常具体的安排:普通文件、终端、管道、套接字,这几种东西的样子差得极远,而它们能用同一套调用去读写。咱们打开一个、读一段、写一段、再关上,四个动作,`open`、`read`、`write`、`close`,一样一套,套在所有东西上。

您想想这省掉了多少东西。程序要对着一块数据干活的时候,不必知道自己摸的是磁盘上的文件、还是键盘、还是另一台机器送过来的东西。它按同一套调用来回搬字节,换掉的是打开的那一头。

它不会写在您的屏幕上,但是您每次把输出重定向进一个文件、每次拿 `wc` 去数另一个命令吐出来的行数,都是在用它。

| 词 | 这个口子看什么 | 怎么看见 | 哪一篇讲它 |
|---|---|---|---|
| `shell` | 一个名字在办这件事的时候有几个身份 | 三个名字各查一次:`echo` 一格同时摆出内建与磁盘两种身份,`cd` 只有内建,`ls` 只有磁盘 | 篇 1《shell 与文件描述符》 |
| 文件描述符 | 三个数字各自指着哪儿 | 把 `0`、`1`、`2` 摆出来,再补一格,看多出来的一格从哪儿来、关掉之后剩下什么 | 篇 1《shell 与文件描述符》 |
| 管道 | 一对数字怎么就接上了一根管道 | 两个数字交到程序手里,到了篇 2 还会看见一条命令行的竖线在内核那边分成了哪几步 | 篇 2《管道与重定向》 |
| 进程 | 一行代码怎么变成两支,系统怎么记它们 | 跑一次 `fork`,一支回来 0,一支拿回孩子的号,花名册上六个身份加一个名字 | 篇 3《进程生命周期》 |
| 信号 | 三拍怎么分别看 | 一小段程序的输出把产生、挂着、送到留成三行 | 篇 4《信号》 |
| TTY | 有没有终端差在哪儿 | 同一份脚本跑两次,一次 `tty` 答 `not a tty`,一次答出一个终端名,那几个身份格里,组、会话、前台组和状态这四格换了两套值 | 篇 5《终端与伪终端》 |
| socket | 两个进程怎么连上,以及它在文件系统里长什么样 | 一条本机连接,再一个 unix 域套接字在文件系统里占一个位置 | 篇 6《套接字》 |

表格您看看就好,它只是把七个口子排在一起。真正管用的是那个想法:每个词背后都有一屏东西能把它照出来。

## 笔者这一侧的三条限制

这三点是笔者这一侧的实际情况,不是通用的说法。您那边至少有一样跟这里不一样,也可能三样都中。

笔者在这一侧的 `uid` 号是 1000,没有 root。所以有一批动作这一侧做不成:改属主、改属组、往系统目录里装东西、动系统配置文件,一律得绕开。`/` 这一层挂进来就是只读的,往它下面写会当场吃一句 `Read-only file system`。要落一个新文件的实验,笔者都落在临时目录里。

这里能看到的进程很少,`ps -e` 只给出一小把,进程号也因此都停在个位到三位数上。1 号在一台普通机器上通常是系统启动时拉起来的头一个进程。笔者这一侧换了人:`/proc/1` 挂着的是一个看守进程,只管守着这一侧,不负责把整台机器带起来。

笔者在这一侧敲 `tty`,得到的是一句 `not a tty`,退出码 1,这一侧没有终端挂着。要终端的实验,咱们都得现开一个伪终端再跑,屏幕上的值才是真的。

三条合起来一句话:这会儿您读到的数字,大半只属于本机此刻。

## 两头各留下了什么

一份磁盘上的普通文件,一个终端,一根管道,一个套接字。这四样摆在一起,样子差得极远:文件躺在磁盘上,终端送进来的是您敲的键,管道只有一个方向,套接字的另一头坐在别的进程里。可是它们在程序手里走的是同一套调用:`open` 交回一个号,`read` 与 `write` 对着那个号搬字节,`close` 把号还回去。程序面对的是同一个号,不必知道号后面是谁。

省下来的是写代码这边的力气,代价落在另一边:系统得替咱们把这四样长相完全不同的东西,接成同一种样子交出来。这活儿不是一层能干完的,底下垫了好几层,每层管一档子事。

`shell` 待在整条线的最外面,负责把您敲的字翻译成一串动作,同时攥着三个数字,那是它自己进程手里的明细,交给孩子进程的时候会一起交过去。管道、终端、套接字,都能交给上面那套调用,打开之后一样落到三个数字旁边去。进程是这一切的骨架,每一根管道、每一个套接字,都得有进程攥着它才活着。信号不一样,它不去搬数据,它只是通报一声出了事。

您要是此刻觉得这个摆法有点糊,那正好。糊的那几处,正好留给后面几篇一层一层看进去。

## 这一篇没有装下的

这一篇是地图,不是操作手册。您在这里拿不到一条现成的命令,也拿不到一段能跑的程序,因为地图本来就不该有这些。真正的活儿在后面的篇里,四个调用怎么用、一对数字怎么接上、三拍怎么分别看,都由您亲手跑出来。

有几样东西,笔者在这儿交代一句,免得后面看到时以为是漏讲。套接字那一头只走到最小模型:两个进程怎么对上手、`bind` 与 `listen` 与 `accept` 那一路、端口号在网络里怎么排字节,这一卷都不展开,篇 6《套接字》只把一根连起来的线摆给您看。老版本的 bash 展 `.*` 的时候会多列出 `.` 和 `..` 两个名字,笔者这一侧见不到,篇 1《shell 与文件描述符》讲通配时会提一句。还有几件要 root 权限的动作,这一侧演不出来,只能照着书页讲,篇 1《shell 与文件描述符》会把它们落到书上。

那行字已经敲下去了,咱们跟着它往里头走。

## 最出乎意料的一格

要说这一趟最出乎笔者意料的,是 1 号那儿换了人。往后再看见进程号,都别拿它跟您那边比大小,能比的只有它们的相对关系:谁在谁前面,谁跟谁一组,谁只是被通报了一声。

笔者这一侧的三处再点一次名:进程号停在个位到三位数,`uid` 是 1000,`tty` 答的是 `not a tty`。这几处在您那边一定会不一样。

往下的篇 1《shell 与文件描述符》,就从您敲下的那行字是被谁分拣的讲起。
