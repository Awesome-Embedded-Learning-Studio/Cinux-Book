# 01 · 把 Linux 请进 Windows:从 wsl --install 到第一个提示符

您也许已经见过那个场面:深夜,您热血上头,点开一篇手搓操作系统的教程,结果第一段就把人按住了:请准备一台 Linux 机器。您环顾四周,桌面上跑的只有 Windows,教程里的命令一条都敲不了,您连往哪儿敲都不知道。热血当场就凉了半截。

嘿！别灰心,您没做错什么,纯粹是工具的户口问题,这一篇就管把它办利索:等您翻过这一页,自己的 Windows 里会跑着一个真的 Linux,您敲一条命令,就能亲眼看到它的内核版本号。顺带咱们聊明白为什么非 Linux 不可,免得您装完还替 Windows 叫屈。

## 为什么偏偏是 Linux

咱们要搓的东西,得靠一整套工具的接力:编译交给 gcc、链接交给 ld、裁出能直接启动的镜像交给 objcopy、把重复步骤串起来交给 make,替咱们跑成品的模拟电脑是 QEMU。

这帮伙计的老家全在 Linux 的世界里,您在 Ubuntu 里一行命令就能把它们全请进门。Linux 最核心的那段程序叫内核,整个系统都是压在它上面的。同一套内核配上不同的套装,就成了市面上各种各样的发行版,Ubuntu 是其中用户最多的一种,咱们全篇都拿它当主力。

您在 Windows 上也不是完全凑不齐:MSYS2 一类的东西能搬来一部分工具,费点劲也开得了工。麻烦在口音:教程的命令按 Linux 终端写,报错也是 Linux 的格式,您上网搜问题,搜出来的答案十有八九也是一段 Linux 命令。工具咱们凑得齐,口音是改不齐的,您一边搓内核一边当翻译,这样的日子没法过。

咱们将来写出来的东西,引导扇区、保护模式、分页什么的,和 Linux 说话用的是同一套词汇。手边站着一个真的 Linux,很多事当场就能看它是怎么做的,连查资料都跟着顺当了。

Windows 其实一点不差,您平时写应用、打游戏、干正事,它都是很称职的。只是手搓操作系统这间作坊的家当,恰好都堆在 Linux 的院子里。所以咱们眼下不补课,直接动手:在自己电脑里养出一个真的 Linux 当书房,后面的活都在它里头干。

## 三条路,咱们走哪条

想在自己的电脑里用上 Linux,常规的路子就三条,咱们挨个看。

- **双系统**:您给硬盘划出一块分区,让 Linux 以第二系统的身份住进去。摸的是真正的硬件、性能最足,代价是要动硬盘的分区,两个系统之间的切换还得重启整机。咱们后面调试是一天几十个来回的节奏,每回切换都是一次完整的重启,人就废了。
- **虚拟机**:在 VMware、VirtualBox 这类软件里,装一个带桌面的完整 Ubuntu。您想开就开,搞砸了删掉重来,倒是稳当,就是整套的块头十几 GB 起步,您还得给整台虚拟机划一块内存,桌面又把基线抬高了不少,而咱们压根用不上桌面。
- **WSL2**:Windows 官方的“适用于 Linux 的 Windows 子系统”。后台跑的是一个轻量虚拟机,里面住着微软自己维护的 Linux 内核,如假包换的真内核。您得到的是一个秒开的终端,就是您敲命令、它回字的那个窗口。Windows 的资源管理器里能直接翻 Linux 的文件,只是大文件的传输会慢半拍,复制粘贴倒是无缝的。后台的虚拟机也要吃一些内存,好在它是按用量长的。笔者的书房就是它,这本教程里的活,全是在它里头干的。

真内核住进了虚拟机,所以 WSL2 对 Windows 版本和 BIOS 虚拟化都有要求,装的时候您会亲手见到。咱们这本教程要敲的命令,在它身上和在正经的 Ubuntu 电脑上,跑出来的没有差别。

咱们把票投给 WSL2,道理前面都摆过了:双系统每回调试都欠一次重启,人就废了,虚拟机整套背着的是咱们用不上的桌面,还有一块得划给它的内存。WSL2 给的正好是咱们天天要用的:说开就开的终端,外加能把工具一行命令全请进门的包管理器,不要的桌面和独立分区,WSL2 也犯不着塞给咱们。您已经有跑顺的虚拟机?也行,留着用吧,后面的内容您照样跟得上,文末有给您的交代。

## 动手:把 Ubuntu 请进来

真正要动手的就这一段,咱们慢慢走。您要准备的前提有两个:Windows 10 的版本得是 2004 或更高,或者 Windows 11(拿不准的话,您 Win+R 敲个 winver 看一眼),主板 BIOS 里的 CPU 虚拟化得开着。BIOS 是主板自带的一小套底层设置,开机狂按 Del 或 F2 进的那个界面就是它。虚拟化是让一块 CPU 假装成好几台电脑的本事,很多电脑出厂就替您开着,真没开的,下面排障一节救您。

咱们开一个管理员终端:开始按钮上右键,Windows 11 的入口叫“终端(管理员)”,Windows 10 的入口叫“Windows PowerShell(管理员)”,然后您敲:

```powershell
wsl --install
```

咱们不带任何参数地敲下去,它默认装的就是 Ubuntu,正合咱们的意。接下来它要把两样东西请进来:WSL 的本体和一份 Ubuntu,几分钟的事,走完它会请您重启电脑。您照做。

等您重启回来,多数时候 Ubuntu 的黑色窗口会自己弹出收尾,没弹的话您也别慌,您在开始菜单搜 Ubuntu,点一下就进去了。它只剩一件事要办:给您造一个用户。屏幕上会问您:

```text
Enter new UNIX username:
```

您起个小写字母的用户名(别带空格),敲下回车就没事了。接下来轮到的是密码,您输两遍就好。

> 这里有个经典的吓人现场:您敲密码的时候,屏幕上是空的,连光标都不带动的。您别慌,程序是故意的,Linux 下的密码一律不回显。您闭着眼睛敲完两遍,回车就是了,大家第一次都怀疑过键盘。

等您把这些都办完了,屏幕上会出现一行大概长这样的东西:

```text
tom@DESKTOP-1A2B3C4:~$
```

@ 前面是您刚起的用户名,再往后到冒号为止是电脑的名字,~ 是您的家目录,相当于 Windows 里的 C:\Users\您,$ 后面就是 Linux 等您说话的地方。这一整行有个正式的名字:提示符(prompt)。标题里答应您的第一个提示符,就是它了。

您别看它就一行小字。您为了它,动用了管理员权限、重启了一次电脑,还扛住了一段不回显的密码。现在您的 Windows 里真的多出了一间 Linux 书房——嘿,亮灯了!

## 战果:亲眼看一眼版本号

往后您想回这间书房,点开始菜单里的 Ubuntu 就进去了,您 Win+R 敲个 wsl 回车,进来的也是同一个地方。验收的时候到了,您在提示符后面敲这一行,回车(uname 和 -r 之间的空格别丢):

```bash
uname -r
```

笔者这边敲下去,回来的是:

```text
6.18.33.2-microsoft-standard-WSL2
```

您那串开头的数字多半和笔者的对不上,咱们不用管,它跟着 Windows 的更新走。值得看的是结尾:microsoft-standard-WSL2。这串字是在告诉咱们,您面前跑着的,是一个正儿八经的 Linux 内核。您现在站的地方是真的 Linux,往后教程里说的“进 Linux 敲命令”,指的就是这块地方。

> 您要是好奇自己装的是哪个发行版哪个版本,咱们再看一条:cat /etc/os-release,PRETTY_NAME 打头的那行就是答案。

## 万一卡住了

最常见的症状有下面三个,咱们按命中率高到低一个个来救。

**0x80370102**:Ubuntu 启动时报的就是这个码,基本就是 BIOS 里的 CPU 虚拟化没开。您重启进 BIOS(您开机狂按 Del 或 F2,具体看您的主板),Intel 平台找的是 Intel Virtualization Technology,AMD 平台对应的是 SVM Mode,改到 Enabled 的那一档,存了盘重启,咱们再试一次。wsl --install 能替您开 Windows 里的功能,这个开关它替不了,非得您亲手进 BIOS 拨。

**0x800701bc**:或者只提示您更新 WSL 内核。这是 WSL 的内核组件旧了,您在管理员终端里跑一句 wsl --update,装完了重开 Ubuntu 就好。

**wsl 不是内部或外部命令**:多半是 Windows 版本太老了,wsl --install 要 Windows 10 的 2004 版(内部版本 19041)起步,您敲 winver 就能确认。真在这一档的话,升 Windows、改走虚拟机(虚拟机的事,文末有专门的说法),也可以按[微软官方安装文档](https://learn.microsoft.com/zh-cn/windows/wsl/install)的手动步骤再试试。

## 别的路线,和没展开的几件事

选了双系统或虚拟机的朋友不亏:进了 Linux 之后,教程让您敲的命令一条不变,您跟着走就行。差别只在进出的方式,双系统的切换要重启,虚拟机自己管自己的窗口,教程里 Windows 与 Linux 互通的那些小方便,您略过就好。

发行版咱们就不比了。默认装的是 Ubuntu,因为它的用户最多,写给它的教程和问答也最多,新手的问题基本都有人答过。您要早有心仪的发行版,装上一样是能用的,命令对不上的时候自行对照,笔者就不掺和发行版之争了。

咱们一句话安置 Mac 朋友:您机器底下本来就是 Unix,和 Linux 同属这一门的另一脉,终端也是现成的。教程里 Windows 侧的动作与您无关,进了 Linux 的部分照样能跟,真对不上的地方,Ubuntu 的官方文档比 Mac 本地的手册靠谱。

提示符还在一闪一闪的,Linux 在等您开口,可您还不会说它的话——这也正常,谁也不是生下来就会的。咱们下一篇要读的“终端生存十条”,教的就是这些活:看东西、挪地方、手滑了怎么救。咱们到那边见!
