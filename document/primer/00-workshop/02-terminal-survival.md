# 02 · 终端生存十条:把黑框用出手感

您上一篇已经把书房装好了,回书房的路也交代过:开始菜单搜进来的 Ubuntu,和 Win+R 敲出来的 wsl,落脚的都是同一个地方。您这会儿多半就坐在那个黑框前面了。它的大名叫终端,光标一闪一闪的,就等着您开口。您的鼠标左键在这儿帮不上忙,您点它,它连眼皮都不带抬的。咱们在这个黑框里说话,靠的是您手底下的键盘,一个词一个词地往外蹦。

上一篇收尾的时候说好了,这边交给您三样活:看东西、挪地方、手滑了怎么救。咱们一条一条来,每一条您都亲手敲一遍。光用眼睛是学不会的,得您亲手敲过,它才真正归您。

## 家里有什么:ls 和它的沉默

咱们从最没悬念的一条开始。您把两个字母敲到提示符后面去,然后您回车:

```bash
ls
```

您敲下去,屏幕上却安安静静的,您啥也没等来。欸?您别慌,这不算坏了,您刚装修好的家,真的是空的。ls 没东西可列的时候就不吭声,它的沉默,说的就是屋里真的没东西。待会儿出场干活的 cp、mv、mkdir、rm 几位,也都是一路的脾气:闷头就把活干完了,您一个字都听不到。它们要是出了声,那多半是真出事了,往后咱们就不重复解释了。

不过,家里真的连一位住户都没有吗?您再敲一条,这回您多给它一个选项:

```bash
ls -a
```

这回您看到的大概长这样:

```text
.  ..  .bash_history  .bash_logout  .bashrc  .profile
```

哦,原来家里是有住户的。点开头的文件,ls 默认是不给看的,得您开口去要,-a 替您吆喝的就是“全都拿出来”。名单里坐着几位老住户:.bashrc 和 .profile 是系统给您备下的起手配置,替您记命令的活归了 .bash_history,像上一篇的 uname -r,它全记下了。不过它记下的东西,要等您关过一回窗口才写进来,您要是一直没关过窗口,名单里见不着它的影子,您也别纳闷。打头的 . 和 .. 不是文件,说的是两个地址,马上就轮到它们了。

这些点开头的家伙,凭什么默认藏起来,藏着的又都是些什么名堂,咱们下一篇专门去问。眼下您只要知道两样:点开头的文件确实存在,而且您拿 -a 就能请出来。

## 地址怎么写:一棵树,两个点,一个波浪号

您想挪地方,咱们就得会写地址。Windows 那边的地址您是熟的,几个盘符就是几个各自独立的院子。Linux 这边倒是不一样,咱们全系统就一棵树,树根是个孤零零的 /,咱们一般管它叫“根”。您的家在树上的位置,是 /home/ 加上您的用户名,tom 的家就是 /home/tom。

地址的写法有两种。从根写起、拿 / 打头的,咱们叫它绝对路径,好比您填快递单,您从省一路写到门牌,写全了才寄得出去。而反过来,从您脚下写起的叫相对路径,您站在哪儿,它就从您站的地方算起。

树上的几位常客,您认个脸就够:/etc 里住的是系统的各种配置,上一篇咱们顺路提过的 os-release 就住在里面。/home 是各家的卧室,您的家就在这儿。/usr 是装好的软件安家的地方,您往后装的工具,多半也就落到这儿了。您拿 ls 就能直接看望它们,比如您来一个 ls /etc,拉出来的名单长长一串,各家 Ubuntu 的内容大同小异,您不用背它。

您真想亲自过去串门,那就轮到 cd 出场了。您敲一个 cd /etc 再回车,这一下您可得盯着提示符看,它当场就换了字:

```text
tom@DESKTOP-1A2B3C4:~$ cd /etc
tom@DESKTOP-1A2B3C4:/etc$
```

您看见了没,~ 的位置换成了 /etc。上一篇咱们解剖提示符的时候说过,~ 就是您的家。现在您动了身,它就地改口,报的就是您眼下的位置。那行小字干的其实是导航的活,您之前没见它变过,纯粹是因为您一直站在家门口没挪过窝。想回家的话,您裸敲一个 cd 加回车就到家了,参数都省了,写 cd ~ 也是一样的效果。

再给您交代两个特殊的地址,往后用得上:. 说的是您脚下这间屋,.. 说的是楼上那间。您 cd .. 就退回上一层,. 的用处,待会儿 cp 那儿就用上了。

地址要是长了,逐字敲全它就遭罪了。好在终端里早就备好了 Tab 补全:您敲到一半,按下键盘左边的 Tab,剩下的它自动补齐。您要是发现补不全,您就再按一下,它会把候选都给您列出来,让您挑。拿待会儿的 playground 举例,您敲 cd play 加一个 Tab,剩下的几个字母,它一口气替您补全。

> 这一手没法贴输出给您,您务必亲手按一遍。按过一次的,谁也不肯再回去逐字敲了。

## 挪地方:cd 领路,mkdir、cp、mv 干活

cd 您已经会了。上一节咱们把您留在了 /etc,这会儿您敲一个 cd 回趟家,等您回到了 ~,咱们再开工。剩下三位都是干搬活儿的,咱们一个个看。您给 mkdir 一个名字,它就给您造出一间空屋:

```bash
mkdir playground
```

cp 的用法也很直白,您得交代清楚复制谁、放到哪儿。咱们拿系统里的一份小档案练手,把它复制一份到您脚下,命令尾巴上的那个点,说的就是您脚下这间屋:

```bash
cp /etc/os-release .
```

您敲完回车,屏幕上又是安安静静的。没动静就是最好的消息,前面交代过的脾气,干活的都这样。不放心的话,您 ls 看一眼,名单里已经多了一位 os-release。至于复制过来的是个啥,上一篇好奇的朋友已经拿 cat 看过它了。cat 干的活是把文件内容整个打到屏幕上,朋友看到的是一份小档案,写的就是您这系统叫什么、什么版本。

咱们再来看 mv,它是个一人分饰两角的家伙。目的地是个现成的目录,它就把文件给您搬进去。目的地是个还不存在的名字,它就管改名的事。您敲 mv os-release my-first-note.txt,文件当场就改了名。您敲 mv my-first-note.txt playground/,文件就搬进了 playground 这间屋。名字尾巴上的那道斜杠,说的就是“这是个目录”,正是 mv 认得出该走哪副面孔的记号。搬家的前提是那间屋已经建好,不然 mv 就报错拦下您,造屋的活它可不揽,那是 mkdir 分内的事。还有一句要紧的:mv 的目的地要是已经躺着一份同名文件,它会一声不响地把旧的覆盖掉,被盖住的那个,当场就没了。

## rm 的真面目:删了就是没了

咱们把最狠的一位留在最后:rm,删东西的。语法跟 cp 的一个样,您写 rm 谁,删的就是谁。

Linux 的删除,是没有回收站的。您在 Windows 里按 Delete,东西进了回收站,反悔了还捞得回来。您 rm 按下去,东西直接就没了,招呼都不跟您打一个。您回头想想 mv 盖掉同名文件的那一下,一声不吭的毛病,就是打 rm 这里家传下来的。“多半还能找回来”这一类的安慰,您趁早别指望。手滑了怎么救?最要紧的一句就是救不回来。所以每一次 rm,您都当它找不回来,请您在动手之前,亲眼把要删的东西核对一遍。

核对的路子有两条,都是朴素的土办法。咱们就拿 ls 来核对:您把同一段路径喂给它,名单亮出来了,哪个文件藏在哪儿都对上号了,您再把命令里的 ls 换成 rm,其余的字一个都不用动。星号 * 在这儿是个得力的帮手,它代表的是“随便什么名字”,ls *.txt 列出来的,就是脚下所有的 txt。另一条路子是 rm 自带的谨慎选项 -i,删谁都问您一句,真实的问话长这样:

```text
rm: remove regular file 'my-first-note.txt'?
```

您回 y 它才动手,您回 n 它就放回去。新手期您把它一直挂着,不丢人的。

咱们删目录的时候还会碰上一个小机关。您拿 rm 去删一间屋,它会拒绝您:

```text
rm: cannot remove 'notes': Is a directory
```

这其实是好事,报错尾巴上的 Is a directory,就是它在提醒您:rm 眼里的 notes 是间屋。您真要连屋带东西一起收,您就给它加上 -r。加了 -r 的 rm,就没有这层犹豫了,里里外外一锅端了。所以 -r 面前,您更要站定看清路径。笔者还得说说 rm -rf 这对组合,它专门发的是“别问了,全删”的横劲,对着错误的路径发作起来,能把您整个家连房本一起清掉。您往后见着教程里这么写,务必把那串路径看清了再回车。

再说救得回来的,全趴在您的键盘上。命令敲错了,您也不必从头重敲,按一下键盘上的上箭头,上一条就原模原样地回到眼前,您拿左右箭头挪过去,把错字改了再回车。您再按一下,它就往上再给您翻一条。接您话的是 bash,就是黑框里那个一直听您说话的程序,您敲过的每条命令,它都替您记着,想看全的话,您敲一个 history 就好。

您眼前的程序要是跑飞了、卡死了、停不下来了,或者您就是不想等了,您按一个 Ctrl+C,当前这茬多半当场就断了,提示符也就跟着回来了。不过笔者得提醒一句,专门说给从 Windows 过来的朋友:咱们这儿的 Ctrl+C,可不是复制!复制粘贴的活儿,您得走右键菜单,或者您用 Ctrl+Shift+C 和 Ctrl+Shift+V。您要是带着老习惯手一快,掐断的,就是您自己刚敲下去的命令。

## 十条连一台戏:从空地开场,到空地谢幕

咱们到这儿,每一条都见过了。您家里现在多半还站着一间 playground,前面 mkdir 的时候您亲手建的,里头要是还躺着练手的残件,rm -r 会把它们一并收掉的。咱们前面说好的,您在动 rm 之前拿 ls 看一眼名单,看清了再推倒。推倒了,咱们就从空地重新搭一遍。您开好终端,您的提示符要是不在 ~,您裸敲一个 cd 就回家了,在的话,咱们直接开工。能按 Tab 的地方您就按,等您敲到 cd play,请您替笔者按一下那个 Tab:

```text
tom@DESKTOP-1A2B3C4:~$ ls
playground
tom@DESKTOP-1A2B3C4:~$ rm -r playground
tom@DESKTOP-1A2B3C4:~$ mkdir playground
tom@DESKTOP-1A2B3C4:~$ cd playground
tom@DESKTOP-1A2B3C4:~/playground$ cp /etc/os-release .
tom@DESKTOP-1A2B3C4:~/playground$ ls
os-release
tom@DESKTOP-1A2B3C4:~/playground$ mv os-release my-first-note.txt
tom@DESKTOP-1A2B3C4:~/playground$ mkdir notes
tom@DESKTOP-1A2B3C4:~/playground$ mv my-first-note.txt notes/
tom@DESKTOP-1A2B3C4:~/playground$ ls
notes
tom@DESKTOP-1A2B3C4:~/playground$ cd notes
tom@DESKTOP-1A2B3C4:~/playground/notes$ ls
my-first-note.txt
tom@DESKTOP-1A2B3C4:~/playground/notes$ cd ..
tom@DESKTOP-1A2B3C4:~/playground$ rm notes/my-first-note.txt
tom@DESKTOP-1A2B3C4:~/playground$ ls notes
tom@DESKTOP-1A2B3C4:~/playground$ rm -r notes
tom@DESKTOP-1A2B3C4:~/playground$ ls
```

台词念完了,咱们品一品。您留意看提示符:它从 ~ 一路走到了 ~/playground,进了 notes,又退了回来,全程都在报您的位置。欸嘿,顺了。

笔者建议您把 playground 这间屋留着,想练手了就往里扔东西,删错了您也不心疼。

## 没教的,和留给下一篇的谜

命令其实还有一大把,找字的 grep、找文件的 find,咱们不急着塞给您,等哪天真用上了,那天咱们再现场学。眼下值当交给您的只有一条:忘了某条命令怎么用,您拿 man 加上命令名,比如您敲一个 man ls,说明书当场就弹出来了,您按 q 就离开。说明书上的字多半是英文,您倒也不用慌,您眼下只要知道它搁在哪儿就行。

ls -a 请出来的那几位点开头的住户,凭什么默认藏身?另外还有一句听着像胡话的话:在 Linux 的眼里,不光您敲的键盘是文件,咱们说话用的终端也是文件,连很多压根不像文件的东西也一样是文件。这话说早了没人信,下一篇咱们专门讲“文件的世界观”,到那时您回头看 rm 的绝情,大概就能看出几分道理来了。

您把十条各敲几遍,手上熟了,咱们再往下走。
