# 02 · 终端生存十条:把黑框用出手感

书房您上一篇已经装好了,回书房的路也交代过:开始菜单搜进来的 Ubuntu,和 Win+R 敲出来的 wsl,落脚的都是同一个地方。您现在多半就坐在那个黑框前面——它的大名叫终端——光标一闪一闪的,等着您开口。您的鼠标左键在这儿帮不上忙,您点它,它连眼皮都不带抬的。咱们在这个黑框里说话,话得靠您的键盘,一个词一个词地往外蹦。

上一篇收尾的时候说好了,这边交给您三样活:看东西、挪地方、手滑了怎么救。三样活凑齐了正好是十条,标题倒是没有吹牛。每一条您都亲手敲一遍,终端的本事,眼睛看会的算不上,手指敲过的才归您。

## 家里有什么:ls 和它的沉默

咱们从最没悬念的一条开始,您把两个字母敲到提示符后面去:

```bash
ls
```

您敲下去,屏幕上却安安静静的,您啥也没等到。您别慌,这不算坏了,您刚装修好的家真的是空的,ls 没东西可列的时候就不吭声了,说的就是屋里真的没东西。待会儿出场干活的几位,cp、mv、mkdir、rm 也都是一路的:它们闷头把活干完了,您一个字都听不到,它们要是出了声,多半是真出事了。往后咱们就不重复解释了。

不过,家里真的一位住户都没有吗?您再敲一条,这回您多给它一个选项:

```bash
ls -a
```

这回您看到的大概长这样:

```text
.  ..  .bash_history  .bash_logout  .bashrc  .profile
```

哦,原来家里是有住户的。点开头的文件,ls 默认是不给看的,得您开口去要,-a 替您吆喝的就是“全都拿出来”。名单里坐的是几位老住户:.bashrc 和 .profile 是系统给您的起手配置,您敲过的命令,还有一位 .bash_history 替您记着,像上一篇的 uname -r 都在里面。不过它记下的东西要等您关过一回窗口才写进来,一直没关窗口的话,名单里就没有它的影子,您也别纳闷。打头的 . 和 .. 不是文件,说的却是两个地址,马上就轮到它们了。

这些点开头的家伙为什么藏起来,藏着的都是什么名堂,咱们下一篇专门去问。眼下您只要知道两样:点开头的文件确实存在,而且您拿 -a 就能请出来。

## 地址怎么写:一棵树,两个点,一个波浪号

您想挪地方的话,您得会写地址。Windows 那边的地址您是熟的,几个盘符就是几个各自独立的院子。Linux 这边倒是不一样,咱们全系统就一棵树,树根是个孤零零的 /,咱们一般管它叫“根”。您的家在树上的位置,是 /home/ 加上您的用户名,tom 的家就是 /home/tom。从根写起、拿 / 打头的地址叫绝对路径,好比您在快递单上从省一路写到门牌。从您脚下写起的叫相对路径,好比跟同屋的人说“楼下、隔壁”。

树上的几位常客,您认个脸就够:/etc 里住的是系统的各种配置,上一篇咱们顺路提过的 os-release 就住在里面。/home 是各家的卧室,您的家就在这儿。/usr 是装好的软件安家的地方,您往后装的工具多半落在此处。您拿 ls 就能直接看望它们,比如您来一个 ls /etc,拉出来的名单有一长串,各家 Ubuntu 的内容大同小异,您不用背它。

您真想亲自过去看看,那就轮到 cd 出场了。您敲一个 cd /etc 再回车,这一下您可得看着提示符,它当场就换了字:

```text
tom@DESKTOP-1A2B3C4:~$ cd /etc
tom@DESKTOP-1A2B3C4:/etc$
```

您看见了没,~ 的位置换成了 /etc。上一篇咱们解剖提示符的时候说过,~ 就是您的家。现在您动了身,它就地改了口,报的是您眼下的位置。那行小字干的其实是导航的活,您之前没见它变过,纯粹是因为您一直站在家门口没挪窝。想回家的话,您裸敲一个 cd 加回车就到家了,参数都省了,cd ~ 也是一样的效果。

再给您交代两个特殊的地址,您往后就能用上:. 说的是您脚下这间屋,.. 说的是楼上一间。您 cd .. 就退回上一层,. 的用处,待会儿的 cp 那儿就用上了。

地址要是长了,逐字敲全它就遭罪了。好在终端里早就备好了 Tab 补全。您敲到一半,按下键盘左边的 Tab,剩下的它自动补齐。您要是发现补不全,您再按一下,它把候选全列出来让您挑。拿待会儿的 playground 举例,您敲 cd play 加一个 Tab,整个名字自己就长出来了。这一手没法贴输出给您,您务必亲手按一遍,按过一次的,没有谁愿意再回去逐字敲的。

## 挪地方:cd 领路,mkdir、cp、mv 干活

cd 您已经会了。上一节咱们把您留在了 /etc,这会儿您敲一个 cd 回趟家,等您回到 ~ 了,咱们再开工。剩下三个都是搬东西的,咱们一个个看。您给 mkdir 一个名字,它就给您造出一间空屋:

```bash
mkdir playground
```

cp 的用法也很直白,您得交代清楚复制谁、放到哪儿。咱们拿系统里的一份小档案练手,把它复制一份到您脚下,命令尾巴上的那个点,说的就是您脚下这间屋:

```bash
cp /etc/os-release .
```

您敲完回车,屏幕上安安静静的。没动静就是最好的消息,前面交代过的脾气,干活的都是这样。不放心的话,您 ls 看一眼,名单里已经多了一位 os-release。至于复制的是什么:上一篇好奇的朋友已经拿 cat 看过它了。cat 干的活是把文件内容整个打到屏幕上,朋友看到的是一份小档案,写的就是您这系统叫什么、什么版本。

mv 是个一人分饰两角的演员。目的地是个现成的目录,它就把文件给您搬进去。目的地是个还不存在的名字,它就管改名的事。您敲 mv os-release my-first-note.txt,文件当场就改了名。您敲 mv my-first-note.txt playground/,文件就搬进了 playground 这间屋。名字尾巴上的那道斜杠,说的就是这是个目录,正是 mv 认得出走哪副面孔的记号。搬家的前提是那间屋已经建好,不然 mv 就报错拦下您了,造屋的活它可不揽,那是 mkdir 分内的活。还有要紧的一句:mv 的目的地要是已经躺着一份同名文件,它会一声不响地把旧文件覆盖掉,招呼都不跟您打一个,rm 的近亲。

## rm 的真面目:删了就是没了

咱们把最狠的一位留在最后:rm,删东西的。语法跟 cp 的一个样,您写 rm 谁,删的就是谁。但您动手之前,有句实话笔者必须当面说:

Linux 的删除是没有回收站的。您在 Windows 里按 Delete,东西进了回收站,反悔了还捞得回来。您 rm 按下去,东西直接就没了,招呼都不跟您打一个。您别指望“多半还能找回来”一类的安慰。手滑了怎么救?咱们把话说全:最要紧的一句就是救不回来,所以每一次 rm,您都当作是“找不回来”,您让它动手之前总得亲眼点过名。

点名的办法有两个,都是朴素的土办法。咱们头一个办法,拿 ls 点名:您在 rm 之前,把同一段路径喂给了 ls,名单就亮出来了,人和物都对上号了,您再把命令里的 ls 换成 rm,其余的字一个都不用动。星号 * 在这儿是个得力的帮手,它代表的是“随便什么名字”,ls *.txt 列出来的就是“脚下所有的 txt”。第二个是 rm 自带的谨慎选项 -i,删谁都问您一句,真实的问话长这样:

```text
rm: remove regular file 'my-first-note.txt'?
```

您回 y 它才动手,您回 n 它就放回去。新手期您把它一直挂着,不丢人的。

咱们删目录的时候还会碰上一个小机关。您拿 rm 去删一间屋,它会拒绝您:

```text
rm: cannot remove 'notes': Is a directory
```

这其实是好事,它在提醒您脚下是间屋,不是单个的文件。您真要连屋带东西一起收,您就给它加上 -r。加了 -r 的 rm 就没有这层犹豫了,里里外外一锅端了,所以 -r 面前,您更要站定看清路径。笔者还得提一对组合 rm -rf,它专门发的是“别问了,全删”的横劲,对着错误的路径发作起来,能把您整个家连房本一起清掉。您往后见着教程里这么写,务必把那串路径看清了再回车。

再说救得回来的,全趴在您的键盘上。命令敲错了也不必从头重敲,按一下键盘上的上箭头,上一条就原样地回到眼前,您拿左右箭头挪过去改掉错字再回车。您再按一下,它就给您往上再翻一条。接您话的是 bash,就是黑框里那个一直听您说话的程序,它把您敲过的每条命令都记着,想看全的话,您敲一个 history 就好。

您眼前的程序要是跑飞了、卡死了、停不下来了,或者您就是不想等了,您按 Ctrl+C,当前这茬就当场断了,提示符也就回来了,一下多半就灵了。不过笔者得提醒一句,专门说给从 Windows 过来的朋友:在咱们这个黑框里,Ctrl+C 可不是复制!您的复制粘贴得走右键菜单,或者您用 Ctrl+Shift+C 和 Ctrl+Shift+V。您要是带着老习惯手一快,掐断的就是您自己刚敲的命令。

## 十条连一台戏:从空地开场,到空地谢幕

单条都见过了,咱们把十条连成一台戏。开场咱们得交代一件事:您家里现在多半站着一间 playground,前面 mkdir 的时候您亲手建的,里头要是还躺着练手的残件,rm -r 也会一并收走的。咱们前面说好的,动 rm 之前您拿 ls 点个名,看清了再推倒,推倒了咱们从空地重新搭。您开好终端,提示符要是不在 ~ 的话,您裸敲一个 cd 就回家了,在的话,咱们就直接开工,能按 Tab 的地方您就按,等您敲到 cd play,请您替笔者按一下那个 Tab:

```text
tom@DESKTOP-1A2B3C4:~$ ls
playground
tom@DESKTOP-1A2B3C4:~$ rm -r playground
tom@DESKTOP-1A2B3C4:~$ mkdir playground
tom@DESKTOP-1A2B3C4:~$ cd playground
tom@DESKTOP-1A2B3C4:~/playground$ cp /etc/os-release .
tom@DESKTOP-1A2B3C4:~/playground$ ls
os-release
tom@DESKTOP-1A2B3C4:~/playground$ mv os-release my-first-note.txt
tom@DESKTOP-1A2B3C4:~/playground$ mkdir notes
tom@DESKTOP-1A2B3C4:~/playground$ mv my-first-note.txt notes/
tom@DESKTOP-1A2B3C4:~/playground$ ls
notes
tom@DESKTOP-1A2B3C4:~/playground$ cd notes
tom@DESKTOP-1A2B3C4:~/playground/notes$ ls
my-first-note.txt
tom@DESKTOP-1A2B3C4:~/playground/notes$ cd ..
tom@DESKTOP-1A2B3C4:~/playground$ rm notes/my-first-note.txt
tom@DESKTOP-1A2B3C4:~/playground$ ls notes
tom@DESKTOP-1A2B3C4:~/playground$ rm -r notes
tom@DESKTOP-1A2B3C4:~/playground$ ls
```

台词念完了,咱们品一品。提示符从 ~ 一路走到了 ~/playground,进了 notes,又退了回来,全程都在报您的位置。ls 有名单可点的时候回回都点了名,干活的几位从头到尾一声没吭,活全办妥了。您最后那下 ls 什么都没说,您现在已经懂它的沉默了:屋里空了。旧屋是您亲手推平的,新屋也是您亲手起的,档案存了进去,又亲手收拾干净了,这一趟全是您自己的指令办下来的。欸嘿,顺了。

咱们回头数:看东西的三条是 ls、带 Tab 补全的路径、隐藏文件,挪地方的四条是 cd、mkdir、cp、mv,救命的三条是 rm、上箭头、Ctrl+C,十条全到齐了,标题到这儿兑现了。playground 这间屋建议您留着,您往后想练手就往里扔,删错了也不心疼。

## 没教的,和留给下一篇的谜

命令其实还有一大把,找字的 grep、找文件的 find,咱们不急着塞给您,等哪天真用上了,咱们那天再现场学。现在就值当给您的只有一条:忘了某条命令怎么用,您拿 man 加命令名,比如您敲 man ls,说明书当场就弹出来了,您按 q 就离开。说明书上的字多半是英文,倒是也不用慌,您眼下只需要知道它搁在哪儿。

收尾还给您留了个念想。ls -a 请出来的那几位点开头的住户,凭什么默认藏身?另外还有一句听着像胡话的话:在 Linux 的眼里,不光您敲的键盘是文件,咱们说话用的终端也是文件,连很多压根不像文件的东西也一样是文件。这话说早了没人信,下一篇咱们专门讲“文件的世界观”,到那时您回头看 rm 的绝情,大概就能看出几分道理来了。

您把十条各敲几遍,手上熟了,咱们再往下走。
