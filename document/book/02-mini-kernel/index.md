# 02 · mini kernel

> 从 004 接力棒递过来的 mini kernel,给它一件一件配上真正内核该有的家伙:串口 + kprintf 让它会说话、双轨测试让我们能验证它、PMM 位图让它开始管物理内存、GDT/IDT/异常让它能被打断并自愈、最后 ATA + ELF 加载器造出"读盘+解析"的流水线,准备把更完整的 big kernel 从磁盘请上来。这一卷是 mini kernel 作为"二传手"的完整故事。
