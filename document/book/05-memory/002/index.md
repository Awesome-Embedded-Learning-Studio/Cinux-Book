# 002 · 把物理页挂进虚拟地址:虚拟内存管理器

> 上一章给物理内存建了账本,能 `alloc_page` / `free_page` 了,但拿到的只是个物理地址。这一章写一个正经的虚拟内存管理器(VMM):它走 4 级页表,把任意物理页映射到任意虚拟地址、能取消映射、能翻译地址;更进一步,在缺页异常里接上它,实现「用到才分配」的 demand paging。内核从此真正掌控了虚拟地址空间。
