# 001 · 给物理内存建账本:bitmap 物理内存管理器

> 到 014 为止,内核有了输入、有了输出,中断体系也开始真正干活了。但有个最根本的东西一直没动:内存。这一章给物理内存建一本账本——用一个 bitmap 记录每个 4KB 物理页的占用状态,然后提供分配和回收的接口,这是整个内存子系统的第一块基石。
