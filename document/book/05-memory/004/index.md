# 004 · 给每个世界一套页表:地址空间

> 堆被硬编码映射在 `0xFFFF800000000000`,016 的 `pml4` 参数也是为「以后给每个进程一套页表」留的——这一章把这两件事一起收口:写一个 `AddressSpace`,把「一个虚拟地址空间」抽象成一个拥有自己 PML4 的对象,构造时拷一份内核映射进来、用户态区域私有、能切换(CR3)、能销毁回收。从此「给某个进程一套独立页表」不再是一句承诺,而是一个能 `new` 出来的类型。顺带,`0xFFFF800000000000` 的谜底也解开了。
