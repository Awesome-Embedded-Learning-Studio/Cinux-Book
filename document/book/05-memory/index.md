# 05 · 内存管理

> 内核第一次能动态管理内存:先用 bitmap 给物理页建账本(PMM),再写一个走 4 级页表的虚拟内存管理器(VMM)把物理页映射进虚拟地址、顺带实现 demand paging,然后在页上切块做堆分配器、接管 `new`/`delete`,最后把「虚拟地址空间」抽象成可创建、切换、销毁的 `AddressSpace` 对象,为进程隔离铺好地基。这一卷是后面几乎所有子系统的底层依赖。
