# 004 · 加载第一个内核

> boot 卷的收尾:把第一个**用 C++ 写的内核**从磁盘读进内存,通过一个 BootInfo 交接结构把启动信息交给它,然后跳进高半内核入口。从此,汇编 bootloader 的历史使命完成,接力棒交给 C++。
