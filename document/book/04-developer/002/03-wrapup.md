# 诚实的边界

**这是基建,不是功能。** 这一章没有任何用户能用到的新能力。产出是「CI 抓得到 SMP/并发 bug 了」「崩了一行定位首故障」——面向的是开发者调 bug 的效率,不是 OS 的能力清单。

**还有 follow-up。** F-VERIFY 这一轮核心做完了(M3 SMP 唤醒 / M4 TSAN 并发检测 / M5 真 fork-CoW 压力 / M6 首故障捕获),但有几样留了后续:KCSAN-lite(内核侧并发检测,比 TSAN 更贴内核)、「integration test」命名的澄清(很多叫 integration test 的其实只链了 unit test、没链真码,37/47 命名误导)。

**gated 钩子不是免费的。** 它让生产代码多了一个「测试可以驱动」的入口,好处是 AP 路径能测了,代价是生产文件里多了一段「测试才走」的逻辑——得靠 `fn=null` 默认值和注释守住「生产字节不变」这个契约。它是个权衡,不是银弹:简单函数不值得一插,只有 ap_main 这种「最该测又最难测」的高危路径才值得用。

验证该看到什么,见配套 lab。下一章换回功能线。
