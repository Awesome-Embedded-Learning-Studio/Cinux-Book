# 008 · 听见键盘:第一个真正的输入设备与 IRQ1

> 到 013 为止,内核有了「脸」——能在屏幕上画字,kprintf 也能双路输出了。但它只会说,不会听。这一章把第一个真正的输入设备接上来:键盘是个 PS/2 设备,每按一个键通过 IRQ1 发中断、顺带丢一个扫描码到端口 `0x60`;我们写驱动把它解码成「按了什么键、按下还是松开、修饰键有没有按着」,塞进环形缓冲区,再让主循环取出来回显。做完这一步,内核才第一次有了「交互」。
