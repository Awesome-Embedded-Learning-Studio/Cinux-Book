# 007 · 文本控制台与 kprintf 双输出:012 那个回调终于接上了屏幕

> 上一章把屏幕这块「舞台」搭好了,但留了个尾巴——kprintf 依旧只走串口。这一章收尾:在像素之上盖一层文本控制台 `Console`,管好光标、换行、滚动;然后回头兑现 012 埋下的承诺——让 kprintf 的格式化引擎接上屏幕这第二个输出后端。做完这一步,内核每一句诊断才会同时出现在串口和屏幕上。
