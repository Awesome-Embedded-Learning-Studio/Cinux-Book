# 003 · 大内核的 IDT 与异常:给内核装上"异常安全网"

> 上一篇我们给 big kernel 铺好了段地基,`TR` 也挂上了 TSS。可你要是这会儿故意往代码里塞一句 `int $3`,内核会直接三重故障重启——因为还没有 IDT。这篇就干这一件事:建 IDT、写 ISR、让 `int $3` 被接住、把寄存器 dump 出来,然后活着继续跑。
