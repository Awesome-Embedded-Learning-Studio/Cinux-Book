# 08 · 文件系统

> 从内核第一次摸到磁盘(PCI/AHCI)、第一次认识「文件」(initrd ramdisk),到立起 VFS 抽象、把 ext2 读通、让 ext2 能写、给文件系统上锁、把启动流程塞进 init 线程;再到 DevFS/ProcFS 这类内存型虚拟 FS、double-indirect 与 TOCTOU 的修复、VFS 地基重做与收尾、ext2 在 SMP 下治成 buffer-safe;最后补上 tmpfs 与运行时 mount/umount——这一卷是 Cinux 从「会读扇区」长到「有一套正经、并发安全、能挂能卸的文件系统」的完整弧线。
