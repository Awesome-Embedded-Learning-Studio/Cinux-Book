# 003 · 让任务睡得下去、醒得过来:内核同步原语

> 020 把 `block`/`unblock` 这两个 API 顺手写了,可写完就再没人用过。这一章把那两个落灰的 API 接成真正的同步原语:把只在头文件里定义着的 `Spinlock` 搬成 out-of-line 实现,再新写 `Mutex`(阻塞式互斥,靠等待队列让竞争者睡下去)和 `Semaphore`(计数信号量,负的 `count` 直接表示「有多少人在排队」),最后用一个生产者-消费者 demo 把三件套拼起来。
