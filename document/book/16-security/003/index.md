# 003 · 进程凭证:给每个任务记一笔「你是谁」,以及为什么 fork 自动就继承了

> 给每个任务加上凭证字段(uid/euid/gid/egid)再开六个查改 syscall;有意思的是 fork 几乎零改动——因为它是整个 Task 结构体一把 memcpy,新加的标量字段会自动被拷过去,这是一笔白捡的便宜。
