# 16 · 安全

> 把内核和用户态之间的硬件隔离真正拨开——NX 落实 W^X、SMEP/SMAP 拦住内核碰用户页;再给用户态布局撒一把随机(ASLR 三件套)、给每个任务记一笔身份(进程凭证);最后把上一章入口级全局 stac 在 SMP 下的雷拆掉,改成局部 accessor + exception table。这一卷是 Cinux 第一次系统性地动「安全」这条线——从硬件位到软件纪律,逐层堵口子。
