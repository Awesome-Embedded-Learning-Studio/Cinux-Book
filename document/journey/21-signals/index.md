# 21 · 听得懂喊声:信号、停走与进程组

看得见的内核那一卷收卷的时候,咱们把话撂在了信号上:进程得听得懂别人喊它的意思,该停的停,该醒的醒,进程组的戏也从它开演。唱的就是这一出,咱们从第一嗓喊声唱起,一直唱到最后的一块门牌。

咱们还是盘一盘缺什么。生与收那一卷教了进程的生死,也教了等待,可一个任务在 CPU 上跑得正欢的时候,咱们手里没有任何一句号令能打断它。您拿跑飞的程序没辙,想重启机器了事。父亲想听孩子的死讯,能做的只有睡死在 wait 里。想让一伙任务一起收摊的话,连喊一片的名字都还没有。咱们缺的这三件事,答案其实是同一个:信号,搭台的是进程组。这一卷的活咱们摊开报数。头一件养的是帧,九十六字节的旧话在这一卷兑现收尾,GS 那边的小银行关门。第二件立的是信号的词汇,号表、集合、动作的名单,外加两个谁也不许碰的例外。第三件修的是两段路,发送那头管的是登记,投递那头管的是办差,再把定制句柄的改写和回家的门装好。第四件定的是死讯的编码,缺页和退场两件事说信号的语言。第五件发的是门牌,pgid 与 sid 的两格,kill 学会的是喊一片,wait 学会的是听门牌。末一件做实的是停与醒,状态名册添了档,类的队列学会摘人,调度器添了三件兵器。

当年的旧话照例交代,交代的是六件活怎么分家。这批活在工程线上是六月十八到十九那二十来个小时连发的六件,到今天正好数过了半:可观测和调度类两件,看得见的内核那一卷吃掉了。本卷再消的是两件,信号占了一件,进程组占了另一件。剩下的是一头一尾,线程是最大的一块,咱们给它独立成了一卷,排在信号这一卷的后面,工具加固的家底咱们一路在吃。当年一口气咽六件的密度,幕间的家法不许再来,一件一个卷的饭量,这一卷装的是两件,因为这两件本来就咬得紧:进程组是喊一片的门牌,喊人的嗓子是信号,少了哪一个都唱不成戏。

合卷的时候,机器答得出的话又多了几句:一个号落在任务身上,默认的有四种下场,装了句柄的走改写帧的门,办完了顺着蹦床回家。死讯编进了收据,喊一片有了门牌,停走的任务抱着自己的内核栈,等的是一声继续。欠的咱们也挂在明处:信号打断睡眠没做,跨类的次序没动,可捕获的十一号在缺页路上没有验过,咱们一样一样记了名。当年六件里最大的那块,说的是线程,一个进程的身子住好几条执行流,它还排在名单上等着咱们,下一卷咱们去接它。
