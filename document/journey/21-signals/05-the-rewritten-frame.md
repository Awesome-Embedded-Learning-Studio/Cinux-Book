# 改写帧与回家的门

定制句柄的投递,是整个信号机制里最像变戏法的一段:任务明明要回自己的用户代码,咱们让它回的却是句柄,办完了还能一字不差地回到原来那行代码。戏法的全部秘密都在上一篇的帧里,咱们一段一段地拆。

咱们动手摆栈。句柄要跑的话,就得有一个 ABI 认可的栈,咱们在被中断的用户栈顶往下摆三样东西。摆得最低的是一个槽,槽里写的是归乡上下文的地址。往上的一个槽里,写的是蹦床的地址。再往上的地方,咱们摆一百四十四字节的归乡上下文本体:帧里的十六个词,按帧自己的次序原样镜像一份,外加投递以前的旧屏蔽字,末了咱们再补上一个零词,凑出的十八个词,大小的落点正好是十六字节对齐。为什么屏蔽字要跟着走?因为投递把句柄的掩码并了进去,句柄跑完该还原成什么,知道的只有这个上下文了。摆以前咱们还得过栈区间的判定:投递要摆下的是一百六十个字节,栈顶往下一百六十个字节要还在登记的栈区间之内,放不下咱们就按杀处理,这就是上一篇说的那道判定。浅得摆不下信号帧的栈,本来也就是个将死的任务,咱们犯不上在它身上多花笔墨。

然后咱们改帧,改的只有四个词,把这段代码的核心抄来:

```cpp
frame.user_rsp = kReturnSlot;
frame.rcx      = act.handler;
frame.rdi      = static_cast<unsigned long long>(number);
frame.rax      = 0;
```

栈顶落在了蹦床槽上,这个位置除十六余的是八,正是 ABI 里一次调用刚发生完该有的栈形,句柄一进门就当自己是被普通调用进来的。rcx 是句柄的地址,回用户态的 sysretq 指令认的就是 rcx,任务出了内核的门,落到的就是句柄的地界。rdi 带的是信号号,C 的第一个参数,句柄是照单全收的。咱们给 rax 清了零,还它一张干净的脸。其余的十二个词一动不动,原样地躺在帧里,栈上的镜像里也各存了一份。上一篇说的分派写回帧 rax 槽的章程,在这儿也不碍事:分派写的是 InvokeSyscall 的答案,而改帧发生在分派问过投递之后,写在前面的话被改帧盖掉了,这正是设计好的次序。

句柄跑完了,它的 ret 一弹,就落到蹦床槽给的地址上。蹦床是一页独立的内存,上面住的就两条指令,咱们原样抄来:

```text
B8 0F 00 00 00    mov eax, 15
0F 05             syscall
```

十五号说的就是 rt_sigreturn。句柄的 ret 就这样变成了一次 syscall,一进了门,回家的路就通了。它住在哪?咱们把它安在 mmap 区的上沿再往上一页的一个固定地址,登记册里记下的是可读可执行、永不许写。每个新世界在 exec 的时候出厂就装上它,fork 的孩子靠共享的页白得一份,运行的时候谁也不用现找。为什么是独立一页,这里有两笔当年的旧话值得咱们对照。头一笔说的是蹦床的家。当年的蹦床是摆在用户栈上的两字节机器码,能跑靠的是栈页可执行、执行限制还没开的便宜,后来开启执行限制的那一天,那两字节当场变成了违禁品,被迫搬了家。咱们生来就给独立可执行页,登记册、页表、内容三处说的是同一句话,往后讲安全的那一卷把执行限制开起来,咱们的这一页也不用挪窝。第二笔说的更根本,当年的定制投递走的是中断路:syscall 帧存不全 r12 到 r15,sigreturn 走 syscall 的话就恢复不齐现场,只好立一个专门的陷阱门收全帧。今天咱们的帧十六词俱全,那一整条推理的前提整个没了,syscall 的回程就是正路。咱们把这话说成一句家常:信号帧的形状,从来是由谁存着完整现场决定的。当年的答案和咱们的答案不同,是因为存现场的人不同。

进了门,咱们看 sigreturn 按帧找人。此刻帧里的用户栈顶,正是句柄 ret 之后剩下的那个上下文地址槽,咱们顺着它读出上下文的地址。两道护栏排在头里:槽和上下文都得落在登记的栈区间之内,而且都得十六字节对齐,答不上来的咱们按 SIGSEGV 处死,一段跑偏的栈就是任务自己的死法,内核是不替它圆的。护栏过了,咱们把十六个词从上下文镜像回帧,旧屏蔽字归了位,被中断的那行代码,连同它当时的 rax,一字不少地回了帧。

rax 这个词值得咱们单独再说一遍,因为在它身上咱们踩过一脚。分派对每一笔 syscall 都把返回值写回帧的 rax 槽,对普通的业务,这是本分的事,换到 sigreturn 的身上,这却是陷阱:它若按寻常的样子答个零,分派紧接着就把零写进帧里了,刚从上下文里恢复出来的 rax 就被冲没了,被中断的程序醒来丢了数,还不知道丢在了哪。修好的形状是:sigreturn 答的不是零,答的是它刚刚恢复出来的那个 rax。写回写进去的,与上下文里躺着的,是同一句的真话,一个数都丢不了。

进出两扇门都装好了,咱们顺手验一发全链:宿主的帧校验案,咱们在假栈上摆完投递,断言帧的四个新词、栈上两个槽的内容、镜像里的旧栈顶和旧屏蔽字,咱们一处一处都对过。RESSETHAND 的案子也在这儿跑:句柄送过一次,动作词回了出厂,第二发同样的信号按默认办。这里有一句验证范围的实话咱们也交代:定制句柄这一路,这一卷验的就是宿主长凳上的这几案,栈是宿主里 mmap 出来的,句柄是断言里的一个地址。真在跑着的机器里装一个句柄、让它接一发信号的戏,这一卷的机内和实弹都没有安排。门是装好了,真客人登门的日子还在后头。信号还欠一样东西:死了之后,死讯怎么写。下一篇咱们给死讯定编码。
