# 验收:喊得应的机器

收卷的章程照旧,咱们看的是三样:面板、测试、实弹。面板这一回安静得和生与收那一卷一个脾气:信号是运行时的家当,装句柄的事、发死讯的事、停与醒的事,哪一件都不会在开机的面板上留行,新行是一行没有的,咱们也就不抄旧的读数了。测试的家底和实弹的会话,才是这一卷的正戏。

宿主的长凳上,新添的是信号这一件,装的是二十二案,号表、发送、投递、改帧、死讯、组、停醒的科目一应俱全,前面各篇点过名的都收在里面。宿主从四十九件长到了五十件,普通线、地址排查线、数据竞争线、内核检查线,四条的配置全数通过。普通线咱们另在开了 KVM 的机器上走了一遍,地址排查线照旧把泄漏的检查开着,长凳上的死链就是它按住的,案子在前面单独讲过了,咱们记名不重数。咱们把整条 ctest 数下来,六十三件全过:宿主占了五十件,机内占的是十三台。这里有一句口径要交代:机内的台子要是并发一起跑,偶发会有哪一台抢不到虚拟化的资源而失败,串行地跑回回都过,计数的口径就是串行,您自己跑的时候要是见到偶发的一红,头一样别疑心的是代码,再串一遍您再看。

机内的十三台,台子还是原来的台子,调度的一台从二十二案长到了二十四案,添的就是停与醒的两案真上下文,那一篇里咱们细讲过,这里咱们记名不重数。

然后是实弹的戏。盘上的 /bin 里住进了新住户 sigdemo,它就是前面各篇一直在等的演示生:fork 出一个孩子,把一伙人的门牌立了,探一针的问安,喊一嗓的停,不开收据地问一声,喊一嗓的醒,末了的一嗓子是组杀,整条链从头演到了尾。开演以前咱们递两句驾驶的小抄:它是盘上的程序,当的不是内建,裸敲名字答的是 unknown command,要 run /bin/sigdemo 的话才请得动它。还有一句是给自动发键的您:拿 QEMU 的控制台发键的时候,斜杠得用键名的 slash 发,字面的斜线它是不收的。咱们把会话抄上来,孩子的拍子中间掐了一段:

```text
cinux> run /bin/sigdemo
[parent] child lives as pid 4
[parent] child now leads group 4
[parent] kill(child, 0) probe answers 0
[parent] SIGSTOP goes out; the ticks should fall silent
[parent] WNOHANG wait answers 0 (zero: halted but alive, nothing to reap)
[parent] SIGCONT goes out; the ticks should come back
  [child] tick 1
  [child] tick 2
```

中间的拍子一个模样,咱们掐到第二十七拍接上:

```text
  [child] tick 27
  [child] tick 28
[parent] SIGKILL on the whole group
[parent] wait reaped pid 4, killed by signal 9
[3] exited with 0
cinux>
```

这一屏咱们念三遍。头一遍看的是名字和门牌:孩子的 pid 是 4,门牌立的就是 4 自己,门牌是拿组长的名字当的,孩子自立门户当了组长。探针的那一行答的是零,人是活着的,发出去的东西是一件也没有。第二遍看的是停与醒,这里是全卷的重头戏:停的那一嗓喊出去,孩子的拍子一声都没有,它压根还待在就绪的队伍里,发送的那一拍就被摘走了,连 CPU 的边都没摸着。WNOHANG 的那一行答零,零说的就是活着但没退场,收据是开不出的。继续的那一嗓之后,tick 从一数到了二十八,任务醒了接着干活,丢的数是一个都没有。第三遍看的是组杀和死讯:咱们把九号喊给门牌四的那一整组,走的是门牌的广播,wait 收上来的是 pid 4,报的是 killed by signal 9,死讯的编码走的是低字节。末一行是父亲自己的谢幕,它交的码是零,shell 照的是另一套报法念 exited with,一屏里两种死法的正读,咱们都见上了面。

该对卷首的承诺了。三件的缺,咱们说都齐了:跑飞的程序,九号喊得停它的胡闹,喊不停的时候也杀得动它。孩子的死讯,十七号追得上正在干活的父亲。喊一片的事,门牌立了,广播也实打实地走了一遍。看得见的内核那一卷里调度类篇末的两笔也当面清了:摘人的门开了,跨类的次序明说没动,留给真正要裁它的日子。欠着的也如实挂在明处:信号打断睡眠没做,写向空管道的那一对信号等管道出生,可捕获的十一号在缺页路上的重跑语义没验。诚实的不做,和诚实的做了,在咱们的名册上是同一页。

幕间的名单,今天咱们勾掉头一项。机器如今是听得懂喊声的了,喊一个人的时候有名字,喊一伙人的时候有门牌,停是停得下来的,醒也是醒得过来的。名单上排下一个的是线程:一个进程的身子,要住进好几条的执行流,世界是共享的,栈是各抱各的,那是当年六件里最大的一块,咱们给它留了整整一卷。下一卷咱们教一个进程里住进好几个执行流。
