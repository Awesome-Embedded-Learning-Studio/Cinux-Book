# 号表、集合与两个例外

信号的词汇分三样:号、集合、动作。咱们把号表立起来,一到二十二号的名册,拼法和语义照的都是 Linux 原样,咱们一张表抄到底。您捡几个认认:九号是杀,十五号是客气的终止请求,十一号是踩了不该踩的内存,十四号管的是闹钟,十七号是孩子的死讯,十八号到二十二号的一小段里,住的是停与醒和后台读写终端的那伙号。范围为什么是二十二?因为当年工程线裁过的就是这一段,常用的都装在里面,咱们重走不重裁,加号的事没有,减号的事也没有。

集合的这件事上,咱们没有另造轮子,SigSet 直接取的 base 里现成的位词件当别名,底子是一个无符号长整型的六十四位,装下二十二号是绰绰有余的,第 n 位喊的是 n 加一号。这个词件自带命名位的脸和整一套的与或非,两个世界读的是同一个类型,内核也就不用写第二遍集合的运算。这里还有一件事值得咱们单独记:用户世界的头文件,从今天起挂上了 base 的目录。这是用户世界第一条通向 base 的依赖边,从前的客人们自带干粮,本卷新写的信号演示程序 sigdemo 领着头,新客人开始吃公共的词汇,边界咱们只开一处,别的都不许跟。

动作记录是一个三词的结构,咱们把它抄来:

```cpp
struct SigAction {
    unsigned long long handler{};  ///< Handler address, kSignalDefault or kSignalIgnore.
    SigSet             mask;       ///< Extra signals held while the handler runs.
    unsigned long long flags{};    ///< kSaRestart, kSaResethand, or zero.
};
```

句柄词是整个机制的正主:零代表的是默认,按内核的处置表办,一代表的是蒸发,来了就地丢掉,别的任何数都是一个用户态句柄的地址。掩码是句柄运行期间额外屏蔽的一伙。旗子咱们收两面,RESSETHAND 说的是这个句柄跑完一次就回默认,RESTART 说的是被信号打断的系统调用回头重跑。RESTART 的事咱们得跟您交底:词咱们收着,配套的重跑机制是没有的,要等系统调用可以被信号打断的那一天才有戏,那件事咱们在本卷的后面如实登记。每个任务出厂的动作表全零,零装的就是句句默认,这是合法的出生证。

然后咱们说两个例外,整张表里咱们只挑出它们两个。管杀的是九号,管停的是十九号。它们是装不上句柄的,也进不了任何掩码,这样的两问咱们各立了一个问答函数,答案对谁都是一样的:不行。道理不用绕:装句柄的门要是开着,一个跑飞的任务头一件事就是给九号装上自己的句柄,从此谁也杀不了它。屏蔽的门要是开着,同一出戏就换了个演法,照样是唱得成的。所以九号和十九号谁也碰不得,它们是咱们手里最后的家伙。掩码操作收到带着九号和十九号的词怎么办?咱们静默地剥掉九号和十九号再存,Linux 也是这么办的,一个库想把所有信号都拦下来的时候,不必知道内核给自己留了哪两个。

词汇齐了,咱们开两个号让用户态使唤,号位照的还是 Linux:rt_sigaction 认的是十三,rt_sigprocmask 认的是十四。头一个号管装句柄:号得是可捕的,第四参必须报对集合的字节数,这个第四参就坐在帧的 r10 槽里,Handler 自己伸手取的,上一篇的地基在这儿交了头一笔租。想装的话就递动作记录,只想问不装的话就递个空,旧动作咱们随时写回。句柄词要待的地方是用户半区之内,越界的咱们当场回 EINVAL。装的时候咱们不查句柄地址那页映没映射,这句诚实的边界咱们得说在前头:真跑不到页,是缺页进门的事,错在调用者的身上,不在装句柄的身上。第二个号管掩码:怎么动报一个词,零是并进去的,一是减出来的,二是把掩码整个地换掉,再递一个地址就把旧掩码写回。

两个号递进来的指针,内核照旧是不盲信的。咱们给柜台添了一件区间检查的家什,问的是两句:起点在用户半区之内吗,长度装得下吗,越界的一律回 EFAULT。它查的是区间和上界,页映射是不查的,坏指针照样落进缺页的路数,这个诚实的口子咱们留着,完整的验证是往后的活。错误名册这一批补了五件:一号的 EPERM,三号的 ESRCH,四号的 EINTR,十一号的 EAGAIN,三十二号的 EPIPE。今日就有消费者的各就各位,换门牌的拒绝、找人的拒绝都用上了。空坐着的咱们也如实登记:EPIPE 等的是管道,管道的影子还没有,EINTR 和 EAGAIN 等的是往后的日子,词咱们备着,免得那一天来了现造。

表立好了,门也开了,可信号的本体还没露面。一个号被喊了出去,又把事情办完了,它走的路是两段,发送占了一段,投递占了另一段,咱们下一篇把两段路修通。
