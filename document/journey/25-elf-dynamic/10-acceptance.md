# 验收:后半场交得干净

咱们收卷的章程照旧,看的是三样:面板、测试、实弹。面板这一回是安静的:装载动态、摆情报、装解释器,全是 exec 一路上的活,开机自报的面板上一行也没添,咱们如实报一个零。机器脸上的变化不在面板上,挪到了提示符上,后面实弹那一场咱们看它。

测试的长凳上,宿主的五十七件,数目还是照旧的,可件里的案长厚了。解析器与画像合住的那件,从四案长到十案:共享座的良构一案,两张座位各自收下该收的。换座两拒一案:共享对象去坐程序座、可执行去坐解释器座的,双双拒在了门口。头表落点两形一案:盖住的推算出地址,没盖住的答零。解释器路径直拷一案:路径从整读在手的 buffer 抄出,界与终结符都有了。auxv 全向量走查的一案:十四个号与值一对对验。静态缺省的那一案,AT_RANDOM 与 AT_EXECFN 省略的形态合法。vma 那件的 protect 案随着逐页覆盖的新语义改写,机内的孪生旧案头一轮机内测试抓了出来,咱们同步跟上了,第二轮全部通过了。机内十五台的数目也照旧,四条配置线全数走完了,六段的验收脚本 exit 零:宿主五十七件乘四,而机内十五台乘二。

实弹咱们分三场念。头一场是开机后的问候与回归,咱们把串口里的对话逐字抄下来:

```text
/ # hello-dyn
Hello from dynamic musl on Cinux!
/ # /bin/hello
hello from the volume/ #
```

第一行命令验的是全链:PATH 找到 /bin/hello-dyn,exec 进了内核,PT_INTERP 被扫了出来,822KB 的解释器整读,256MiB 的家落位,auxv 的情报摆上栈页,ld.so 自家收了尾,最后一跳跳进主程序的入口,而 printf 经 libc.so,结果 write 进内核。第二行是一发没炸的静态老客人。末行的那个问候贴着提示符,是老 hello 不带换行的老脾气,不是咱们的毛病,咱们如实抄了。

第二场是盘面的清点,busybox 本人出了场带着 ls,咱们看 /bin 与 /lib 各住了谁:

```text
/ # busybox ls /bin
busybox     hello       hello-dyn   mapper      sh          sigdemo     threaddemo  tlsdemo     ttydemo
/ # busybox ls /lib
ld-musl-x86_64.so.1
```

/lib 里孤零零的一位,正是两份差事一身担的解释器。/bin 里的老住户齐全,busybox 与 sh 是一具身子的双名,hello 与 hello-dyn 是一静一动的一对,九个名字就是收卷时的全班人马。第三场是复跑的脚本,脚本住在了 scripts 目录,它的名字是 test_execve_dyn.py,而一句 python3 就能起:起机,等 / # 的提示符,敲了裸名 hello-dyn,等了那句问候,再敲了 /bin/hello,等静态的问候,退出码报了零。这一夜的复跑,咱们自己的手稿上也记了两笔:头一笔,串口读回来的本来是一整串,咱们头一回当成行表去拼接,提示符被拆成了单字,怎么都配不上,改成在整串里找就过了。第二笔的事,收尾退出要传的行数,没传的那版把尾巴吃掉了。脚本的手稿和正文一样,错处摆出来的才值钱。

对卷首的承诺,咱们逐项过。内核的三件事:PT_INTERP 的扫描,解释器座位的解析器与固定基址的装载,入口的改写与 auxv 的情报桌,三件全落地。解释器的家选了确定,选的道理与留白都写进了正文。栈页的画像从空席摆成全席,二百六十四字节的数算在前头,movaps 的形态保住。工具链铸出了动态的客人,盘默认自带了全套,说谎的探测被魔数拦在门外。实弹首弹炸出的两桩案子连着破,号位锁进了编译期,protect 换了新门。ash 坐进了登录座,init 直拉的暗口补了 PATH。当年的绕行考古归档。十章的活一件不少。

边界咱们照旧挂明处。brk 的扩张不查重叠,堆长到 256MiB 有理论上的机会啃进解释器的地盘,正解是堆的扩张也查,这一卷咱们没动,挂上了。PIE 的主程序与解释器基址的随机化,整片留给讲安全的那一卷。ld.so 报错里 %m 打的是陈旧 errno,读它的时候留心。busybox 与 musl 的源树都住在开发机本地,仓库里是没有的,没有源树的机器烤盘自动回退并打告示,复跑脚本自带的说明,记了缺工具链时的回退。符号链接的形态咱们的盘还不认,busybox 的命令联动得敲全名。ash 的作业控制面,沿假文件与真终端那一卷的原样,没添新的。上一卷挂的老欠,这里点着名接着挂:写往空管道的那对事件,PTY 的座位只铸不还,行池认不出 EOF 的边界,还有跨全部系统调用读用户区间只查界不查映射的系统性旧债。

合卷的时候咱们回头看这一卷的骨相:内核侧的活其实不多,三件而已,而且件件都小,真正的大头是 ABI 的对齐,auxv 的每一味,号位表上的每一个座,protect 的每一种落笔,对的都是别人的本。可正是这些对着别人的本干的小活,把机器从跑得了别人编的静态程序,带到了跑得了别人编的动态程序,往后的日子,盘上多出的一个库,加上一个依赖它的程序,机器都是伺候得起的。欠的照旧挂在明处,戏也照旧往前排:咱们的机器到今天还是一个脑子在转,把第二颗请上了线,让两颗各有各的家当又同唱一台戏,那是排在后面的路上的一场大戏,咱们在这里把话撂下,这一卷就收了。
