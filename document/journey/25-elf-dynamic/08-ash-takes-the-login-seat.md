# ash 坐进登录座

动态的链通了,收尾之前还有一件大事等着咱们。教学 shell 服务了咱们这么多卷,可它的动词表是写死的,能启动程序的动词只有 run 一个,不认 PATH 的查找,到了每一回实弹,咱们的命令都得敲全路,动词咱们都得换成 run,回回都免不了摩擦。开门迎客那一卷 busybox 上过 /bin/sh 的座,可那是烤盘时用外层钩子另指的,默认的盘还是老 shell 的一座。这一卷咱们把这件事办成正形:登录座换血,ash 就座了。

形态咱们定清楚。kernel_init 的身份还是 pid 1,这一点是不变的,它拉起的 /bin/sh,如今默认指的是 busybox。为什么不让 busybox 的 init 真接 pid 1:busybox init 是一整套自己的语义,收尸、按表起进程、死了重拉,那是进程弧线的最后一段合拢,提前搬进来会跟咱们后面几卷收尸与等待的正戏打架,留给后面让它的 init 接管一号进程的那一卷。这一卷咱们只是会话换血:同一张开机流程,登录座上坐的人换了,户口倒是没换。

busybox 这边的安家照它自家的章法来。源树住在咱们的开发机上,配置调好了放着,构建脚本 build-busybox.sh 拷了一份临时树出去编,几秒出了活,产物缓存在了 build 目录,源树还是干净的。烤盘脚本把就座写成了默认:构建缓存里有 busybox,咱们就把它写进了 /bin/busybox,再写了一份 /bin/sh,双名住下了,找不到就回退老的教学 shell,打一行告示说明的是谁在座。就像上一篇默认装盘的那样,咱们记着同一句嘱咐:烤一份默认的环境,别让咱们每一回实弹都重新搭台。

就座的过程里炸出一个小暗口,值得咱们单独记。execve 的那一路,开门迎客那一卷立过的一条好章法:envp 递空,内核铺一条默认的 PATH,免得咱们的裸命令没处找。可 init 直拉 shell 走的不是 execve,它直接调画像的那件构件写栈页,不经 exec 的默认铺路,envp 递什么就是什么。头一版递的是空,ash 起来之后它是无路可查的,裸命令的答复一概是 not found。修法:直拉的那一路亲手递上 PATH=/bin:/usr/bin。execve 的那一路有默认,直拉的那一路没有,这样的不对称就是暗口。好章法铺上了 execve 一路,直拉的那一路还空着,咱们补的就是这一路。

然后是实弹的画面,咱们逐字抄在下面,各位看三样东西:提示符换了相,从 cinux> 变成了 / #,这是 ash 的脸。裸名 hello-dyn 一次验完了两样,PATH 查找是 shell 的活,动态链接是内核的活,一行命令两头都过了一遍。末一行静态的 /bin/hello 老样子,守的是零回归:

```text
/ # hello-dyn
Hello from dynamic musl on Cinux!
/ # /bin/hello
hello from the volume/ #
```

画面里还有一处不体面的事,咱们也如实交代。盘上住的名字只有 busybox 一个,ls 不是独立的文件,busybox 的命令联动靠的是符号链接,一个命令一个链接名的对应,而咱们的 ext2 还没有符号链接的形态,认字那一卷立后端的时候没做它。所以裸敲 ls,ash 的答复是 not found,咱们得敲 busybox ls,请 busybox 本人出了场。符号链接这门形态挂到往后的卷,眼下敲全名的时候,是不丢人的。

两笔边角咱们也照实记。头一笔咱们试过把整具 busybox 换成动态链的,这样连 shell 自己都跑在了解释器上,画面是最漂亮的。可它的构建系统一圈下来把链接拐回了宿主的 glibc,驯服它是一门 busybox 工具链的工程,不是这一卷的正菜,咱们弃案,内核侧的画面已经够看。第二笔想提醒的是,想拿键盘验 $? 的各位别急着试,咱们的键盘键位表是英式配列,shift 加 3 出来的是井号不是美元符,如实记在了这儿,键盘表的修缮往后另排。

合上这一卷的时候,机器的脸已经换了另一副:开机提示符 / #,敲裸名出动态的问候,echo 这样的内建张口就来。咱们的户口还是那个户口,pid 1 的座还是 kernel_init,座上的人换了,这就是咱们这一篇干的事。
