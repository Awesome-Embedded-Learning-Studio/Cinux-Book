# 真正的 auxv

栈页上的那幅画像,开门迎客那一卷咱们画完了 argc、argv、envp,可 ABI 还规定了第四样东西:辅助向量,行话的叫法是 auxv。它是紧跟在 envp 结尾的零词之后的一串配对,每对的两格,前格放的是类型号,后格放的是值,最后一对是类型零的 AT_NULL,收住全桌的尾。它是内核递给程序启动代码的一桌情报:你的入口在哪,你的程序头表落在哪,页是多大的,这些事你自己在用户态打探不着,内核不说的话,你就不知道。咱们那一卷摆的,是一桌空席:只摆了一条裸 AT_NULL,问了也不答。

空席为什么这些年没人掀桌?因为静态的客人不点菜。busybox 天天在空席上吃得饱饱的,咱们把 musl 的源码翻开找原因,找到了:musl 对缺的每一味都有自己的兜底。最惊险的一味是 AT_RANDOM,十六字节的随机数,栈护甲的种子。栈护甲的行话是 stack canary:函数返回地址前埋的一只金丝雀,进了函数抄一遍、出了函数对一遍,对不上说明栈被人冲了,当场自杀谢罪了。金丝雀的值得是随机的,不然攻击者照着公式算出来了,护甲就成了摆设。musl 拿不到 AT_RANDOM 的时候收零,走确定性回退:护甲值等于护甲自家地址乘 1103515245。地址是能打探的,数是能算的,金丝雀是人人能喂的。咱们这些年的静态实弹,背后靠的全是它在硬扛。这一课咱们记下了:没炸不等于没问题,可能只是没人来查而已。

解释器可就不一样了,它是真正点菜的客人,而且点的菜缺一味就掀桌。咱们把 musl 1.2.5 的 ld.so 启动代码从头翻到尾,启动代码住在 musl 源码树的 ldso/dynlink.c,每一处 auxv 的用法都核过,这一桌菜咱们不猜,是照着菜单数的。菜单分了三档。第一档是缺了就崩的硬需,五味里打头的是 AT_PHDR:主程序头表在内存的落点,ld.so 拿它与自家的头表比对,认出两张表里哪张是主程序的,缺了这一味,它拿零当地址去解引用,当场就死了。AT_PHENT 与 AT_PHNUM 说的是头表的几何,一条的大小与总的条数。AT_ENTRY 说的是主程序的入口,ld.so 忙完自己的事,最后一跳跳的就是它。AT_PAGESZ 说的是页大小,musl 的 libc 里页大小就吃这一味,缺了它收到的值是零,装载里一切按页取整的算式,从 mprotect 的边界到 mmap 的落点,跟着一起歪了。第二档是缺了能活但可惜的营养组:AT_RANDOM,真随机的金丝雀。AT_BASE 说的是解释器自家的基址,这一味缺席的话它有兜底,拿 AT_PHDR 的页对齐去猜也猜得回来,可咱们有真数,凭什么让它猜。AT_EXECFN 说的是被执行文件的路径,落点复用 argv 的第零支,咱们一串都不用多写。UID 的四味,用户与组各两问的身份号,咱们再加一味 AT_SECURE,管的是身份与安全态,咱们的机器只认一个 root,如实地全零,词到了位,值是诚实的。第三档是有守卫的散席,AT_HWCAP 的那一类,musl 拿的时候要看 bitmask,缺了不问。咱们摆前两档,散席就不摆了。

实现上情报的源头收成两个半场。装载的半场,EntryFacts 结构的前四格:程序入口、头表落点、头表几何,装载器装图的时候顺手填。世界的半场:解释器基址、页大小、随机源,exec 的路自己填。随机源接的是 getrandom 那一路真随机的线:探 CPUID,有 RDRAND 的话就连取两发八字节,拼成的是十六字节,两发都落了空,整条 AT_RANDOM 就省了,musl 退回它的确定性回退,咱们不装。argv 与 envp 也收进了一个 EntryRuns 小包,递给画像的时候还有情报作伴。参数也一并收进了包里,就是装载那一篇交代的那道参数上限的家法咬出来的:两次都咬在超了四个词上,合进包里就成了一趟。

十四枚类型号咱们一个都没有放任自抄。每一枚都拿 static_assert 对着宿主系统 <elf.h> 里的 AT_ 常量一一对表:AT_PHDR 必须是 3,AT_BASE 的号必须是 7,错了一个,编译期就爆了。这些号和系统调用的号是同一种东西,都是 ABI 的门牌,自家抄错自家的表,测试永远发现不了,得让别人的表来对。这一道锁眼下倒是看着顺手,到了实弹那一篇,它会变成一句庆幸的话。

画像本身的代码也搬了一次家。WriteEntryPicture 从装载器的大文件里分出来,自成一件纯内存算术的构件:进的是一页字节、一个栈顶、两组串、一份情报,出的是画好的页,不碰页表、不碰分配、不碰内核的任何设施。这样的身子宿主世界链得起,画像的案子从此全在宿主长凳上直测,分家的家法在这一卷又落了一子。写画像时顺带交代:静态客人走的也是同一张画像,装载的半场照填,世界的半场基址给零,随机源没有就省了,一条 AT_RANDOM 和 AT_EXECFN 的缺席都是合法形态,静态的实弹一发不能少,这是咱们给自己定的零回归门槛。开门迎客那一卷挂过的画像机内案,这里一并交代下落:画像成了纯内存构件,案子全数搬进了宿主长凳直测,机内的装载案改口断言 EntryFacts,旧挂的案子销掉。

宿主长凳上添的新案,咱们按名点齐。共享座良构的一案,换座两拒的一案,头表落点两形的一案,解释器路径直拷的一案,auxv 全向量走查的一案,静态缺省的一案。这批案子的手稿咱们如实记四笔错,全是测试自己的错,不是实现的。argc 数错了一处,单参数的案却断言了两支。落点差了一字,/bin/prog 连 NUL 的长度是十字节,串区的偏移该是二十六,咱们写了二十五。起点用错了一处,带 envp 的画像 auxv 从第四十字起,咱们拿去量了 envp 空的版本。对数漏了一词,EXECFN 在场的时候,数出来是十二对而不是十一对。四笔都摆在这儿了,给往后写测试的咱们留一面镜子:实现一遍过的时候别高兴太早,回头去把测试查了。
