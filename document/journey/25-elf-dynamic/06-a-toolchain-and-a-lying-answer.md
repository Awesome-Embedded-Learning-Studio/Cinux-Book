# 动态的工具链,与一句说谎的回答

内核侧的地基铺完了,咱们去造客人。客人当然得在开发机上编出来,所以这一篇从工具链讲起。musl 是开门迎客那一卷自家编的版本 1.2.5,住在自家的前缀里,musl-gcc 这个包装命令也在同一卷里经过了 busybox 的实证,咱们放心用。

动态的这一套,咱们得认识 musl 那件最大的家什:libc.so。它一具身子干的是两份差事。第一份的身份是共享库,printf 的实现、每一个 C 程序要借的轮子,全住进了这一具身子里,程序不再把轮子链进自己的身子,而只留一张借条。第二份的身份是动态装载器本身,ld.so 的戏码:重定位、对号、跳转,唱戏的就是它,只是 musl 的传统里两份差不分家。名字有两枚:链接期认的叫 libc.so,运行期烤进程序 PT_INTERP 那句路径的,叫的是 /lib/ld-musl-x86_64.so.1,后一枚名字咱们记牢,盘上就得有它的家。

铸动态的 hello,用到的命令一行,三面旗各有各的道理。咱们把配方的每一面都摆在明处:

```bash
musl-gcc -no-pie -Os -Wl,--build-id=none \
    -Wl,-dynamic-linker,/lib/ld-musl-x86_64.so.1 \
    hello-dyn.c -o hello-dyn
```

命令里还带了一个 -Os,取小体积的优化档,顺手的事。第一面的旗是 -no-pie。咱们的程序座位只收类型 2 的固定地址形,位置无关的可执行文件是类型 3,坐程序座位是要被拒的,PIE 留给讲安全的那一卷,所以这里把形定死。第二面的旗是 `-Wl,-dynamic-linker`,后面跟的是那句路径。不覆写的话,烤进 PT_INTERP 的是开发机上工具链自家的安装路径,客人的盘上没有它,进场就找不到解释器了,所以要亲手把客人的路径写进去。第三面的旗是 build-id 不带,那几节字节咱们这一卷用不上,也就不往盘上添了。产物的个头是 15KB,咱们拿 readelf 验形:类型 EXEC,一条 INTERP 指的就是那句路径,PHDR 与 DYNAMIC 的登记都在,这就是咱们要的客人。

装盘的事,教学盘头一回开出了 /lib 这个目录。解释器落的名字是 /lib/ld-musl-x86_64.so.1,用的是单名。这里有个细节咱们当年只敢推断,这一遍开机实测对上了。hello-dyn 的依赖表里记的名字只有一个:libc.so,而 musl 的 libc.so 没带 SONAME,盘上的 /lib 里也只有一个名字,对不上号怎么办?ld.so 拿到 libc.so 这个名字去找库,走的是源码里 load_library 那一段,拿名字与自家的短名比对,对上了就算自己,认的就是自家人,不用再找了。单名就够了,盘上就不用第二个名字了,当年教学线的推断如此,咱们这一遍开机实测对过,是真的。

然后是这一篇真正想讲的案子,一句说谎的回答。烤盘脚本当然要找解释器,咱们第一反应是问工具链。musl-gcc 有现成的问法:`-print-file-name=libc.so`,咱们敲了,它答出的是一个路径。咱们头一版探测,把这个路径装进了盘。装进去的是什么?拿头四个字节一看:斜杠、星号、空格、大写 G,念出来的正是 /* G,这是一句 C 的注释,这是宿主 glibc 的链接脚本。musl-gcc 这个包装命令的奥妙在 specs 文件,specs 只在链接期往搜索路径里插自家的目录,这句 -print-file-name 的问话它根本不管,答的是底层 gcc 的默认搜索,默认搜索找到的当然是宿主自带的 glibc。盘面的症状也就明摆着了:/lib 里躺下的解释器只有几百字节,连 ELF 都算不上了。真开机去装它的话,回报的会是一句没头没尾的装载失败,排查的人得绕好大一圈,才会想到去怀疑工具的回答。

修法的第一步也是最后一步:验货。每一份要装进盘的解释器,开头读的就是头四个字节,必须读到的是“7f 45 4c 46”,ELF 的魔数,不是的装都不装。工具的回答也是数据,答得再怎么自信,马上要进盘、上机器的东西,咱们用之前都得验。验货的这一步加上之后,探测序也顺手理直了:环境变量可以覆写,不然头一处看自家前缀里的 libc.so,退一步再到系统装 musl 的位置,三处里哪一处找到了,咱们就从哪一处装。

最后的一步是把它变成默认。烤盘脚本如今默认装的是解释器和动态 hello:有工具链的话,烤出来的盘自带全套,咱们开机就能敲,不再要外层的环境变量钩子伺候。没有工具链的话,一行告示说明的是 /lib 留空,后面的机器照跑静态的世界。hello-dyn 缺了才现场编,编好了缓存进 build 目录,第二回烤盘直接用的就是它。这一步的原动力是一句话,咱们把话听进去了:烤一份默认的环境,才是正经的正形。
