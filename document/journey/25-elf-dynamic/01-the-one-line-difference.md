# 差的那一下

上一卷收卷的时候,欠下的话咱们认领:客人还等着一场动态的戏,链接器、装载器与库三方怎么搭台,这场戏的戏文全没开写。这一卷要演的就是那场戏。趁锣还没敲的空当,咱们把最要紧的一句理一遍:静态与动态,差的到底是哪一下。

开门迎客那一卷请进门的客人,全是静态的。静态程序是一具自足的身子:printf 的实现早在链接期就被塞进了身子内部,内核把文件整读进内存、按段铺进新世界、递一页栈、末了给一个入口,程序落地就能跑。装载器认它靠的是生与收那一卷立下的那一套检查:文件头说自己是类型 2 的可执行文件,段表(也就是 ELF 标准里的程序头表),里面的每条 LOAD 都在说同一件事,文件里的字节落在哪个虚地址,一条条写得明明白白的。咱们从生与收那一卷到现在装载的每一位客人,走的都是同一条路。

动态的程序差的那一下小得出奇。它还是类型 2 的可执行文件,段表倒是照旧,只是表里多了一条不一样的登记:行话叫 PT_INTERP,装的是一句路径,比如 musl 家的 /lib/ld-musl-x86_64.so.1。登记的意思用白话说就是:我这一具身子里有些符号只有名字、没有实现,我自己跑不起来,有劳装载我的人照着路径再装一位进来,让它替我把剩下的活干完。照着路径进场的它,咱们叫它解释器,而行话叫动态装载器,大家平时也叫它 ld.so。

差的这一下,把启动的戏拆成了前后两半。前半场是内核的:程序进场,咱们的内核照旧装它,装完了看一眼段表,发现有 PT_INTERP 的登记,就去把解释器也请了进来,再把 CPU 的入口递给解释器。后半场咱们全交给解释器:它把自家的重定位做完,再照着段表把主程序里那些只有名字的符号一一对上号,最后跳去主程序真正的入口。全局偏移表是程序里存放外部符号地址的一排格子,过程链接表是调用外部函数时经过的跳板,第三样要说的是符号解析,三个名词各管各的活,不过它们全都住在用户态,是解释器肚子里的学问。内核倒是一个字不碰。

分界线不是咱们自己发明的。Linux 从头到尾就是这么分的:内核不自建动态链接器,内核要做的只有三件事。第一件:扫出 PT_INTERP 的登记,读出解释器的路径。第二件:咱们把解释器当作另一位客人,装到一个固定的基址上去,和主程序住进了同一个新世界。第三件:把入口改成解释器的入口,再在栈页上摆好了一桌情报递过去,主程序自己的入口、段表落在哪、页多大,都写在这桌上了,解释器拿了单子照办。除了这三件事,内核就退场了。

这一卷的活,咱们照着内核的三件事摊开。解析器要给主程序和解释器分出各自的座位,这一篇的后面紧跟一篇讲它。装载器要学的新词是基址,主程序的基址是零,解释器的基址是 256MiB 处一个固定的家,选址的道理单开一篇。栈上摆的那桌情报:行话叫 auxv,辅助向量是它的中文名,是这一卷分量最重的一篇:musl 的解释器到底等咱们递什么,咱们翻着 musl 的源码一条条数,当然不猜。摆情报之前还有一笔数等着咱们算清,栈页就那么一页,字摆不下是要翻车的。地基铺完,咱们去铸一个动态的小程序,盘装好了开机实弹。实弹的头一枪会炸,炸出来的两桩案子是这一卷的金矿,咱们一案一案破。案破了之后,busybox 的 ash 坐进登录座,开机提示符换了相。末了还有一段当年的旧话:解释器这个大个子,当年把盘的文件上限挤爆,绕行的故事咱们单独讲。

边界咱们在卷首就划清。解释器肚子里的重定位学问,这一卷不替它讲学:咱们不教 GOT 表怎么填、PLT 跳板怎么跳,咱们验证它的方式,是把它请进门、看它跑通了没有,不复述它的课本。咱们教的是内核侧的三件事,和三件事背后每一条 ABI 的道理。位置无关的可执行文件,而行话叫 PIE,还有解释器基址的随机化,这两样是安全的活,咱们留给后面讲安全的那一卷。这一卷认定的形态就一种:主程序是固定基址的可执行文件,解释器装在一个确定的家。确定是咱们挑的,打破它的日子排在讲安全的那一卷。
