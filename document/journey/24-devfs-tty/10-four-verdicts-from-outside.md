# 外面回来的四纸判决

作业控制的大件落齐之后,场子里坐着的还有四桩悬案,咱们自己查了两轮也没查穿,照上一卷的老章程,把案卷整理成稿送了出去,请外面的眼睛看一遍。眼睛很快就回来了,四案对应的是四纸判决,咱们一纸一纸念。

头一纸判的是座位折号,案情是最绕的一桩。ash 在完整形态下把自家的终端描述符记在一个全局变量里,记的是十号。fork 出的孩子在换世界之前有一道自己的手续:要拿这个号去认前台组,可孩子的表里根本没有十号,内核答的是 EBADF,这道手续败了,后面的全乱了。孩子的表里为什么没有十号?咱们头三号那篇埋的引信炸了:头一版的家当继承走的是找座的路,父亲的表里坐着零、一、二、十共四座,孩子逐座地认领,最小空闲把它们折成了零、一、二、三。十号的描述是搬过去了,搬到了三号座上,可 ash 认的是号不是座,十号在孩子表里是空的。修法把继承改回了保号:父亲的几号就是孩子的几号,咱们一座也不挪,逐座连关 exec 的位一起继承,新分配的座清位起步。咱们拿探针把三种形态都量了一遍:父亲的座、孩子的座、继承的位,三面对上了才销案。

第二纸判的是 ^C 的双上游:一案里藏着两病。头一病在键盘:咱们的键码翻译只认 Shift 修饰,Ctrl 按着的时候查表查出来的还是个普通的 c,^C 的三号字节根本到不了行纪律。修法是左右 Ctrl 各自独立地跟踪,修饰在的时候按控制字节映射,字母折成的是一到二十六,从 @ 到 _ 折成的是零到三十一。第二病在出生表:ash 的行编辑开工,头一件事拿 TCSETS 把 ISIG 关了打算自己管键,可它挑终端的时候,要看的就是 c_cc 表里 VINTR 是不是非零,咱们头一版的表生来全零,它一看这终端是没有信号字符的,整套行编辑就缩了。这第二病的修法,就是上一篇说的填满的出生表,回来的判决把它立了起来。POSIX 的章法也一并理清:ISIG、ICANON、ECHO 三位各管各的,回显只听 ECHO 的,关掉了 ISIG 也不等于关掉了回显,咱们的实现照此对齐。

第三纸判的是 ps 的空表,案情是最短的,教益倒是不小。表头出了,而行却一行不出。busybox 的 ps 拿 sscanf 解 /proc 里的 stat,解析式一次要的是十一个赋值:数不够它整个不认。咱们头一版的五个字段,是喂不饱它的。修法顺着 Linux 的字段编号补:快照里添上 sid,stat 一路写到了第二十四字段 rss,后面的计时与内存,咱们没有的零占位,占的是诚实。ps 的三行全出来了。这一纸的教训是格式两个字:人家按编号数格子,咱们按内容挑字段,两家对不齐的时候,不看编号的人吃瘪。

第四纸判的是一号的失踪,藏得最深的一桩。开机亲手造的头一个任务 init,父是没落过的,咱们在名册里却查无此人:枚举数不到它,快照也拍不着它的影子,按 pid 找它也落了空,组发信号也漏了它。病根在名册的结构:咱们收任务用的链,收的是有父任务的孩子,init 造出来的时候没落父:链上一根线都没挂上。它是活着的:调度器也调度它,可名册的世界里它不存在。修法把名册一分为二:全量的任务名册另立一条链,谁出生都挂了上去,亲子的语义保留在原来的链上,两边是互不相扰的。这一改把宿主测试的夹具也牵了出来:地址排查线当场拦下一处悬链,夹具跟着修了。四案念完了,咱们合上卷宗看了一眼,病根其实是一条:咱们的测试造不出真客人的形态,座位折号要的是真 shell 的十号,^C 要的是真键盘的修饰键,ps 要的是真 sscanf 的计数,名册要的是真 init 的无父。绿的测试与真的世界之间,差的从来都是这一截。

四案修完了,咱们把验收与实弹全家再打了一轮,全数过了。还剩的是最后一件收官的活:检查镜像里最后一声 ud2。
