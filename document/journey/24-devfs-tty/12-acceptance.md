# 验收:门里门外都是真话

咱们收卷的章程照旧,看的是三样:面板、测试、实弹。面板这一回是安静的:一行也没添。两个假文件系统挂在了挂载表上,设备住的是表,事实住的是源,全是运行时的家当,开机的面板上没有它们的戏份,咱们如实报一个零。

宿主的长凳上,五十三件长到了五十七件,新住进来的是四件,咱们按名点齐。devfs 十六案:枚举的次序,null 的干净 EOF,zero 的整片零,stat 的目录与设备两种形态,注册面拒绝重名与超长的两拒,挂载之后的解析。终端的四案:喂一行收一行,ICANON 落下时的裸字节直通,ECHO 落下时的静默取键,行池的短读留余,termios 线格式的断言跟着立了。伪终端的六案:键盘跨对成行,回显流回的是主机,从机的输出只到主机不回自己,ECHO 关了只有静默,ICANON 关了单字节直通,外加清对复位的一案。procfs 的十案:活体枚举,死 pid 的拒绝,快照的锁内拷字节,stat 与 cmdline 的现写现读,meminfo 的两行,exe 的委托与 readlink 的直答。老住户那边文件表与门面的案子跟着座位的新语义添了案。机内的十五台照旧,整条 ctest 数下来七十二件全数过了,口径照旧走的是串行。四条配置线全数走完了,六段的验收脚本 exit 零:宿主五十七件乘四,机内的十五台乘二。

实弹的戏码,咱们一场一场念。设备目录的四场前面演过:五条的枚举,null 的吞零,重定向的干净,根目录里的两块新门牌。ttydemo 的秘密行全链走通,栈顶的八字节修完之后,它是一枪过的。script 的三层回显是全卷最热闹的一场,三个终端实例各司各的职,画面逐字抄在了伪终端那篇。free 念出的是真数,ps 的三行全出了。readlink 那一发咱们也打了,对着 self/exe 也答出了 /bin/busybox。ash 从 console 起了整套会话,降级是一次都没有的,sleep 10 被一个 ^C 干干净净地打断:零 unserved。检查镜像带着数据盘一路启动进了 shell:零 trap。这些戏码没有一场是脚本代看的,每一发都是咱们亲手敲键、对着串口逐字核出来的。

对卷首的承诺,咱们逐项过一遍。名字里的家什,/dev 与 /proc 都造出来了,设备的与事实的两种假文件各自立住了。终端的单例拆了,一门纪律喂得出的是任意多台。开关面立了,ECHO 与 ICANON 的行为全生效,ISIG 从存位走到了动作。伪终端成对地铸了出来,ptmx 一开就成了一对。fd 头三号的假座换成了真座,九个特权分支一个都不剩了。进程的名册照出了活的事实,拷的是锁内的字节。作业控制整台戏开了锣,控制终端、前台组、^C 与 ^Z 的翻译投递,全链在真客人身上走通了。ppoll 的掩码真验了,nanosleep 与 tgkill 补了号,外面回来的四纸判决落了地,最后一个 ud2 收了尾。

复阅的十处发现,咱们也逐项交代。这里说的复阅,是咱们自己收工之后把整站的活从头再过一遍,与送出去请外面的眼睛看是两回事。必修的六处:七号 poll 的零限期,头一版当成了无限等,如今只扫一遍就答了零。管道的 ioctl 与 fstat,头一版走到的是空函数指针,内核直接就炸了,如今各自有了答法。readlink 的头一版只验读不验写,补齐了。TIOCSCTTY 的参数是零,被一概的零参拒绝误伤,如今每一问按自家的宽窄分面。伪终端的设备号头一版答的是零,如今按章法拼了。改良的两处:设备表添了还座的脸,问话的词表十词归了一家。登记的两处:行池还认不出 EOF 的边界,零值字节与无键的哨兵在键盘链上还打架。顺手的两笔也一并换了:裸的负二十五,ENOTTY 的那一号,换成了名册里的词,手写的设备号位运算换成了现成的家什。

边界咱们照旧挂明处,这一卷的边界比往常厚,咱们一样一样念。无读者时的信号推进,架构上没有走通:sleep 睡着的时候,ash 的等没有人在读终端,键全躺在了队列里,如今实弹倒是能过得去,靠的是行编辑手里还握着读的路,真正的收键要一个专职的工人。wait4 不报停止状态:^Z 之后 jobs 与 fg 的后半场,咱们不敢说办完了。SIGTTIN 与 SIGTTOU 两个号只枚举在了名册上,咱们一台也没生成。伪终端的座位只铸不还,八对铸满了之后,第九对老实答的就是内存不足。名册的序数在念的当口有人退场是会漂的,咱们暂且容忍着。EOF 的边界与零值哨兵,复阅里登记的两处留着待裁。读用户区间的家什只查上下界不查页映射,这是跨全部系统调用的系统性旧债,单独立了项。script 的会话里孩子退场之后整个会话不再应声,这是收官之后冒出来的新疑点,登记在了卷里。

老欠的,咱们照旧挂着:写往空管道的那对事件,信号侧的 SIGPIPE 与 errno 侧的 EPIPE,词仍然是备着的,挂点仍然是没有接上的,可捕获的十一号在缺页路上的重跑语义没有验,跨类的次序没动,内核栈的守卫页没立,futex 的超时没抓,信号打断睡眠还完了两角,算不得完整的一片。

上一卷挂在名册上的四笔,咱们也接着挂:入口画像的机内案没立,目录缓冲跨重拉的观察还挂着,HPET 的机型约定记了档没定,O_* 一整类还裸在词表的外头。

合卷的时候咱们回头看,这一卷的骨相比前几卷齐整:两位假文件的后端都没碰硬件,接线各归了一层,在宿主上全测了。真出事的四处,栈顶的八字节、座位折号、Ctrl 的修饰、名册的链,没有一处出在新代码的正面,全是旧形态欠下的债,被真客人一件一件讨了去。客人在静态世界里的家什,到这一卷是齐了。它还欠咱们一场动态的好戏:装载器与库的三方协议,链接器怎么排、装载器怎么搬、库怎么各就各位,那一卷排在后面的路上,咱们把这一卷的门牌挂好,该动身了。
