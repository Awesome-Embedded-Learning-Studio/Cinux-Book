# 活着的镜子

假文件的第二种,咱们造一面镜子。ext2 答的是盘上的字节,ramfs 答的是内存里的字节,procfs 底下什么字节都没有:名字念到的那一刻,内核把此刻的事实写成字节递出去,下一次您再念,事实变了的话,字节也就变了。镜子照的是三样:内存的家底,进程的名册,还有每个进程自己的几行身份。

形状上它把 devfs 的注册制又推了一步。devfs 的手里好歹还有一张设备表,procfs 却连个表的影子都没有,全部的事实从一台注入的源里来,咱们给它立了七座:第几个活着的进程首领、一位任务的快照、当前任务的程序路径、程序字节的委托读取、程序的大小、内存的两个数,外加的就是老熟人那个上下文词。进程首领说的就是同一副身家那一卷里线程组的组长,同组的几条流不各立门户,名册里数的是组,不是一条条的流。内核接的源是真源:出身是调度器、页管理器与当前任务,宿主测试接的源是假桩,所以整面镜子在宿主上照得纤毫毕现,与 devfs 同款的可测缝。根目录里坐着两个固定的名字:meminfo 与 self,其余是每位活着的进程首领一座目录,目录里的两份文件是 stat 与 cmdline。cmdline 咱们照旧话用进程名顶替,命令行整条咱们是不留的。

活体的名册有两个讲究。头一个是枚举:目录念法按序数问的是第几位活进程,咱们在名册的锁里数着链表走,数到了第几位,活的正是谁,不做整表的快照,内核栈拢共四页十六 KiB 的量,整表的快照在栈上放不稳,Linux 同款的口径也是每次现数。这样数有个诚实的毛病:念的当口有人退场,序数是会漂的,咱们暂且容忍,实弹炸了再升级,这句也记在了明处。第二个讲究是活性门:咱们按 pid 查目录、读文件,头一句问的就是这人还活着吗,死了的 pid 答的是找不到,镜子是不照遗容的。

然后是这一篇的真案:快照怎么拷。当年的工程线上,镜子立起来之后被自己人审核出了一桩竞态,咱们这一遍把它按教学的样子重演再修对。竞态的形状:按 pid 找人,在名册的锁里找到的是任务的指针,放了锁之后,再在锁外去读这个任务的字段。单核的日子这没事,可这话咱们得补上一环才立得住:中断是插得进放锁与读字段之间的,时间片耗尽的时候,中断出口的钩子还会把 CPU 转给别的任务,单核也挡不住这样的插队。挡下的只是出事的那套手续:目标任务的退场、名册的摘链、内存的归还,全得挤在这几条指令的窗里办完,前后还得搭上两回调度的转手,窗是窄的,不是关死的。多核的日子,这道窗干脆常开:CPU 这头放了锁要读字段,CPU 那头同时就把任务退场、名册摘链、内存归还全办了,这头读到的就是已归还内存里的旧影子。前提为什么塌了?当年名册的旧话写着任务永不释放、安全,后来任务真的会释放了,而旧话没跟着改,纸上的安全比纸还脆。修法咱们叫拷字节不拷指针:快照是一个朴素的值结构,在名册的锁里把要读的字段一个一个拷进去,出了锁,手里的快照与那个任务的生死已经无关。格式化的函数签名也跟着改了,吃的是快照,不是任务的指针。咱们这一遍是单核的机器,窗口就按单核的口径讲,多核的那一幕排在那时的卷里回望,这里就不预支了。

self/exe 是镜子里最有意思的一个名字,咱们多花两句。进程问自己是谁的时候,顺着 self/exe 就能找回自己的程序。任务的家册里为此添了一个字段:程序的完整路径,exec 的时候写,fork 的时候继承,开机的 shell 由咱们预填了 /bin/sh。可这个名字底下不能是一行路径的字节,客人的期待是它就是那个程序:read 要读得到 ELF 的真身,stat 要答得出真文件的大小。所以 exe 这个节点是面镜子里的窗户,读与问都委托给了文件世界,按路径解析了真文件再转交。busybox 的 applet 联动指着它吃饭,execve 吃自己的路,从今天起也通了。配套的号位 readlink 落在八十九号:对着 self/exe 它答出路径的真身,对着别的名字,咱们没有符号链接,答的是 EINVAL,无链接系统的诚实词。拷贝那一步的长度也有讲究:头一步算路径的真实长度,与调用方给的容量取小,整段验过了可写再动手。写的那一侧,自家复阅那一轮补上了,实长取小的细化,是送出去的复核又补的一笔,咱们记下名字就行。

meminfo 与 sysinfo 凑成了一对,咱们合着讲。meminfo 照 Linux 的排场写的是两行:MemTotal 与 MemFree,数字从页管理器的两页数折成 kB。可 busybox 的 free 实际不读 meminfo,咱们翻它的源码看的:它读的是 sysinfo 这个号:九十九号。咱们把九十九号补上了,一百一十二字节的记录,页管理器的两数换算成字节,再添活进程首领的计数,开机时长与负载的三个词,咱们没有的诚实填零。实弹里 free 念出了真数,总量报了约十二万九千九百 kB,余量报了约十二万零二十八 kB,都与页管理器的册子对得上。ls proc 把活的 pid 枚举了出来。readlink 也过了一发:对着 proc/self/exe,它直答的是 /bin/busybox。

stat 文件的头一版,咱们只写了五个字段,结果 ps 只出表头不出行,这桩案子在后面自有它的一篇,咱们按住到那里再讲。宿主长凳添了 procfs 一件,十案全数过了。镜子立起来了,锣也该敲了。
