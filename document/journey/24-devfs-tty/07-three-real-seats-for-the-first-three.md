# 头三号的真座位

翻车现场咱们头一步还原。script 的孩子在从机上安家,头一套手续是搬家:close 掉的是零号,再开的是从机节点,期待新开的座落在零号上,因为 POSIX 的老章程是从最小空闲号给起,零号刚被关掉的时候,该轮到的就是它。然后它把一二号也都指到了从机上。可咱们的零号是一张特权假座,close 它跟没关是一样的,新开的文件按老章程只能从三号起找座,它拿着一个没关成的零号去搬家,内核回它的是 EBADF,孩子当场死在了搬家的路上。

这就是假座的日子到头了。生与收那一卷立 fork 的时候,任务的家册里还没有描述层这层家当,打开的文件是一格一格跟着任务走的,后来同一副身家那一卷把这层立了起来,开门迎客那一卷的管道与 dup 又把找座、定点落座、认领都办齐了,可这一切都发生在三号以上的世界里,零到二号始终是系统调用里写死的三个名字:read 认的零号直通行规程,write 认的一二号直达屏幕,close、ioctl、fstat 与 getdents、ppoll 各占了一处,fcntl 独占了两处,一处问的是状态,一处改的是状态,九处的特权分支,摆的是九张假座,见了三号以内的号,走的全是特殊通道。咱们知道它虚,只是自家的 shell 从不较这个真,今日真客人较了。

改造咱们一刀切到底,过渡是一点不给的。头一刀是常数退役:文件表里从三号起算的旧底子整个撤掉,找座的语义改成了最小空闲。空表的第一次 open,拿到的就是零号。第二刀是 shell 的家当预置:开机的时候,咱们给 shell 任务的文件表预置 console 的三座,一个打开的描述,三座共享的,状态给的是读写两可。这一来 shell 的世界里,零一二号是表里实实在在的三个座位,底下的后端是 console 设备节点,与任何一个三号以上的 fd 走的是完全相同的路。第三刀拆的是九处特权分支:read 与 write 从此只认表,close 是真的关,关了零号,零号就真的空了,下一个 open 就坐了进去。预置这一步咱们还翻了一版:头一版把三座预置进了开机任务自己的表,可 shell 的任务是另起炉灶新建的,不继承它的表,shell 起来的时候一看,手里是空的,还是死了。改落在 shell 任务自己的表里,这才通了。

座位多了,文件表也到了要扩的时候。ash 这类真 shell 的行编辑开工时,会拿 F_DUPFD_CLOEXEC 从十号起找座存自己的终端描述符,咱们的表只有八座,它一伸手就摸到了满。咱们把表从八座添到了十六座,扩到十六座所依据的,是客人伸的手,咱们不凭感觉定数。

顺路补上的还有七号的 poll。script 的父进程要在自己的标准输入与伪终端主机之间两头张望,用的正是 poll,而咱们只有 ppoll 一个门,七号的门牌空着,客人来敲门的时候,听到的就是断流。咱们把它落在 ppoll 同一个文件里:同一种记录,扫描的还是同一套,限期递的是毫秒,零毫秒的意思是只扫一遍就答,无限等递的是负数。就绪的判定这一篇也彻底归了位:问后端的 readable 脸,设备有就绪脸就听设备的,没有就绪脸的设备恒就绪,与伪终端那篇添的三钩子严丝合缝。

这一片改完了,验收与实弹一起过了,script 那场实弹头一轮里孩子死于座位的那一翻,到这里才真正翻了回来:座位真了,重跑出来的,就是上一篇里抄下的那幅三层回显。还有一笔要跟您打招呼的:fork 的家当继承,这一卷里也跟着找座的新语义改了道,孩子逐座认领父亲打开的描述,头一版走的是找座的路。这一版里埋着下一桩案的引信,孩子表里的座位号会被重排,咱们当时没看出来,后面外面的眼睛看出来了。座位的事到此告一段落,该照镜子了。
