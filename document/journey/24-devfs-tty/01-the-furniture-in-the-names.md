# 名字里的家什

上一卷收尾的时候,客人把话留在了咱们这儿:它住下了,可它伸手指了指,指名的家什,咱们一件也拿不出来。咱们把客人带来的代码翻开看,它的世界里到处是两个名字:/dev/null、/dev/zero、/dev/console,还有 /proc 底下的 self 与 meminfo。free 要读 /proc 才知道内存的余量,ps 要读的也是它才数得出进程。连 busybox 自家 applet 的联动,都要顺着 /proc/self/exe 才能找回自己的身子。这些名字在 Linux 的世界里是水电煤,咱们盘上只有 ext2 一棵真树,树里没有它们的位置。

那咱们就造。造法咱们在卷首定谱,这一卷造的都是假文件,假的有两种。第一种假在介质:名字底下的字节不在任何盘上,读它的时候设备现场干活,写它的时候字节进了设备的嘴,/dev/null 吞了便算,/dev/zero 您要多少零就给多少零。第二种假在时间:名字底下根本没有存好的内容,读取的那一刻内核把此刻的事实写成字节,下一次您再读,事实变了的话,读到的也就变了。第一种咱们叫它设备的目录,第二种咱们叫它进程的名册。两种的骨架都是咱们已经穿熟的那件外衣:一个像模像样的文件系统后端,挂在了挂载表上,走的是与 ext2 一模一样的门面。

终端这一头欠的东西,咱们也数清楚。上一卷把行编辑搬进了内核,行规程在 read 里跑了起来,这些都站住了。可咱们把它立成了单例,全机器就造了一台,谁来了它就归谁。真终端不止一台的世道里,这个形状撑不住:伪终端是一对一对出生的,每一对里都得有一台自己的行规程,而单例连第一对都造不出来。开关面也没有:termios 只答了一版全零的记录,行编辑是常开的,回显也是常开的,ash 被双重回显闹了一卷,治它的药就是开关。作业控制的整台戏更是连锣都没响:控制终端、前台组、^C 翻译成信号投给一伙人,这些词在咱们的树里一个都找不到。

咱们心里最有数的虚火还有一处。fd 的零、一、二号,在系统调用里是三张特权假座:read 认的是零号,write 认的是一二号,ioctl 与 fstat 认的是三号以内的,它们绕开了文件表,也不看后端的脸。自家的 shell 从来不较这个真,东西是它自家的,而内核与它同错对齐,绿了多少年都不算数,这句家训上一卷咱们刚誊过一遍。真客人里迟早有较真的:谁的代码关掉零号再开新文件,POSIX 答应他拿回的就是零号,咱们的假座是答不出来的。

缺的单子连成片,咱们按片报数。号位表这边咱们细数:ioctl 缺 TCSETS 一类的写开关,缺控制终端与前台组的三问,缺伪终端的两问。readlink 的号没有,sysinfo 的号也没有,七号的 poll 空着,表上没有的还有 nanosleep 与 tgkill。挂载表的八座里空了七座,可挂载点要落在 ext2 的目录里,而咱们的挂载不回写父盘的目录念法,ls / 看不见挂上去的东西,这件事咱们记下,办的时候当面解。

顺序上咱们照着依赖走。头一件把设备的目录立起来,假座换真座的事顺路办,因为设备一进了文件表,特权假座就到了退役的日子。然后拆终端的单例,开关也在这一步立了起来,这里埋着一桩回归的旧病等着炸。伪终端成对地铸出来,busybox 自带的 script 命令跟着有了真舞台:它在伪终端的从机上跑一个交互 shell,自己守在主机这一头当起了转播,实弹会把三层回显的画面送给咱们。进程的名册随后照镜子。作业控制压轴开了锣,夹在中间的四桩悬案也送出去看了。末了是收尾与验收。咱们动身。
