# 键是哪一组的

作业控制的整台戏,咱们头一步立台本。一台终端的键盘,不能是谁都在读就归了谁。会话首领这个词说的就是听得懂喊声那一卷里拿 setsid 自立了门户的人,他把终端认作自己的控制终端,终端记着的是一个前台组,键产生的信号发给前台组,后台的不沾光。控制终端、会话、前台组这三层名词的地基,听得懂喊声那一卷立进程组与 sid 的时候就打好了,今天咱们在上面起楼。

这层关系记在任务的家册里,添的就是一枚控制终端的指针:fork 抄的是父亲的,而 setsid 把它清空,这是 POSIX 的老章程,新会话落地就断旧关系。认终端走的是 TIOCSCTTY 这一问,条件是您得是会话首领,而且手上没有终端。

设备的两侧各管各的:console 是一台,前台组全局记的是一份,伪终端是每一对自己的一座。TIOCGPGRP 与 TIOCSPGRP 的两问,管的是前台组的读与写。开机的登录 shell 由咱们预置:控制终端指着 console,前台组就是它自家的那一组,开机的第一个提示符,就站在作业控制的完整体上。

信号的翻译在行纪律里做,这一篇它从存位变成了动作。ISIG 立着的时候,纪律收的每一个键,头一件事就是对照 c_cc 的控制字符表:对上 VINTR 座的是 ^C:字节 0x03,翻译成的是二号信号,对上 VQUIT 座的是 ^\,翻成的是三号,对上 VSUSP 座的 ^Z 翻成二十号,也就是停的意思。表里的值头一版生来是全零的,ISIG 立着也对不出号的,案卷送了出去,回来的修法把表填满了:INTR 给的是 0x03,QUIT 给的是 0x1C,SUSP 给的是 0x1A,擦除给的是 0x7F,行抹除给的是 0x15,EOF 给的是 0x04,VMIN 给的是一,哪一格填了零,咱们就把哪一位当禁用。表是满的还是空的,关系着键的翻译能不能对出号,后面请外面的眼睛那一篇里就有案。信号一来的时候,咱们若没立 NOFLSH,纪律还会把攒了一半的行与池里待取的行都清了:被打断的输入不该留给下一位。同一时间咱们只记头一个信号,后到的不覆盖早到的,翻译的结果挂起,等读的人来取。

投递的路径咱们接在读的门口。读者在行纪律里等行,信号字符到了,read_line 交零让了路,设备这一层取出挂起的信号,发给终端的前台组,然后给读的调用答 EINTR,errno 名册的新词 kInterrupted 映的就是它。这句话在欠的名册上还着另一笔:听得懂喊声那一卷欠的信号打断睡眠,上一卷在 ppoll 的门上还了一角,这一卷终端读的门上又还了一角,两角加起来仍不是完整的一片,睡眠家族的其它门口还是老样子,咱们照实说。/dev/tty 那个名字在这一篇也有了真身:它是每进程的别名,不管您自会话的控制终端是 console,还是某对伪终端的从机,顶的都是一个名字,各回各的家。

ppoll 的掩码,上一卷咱们收下不验,这一卷真验了。掩码的那个参数,等待期间咱们真的换上:进等待前把屏蔽字换成调用方给的临时屏蔽,等待的路上有三个出口:就绪答数、限期答零、信号答 EINTR,每一个出口都把原来的屏蔽字还回去。配套的两个号也补上:三十五号 nanosleep,busybox 的 sleep 指着它过日子,二百号的 tgkill,raise 的真身走的就是它。

实弹咱们挑最硬的一场打:sleep 10 敲下去,趁它睡着的当口,咱们补上一个 ^C。纪律把它翻译了出来,投给的是前台组,sleep 被 EINTR 打断退了场,ash 收了它的尾,提示符干干净净地回来,咱们在串口上连一句 unserved 都没听到。然后是全卷的主画面:ash 从 /dev/console 起整套会话,把 setsid、认控制终端、立前台组走了一遍,降级是一次都没有的,上一卷那句 can't access tty 的告白,从此听不见了。还有一桩随手的销案:双重回显。ash 的行编辑开工时,头一件事就是拿 TCSETS 把 ECHO 关了、ISIG 关了,自己接管了整行,于是内核的回显与它的回显不再叠加,咱们 echo 一句,屏上出的就是一份字。上一卷挂在明处的那笔,这一卷销了。

可戏排到了这一步,场子里坐着的还有四桩悬案:普通 shell 里 ^C 时灵时不灵,ps 报的是空表,还有两位连症状都是古怪的。咱们把案卷整理成稿,又送出去了。
