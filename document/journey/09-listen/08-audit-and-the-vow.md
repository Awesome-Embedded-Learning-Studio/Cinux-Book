# 验收,和立志的日子

发货链走的照旧是一条命令:`cmake -B build && cmake --build build --target run`。开出来的面板,kern 的部分如今是六行,咱们原样抄来:

```text
[kern] 64-bit C++ world alive
[kern] gdt+idt self-owned, sse on
[kern] bootinfo: 8 e820 entries, fb 1024*768*32
[kern] kernel at 200000 size 84918 entry 2003F0
[kern] pmm: 32347 pages free (probe 100000 ok)
[kern] irq on, tick 100Hz
```

头五行是老熟人——咱们只对一遍变动。说 pmm 的变化:册子没换、图谱没换,变的只是内核自己。它长了个子。面板上 kernel at 那行打的数是十六进制,咱们把 0x84918 换算成十进制得到的 543000 个字节,向上取整占了 133 页。pmm 那行的页数倒是十进制,空闲落在了 32347:1MiB 之上的 usable 还是 32480 页,咱们拿它减去 133,得的就是 32347。probe 落的还是 0x100000——低 1MiB 保留,内核住在 2MiB、头一个空页永远落在中间那 1MiB 的地界上,老册子倒是一笔没乱。第六行是本卷的新行,咱们上节刚陪它站过岗。

长凳那头照例数的是家底,眼下收到的是十五件:e820、format、framework、result、vesa、bits、gdt、layout、page、image、bitmap、pmm、kernel_image、idt,加上本卷新添的 tick。机器里的那头,`cmake --build build --target test_kernel` 跑下来的是两个条目:kernel_test_selfcheck 三件用例,kernel_test_tick 的用例是两件。咱们拿 nm 翻过它的 ELF,两根围栏之间躺着的记录正好两个,名字尾巴上的 14 和 24,正是那两件用例所在的行号。咱们实测了一轮:一台开机花了 0.29 秒,另一台花了 0.33 秒。零点三秒上下的开销,听的是一声心跳,验的是一身伤。红路也走过了,退出码 5 解码出来坏了一件,验完撤干净了再复跑,退出码回到了 3。

尺寸咱们也报一下。selfcheck 的测试内核,盘上 12640 个字节——住户、字符串加 runner 的分量。发货的内核,盘上躺的是 14336 个字节。盘上的分量咱们用十进制报,内存里的地界就是上面那笔 0x84918,差值您已经熟了:几乎全是 .bss 里那半兆名册、本卷没给它添一个字。镜像还是原来的 1MiB、一格没动。最干净的一笔在符号表里:发货内核咱们也用 nm 翻过,测试的痕迹只剩 g_test_start 和 g_test_end 一对名字,还落在同一个地址上——段是空的。测试走的是另一个产品,这话咱们念了一卷,这句是它最硬的实证:发货件上、一个字节不为它花。

收尾之前咱们去考古箱里翻两段日子。头一段翻的是三月二十六。当年第一遍的笔记得那一天写了十二篇,合 3338 行——host 与 kernel 两个世界的测试框架,志向就立在了那一天,而且当天 kernel 半边就真跑过一回。可您猜那一天的提交说明写的是什么?一句:修运行时崩溃。框架的基因,藏在一句修崩溃的说明后头,笔记里的那 3338 行才是正文。这一遍咱们把它压到听世界之前才兑现,次序倒了个个儿:伤都验不了,咱们是不敢动手术刀的。如今刀动了,伤验了,志向也算还了。

第二段翻的是四月二十。当年那一天、单日过了九站。头一站就是本卷的祖站:PIC 重编程加 PIT 时钟、十八个文件、三千余行,一口气就写完了,后面八站也挤在同一天里跑完了。第一遍的读者后来说:太陡峭、跟不上。这一遍咱们不辩解,把当年那一天的头一站,展开成了您眼前的一整卷:门房一章、心跳一章、桌一章、闸一章,一步一步地走。当年一天的路,今天走了一卷,您走到这儿,喘匀了没有?

咱们的十六条线,只开了一条:0 号,跑的是定时器。下一卷的正主已经在门口排着队:键盘,1 号线上头一条会说话的线——按一个键,它真的有话要说。画面也在后面的路上。倒不是忘了谁,是各自的动机还没到,到那天您会认得它们为什么来。机器眼下停在开着中断的 Halt 里——它睡着了还在听,胸口一秒一百拍地跳着。下一卷咱们教它听人话。
