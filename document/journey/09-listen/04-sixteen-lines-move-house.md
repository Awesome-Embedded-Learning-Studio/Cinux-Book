# 十六线搬家

上一卷立中断表的时候,咱们留过话:前 32 个号是 CPU 自家的异常,32 往后的号才轮得到外设。可外设的敲门声最后报成几号,不全由咱们的表说了算,中间隔着的还有一层门房。PC 平台的门房叫 PIC,可编程的中断控制器,老资格的 8259,一片管八条线——PC 里装了两片、一片主、一片从,从片挂在主片的 2 号线上,而两片合起来就是十六条线。键盘、时钟、盘之类的,谁有事就拽自己的线,门房收到了,翻出来的就是一个中断号,递给 CPU 去咱们表上查。

麻烦就出在门房的默认号上。芯片手下的每条线都有自己的名号,主片的八条叫 IRQ0 到 IRQ7,从片的八条叫 IRQ8 到 IRQ15。两片 8259 上电之后的报号是 BIOS 年代传下来的:主片把自己的八条报成 0x08 到 0x0F,而从片把它的八条报成 0x70 到 0x77。您对着 CPU 的家谱一读就冒冷汗:0x08 是双重故障、0x0E 是页错误,全在异常的地界里。设备响了,CPU 照号翻了过去,按异常的章程办——转储、停车。中断还没进过一次门——命就没了。所以十六条线必须搬家,搬去 0x20 到 0x2F:上一卷立表时特意留空的空区,今天等来了它的住户。

搬家在芯片那头有自己的行话:重映射、remap。办起来是给每片芯片递一套初始化的命令字——行话叫 ICW。咱们不逐位铺开,数据手册里有整章的明细,咱们只认亲手写进去的。主片的五写,咱们在 `kernel/arch/x86_64/pic.cpp` 里摆成了一张表:

```cpp
const cinux::driver::PortWrite kMasterSetup[] = {
    {.port = kMasterCommandPort, .value = kIcw1Init},
    {.port = kMasterDataPort, .value = kMasterVectorBase},
    {.port = kMasterDataPort, .value = kSlaveOnIrq2},
    {.port = kMasterDataPort, .value = kIcw4x86Mode},
    {.port = kMasterDataPort, .value = kMaskAll},
};
```

您把常量的值垫进去读,它就是一页能读的数据手册。头一行 ICW1 写的是 0x11,进的是命令口,说的是“要初始化了,级联方式,后头还有 ICW4”。第二行是搬家的正主:向量基址,主片的 0x20、从片的 0x28,从片接在主片的八格之后,两片合起来正好铺满了 0x20 到 0x2F。第三行是级联的接线图。主片写的是 0x04,说的是“我的 2 号线上挂着从片”。从片写的是 0x02,说的是“我的级联身份是 2”。第四行的 ICW4 写 0x01,选的是 8086 模式,而且不用自动应答,为什么不用,咱们下面单说。第五行不是 ICW 而是掩码:0xFF——全捂。两张表都备好了,remap 里一次 OutB 就各发了一遍。串口那一卷立的端口词汇,在这儿又收了一笔红利。七张条子在那一卷就是这么写成表的,今天十张也是一行的活。

写端口的事,考古箱里倒是有笔对照。当年走第一遍的时候,每个 ICW 之间都垫了一个 io_wait。垫法是往 0x80 的诊断口写一个字节,图的就是耗时,老 ISA 总线给时序留的要求。到了这一遍,KVM 里的五连写安然无恙,咱们也把实测的话说到实测为止:KVM 里成立,是开机验过的。真开发板上的时序,等咱们真把内核放上去那天再核。今天咱们一个字也不多许。

收尾的 0xFF,咱们单独说说,因为它背后改的是章程。当年第一遍的 init 有个讲究:进门把旧掩码存下来,配完了原样写回去——“init 不改变谁被屏蔽”。听着倒是体面,可它微妙到连自家的文档都写岔过一回,读代码的人得追三个来回才知道线上的状态到底是谁定的。这一遍的 remap 一收尾就全捂:每一扇门都关着——直到有人来开。开了一扇就亮一扇,行为是一眼可判的,连旧都不用翻了。

开门的活,咱们交给 unmask:读掩码寄存器,清掉对应的位再写回去——读、改、写,放行的是一条线。线号在 8 以上的话,还得多干一步:顺手把主片上的级联位也清了。从片的敲门声要经主片的 2 号线转递,开从片的门,得连级联的门一起开——少一扇声音都进不来。

最后的一样家当是应答,行话 EOI——处理完了给芯片回的礼,往芯片的命令口写一个 0x20,说的是“办完了,可以放下一发了”。从片上的线要谢两片:从片的命令口谢一笔,主片的再谢一笔,ack 的实现里写得明明白白,线号到了 8 往上就多写那一笔。主片上的线谢一片就够。咱们再把话头转到忘谢的下场上:芯片把来过的线锁住,下一发就永远不来了。您注意,那不是死机——机器活得好好的,就是时间冻住了。本卷心跳的测试要至少三拍,给的就是应答纪律的岗哨:忘了谢,第二拍永远到不了,测试当场就红了。

ICW4 里其实备着一根自动应答的位——置上它,芯片在中断被接受的那一刻就自己放行,连谢都省了。咱们刻意不用。自动应答省下了一行,代价其实是“处理完了”的定义变了:处理函数还没跑完,同级里的下一发已经能进来,重入的风险全压在咱们自己头上。手动多谢的那一声,换来的是什么时候算完由咱们说了算。少写的一行,买回一句由咱们说了算,是划算的。

还有一句交代身份的话:Pic 也是 Meyers 成员单例的住户,Pmm 之后又添的一户,范式是上一卷立的,咱们这儿只报个户名。它长着中断服务要的脸,开门的 unmask、应答的 ack 两下,可它自己倒是不知道:设备不知道服务,而服务知道设备。这话咱们按下不表,等过了心跳那一章、中断桌摆了开来,您就知道两边是怎么握手的。

门房搬完了家,门全关上了,谢礼的纪律也立了。可十六条线上偏偏还一样动静都没有。咱们还得去请一位敲拍子的人。
