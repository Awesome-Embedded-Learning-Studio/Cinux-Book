# 四个号开窗

册子立在了任务里,而程序还够不着它,够得着的路只有一条:系统调用。本节咱们开四个号:mmap 坐的是九号,brk 坐的是十二号,两个座次跟 Linux 的一样。munmap 和 mprotect 这一对换了座:咱们的表上 munmap 十号、mprotect 十一号,Linux 的表上正好倒过来,这一对要到往后讲 ABI 的那一卷才换回原样。北极星的那块砖,生与收那一卷对过数的,这一卷又添了四行。为什么照人家的号位,老理由还是那个:往后跑别人编的程序,人家的 syscall 一发,号对上了就是咱们的门。

mmap 进了门,咱们看它办三件事:头一件把长度进页凑整,零长的直接请回。第二件找的是空档:用户半区的顶上,咱们划了一片从顶往下长的 mmap 区。册上每有一段挡在候选地盘的路上,候选就被压到那一段的更下方,一整圈压下来不动了,地盘才算真干净。这个找法用的是纯算术,册上扫了一圈,分配的影子都没有,宿主的测试世界里也能真跑。第三件按旗标分了两路。匿名的,册上添了一条匿名条目,就完事了,咱们一个页都不发。文件的,查的是描述符在不在、活不活,再翻保护位:这一卷的文件映射只做只读,谁要映射了还想写,咱们拿 EINVAL 请回。写共享的文件映射是往后共享内存那一卷的活,门咱们这一卷不开。返回值是地盘的起址,负数的就是错误码。

munmap 干的是摘除。册上整段整段地摘:完全落在给定范围里的条目离册,半截搭在边上的,咱们照样拒绝,回的是一声 EINVAL。页表的那一边,一页一页地走:内存当家那一卷备下的 UnmapPage 原语,零消费者地等了这么久,第一个真消费者这一卷上了岗。拆下来的叶表项要是带着现在位,说明页真的在,得走帧计数那一道还帧的手续,写时复制分家出的私页和共享页,在这一步拿的是同一个待遇,数减到了零,帧回了池子。还帧之后紧跟的是一声作废,invlpg 就地把这一页的翻译打掉,不然残留的翻译还会把旧页当成活的指给人家。这是内存当家那一卷立过的义务,拆完的页,作废是欠不得的。册和页表的两头都动,次序是册动在前、表动在后:册上不认了,咱们再拆页表,拆的过程中就算缺页打进来,一查册查了个空,响亮地拒,不会出现册上还有、页上已无的悬空瞬间被当成合法访问放过去。

mprotect 干的是改词。在给定的范围里,整段整段地改权限,一样不做劈半的事。这里有个次序的讲究,咱们特意留了半截:册上当场改,页表上的位本节不动。已经映射着的页,还揣着昨天的表项。您要问这算不算言行不一,算的,而且是故意的:改词要收全,得等缺页裁决者的新业务开张才补得上,补的那一拍,册上的词是承诺,页表跟在承诺的后头走。咱们把册这一半立住,另一半怎么合上,裁决者的那一篇再讲。

老词新开的 brk,咱们把它单独说,因为它跟前面三个的脾气不同。堆的家当在册子里没有上链:链上的条目都要有起有止,而堆生下来长度是零,空区间进不了链。所以堆骑在册子自己的一个成员上,exec 的时候种下:起点是程序影像的末页进上去,天花板是咱们画好的分界线。brk 的语义照 Linux:传零是问询,回当前的断点。传目标地址,对齐到进页的边界,夹在起点和天花板的中间,然后把断点挪了过去。您注意咱们没说 map,也没说 unmap:brk 动的只是指针,一个页都免了。断点挪了上去,新地盘在册上有名了,页的事,等缺页来了再说。收缩的那一边同样只动指针,已经铺出去的页不急着拆,等进程退场、整个世界连册带表一起清算的时候归池,咱们这一卷不抢这个活。还有一个脾气:brk 返回的是地址,错误码是不返的。目标要是落了空,返回的还是当前断点:让调用者自己比对出没挪动。这是 Linux 的老脾气,咱们原样学来,一个字的发明都没有。

对了,当年 brk 还留过一笔上限的旧事,咱们顺路交代。工程线后来跑位置无关的可执行程序,程序的堆一路往上长,顶到了当年 brk 的天花板才停,那个数是两百四十兆字节:当年记下的绝对上限。天花板为什么必须有,您现在自己能答:没有天花板的堆,长上去就跟 mmap 区、跟栈的地盘打架,册子的第一条家法就是不许重叠。咱们这卷的天花板画在四太字节,离得远了,可道理跟当年的是同一个。

四个号开完了,咱们盘点本节真正发出去的页:零。册上添了行、减了行、改了词,断点挪了位,物理内存的占用纹丝没动。这才是懒章程该有的样子,窗口开了,兑现的事另算。兑现要一页一页地来,一页的大小是四千零九十六字节,而咱们块缓存的槽眼下只有一千零二十四。下一节咱们让缓存长到页的个头。
