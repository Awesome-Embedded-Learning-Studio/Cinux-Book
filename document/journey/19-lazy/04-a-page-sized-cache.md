# 缓存长到页

按需补页要吃的饭,咱们把饭量算清楚。缺页补的要是文件页,一口咬的就是四千零九十六字节。块缓存眼下的槽,一槽的饭量只有一千零二十四字节,形状是认字那一卷立下的:八槽,每槽配的是两个扇区,键记的是扇区号,写完就到了盘上。咱们拿它伺候 superblock 和位图,是称职的。而拿它补文件页,一页要串的是四个槽,还得保证四槽在盘上是恰好挨着的,不是它干得了的活。手术分了两刀,咱们一刀一刀来,每一刀绿了再进下一刀。

头一刀动的是槽。咱们把槽升到四 KiB,一槽盖的就是八个扇区,正好凑足了一页。键也跟着换了:从扇区号换成盘上页号,扇区号除以八得回的就是页号,乘回去得到的又是扇区号,一来一回是无损的,两个词说的是同一块盘。调用方的那头不用改口,人家报的还是扇区号,缓存替他做了换算,报回的指针指进槽的中间,偏移的事他自己去算。槽的数目没变,还是原来的八个,内存的开销从八 KiB 涨到三十二 KiB,堆上的事。构造也顺手收了单参:槽的扇区数从前是构造时传的,如今咱们把它固定成页,再传就是多余的自由度,删了。

就是头一刀闯了祸,而且闯得很有讲究,咱们把案子完整摆出来。症状:ext2 的机内测试,八个用例死全死在挂载的那一关。挂载是文件世界的头一道关卡,superblock 读不回来的话,后头就全塌了,可读路径的代码一行没动,怎么就全灭了。咱们上真正的机器,拿调试器一步一步地走,走到该发盘命令的那一拍,看住设备的缓冲区:纹丝不动。盘命令的影子都没有。一个读请求没发命令就拿到了数据,那数据的来处只有一个,缓存说它命中了。可这个盘咱们冷启动,缓存里不可能有任何真实的数据。咱们顺着命中条件回去查,病根出在了构造函数里,而且是笔从前欠下的旧债:槽出厂的时候,自带的是活标记,键记的是零。老形状里的键是扇区号,零号扇区当了引导块,而 ext2 从不读它,那个出厂就活着的零号槽一辈子没人问,病埋下了不发作。槽长到了页之后,零号页盖的是零到七号扇区,superblock 住的是 2 号扇区,偏偏就在零号页里。挂载的头一件事就是读 superblock,问的正是零号页,缓存里那个出厂就活着的零号槽举手:我命中。交出去的是一槽从未上过盘的全零。修法只动了一行:槽出厂一律不带活标记,见过盘了,才有活的资格。命中认的凭据只能是见过盘,出厂的状态一个事实都不许自带。八案全灭的大案,病根就这么一行,可要不是真正的机器上看一眼盘命令,纸面上是想破头也想不到的。

第二刀动的是写路。写穿的老实,咱们在认字那一卷夸过:patch 落槽,整个槽都写到了盘上,这一拍写完了,槽和盘就成了同一份字。可懒章程现在管到缓存头上了:盘命令是最贵的动作,能省一趟的就省一趟。新的形状落在 patch 的收尾上,咱们改的就是这么两行:

```cpp
    base::CopyBytes(kSlot->bytes + kInPage + offset, source, bytes);
    kSlot->dirty = true;
```

CopyBytes 把字节落进了槽里,dirty 也跟着置了真,往下就 return 了,盘命令一趟都不用发了。这一改立下的唯一新事实,就是一枚脏位:槽里的字换过了,盘上还是旧的。见盘的日子,咱们把它往后挪,挪出来的是两个时辰。

逐出的时辰,咱们看 claim_slot 里领到受害者之后的那一段:

```cpp
    Slot* const kVictim = slots_.get(victim);
    if (kVictim == nullptr) {
        return nullptr;
    }
    if (kVictim->live && kVictim->dirty && !spill(*kVictim)) {
        return nullptr;
    }
    const Lba       kPageStart{.value = page * kCachePageSectors};
    const BlockSpan kWhole{.value = kCachePageSectors};
    kVictim->page  = page;
    kVictim->live  = false;
    kVictim->dirty = false;
    if (!queue_.read(kPageStart, kWhole, kVictim->bytes)) {
        return nullptr;
    }
    kVictim->live = true;
    return kVictim;
```

承重的是 spill 前头的那个条件:受害者是活的、又是脏的,咱们头一步做的就是回写。spill 要是被盘拒收了,整场逐出当场就作罢了,受害者原地保留了下来,槽还是脏的,等的是下一趟重试。腾干净了,咱们才换键、清位、把新页整页地请进门,读的长度是 kCachePageSectors,一槽盖的八个扇区一次要齐。这样槽里的字始终有人答,一个字也丢不了。

flush 的时辰,咱们立的是一个显式的面,原身拢共不过十行:

```cpp
bool BlockCache::flush() {
    const proc::MutexGuard kGate(gate_);
    bool                   all = true;
    slots_.for_each([this, &all](unsigned long, Slot& slot) {
        if (slot.live && slot.dirty && !spill(slot)) {
            all = false;
        }
    });
    return all;
}
```

名册上活着的脏槽,咱们挨个请它们 spill,拒收的不拦后面的,只把 all 拉成了假,末了把成没成报了回来,这就是那个面的形状。这一拍写完了,槽和盘不再是同一份字了,这是第二刀真正的语义翻转:隔着缓存看盘的人,跑测试的也罢,看崩溃现场的也罢,看到的可能是旧字,要新的,得显式地 flush 一遍。三处隔着缓存直接窥盘的测试,这一批全补上了显式的 flush,清偿完了再看盘。产品的代码里,到今天还没有谁真的调它,门倒是开在这儿,是给往后同步和关机的路预备的,逐出的自动回写已经在日常兜底。

这一卷的缓存,从认字那一卷的形状里走出来两步:槽长大了,写懒下来了。当年工程线同一段路里还记了一笔数:块缓存聚到页粒度之后,ext2 的读聚合了两成五,一趟盘命令捎回的字节多了,排队的就少了。这说的是当年。咱们这一遍,功能由实弹验过了,收益的计数没另做,当年那笔数咱们不冒领。缓存备好了页的饭,窗口也开了,就差把饭端到缺页嘴边的那双手。下一节裁决者要开新业务了。
