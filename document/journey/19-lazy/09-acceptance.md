# 验收:会懒的机器

收卷照旧看的是三样:面板、测试、实弹。面板咱们实跑了一趟,有数的几行抄上来:

```text
[kern] kernel at 200000 size 4A0840 entry 200040
[kern] pmm: 31272 pages free (probe 116000 ok)
[kern] kernel_init: root mounted, launching shell from the volume
cinux shell - type 'help'
```

报上来的数,咱们跟生与收那一卷对。size 报的是装机后内存影像的跨度,从 49DF00 长到了 4A0840,多出了一万零五百六十个字节,按页凑整是三页:生与收那一卷的跨度折一千一百八十二页,这一卷折的是一千一百八十五页。咱们再看 pmm,空闲页从 31275 走到了 31272,恰好少了三页。您要问缓存槽从一 KiB 长到四 KiB 怎么不见数里,那笔是堆上的开销,而 pmm 这行印在堆世界出生之前,它数的是影像自己吃掉的页。一来一回都算完了,三页对的是三页,是对得上的。盘还是那一卷的四 MiB,ahci 报的八千一百九十二扇区一扇区没多,只是 /bin 里多住进了一位新住户 mapper,下面的实弹就是它的戏。

测试的家底,咱们按套件点。宿主那边数的单位是件,而一件就是一个测试套件,总共记的是四十七件,普通线、地址排查线、数据竞争线、内核检查线,四种配置全数通过了。内核检查线把未定义行为检查和锁的名册都开着,锁那一篇立的两世界家法,在这儿兑现了。机内那头跑的是十三个套件,普通线和内核检查线里各跑了一遍。件里的案子,咱们挑新的点。登记册立的是一式两份,宿主的二十案,机内的十四案,查册、拒重叠、找空档、堆的家底、整段改词的拒绝,一把考全了。补页的一件是十案,首跑七绿三红的就是它,三红的根都治了,如今十案全过了,守卫页的拒绝也正着考:压守卫,响是要响的。浮点闸门的一件是四案。老的套件里添的是案:链表添了两案,只读走链的一案,走读计数的一案。同步添了两案,登了名的锁转储报名,没登名的报地址。调度的套件长到二十一案,四代辈分那案红过又绿过的,在验收里稳稳地站着。

实弹是 mapper 的独角戏,咱们把它的戏本念一遍。头一幕的戏码是匿名内存:mmap 三页起步,每页咱们写一个字母再读回来,改了只读再读一遍,末了 munmap 摘掉。第二幕的戏码是堆:问一声断点,伸了五页,半页一格地写读,再把断点收了回去。第三幕的戏码是文件:打开认字那一卷烤进盘里的两行开机问候,以只读的方式映射进来,read 读回来的字节,跟映射里的头四十个字节逐字节对拍。第四幕的戏码是深栈:二百五十六层的递归往下压,压过 exec 时真铺的那一页,一路压出了三十几页,全靠缺页一页一页地接着。收官的那阵,这出戏已经把四幕走全了。浮点那一批又添进带魔数的新对拍,重排之后的戏本,十九步的清单就摆在下面的会话里。它还替咱们收了两颗实弹才炸得出来的金子,咱们一颗一颗说。

头一颗炸在用户那一侧的封装上。六个参数的系统调用,Linux 的约定是第四个参数走 r10,第五第六走的是 r8 和 r9。咱们用户侧的封装,头一版拿通用的 r 约束喂后面三个,通用的意思是编译器随便挑寄存器,它才不保证挑的就是 r10。宿主的测试全过,因为宿主和内核是同一副编译器的脾气,实弹的头一枪,机器上的 mmap 参数就错了位。修法是把三个参数用寄存器变量显式地绑定到 r10、r8、r9 上,绑定了才算数。跨世界的约定就得按约定写死,宿主和内核碰巧一致的那阵子,救不了真正的机器。

第二颗是生与收那一卷埋下的旧债。程序进场的栈顶该落在哪,下楼开张那一卷的跳板早就把姿势立对了:调用方只递页顶,余八的事门里自己办。可生与收那一卷写 execve 的时候,进场栈顶给的是减十六,数字上是整整齐齐的,却差着编译器对用户进场的约定一口气:约定的进场栈顶,除十六该余的是八。就差了八个字节,程序往栈上摆的缓冲全歪了一格,从前的程序没有一条指令在乎它,一直是太平的。mapper 里一段把读进来的字节清零的循环,编译器向量化成了 movaps,它认的是死理,操作数要的是十六字节对齐,歪了一格,当场的下场是一般性保护异常。咱们拿反汇编对着出事的地址一看,死的位置落在 movaps 上,不在咱们的逻辑里,回头数 _start 里三次 push 的对齐数,一笔一笔地对清,旧债就此定了案,进场栈顶改成了减八。跳板立对的姿势,execve 抄错了格子,实弹来收了它,收得咱们心服口服。

会话咱们从串口原文合录:其中一趟完整的报数原样抄在下面,exit 和重生收在末尾的那几行,中间隔着的一趟一模一样的全过,咱们省去没抄:

这一屏咱们念三遍。头一遍看的是懒章程过日子:匿名页,写了它才来补,补的是零页。堆页的断点伸了五页,咱们一个没铺,写到了才来。文件页的映射只是登记,到了头一次读,经缓存把盘上的字请进内存。深栈压了三十几页,exec 时真铺的只有一页。第二遍看那三行 xmm:文件补页一遭来回、一发系统调用、一次 fork 的父子两半,十六个魔数词个个原样地活着,浮点闸门在真正的机器上站着岗。child inherits 那一行是 fork 出的子进程自己报的,报数的点在源码里有二十处,子进程占的是这一行,父亲等的也正是它。第三遍看的是收尾:退出码七,是 mapper 自己交的,父亲收了,退了场,init 又把 shell 拉了起来,提示符回来了。咱们连着跑了五回,回回都是如此的。

北极星的砖,咱们这一卷对一遍数:mmap 报的是九,brk 报的是十二,两个座次跟 Linux 的一样。munmap 和 mprotect 的座次在咱们的表上换了座:munmap 十、mprotect 十一,Linux 的表上正好倒过来,往后讲 ABI 的那一卷会把座次换回去。座次对齐的功课补齐之前,用到这一对的程序还不好照号请进门,这门功课咱们记下了。

该收卷了。第二幕的头一卷,咱们教机器偷懒,教成了:登记册立在任务里,缺页的裁决者两半俱全,缓存按页的个头伺候,往下长的栈还带守卫,锁学会了报名号,两件遗留销了,浮点的闸门立了。当年两天八件的冲刺,咱们拆成一卷,一节一节地消化,幕间为密度立下的家法落了地。开篇押的那句话,现在兑一半、欠一半:省的那一半有实数,断点伸了五页,铺出去的是零页,深栈压出的三十几页,靠的全是缺页一页一页地接着,登记在册的地盘远多过真发出去的页。快的那一半,当年工程线量过的是二十二秒归零,咱们这一遍没有另计时,十九步实弹验的是功能全过。懒不是为了省事,懒是为了快,快的数,咱们认当年那一笔。第二幕的路还长,名单幕间立过:信号、线程、装库跑别人的程序。下一卷咱们教内核看得见自己。
