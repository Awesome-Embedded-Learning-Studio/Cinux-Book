# 19 · 懒到家:从登记册到补页

幕间收卷的时候,咱们把锣举起来了:第二幕的头一站,要教的是机器偷懒。轮到了这一卷,锣敲响了。

咱们把机器今天的日子盘一盘。装载器把每个段的每一页都提前铺好,exec 的那一拍里,栈领到的就是一页,堆的影子是没有的,细的数目头一篇里算。这样的日子跑 hello 和 shell 是够的,可真正的程序要按需伸缩的堆,要随手 mmap 出来又随手还回去的内存,要敢往深里递归的栈,咱们要是想在装机那一刻把一切都备齐,内存再大也是备不齐的。答案咱们在幕间就报过:懒。

懒章程的三个词,咱们在头一篇里立成,后头的每一节都照着它办,卷首只报一句:登记在册的才给,哪一页用到了就补哪一页,没碰过的页一片不发。

活分的是四件,咱们摊开报数。头一件的活是登记册:每个任务一本,记着自己名下每一段用户地址,从哪到哪、许做什么、背后站着谁。第二件的活是四个号:mmap、munmap、mprotect、brk,窗口开了,册上添了行、减了行。第三件的活是缓存长到页:块缓存的槽从一 KiB 升到四 KiB,写穿改成的是脏页延迟回写,给文件页的按需补页备好饭。第四件的活是裁决者的另一半:缺页的裁决者从只管写时复制,扩到整页没映的案子,匿名页补的是零、文件页走的是缓存、往下长的是栈、拦底的是守卫页。随行的家当一串:锁要会报名号,两件生与收那一卷记在明处的遗留要销,收官之后还补了一道浮点现场的闸门。

当年的旧话,咱们也交代在卷首。这批活在当年的工程线上,是两天里连着铺完的八件,测试从七百零五件走到了七百五十二件。两天八件的密度人跟不上,教程就更别提了,咱们按幕间为密度立下的家法分成两截走:四件大头进这一卷,分配器的专题分给后面单独一卷,当年一笔做完的事,咱们一卷一卷消化。当年那轮改造里留下的一笔实测,咱们搁在这儿当广告:装载从整份铺好改成按需补页之后,工程线上最大的一份程序,编译器的前端,从盘上请进内存的时间,二十二秒归了零。懒到底值不值?验收的那一章见分晓。

合卷的时候,咱们把第二幕的头一卷交了。机器换了过日子的法子:内存不再装机时备齐,咱们登记在册,缺页了才补。实弹的数,验收那一篇一笔一笔对过了,这里就不念第二遍了。当年两天连铺的八件,咱们收成一卷四件加两件销旧,幕间为密度立下的家法头一回真正落了地。往后的路幕间立过名单:信号、线程、装库跑别人的程序,一样一样地来。偷懒教完了。
