# 第二颗核的第一句话

核从蹦床的门里跳进来,落在内核高半部的入口上,手里攥着的是三个数:核号、页表根、栈顶。入口函数把根切了,把栈立了,清了帧指针,一头扎进本核的主函数。主函数干的事,咱们按次序数,次序本身就是要讲的内容。

第一句:认自己的家。GS 指到自己的那块小抽屉上,从此本核这个词有了着落,后面每一步说的自己都是真的自己。第二句装的是自家的表:描述符表、任务寄存器、中断表,上一章备好的家当一件件穿上,认家的在前、穿表的在后,当年装表抹 GS 基址的案子咱们已经免疫,次序上的讲究仍是次序。第三句做的是浮点复位,把上一世留下的浮点乱摊子清干净。第四句把系统调用的三件模式寄存器装全:入口的 LSTAR、段选择子的 STAR、标志掩码的 FMASK,什么都没落下。第五句:读自己的中断身份号,户口本对上了号。第六句:开本地中断的门。第七句:武装自己的钟。

钟的事单说。头核的心跳是可编程定时器,老掉牙的芯片,每秒一百下地跳,全机的壁钟靠它走。第二颗核也用老芯片就分不出来了,那芯片的一根线只喊一颗核。所以每核的本地芯片里都带一个定时器,第二颗核的钟要自己跳。跳多快是要校准的,校准的尺就是头核的老定时器。咱们在发信号之前就把数量好了,量的活干在头核身上:头核把自己的本地定时器装满一次性的大数,用老芯片的另一个通道等上十毫秒,读回走过的刻度。两片本地定时器敲的是同一根总线钟,所以全机同频,头核那片上量出的差值,直接就是第二颗核每十毫秒走的数,除数的分档与初值由此定死,蹦床那一章讲的就是这件事。校准用的延时走老芯片的另一个通道,心跳的那一通道照旧留给头核,一芯两用倒是不打架。轮到第二颗核的时候,咱们手里的活只剩武装:把量好的数装进本地定时器,设成除数十六的周期模式,自己跳自己的。除数为什么是十六,咱们补一句实话:没有算出来的道理,当年实测起步时拍的就是这一档。要紧的地方在于校准与武装用的是同一档,好比尺和表刻的是同一刻度,量出来的数咱们装上去就能用。本核的钟跳出来的中断只管本核的轮换计数,不往全局的壁钟上加一秒,两颗核守着自己的钟跳,公共的时间只有一份。

然后是最要紧的一句:等。核把自己的机制快照填好之前,要等到自己的第一次本地心跳。没醒的钟不算钟,快照里的心跳计数一格必须非零,发布出去别人才信这颗核真的活着,不是只把状态字写上了。等到了,发布的快照里有几项机制字,描述符表与任务段的基址,心跳的计数,自己的核号与身份号,末了一枚魔数当收尾的记号。发布的那一笔带 release 顺序,头核那边配的是 acquire 顺序读。快照的这套东西,是当年一桩大案换来的,咱们讲考古。

当年工程线收尾的时候,有人发现一个难堪的事实:号称多核的那一批测试,几十项全数过了关,别的什么核都没碰过,其实测试内核压根没叫醒过第二颗。绿是真的绿,验的东西是假的。这病的名字叫空转盲区,病出在测试的姿态上:参数给了两颗核,谁也没去核对第二颗真的上线了。从那以后立下自检钩子的家法:核上线时把关键机制字回读进结果槽,配一个魔数防的是读错行,测试逐项与头核对上了表。它立竿见影地抓过一桩大案:第二颗核漏写了系统调用入口寄存器,用户态一执行系统调用的指令,处理器跳到零地址,当场就缺页了,进了缺页处理又炸,双错叠了出来,现场是最难看的一类。这病在单核上永远发生不了,头核的这些寄存器是启动链条装的,第二颗核怎么都得自己装,谁忘了谁背。钩子这么一立,对不上表的机制字当场红,连排查都省了。这一遍咱们把钩子做成了常备件,五项等值断言上一章咱们已经见过它发威。

发布完了之后,核进了空闲循环。这里的发布屏障是:全局一个分发许可位,头核还没拉起初始任务、也没备齐调度器的当口,这个位是关的。第二颗核的循环就一句话,许可开了没有,没开就睡自己的觉,开着的时候去问队列拿活,拿完了再睡。睡觉用的原语是老朋友:开中断的 sti 紧跟停机的 hlt,虽然说是两条指令,却合成了一个不可分割的动作。咱们看它的妙处,开中断之后的第一条指令没执行完,中断进不了门,这层保护罩住的恰好是紧跟着的停机。醒来后的头一件事是关上中断再查状态。为什么非要这个屏障,你想,调度器的类注册表、初始任务、文件世界,都还是头核单手的半成品,第二颗核偏偏此刻冲进共享队列,拿到的是没写完的元数据。等一切都备齐了,头核把许可位这么一放,再广播了一声,两颗核这才并驾而行。这个分两拍发布的思路,下一章还会在更细的粒度上再见。

首亮的面板咱们把串口原文抄来:

```text
[smp] 2 CPUs online
[cpu 0] APIC 0 online, LSTAR ffffffff80223901
[cpu 1] APIC 1 online, LSTAR ffffffff80223901
```

在线数涨到了二,每核的身份占两行,系统调用入口的值一颗不差,这是自检对表在面板上的回声。这行面板背后还有一笔工具的旧病顺手清了:咱们跑机器的几路脚本,从前各自硬编码了一份参数清单,谁也不看谁的,头一回实弹只跑了一颗核,咱们一追查,发现清单里压根没有核数这么一项。归拢成构建时输出一份逐行的设备参数,几路入口共读的是同一份,核数只往顶层加了一处,各处吃到的都是它。两颗核都在线了,家当各穿各的,钟各跳各的,可它们还只会睡自己的觉。下一章咱们给它们一口锅。
