# 26 · 请第二颗脑子上线:APIC、蹦床与共享调度

把后半场交给解释器那一卷收卷的时候,咱们把话撂在了明处:机器到今天还是一个脑子在转,把第二颗的核请上线,让两颗各有各的家当又同唱一台戏,是排在后面的路上的一场大戏。这一卷就是来唱这出戏的。

咱们照例盘家底。手里有的:轮流当家那一卷立下的调度器与自旋锁,生与收那一卷的 fork 与写时复制,懒到家那一卷的登记册,看得见的内核那一卷的调度类插拔,听得懂喊声那一卷的信号,同一副身家那一卷的 futex 与双基址,认字那一卷扫过的 ACPI 表根,验明正身那一卷的完成件与睡觉原语,还有开门迎客那一卷请进门的 busybox 压测真负载。缺的咱们也一片一片数:老门房 8259 只向头一颗核喊话,第二颗核连一个中断的影子都收不到。固件写的中断户口本咱们还不认。每核的家当现在全机只有一份,GS 指的块、GDT、TSS,第二颗核来了一样也穿不上。没有叫醒它的序列,没有它落脚的代码,没有它的栈。就绪队列的锁还没有,引用计数是裸的加减,console 一个字一个字地往外蹦,排队的事没人管。家底数完了,活就都现了形。

咱们进站时,机器是一颗核的世界:开机只认一颗,中断只送到一颗的手里,队列的不设防,是因为不存在第二个闯入者的威胁。出站的时候,面板亮出的是 [smp] 与两行 [cpu],两颗核各穿各的家当,各睡各的觉,从同一个上锁的队列里领活,96 轮跨核的 fork 父子各写整页互不相扰,busybox 的管道在两颗核之间流水,单核的镜像照样开机,并且诚实地不冒充双核。

这一卷的活,咱们摊开报数。头一件读固件的中断户口本,变长的条目一个字节一个字节读,坏表的处置是整张拒收。第二件两片 APIC 上了岗,本地的每核一片,外面的管全部引脚,只向一颗核喊话的老门房光荣退休,代码留作对照的样本。第三件每核一份的家当,静态块扩成了数组,自己认自己的门,当前任务从调度器的成员搬进每核的块。第四件的一页蹦床,醒来的核从 16 位一路变回 64 位,启动序列与机制的对表一起立。第五件第二颗核的第一句话,把自家的表装全,校准自家的钟,自检过了关才报在线。第六件讲的是一个队列与两颗核,共享的就绪队列挂上真锁,唤醒的请求归并到最外层放锁之后,让位中断的那一发广播也等到那时。第七件管的是谁还握着这块栈,任务跨核迁移的窗口立下纪律,收不走的送孤魂册。第八件睡与醒的口径,五处的等待全查一遍,入队与置阻塞收进的是同一把锁。第九件清锁家族的旧债:自旋锁学会跨核争抢,登记簿与顺序图改成了各核一份,引用计数换成了原子加减。第十件锁的生卒,检查镜像的容量断言炸出一串引用配对的旧病。第十一件破案:盘的完成通知被谁吞了。第十二件再破一案:太勤快的扫帚弄脏了浮点现场。末一件收尾照旧走的是验收。

当年的旧话咱们也照例交代。工程线上这一段是当年密度最高的一段,多核的活几乎是一口气发完的,随后又跟着一条跨了三站的追杀线,案子一串偏偏咬着一串。重走这一遍咱们按件分开,一件一章地排,一章讲清的是一件事,这是幕间立下的节奏家法:第一遍的读者被单卷的陡度喷倒过,这一遍是不许再犯的。追杀线上的案子,咱们按一条家法取舍:能解释今天手里这套机制的,进正文:在它该在的那一章把来龙去脉摆开。只是当年受了疼、如今结构上已经免疫的,考古的一段交代来历,不占正文的位置。还有当年计划书写了、最后没做的那一类,每核一队、偷活、票锁的那一类,咱们照样写明,登记在明确不做的那页上,不冒充什么实落。

合卷的时候咱们再点一遍手里的新话:固件的户口本会读了,两片 APIC 在了岗,每核有每核的家当,蹦床立起来了,第二颗核的第一句话说利索了,两颗核从同一个上锁的队列里领活,任务跨核迁移的窗口立了格子,五处的等待按同一个口径睡与醒,锁与引用的旧病清了,两桩大案的卷宗归档。欠的照旧挂在明处,跨核的速查表冲刷没做,共享地址空间在两核同跑时的远端旧翻译不受本核刷新保证,实弹有意避开了那类组合,信号位的共同协议、共享文件表的竞争这些边界,验收里逐条地写着。下一卷把散装请进门的设备收进一座统一的门房,中断的消息新路也排在那时铺。

卷名咱们暂记作《请第二颗脑子上线》。候选的另有三个:《第二颗脑子》《两颗脑子一台戏》《多核闯关》,连同定名的事,都留到日后慢慢地挑。
