# 验收:两颗脑子的成绩单

咱们收卷的章程照旧,看的是三样:面板、测试、实弹。面板这一回添了三处新相,咱们把串口原文抄来:

```text
[apic] 2 processor(s), local id 0, IOAPIC fec00000, overrides 5
```

咱们看这一行:它是户口本的当面回执:两颗处理器,第一片 IOAPIC 的门牌,改写记录收了五条。接着在设备各就各位了之后:

```text
[smp] 2 CPUs online
[cpu 0] APIC 0 online, LSTAR ffffffff80223901
[cpu 1] APIC 1 online, LSTAR ffffffff80223901
```

在线数涨到了二,每核的身份占两行,那串系统调用入口的值两颗核一字不差。除了这几处新相,面板再没多出什么行,咱们如实报。

测试的长凳上,咱们报数字:宿主五十九件,四条配置线各跑一遍全部过了关,普通的一遍,地址越界、未定义行为加泄漏三查的一遍,线程竞争检查的一遍,内核侧锁序图加未定义的一遍。机内的十八台,普通与检查的两个镜像各跑一遍。名单里有一台是这一卷新立的独立多核测试内核:它自己发初始化与启动序列,真的叫醒第二颗核,机制字的对表有五项,两颗核真从共享的队列取任务,让位的次数各是两百五十六,两核抢的是同一把自旋锁,核位掩码凑齐了三、计数凑齐五百一十二,浮点哨兵的两条主动中断案也在其中。跑机内案的目录也交一笔手稿:头一回手调测试指错了目录,得到的回复是没有测试,空跑差点被当成了通过,改成了指对目录并要求没有测试就报错,如实地记下。另有单核的负例:专门烤一个单核镜像,开机的流程照常,面板上没有双核的报告,压测器也不报双核的通过字样,机器有几颗脑子报的就是几颗,虚报是不许的。

实弹安排了三场。头一场是开机的面板,上面咱们已经逐字抄过。第二场的主角是压测器,它从盘上的裸名起跑,咱们把串口原文抄来:

```text
/ # smpstress
SMP_PIPE_EOF_PASS
SMP_FORK_PASS cpus=2 rounds=96
/ # 
```

这两行的通过字各验一摊。前一行验管道的文件尾:父开管,写者的子进程写两个字退出,读者子进程读满两个字再读一次必须得到零,读者的收在前,写者的收在后,两份退出码都是干净的。后一行验跨核的生养与分家:九十六轮,每一轮走的都是一次 fork,父进程把整页写满自己的花样,子进程验证继承的页分毫不差,再写自己的新花样,三十二次的让位之后再来验,父进程写下了第三套花样,把孩子的退场也收了,末了父子各验整页,一页五百一十二个字全数对上了,不是只看单独的一个字。孩子的退出码里带的是它运行那颗核的身份号,父进程从孩子与自家的两头各收一枚核号,收齐后的交集等于全集才算过,不是命中了其一就算。这里单核负例镜像上它诚实地不报通过。压测器自己的手稿也记一笔:首跑挂在等待的状态字上,读回的二百五十六看着吓人,细看是内核按外界的家法把退出码左移了八位,wait 报回的状态字,咱们看位子:低八位留给终止信号,退出码住的是高八位。错在测试器的解码,修的也是它,内核的断言一个没动。

第三场是 busybox 的管道压测,脚本放进了盘里,跑了二十四轮,每轮把一个带轮次号的消息经管道送进字数统计,把字节数对了,再把目录念了个遍,把名单对了。这一场的串口记录咱们如实交代:捕获存到命令敲下去的那一刻为止,后面的轮次没有存下来,咱们把存到的尾巴逐字抄来:

```text
[kern] kernel_init: root mounted, launching shell from the volume
/ # echo six four 
```

截断的记录不算数,通过与否看的是留档的实弹日志,二十四轮全过了。这一场的手稿也有一笔:头一次脚本其实根本没跑起来,命令停在了小数点前,送键的桥上缺那个键名的映射,咱们补上键名,并把送键被拒绝时的返回认真检查,才算真跑了。普通与检查的两个镜像各跑一遍全套,一动一静的两个 hello 也各复验一遍,全数通过了。

对卷首的承诺,咱们逐项过。户口本读了,两片芯片上了岗,老门房退休留了档。每核的家当齐了,当前任务进了每核块。蹦床立了,启动序列拍了,机制对表拦下了一位之差。第二颗核的第一句话连同自检钩子立了形。一个队列带起了两颗核,嵌套锁与归并唤醒立了纪律,登记分成了两拍发布。栈的归属立了法,孤魂有了册。五处睡与醒统一了口径。锁家族跨核了,持有记录成了各核一份,引用计数原子了。锁有了生卒,引用配了对。两桩大案破了,完成通知的吞没与扫帚的越界,卷宗归了档。十三件活没有一件缺席的。

边界咱们照旧挂明处,这一卷欠下的从最大的一笔念起。跨核的 TLB 冲刷没做,共享一套地址空间的两颗核同时跑时,写时复制、卸映射、改保护这三路消费者在远端核速查表里留下的旧翻译,本核的刷新管不到,实弹因此有意避开了两核同跑共享地址空间的组合,这是本卷最大的一笔欠,正解是核间中断的远程冲刷骨架,留给后面的卷。信号的待处理位还没有共同的原子或锁协议,一颗核的置位与另一颗核的清位交错,旧的掩码可能盖掉新的信号,名册的锁只保名册,不保信号的状态。共享文件表在克隆两份描述的场景下,两核同时看中的可能是同一个空槽,共享的读写游标也还是普通变量,从同一个旧位置起步的两个进程,写出去的字会互相覆盖。文本控制台是一把粗的锁,细的锁缓办。两颗核同时读一台终端的行编辑,立护栏的事还没办。词上的等待二百五十六只桶共用一把闸,退化成了一把全局锁,慢而不坏。多片 IOAPIC 的平台拒收。设备中断的消息新路,行话的叫法是 MSI,整条的路留给下一卷。每核一队、偷活、票锁咱们明确不做。上一卷挂下的老欠,咱们挨个接着挂:堆的扩张不查重叠,符号链接的形态不认,ash 的作业控制面没添,伪终端的座位只铸不还,还有读用户区间只查界不查映射的那笔系统性旧债。

合卷的时候咱们回头看这一卷的骨相:两片芯片换了门房,一页蹦床请来了第二颗脑子。请来之后咱们给就绪队列挂上了真锁,给任务的栈立了归属的格子,把五处等待收进了同一个睡与醒的口径,让引用的拿与还配成了对,两桩大案都是被第二颗核逼出来的真病。咱们的机器从一颗核的两条执行流,变成了两颗核的一台戏,busybox 的管道从这颗核流向那颗核。欠的照旧挂在明处,戏也照旧往前排:散装进门的设备该立一座统一的门房,中断的消息新路该铺了,咱们在这里把话撂下,这一卷就收了。
