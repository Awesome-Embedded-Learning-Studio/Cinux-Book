# 把栈接进开机的世界

上一卷立的栈是纯逻辑,长凳上验完就收了,开机的世界里一个字没动,接线的活连着泵一起撂给了这一部。今天咱们来还:头一件是给生产立一个家。kernel/net 里添的是一位 NetWorld,做的是单例,协议家族要在机器里跑起来要的每一件,全归它管:回环的口,立起的栈,IPv4 与 ICMP 的两个件,ARP 的名册,肚里是一样不缺的。init 的活就是接线,口挂进了端口表,件落进了座,汇瞄上发送的路,一家一家地接好。init 是幂等的,重跑一次的话,世界回到干净的开局,跑了一半的分数不带走。等往后真线进了门,换路走的是重瞄,而不靠重跑接线,幂等只是接线自己的性子。

接线的次序,照的还是上一卷立下的老话,两个件都活了才接线,构造期谁也不欠谁什么。ICMP 坐进 IPv4 门下协议一号的座,IPv4 坐进栈的类型字的座。这一卷新添的一笔是 ARP 的座:类型字 0x0806 的座上,坐的是一枚小小的内嵌件,它是不解析也不造包的,只把路过的 ARP 包递给名册看一眼。回环是没有以太头的口,直送 IPv4 的座,家法是原样不动的。可真线的口是有头的,带头进门的帧,类型字说了算,ARP 的座就是为它备的,上一卷说无头的口一律当 IPv4:边界卡在带头口上线之前,今天咱们就把这个座摆好。

开机的阶梯上,网络回环的那一步本来只有两件事:回环起了活,进了设备册当首住户。这一卷在后面追加了两件:NetWorld 接线,面板添了一行。原文咱们抄来:

```text
[net] loopback stack wired, pump seats with init
```

那后半句的 pump seats with init,说的正是坐泵这件事的落点,这里有一桩当天就遇上的判例。咱们本来想把泵顺手在阶梯上坐了,省得到处跑的麻烦,机器的一句 scheduler has no sink installed,当场就停了机。调度器坐的是任务,身下是要有一口锅垫底的,任务切换的汇,汇编写的那一副。这口锅是整架梯子爬完、面板打完之后才装上的,装在 Main 的最后几行。而 kernel_init 这个任务之母,它跑起来的时候调度器早就是活的,泵坐它那里是顺理成章的。所以面板那半句说的是,接线放在了阶梯,座位判在 kernel_init 的名下,一行话把两件事的分界写在明处。

接好线的世界,自家的地址起手写着 127.0.0.1,汇瞄的是回环的发送。这是一张静态的开局,咱们面前的机器听得见回环,而听不见网线,跟上一卷出门的时候一个样。
