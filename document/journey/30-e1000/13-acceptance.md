# 验收:泵与网卡的成绩单

收卷的章程照旧,点的还是面板、测试、实弹三样。面板这一卷终于有了新话,咱们一行行数。走线里多了一张卡的户口行,念的是 pci 0:5:0 8086:100E network 2:0。默认的收了,明点的进了册,走线的报数还是八台,一台换了一台。走线之后添的是两行 [net],一行报的是接线,一行报的是卡。老面板打完了,kernel_init 的行换了词,报的是 ping 的成绩:四发三答,提示符照常地落。从块设备那一卷立下章程的时候起,面板一行行都是实在的报数,这一卷的报数如上,读者开机可对。

测试的数字,咱们照实报。机内的一件文件装了三案:手摇两案加真网的回声案,全过了。全量的 ctest 九十二项全过。验收的四条配置线各跑各的,咱们照验收那天留下的记录报数:普通的一条,宿主侧交了七十二项,机器侧交了二十项。地址越界、未定义行为加泄漏三查的一条,过了七十二。线程竞争检查的一条,过了七十二。内核侧锁序图加未定义的一条,过了七十二加二十。一点二秒的等待窗在机器侧同样通过,机内那件网络的 ktest 总时长十二点六秒:三案在内。tidy 的告警是零,format 过了,解耦的检查脚本也过了,双向禁令管着的新件,进门个个验了身。

对卷首的承诺,咱们逐项过。旧案重讲了,三层道理各归了位。世界接了,栈进了开机的阶梯,坐泵的座位判给了 kernel_init。泵立了,引擎与调用者分了家,线程是常驻的,测试是亲手摇的。两案进了树,倒序的排兵照判例办了。卡点了,按名认的,两道许可开了,八页的窗开了。起卡的全套走完了,复位静音拉了链路,EERD 逐词读出了门牌。收环立了,描述符与缓冲都各就了位,哨兵纪律进了代码。发环立了,门铃挂了上去,补短帧开了,大端写词到驱动里当了差。悬案破了,使能位的位号入了册,战法三件套入了册。收头那一读立了,迟滞的窗定了一点二秒。线挂了,路由备了两条路,ARP 真线上开了张。第一声 ping 响了,面板为四发三答作了证。一件不落地交齐了。

边界咱们照旧挂明处,这一卷欠下的从大的念起。两笔从上一卷撂过来的防线,咱们这一卷没还上,如实地登记在案。头一笔是头的声明对缓冲的核对:头说自己六十个字节、缓冲里只躺着二十的截断包,今天照样一路走到校验的那一步,校验和会读到界外的字。上一卷说真网卡进门的那天再补,卡今天进了门:防线还没落,这道防线比上一卷更重了,因为线真的来了。第二笔是应答缓冲的入站边界:一千四百八十是自家出站的章法,线上来的消息可以到一千四百八十四,回声的抄写差着四个字节,同款地登记在案。线上来什么咱们管不了,这两笔是登记在案的活,排在往后的检查点。别的欠照旧念一遍名字:IPv4 仍不分片,算出零发全一的特例仍留给 UDP,反码和分段累加仍是没主顾的,中断驱动仍是登记远期的,发送的回写仍不读。

咱们合卷点数:泵立了一具,世界接了一位,卡点了一张,双环起了两只,判例入了三桩,ping 响了一声。次序上咱们只认一条,泵立稳了,咱们点卡才放心。往前的戏排在第三部:socket 的号位生在门上,那是那边的正主,UDP 与用户态 ping 都坐的这一程,四层的座就是他们的凳子,门也早在安全那一卷立好了。再往后的戏还有一部,正主是 TCP 的完备,这里只带了一句,不抢这一卷的戏。验收的数字点完,咱们在这里收卷。
