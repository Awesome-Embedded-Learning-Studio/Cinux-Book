# 异步基建与点亮网卡:一具泵、一张卡与第一声 ping(卷名草稿)

安全那一卷收卷的时候,把话撂在了两处:socket 的号位要生在那扇门上,还有一套当年内核里开着中断跑长活的死法,现场排在网络的名下。校验与回环栈那一卷接过了前一句的一半,又把后一句指得更准:死法长在泵的身上,长在异步的等待上,是第二部开场的正主,咱们这一卷就是第二部。它的位置在四部里这样摆:第一部立的纯逻辑栈,这一部接上的是生产,泵把栈摇了起来,真网卡把线接了进来,第一声真线的 ping 落在面板上。socket 的号位还是第三部的活,这一部把它脚下的地焐热,咱们一行号位都不生。所以这一卷的名字,咱们暂且叫它异步基建与点亮网卡:异步说的是泵与等的学问,点亮说的是 e1000,从认卡到双环到第一声 ping 的一路。

咱们照例盘家底。手里有的:进程那几卷攒下的任务词汇,起线程的,定权重的,让位的,调度器的座位与任务切换的汇。块层与 USB 那边当差的完成件与一次性回调,睡眠唤醒的那一档,那边早就在用了。驱动基本框架那一卷的家底厚:设备模型的网络册,回环当的是首住户,MMIO 的开窗手法与缓存禁用的页,PCI 的走线与按类找卡的旧脸。上一卷的家底是整套栈:端口表,类型字的座,四层的座,预算的缰绳,ARP 的名册,IPv4 的判两次,ICMP 的记分,长凳上是全验过的。缺的咱们也一片一片数:kernel/net 里只有纯逻辑件,世界接线一件没落地,泵的一个也没有,网卡驱动的一行也没有,参数表里网卡的一个字也没有,机内的网络测试的一件也没有,当年那套死法的讲法,也还是欠着的。

咱们进站时,机器的面板与安全那一卷出门时一个样,校验与回环栈那一卷是一个字没动它的:机器听得见回环,而听不见网线,总线一角还坐着一张没人理的默认网卡。出站的时候,面板上多了两行 [net],kernel_init 的报数换了词,四发 ping 换了三声回音,提示符照常落了,泵在后台常驻地摇。全量的测试九十二项全过,四条配置线各绿各的。判例入册三桩:使能位的位号一桩,收尾的哨兵一桩,读收头的那一读一桩,连同一套分层取证的战法。

这一卷的活,咱们摊开报数。头一件重讲了旧案,当年系统调用里开中断睡等的死法,按今天的语义理成三层道理,当这一卷的骨架。第二件接了线,NetWorld 单例立了起来,栈进了开机的阶梯,坐泵的座位判给了 kernel_init。第三件立了泵,引擎与调用者分了家,net_poll 是常驻的,注入的口子开着,谁的手都能摇。第四件两案进了树,接线说的是世界话,yield 的判例照讲,倒序的排兵照着办。第五件插了卡,参数表里添了两行,按名认了卡,开了两道许可,开了八页的窗。第六件起了卡,复位走完了,静音写了全一,链路拉了起来,EERD 逐词读出了门牌。第七件立了收环,描述符与缓冲都各就了位,哨兵纪律一整套进了代码。第八件立了发环,门铃挂了上去,补短帧开了,大端写词到驱动里当了差。第九件破了悬案,包零出门的案子破了,使能位归位到了第一位,战法三件套入了册。第十件把读立住了,poll 每圈的开头读收头,踢醒的是主循环,迟滞的窗定在一点二秒。第十一件挂了线,汇重瞄了,路由分了两条路,ARP 在真线上开了张。第十二件打了 ping,kernel_init 报了四发三答,面板作了证,边界照当年的实测念了。末一件收尾走的还是验收。

当年的旧话咱们也照例交代。当年网络的那一段:点卡、接栈、真 ping 与泵的根治,是几天里连着打完的,重走的这一遍摊成一卷,一步一步地验证。取舍还是原来的家法:能解释今天手里这套机制的,进得了正文,在它该在的那一章把来龙去脉摆开。当年那声双错的死法,按新语义重讲成了三层的道理,当年测试绿生产死的盲区,讲成了 ktest 判例的注脚。当年词书的位号,收尾的哨兵,读 MMIO 的脾气,三笔正判例一一兑了现,抓包器的假绿那一笔姊妹判例,也顺手入了册。分层取证的战法,当年拿半夜换的,这一卷写成了正课。只作反面教材的,收敛地讲。

合卷的时候咱们再点一遍手里的新话:kernel/net 里有了一位世界,栈接进了开机的阶梯。泵立起来了,线程是常驻的,测试是亲手摇的,同一具引擎在两个世界里是各自安全的。卡点亮了,按名认的,双环立了,哨兵上了岗。栈上了真线,路由学会了问路,ARP 的名册开了张,第一声真线的 ping 有了回音,四发得了三答。判例入了册,分层取证的战法也入了册。欠的还挂在明处:两道从上一卷撂过来的防线至今未落,截断包的与入站四字节的,线上真的来了,这两笔比从前更重了。IPv4 仍是不分片的,中断驱动仍是远期的,发送的回写仍不读。戏照旧排了下去,第三部的正主是 socket,再往后的第四部把 TCP 做完备。这一卷咱们就收在这里。

卷名咱们暂记作《异步基建与点亮网卡:一具泵、一张卡与第一声 ping》。候选的名字另有三个:《包零出门》《一读踢醒主循环》《迟到一秒的假象》,连同定名的活,都留给咱们日后慢慢挑。
