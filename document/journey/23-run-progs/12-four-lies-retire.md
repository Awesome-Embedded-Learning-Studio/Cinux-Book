# 四句假话,换成真话

咱们开头盘的是一笔旧欠。铺号那一晚咱们图快,有四个号头一批答了假话:fcntl 一律答读写态,prctl 吞掉了也不响,prlimit64 见了指针就答一对无穷,getrandom 拿心跳凑的伪随机。门是开对了,话是假的,咱们当时一笔一笔记了号。客人如今住下了,假话也该到头了,这一篇咱们把四句全换成真话,四个桩退役了。

咱们头一件修的是 fcntl,也是最大的一件,咱们把它的两张脸分清:状态面与座位面。状态字说的就是追加、非阻塞那一类,住在打开的描述上,按描述共享:dup 出去的两个号,看的是同一面,改一面两面都变了,这是 Linux 的语义,同一副身家那一卷立的描述层正好接得住。close-on-exec 的位子不一样,它姓的是座不姓描述:同一个号在表里换一份描述,位子是不跟着走的,所以它住在文件表的座上,伺候它的是 base 的位图件,与 PMM 同款的双件形状,base 的家底从此进了文件主题:这是头一例。F_SETFL 的白名单:追加、非阻塞、直读、不更访问时间四位可改,访问方式的位不许换,开门的方式是开文件那一刻定下的。F_DUPFD 真的找座,下限钳到了三,保的是头三座标准输入输出的老座,满了答 Emfile。F_DUPFD_CLOEXEC 找好了座顺手武装。open 的 O_CLOEXEC 落座,O_NONBLOCK 一并落了:开门那一刻旗标里认得的状态位,都记进了状态字。exec 的收尾把武装过的座连开带位一起清,换世界的路上不给旧描述留门。

咱们第二件修的是 prctl 与 prlimit64。任务的家册添了一枚十六字节的 comm,PR_SET_NAME 写的是名:至多十五字节加一个零,PR_GET_NAME 走的是整记录回读。fork 抄的是父亲的,exec 换成程序路径的叶名,叶名的拆分用的是 base 现成的 SplitLeaf,家底的第二例。prlimit64 立了真表:十六行,一行一对的软硬顶,任务一创建就照默认表装好了。默认的家底咱们照 uapi 的数填:栈的软顶八 MiB,core 的软零,打开文件的一千零二十四对四千零九十六,其余的无限。fork 继承而 exec 不动。只服自家的 pid,问别人的答 Eperm。软顶的改动得看硬顶的脸色,咱们用三行说清:

| 想改的软顶 | 硬顶 | 答法 |
|---|---|---|
| 不超过硬顶 | 任意 | 改 |
| 超过硬顶 | 无限 | 改 |
| 超过硬顶 | 有限 | 拒 |

咱们第三件修的是 getrandom 接上真随机。硬件的路是 RDRAND:咱们探 CPUID 的特性位,再十发循环地取,单发的失败不算数,接着取的还有下一发,成败看的是进位标志,咱们拿 setc 折出来的字节当判据,打成的就是真随机。特性不在的机器上,xorshift 的兜底,兜底走的是算法形,咱们如实交代:那不叫随机,叫的是凑合能用。

真话换完了,咱们又回头把整棵树扫了一遍裸数,修了四处。八 MiB 那样的字面量领了名字,常量边上注着 uapi 的原名:栈顶、打开文件、资源行数,一个一个认领了。手搓的位运算换成了位图件。comm 与 limits 的宽度从成员的 sizeof 派生,不另立别的数字。exec 的改名不再手写。三处留白有各自的理由:特性位照的是 gdt 的形,兜底用的是算法形,O_* 一整类都还是裸的 uapi 词,要不要也收进词表:咱们记在明处,这一卷咱们不动它们。

测试的家底这一篇添得厚。宿主的长凳上没有一台真跑着的机器,门面的案子得有个能跑任务的小院,咱们立了一个一问一答的夹具:两位任务,问的递话,答的收尾,点齐了六案直测。案名点齐:at 的两种符号扩展,uname 六槽的次序,prlimit 的读写与拒陌,fcntl 经 dup 的流面与座面,prctl 的名一来一回,getrandom 的计数与护栏。立这个小院还捎带教了咱们一课:长凳的世界里,任务体内落的断言:得任务自己走到退场那一步才作数,run_until_done 的老家法又教了一回。

验收:四条配置五十三件全数过了,机内的十五台照旧,实弹里 ash、竖线、ppoll 走通了全链。到了这儿,这一卷的活交齐了。咱们把整卷的活从头到尾复阅了一遍,末了一句评语,五个字:我没意见了。收工的碎活还有一件,下一篇把验收的面板、案数与实弹的戏码逐字摆开,咱们收卷。
