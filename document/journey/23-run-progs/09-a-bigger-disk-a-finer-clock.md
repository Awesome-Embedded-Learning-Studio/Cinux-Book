# 大一号的盘,细一档的钟

这一段咱们有四件活:盘、路名、钟、终端。终端咱们单开一篇,这里办的是头三件。头一件办的是盘。上一篇末尾大家都看见了,四兆的教学盘装下双份的客人就见了底,咱们把它扩到了十六兆,inode 从一百二十八添到了五百一十二,烤完盘余量从此宽裕了,后面的客人也有地方搬了。有一处要分清:busybox 以 /bin/sh 与 /bin/busybox 双名住下的,是实弹时另烤的一张一次性副本,教学盘默认烤的,还是咱们老 shell 的一座 /bin/sh,后面亲手玩的时候您会看到,cat 在教学盘上是没处请的。

第二件办的是路名。接上一篇的话头:开机直拉的 ash 手里,exec 铺的 envp 是空的,它的手里没有 PATH,裸名字是没处找的。修法在 exec 的门上:调用的人 envp 递空,咱们替他铺一条默认的 PATH=/bin:/usr/bin,铺的只有 PATH 一条,走的是暂存池同款的预算。裸命令从此有路可寻了。咱们看着它小,道理不小:人家的 shell 找命令靠的是环境里的话,咱们不给环境,就得咱们递话。

第三件办的是钟,这一卷里案情最曲折的一件。这件事的主角是 HPET,高精度的事件定时器,一块从 ACPI 表里请出来的细钟。这一卷开工铺时钟号位的时候,咱们试过一版它的读取,机器每次启动都回这么一句:

```text
[kern] hpet absent, clocks stay tick-grained
```

细表咱们请不来,秒针一直踩着一百赫兹心跳的十毫秒粗步。咱们手里攒了两个解释:模拟器默认把 HPET 关了,表是固件顺手发布的残货。这一桩咱们也把案卷递了出去,那双眼睛看完回来了,头一件事就是推翻咱们的两个解释:直问模拟器的设备树,默认机型的 HPET 是开着的,显式打开了之后原代码照旧报缺,显式关掉了才连表都没有。推翻了个干干净净,咱们原样收回,旧的两个解释,咱们往后一个也不许再提。

咱们把真因找了出来:它在表的字段偏移上。表其实就在那儿,五十六字节的真表,OEM 报的是 BOCHS BXPC。表体里那段通用地址结构,ACPI 的行话叫 GAS,address space 的那一栏在加 0x28,八字节地址在加 0x2c,旧代码各晚了四字节:前者碰巧读到地址的最低字节:零,后者把地址的高半截与尾字段拼成了零,块基址读成了零。而基址是零,period 就从 direct map 的物理地址四上读回来了,读到的 0xf000ff53,是 BIOS 实模式中断向量表里的内容,不是设备的垃圾值。旧代码为什么一路没炸缺页,也清楚了:它压根没摸到设备。三道修复咱们一层一层上:解析、映射、使能。头一道是独立的布局件,按规范的五十六字节布局解 GAS 的完整八字节地址,检查的是长度、system memory、非零、一 KiB 对齐:

```cpp
    constexpr unsigned long kSpaceAt   = 40;
    constexpr unsigned long kAddressAt = 44;
```

第二道做的是映射。不为一块钟把 boot 的帧缓冲门扩成常驻的约定,咱们走的是仓里现成的正式设备窗:二 MiB 的 uncached 设备页,IoremapVirt 的别名访问,地址还得落在预留的范围里。第三道管的是使能。caps 与 period 用对齐的 volatile 读,能力里要求的是六十四位的计数器,三十二位的就回退心跳,免得把回绕当成了大跳。咱们对 General Configuration 做读改写:置使能位,清了 legacy route,其余的位保留原样,咱们一个 comparator 也不武装:心跳照旧归 PIT,这块钟只管两次心跳之间的细针。

使能这一道还有个独立的发现:设备在而计数器没开。独立的机器里映射刚成、使能未写,直接读出来的 config 是零,counter 也报的是零。主计数器有自己的开关,读改写置上了之后,period 读回的是一千万飞秒:十纳秒一步,counter 开始走了。零起点是合法的,失败的话保持不出现,咱们不再拿计数器非零当存在的判据。换算也有一病:ticks 乘 period 的中间积:在百兆计数器上约五点一二小时就溢出,改成商余分解的路子,除在乘的前面,末了相加,结果在六十四位纳秒的量程里:约五百八十四年,咱们不用担心提前回绕,宿主的案子专门锁了六小时样本与带分数的 period。

实弹咱们跑三组:默认机型、显式开、显式关,各自独立的机器与盘的副本。date 连打八发全过了,咱们把开着一组的样子抄两行:

```text
CLOCK_MONOTONIC=0.101330430 CLOCK_REALTIME=1792300793.101337840 GETTIMEOFDAY=1792300793.101344
DATE=1792300793.162046230
```

本机复核还有个朴素的对照:隔上几十秒再打一发 date,两发的差值与真实过去的工夫对得上,秒针走的是真时间。开着的组里,clock_gettime 打了一千零二十六发,发发带亚毫秒的尾数。关掉的组回退心跳,六万八千多发的采样全是整十毫秒的粗步,回退的路也是考出来的,这个用例咱们留着。十纳秒是计数器的分辨率,采样之间的差是调用开销,这两笔咱们不混着算。咱们记下一档:机型要不要把 HPET 写死成约定,不把机器参数当本案的修复条件。验收:宿主长凳添了 HPET 一件,四条配置全过了,机内十四台照旧地过了。清单上剩的是最后一件,终端的真身,下一篇咱们立。
