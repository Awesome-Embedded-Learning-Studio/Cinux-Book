# 一根管子,四个号

管道是 Unix 的竖线:左边的命令写,右边的命令读,中间一截有底的缓冲。咱们给一根管子一次立齐四个号:pipe 排的是二十二号,pipe2 排的是二百九十三号,dup 与 dup2 排的是三十二号和三十三号。pipe 递回来的数组两格,头一号坐的是读端,二号坐的是写端。咱们动手之前,欠着一笔得当面还的旧话。听得懂喊声那一卷讲死讯配对的时候缓办过一对事件:写往没有读者的管道,配的是 EPIPE 那一号,当时说等管道出生的那一卷补上。今天管道出生了,那对事件的实话是:词都是备着的,errno 名册上 EPIPE 坐的是三十二号,信号的十三号也在表上,可挂点咱们这一卷还是没有接。咱们的管道只数写端:写端走光,读者被唤醒,答的是零,告别的一头是有的。读端走光了,写者是不知道的,写满了他就睡着等地方。两个词备好了,接线的事挂在明处。

形状上最要紧的是一件外衣。无盘起家那一卷立大门面的时候,定过一张擦掉脸面的后端接口,管道就穿这身外衣:两端各是一份打开的描述,底下连的是同一个管道对象,read 与 write 两个号的既有 handler 一个字不用改,fd 落进来自然滑进管道的 pull 与 push。谁读谁写?节点上的一个不透明字说了算:空的是读端,置了的是写端,关写端的时候替它记一笔写者走了。容量给的是四千零九十六字节,底下是 base 的环形队列,读写两侧各站一支信号量:生产者与消费者的基因,轮流当家那一卷就铺好了。写端的计数,管的是告别:末位写者放下笔,唤醒读者,读者答零。errno 添了新词:Emfile 坐的是二十四号,表满的时候报。

咱们把 dup 的两张脸分清楚。dup 走的是 shared 加 adopt,出处是同一副身家那一卷在描述层立的两种认领:shared 说的是两号共享同一份打开的描述,adopt 说的是新号把描述认到自己名下。老号新号看的是同一面,游标是共用的:谁读谁推,这是 Linux 的语义,同一副身家那一卷立的描述层正好接住,生与收那一卷当年留下的 dup 旧话,咱们在线程那一卷兑现过一回,今天管道又把它用到了实处。而 dup2 不一样,它要的是定点落座,号码由调用人指定:关掉的是旧座,认领的是新座,同一个号指的还是同一份描述。base 的槽表为此添了个新词 place,落位按的是下标,它是编号面上 insert 的兄弟,一个找的是最低空位,一个落的是指定的座。文件表跟着添了一张新面,认的就是把座落到指定号码上的写法。竖线的接线全靠它:两边各把管道的一端 dup 到自家的标准输出、标准输入上,再各自 exec 了自己的程序,管子就这么接通了两代进程。

机内立了两案,走的还是照旧的家法。头一案考的是往返、容量、告别:写满读空,末位写者放了手,读者醒着答零。第二案阻塞的读者被写者唤醒,造孩子跑到底的家法。实弹咱们在 ash 里验:竖线连两条命令,fork 了两回,pipe 立了一根,dup2 下了两笔,exec 了两回,wait4 收的尾,左边命令的答话流过管子,由右边原样交到了控制台,整条河走通了。盘上还有个小插曲:咱们想给 busybox 挂个硬链接省地方,这件事在烤教学盘的流程里竟办不成,只好老老实实地双写两份,各占了一千一百八十六块,四兆的盘立马见了底。扩盘的实测依据又添了一条,这件事咱们记下,排在后面的活里。

验收:机内添了管道一台,十三台长到了十四台,全数过了。客人跑起来了,管子通了,可 ls 在 busybox 手里还开不了口:咱们 getdents 的念法,和人家期待的不是一个形状。下一篇咱们改念法,顺手还要破这一卷最隐蔽的一案。
