# 验收:客人住下了

咱们收卷的章程照旧,看的是三样:面板、测试、实弹。面板这一回添了一行:HPET 进了开机的次序表。这一卷铺时钟号位的时候试过的那版读取,收官之后成了开机的一步。细表请不来的时候,它回的是这一句:

```text
hpet absent, clocks stay tick-grained
```

钟就留在心跳的粗步上。这一卷的家当几乎全在运行时与号位表上,咱们添进面板的只有这一行。

宿主的长凳上,五十一件长到了五十三件,新添的两件:一件是 syscall 直测小院那样的门面,另一件是 HPET 的规范快照加六小时数值四案。老件添案的还有一片,咱们按名点齐:装载件添了不对齐段一案,六个卷只喂对齐段的绿,从此不对齐也有案子看着了。补页件添了两案,内核来向的写,有承诺的补,无承诺的拒。管道件添了三案,终端件也添了三案,块设备、vfs、ext2、信号四件也都添了案子,案子的来历各篇讲过,咱们记名不重数。机内的台子从十三台长到了十五台,管道添了一台,终端添了一台。整条 ctest 数下来六十八件全数过了,口径照旧是串行的。四条配置线全过:普通线、地址排查线、数据竞争线、内核检查线,一条不落地走完,六段的验收脚本 exit 零:宿主五十三件乘四,机内的十五台乘二。

实弹的戏咱们一场一场念。自家这边的老住户,咱们头一拨请安:打包改形之后,标准盘的 ls 照常过,这是特意回归过的。hello 交的还是四十二,折腾了几番,咱们没惊动一位老房客。客人这边:串口形态的机器跑起来,ash 的提示符活着,咱们敲什么它应什么,逐键报的是零 unserved。竖线的戏码验了整条河:左边的命令把话写进管子,右边的 ash 从管子里读出命令,办完了,写端走光了,read 答的是零,自己退了场。ppoll 的门是它逐键敲出来的,如今每键都应了一声,再没有抱怨了。复跑脚本连打了二十发,hello 报的是四十二,false 报的是一,缺路径的报一百二十七,父 ash 报的是零。钟的两出戏前面演过,这里咱们只点一句:隔几十秒打两发 date,差值对得上真工夫了,显式关掉的组回退十毫秒粗步,也是全过的。

对卷首的承诺,咱们逐项过一遍。号位表上 musl 要敲的号,铺齐了,表界挪到了三百一十九。stat 的两笔真 ABI 旧欠:座次与布局,都还清了,断言把形状定住了。管道一家四号立了起来,告别的一头在真客人身上走通。行编辑进了内核,fd0 交出去的不再是裸键。ioctl 与 ppoll 的问话门开了:窗口大小、就绪、超时,问什么答什么。钟细了一档,从十毫秒到了十纳秒。四句假话全换了真话。北极星的三条约定:编号、寄存器、负 errno,号照的是人家的表,结构按的是人家的 ABI,连动作记录的词序都照人家的排。

欠的咱们也照旧挂明处。写往空管道的那对事件,词是备着的:挂点没接,写满的写者还睡着等地方。键盘回显与行编辑的双重回显。ppoll 收下未验的掩码。termios 的开关面没做,行编辑是常开的。各篇里自己记下的四笔也一并挂上:入口画像的机内案没立,目录缓冲跨重拉的观察还挂着,HPET 的机型约定记了档没定,O_* 一整类还裸在词表的外头。老欠的几笔接着挂:跨类的次序没动,内核栈的守卫页没立,futex 的超时没抓,信号打断睡眠只在 ppoll 的门上还上了一角。

合卷的时候咱们回头看,这一卷的五桩案子值得摆在一张桌上:stat 的座次,stat 的布局,信号的摆栈,块缓存的指针,完成件的窗口。前后的三桩错在跨边界的形状,块缓存与完成件的两桩错在并发里的窗口,病是两样的,缘却归了同一条:真客人的形态与频率,咱们自家的测试从来没造出来过,客人一进了门,五处接连现了形。北极星从下楼开张那一卷挂到了今天,立约的本事它没考,考的是守约的成色。客人住下了,它要的下一批东西也现了形:终端要的是开关与伪终端,作业控制的整台戏等着锣,还有几样名字里的家什,照得着面的日子排在下一卷。这些是下一卷的活:假文件与真终端。咱们把这一卷的门牌挂好,该动身了。
