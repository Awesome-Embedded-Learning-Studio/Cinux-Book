# 亲手一玩,三件补齐

客人的实弹,到这一篇之前都是脚本喂的键、断点看着跑的。这一回咱们把机器跑起来,咱们自己坐到键盘前玩。玩是玩了,玩出来的东西不掺假:两个断点一桩噪声,诊断都是玩的人当场做的,头一个断点一上手就来了。

咱们跑机器走的是串口形态,标准输入输出都接在了串口上。可咱们的终端只认 PS/2 键盘,串口的驱动打从出生那天起就只有发送,没有接收:串口上敲进去的字,走的是条死路。咱们修两件。串口加了一扇收字节的门:状态寄存器里有一位 data ready,咱们轮询它,有了就取走,另配一个不取只看的有无键。终端的 read_line 改成了双源输入:串口在前,而键盘在后,两个座位都空了,就 yield 把 CPU 让了出去。从此敲在串口上的字与敲在模拟器键盘上的字,进的是同一间编辑室。

第二个断点把咱们自己的旧说翻了篇。上一篇咱们说 TCGETS 答上 isatty 就齐了,咱们亲手一玩,ash 还是进不了交互模式。追了下去才知道,musl 的 isatty 真正探的是另一处:TIOCGWINSZ,0x5413 的那一号,问的是窗口的大小。好办:咱们给 ioctl 补一答,窗口的记录是四格十六位:行、列、横像素、竖像素,咱们答的是开机横幅同款的四十八行一百二十八列,像素两栏填了零。答完 ash 当场进了交互,提示符立住了。旧说咱们当卷更正,咱们不带到下一卷。

然后是那桩噪声:提示符是活了,可咱们每敲一键,串口上就多了一行,写的是 [kern] syscall 271 unserved。二百七十一号说的就是 ppoll。ash 的行编辑是逐键在问:现在有事了吗。这一件咱们定了不做桩,要做咱们就做全量。

ppoll 的全量咱们分两张脸说。头一张是就绪的脸:按描述符答。fd0 到 fd2 走终端的 has_input:行池里有行,咱们算它就绪,行编辑里攒下的半行也算。串口有键的算,键盘有键的也算。把半行也算进就绪的门里,是 ash 拿实弹教咱们的:就绪的回答只须承诺一件事:现在去 read,会有进展的。行规程跑的是 read 这一路,原始的键还躺在驱动队列里的时候,整行的池子是空的,就绪的脸要是只看池子,就会把答应过的进展赖掉,ash 就此卡在了门外。各路 fd 的答法,咱们用一张表摆开:

| fd 的出身 | 就绪的答法 |
|---|---|
| 终端 fd0 到 fd2 | 行池里有行算就绪,行编辑攒下的半行也算 |
| 管道的读端 | 有待读的字算就绪,写端走光了连挂断一起答 |
| 管道的写端 | 有余量就算可写 |
| 普通打开的文件 | 恒就绪 |
| 坏号(表外的座) | 答 POLLNVAL |
| 号是负数的条目 | 回话清零,不查也不计数 |

负号那一行是 POSIX 定下的老语义:fd 是负数的条目不算错也不问事,咱们直接略过。第二张是记录的脸:一条 pollfd 八个字节,号蹲的是零,关心蹲的是四,回话蹲的是六,与 getdents 同款的手法,顶住线上格式的是偏移常量加断言,真码咱们抄在这儿:

```cpp
constexpr unsigned int kPollIn   = 0x0001U;
constexpr unsigned int kPollOut  = 0x0004U;
constexpr unsigned int kPollHup  = 0x0010U;
constexpr unsigned int kPollNval = 0x0020U;

constexpr unsigned long kPollRecordBytes  = 8;
constexpr unsigned long kInterestOffset   = 4;
constexpr unsigned long kAnswerOffset     = 6;
constexpr unsigned long kPollRecordsLimit = 32;
```

四个旗标的值照的是 Linux 的原样,三个偏移把一条记录的格子定死了,三十二是咱们一次问话收的条数上限。

超时那一味也有全数的讲究:timespec 十六字节,负的秒,或纳秒一栏攒满了一整秒的量,答的是 Einval。地址递零是无限等。长得超过单调钟量程的,咱们视为无限,限期折成单调钟上的绝对时刻比对。回话的脸咱们也补上:有就绪的,答的是就绪了的条数,限期到了一条也没有,答的是零。等待用的是 yield 循环。未屏蔽的待办信号在场的话,答的是 Eintr,ash 的作业控制指的就是这一声醒来收尸:听得懂喊声那一卷欠下的信号打断睡眠,在 ppoll 的门上还上了一角,别处的睡眠门口还是老样子,咱们如实记着,不把一角说成了一片。sigmask 的那个参数,收下不验:真的掩码挂起与恢复,要真的睡眠与唤醒来撑,记给了下一卷。顺手的一笔是单调钟升格:纳秒的一张脸从匿名空间请了出来,成了公有面,ppoll 与时钟两家从此读的是同一份源。

测试三处跟上:终端件添了一案:整行没有之前,原始的键也算输入,这一案头一个抓出的是咱们 has_input 初版漏半行的洞,又暴露了两案共用单例、上一案的半行漏给下一案的私事,清池的家务补上才全过。管道件添了就绪三面案。门面件添了 pollfd 与 timespec 的 ABI 断言。

然后是 busybox 的两轮实弹。提示符活得好好的,逐键报的是零 unserved,echo hi 走通了全链。竖线的真考题咱们原样抄:echo done 一竖线 /bin/sh。右边的 ash 从管道读进命令,办完了,写端走光了,read 答的是零,自己退了场,告别那一头的语义在真客人身上走通了。有个小如实:盘上只有 /bin/sh 一位的时候,cat 这样的名字无家可归,单个命令的链接没烤进盘,这是盘的事,不是管子的事。键盘回显与 ash 行编辑叠加的双重回显还在,欠的记在下一卷。号都铺到这里了,还剩几句话是假的。下一篇咱们把假话全换掉。
