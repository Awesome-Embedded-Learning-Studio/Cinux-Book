# 为什么开门迎客

下楼开张那一卷立柜台的时候,咱们把远景说过一遍,今天念回来:机器将来要跑别人的程序,咱们把 musl 这个 C 库装进来,跑 busybox 里的常用命令,人家认的只是这套约定。咱们还给这远景起了名字,叫的是北极星,并说定了地基那天踩实,往后咱们只加号,约是一处不改的。几卷过去了,名册轮到了它:同一副身家那一卷收卷的时候,名单上只剩了最后一件。今天就是北极星指着的那一天,咱们开门。

客人是谁?咱们看清楚:头一位是 busybox,一具静态的 ELF 身子里装着四百零七个命令,常用的 ls、cat、echo、uname、date 全在里头,它自带的 shell 叫的是 ash。musl 是个精瘦的 C 库,编出来的程序静态就是一份 ELF,不挑动态的装载器,也不挑库的路径,正合咱们的教学线。请它们的道理也简单:一个把常用命令打成了包,一个把 C 的世界最薄的一层铺好,两样合了起来,别人的整套手艺就能在咱们的机器上开张。北极星图的,就是它了。

自家的家底,咱们也照例清点。四卷的供给线,一件一件都在号位表上应着各自的号。号位表说的就是下楼开张那一卷立下的分发表,号照的是 Linux 的原样,一格挂的是一位:fork、execve、wait4 是生与收那一卷给的,mmap、brk 是懒到家那一卷给的,信号全套是听得懂喊声那一卷给的,clone、futex、打开文件的描述层是同一副身家那一卷给的。单子不是咱们自己说绿就绿的,后来真客人进了门,咱们拿它逐号对过,结果确实全过。四卷攒下的家底,到了今天全要派上用场。

可客人要的东西,单子上没有的也一片一片。它进门问的头一件事是 uname,咱们的表上没这个号。它的输出走的是 writev,咱们照样没这个号。它跑 shell 要的是管道,咱们一根也拿不出。它读命令守的是 fd0,可咱们的 fd0 交出去的是裸键,退格、回显、攒整行的活,就全得客人自己干了。它还要隔着 ioctl 问终端的事,等键的时候要隔着 ppoll 问有没有事,而它们问话的门,咱们也还没有开。咱们把这些缺口一卷补齐,这就是本卷的活,也是北极星真正的考题:人家的程序不跟咱们商量,它全按 Linux 的老章程来敲号、递指针、读记录,咱们的约定但凡有一处走了样,它当场就死给您看。

手搓的 shell 怎么办,咱们把话说定。它从下楼开张那一卷就把咱们陪到了今天,ls、run、cd 都是它的手艺。交棒的事归交棒。棒是递过去了,老 shell 还是在岗的。造盘的脚本认一个环境变量 CINUX_SHELL_ELF,指的是谁,盘上 /bin/sh 的座就是谁烤的:教学盘默认还是咱们的老 shell,busybox 烤了进去,开机的第一位常客就是 ash。这就是试金石的意思:客人能不能上岗,考的不是客人,考的是咱们四卷攒下的地基,还有地基底下没扫干净的旧病。

咱们还有一句分界的话,卷首说定了。生与收那一卷教装载器的时候留过话:动态链接的学问,是留给装库那卷再展开的。装库的这卷今天到了,可这一回请进门的,是静态的客人。动态的学问,链接器、装载器与动态库的三方协议,自有单独的一卷排在后面,这一卷一个字也是不碰它的。

顺序上咱们照着侦察走。起手请的是工具链,咱们把客人编出来,让它顶进 /bin/sh 的座,自家装载器的旧病会被它的段表逼出来,这是下一篇的活。旧病清完了,才轮到号位的正戏。咱们动身。
