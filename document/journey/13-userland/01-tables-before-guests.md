# 桌还缺四件

进程那一卷收工的时候,咱们把家底数了数:任务会轮转了,会抢占了,会抱着锁睡觉、也能被一声唤醒了。可您把调度器的队列从头点到尾,里头站着的全是内核自己人——echo_a、生产者、消费者,名字换了一茬又一茬,个个都是出身没变的内核亲生任务。而整台机器到今天为止,还没有执行过一条不属于内核的指令。这一卷咱们请客:让 CPU 头一回把执行流交到一段内核管不着的代码手里。要请客的话,您别急着写请柬,咱们把房东的桌子好好盘一遍——座位够不够,锅备了没有,而门轴在哪。

请来的客人住哪,得从 x86 的特权级说起。CPU 此刻住在哪个环?您从 CS 寄存器的最低两位读得出,行话的名字是 CPL:0 是内核的环,3 是客人的环,所以把程序放到楼下去跑这件事,行话的说法是 ring3。环与环之间隔着一道道检查:ring0 专属的指令(cli、hlt、直接摸端口),执行前您让 CPU 看一眼 CPL,环要是错了,就是当场的一次 #GP。而页表项里有一位 U/S,写着这页归的是用户还是内核,标成 S 的页 ring3 碰一下就是缺页。段描述符里写的还有 DPL(描述符特权级,管的就是这个座位给谁坐),标了 0 的座位,ring3 的选择子递不进去。咱们从 boot 挪进内核到今天,CPL 的读数一直是 0——谈不上把特权用得多讲究,这机器上从头到尾只住过内核的一家。保护机制全都到位了,只是来检验的客人从来没有。

现在咱们盘桌子。头一件盘的是 gdt.hpp 里咱们自己的表:坐打头的是空槽,坐第二个的是内核代码,坐末位的是内核数据,数到三个就到头了。客人进门要坐的是 DPL=3 的代码段和数据段,咱们一个座位也没画。第二件是缺着的 TSS(任务状态段,x86 的一块专用结构),客人在楼下时来了中断,该换去哪口 ring0 的栈,由它里头的 rsp0 指着。TSS 缺了席,客人住下的第一天,头一个上门的中断就是双重错误。咱们至今没缺过它,是因为中断从来只在内核自己的栈上落地——世上没有 ring3,换栈这回事自然也就无从谈起了。第三件盘的是 MSR 工具——满屋一件没有。MSR 是所谓的型号专属寄存器,CPU 机箱里一排按编号访问的暗格,SYSCALL 和 SYSRET 的门轴全开在里面,而内核树里连读写它的函数都找不出一个。长模式的门当年是 boot 拧开的,boot 拧完就跳走了,手里的工具也没能传下来。第四件盘的是 GS 的落脚点,眼下还是空的。跨环的那一瞬,内核栈顶、用户栈顶这样的几个数,得放在一个换了页表也照样找得到的地方,那是段寄存器 GS 的差事,而咱们的 GS 从出生起就是零。

缺着的四件,咱们把它们拼成这一卷头一段的工程清单:给 GDT 添座位,给中断备一口换栈的锅,打齐 MSR 的工具,也把 GS 的家安上。前两件咱们下一节办,后两件是再下一节的事。四件都齐了,桌子才算摆开了,客人才有地方坐。

咱们动手之前,还有两件工程上的家务得办了,不然的话新东西没处落。头一件家务是 Main 的前半截撑不住了。咱们过完进程那一卷,Main 开头留下了十来个初始化调用,凑足了五十来行,新子系统一个个地来,它就一截一截地长,而照这个长法,不等客人进门它就成了一座山。咱们把启动顺序从 Main 里搬出来,变成数据:kernel/init/ 里立一张按次序排好的表,咱们给每级台阶记一个名字加一个函数。头一版十一级:串口、名册、地址空间、控制台、堆、中断控制器、tick、中断桩、0 号中断线、键盘,末了开中断。签名统一:每一步收上一步交出的交接单,再把交接单交给下一步——地址空间那一步要换手,换手这件事也就写进了签名里,不读函数体也就心里有数了。哪一步不成了,统一口径:把这一步的名字打到串口上,就地停机。而开机失败本就该停机,带着半套子系统继续跑的机器,坏在哪里也说不清了。Main 的前半截就此缩成一行调用,面板的时序统一挪到整架梯子爬完之后,串口上的行数和内容,其实一个字也没变。往后咱们还要往这架梯子上添台阶,添的时候改的是表,Main 也就不再长个了。

第二件家务是构建的手工清单退休。内核源文件的名单,原来是一份手写的三十六行:每添一个文件都得记得把名字写上去,忘了写,链接器就出来要人了。这回咱们把它换成递归自动收集:kernel/ 全树自己报名,收了进来再按路径分桶,住进 /arch/x86_64/ 的进架构桶,其余的进通用桶。桶沿上写的构建变量默认是 x86_64,哪天要换架构了,要改的只有一处,别家架构的目录自动落选——口子就留在那儿了,留着也不碍咱们的事。有两处是故意留着不自动的:产品入口 kernel.cpp 显式移出清单,因为测试内核要用另一张脸来顶替它的位置。base 里那几个与操作系统无关的共用件,住在 kernel/ 树的外头,照旧是手点的。改动的红利当场兑现:init/ 是个新目录,新文件一旦落了进去,构建一个字没改就收进来了。

桌盘完了,碍事的家具也搬走了。缺着的四件,咱们从第一件办起:给 GDT 添座位。下一节咱们让三槽的表坐上七位。
