# 第一跳实弹

万事俱备了,咱们按下运行。Main 送走最后一个演示任务之后接上了这一段,次序咱们排过一遍——一步不能乱。头一步咱们建世界,AddressSpace 取一页清零做它的根,铺上高半区的镜像,上一节备好的权限与门都等着往这根上挂。第二步咱们画两页。0x400000 挂客人的代码,物理身家是拿镜像里的起点符号算出来的,代码里的写法就是一笔减法,起点符号的地址减去镜像基座。基座在内核里是立了名字的常数 kKernelImageBase,它的值是 0xFFFFFFFF80000000,内核的高半区窗从它起算,起点符号的地址就在窗里。咱们拿一组示意数走一遍,符号落在了 0xFFFFFFFF8028A000,减去基座得到的是 0x28A000,客人的 0x400000 挂上的就是这一页物理内存。地址本身随链接挪窝,您机器上算出别的数才是正常,算式是不变的。符号的名字跟着住客走,首跳的验收员交差以后,名额换给了常客,今天树里查到的名字是 g_user_shell_start。0x500000 挂一页新取的空页做栈。第三步咱们备锅,从名册再取了一页做 trap 栈,也就是 ring3 来中断时 CPU 换栈用的内核栈,栈顶写进 TSS 的 rsp0。同一页顶也写进 GS 落脚点的 kernel_rsp,那是给下一块的柜台预铺的路,同源的两扇门眼下都通着这一页。一页就这么开着,中断的路子眼下就这一层,不够了再扩,家法没让咱们提前备货。末了三拍:关中断,换了根,一跳而下。换根用的就是内存当家那一卷留下的 activate,它等的头一个真用户,今天到了。换根前后中断是必须关着的,这是换世界时就立下的纪律,咱们一步不省。

还有一层得挑明:这扇门是单向的。sysretq 送咱们下去,那半边的 SYSCALL 还没开张,柜台是下一块的事,所以这一跳没有回程,跳之前 Main 把该交代的都交代完了。

咱们看串口,这一趟的输出就两行:

```text
[kern] launching first ring3 program
exception #13 rip=400031 cs=33 rflags=10212 rsp=500FE8 err=0
```

中间隔着的几秒钟一个字都没有。头一行是内核下跳前留在串口上的话,打完了它,当家的就换成了客人。可这段安静咱们读得懂:三亿次自增的活儿里,百赫兹的心跳一下没停,每一拍都是客人家里来了中断,从 TSS 换了栈进内核,应答完了,iretq 又送了回去。这么几百次往返,串口上没掉什么字。安静本身就是平安的证据,真出事的话:第二行就不会长这个样子。第二行是内核重新开口说的话——异常转储是它的本分,谁家出了事,它都得把现场原样报了出来。

咱们把第二行一个字一个字读开,您跟着对。头一个读出来的是 cs=33,客人的代码段选择子 0x33 带着 RPL 3,CPU 此刻真的住在 ring3,不是内核演出来的布景。rip=400031 正落在程序末尾的 cli 上。三亿次转完了,客人伸手去关中断的那一拍,fault 偏偏就出在它身上。#13 指的是通用保护异常。err=0 说明的是错误码里连个选择子都没有,这个特权级压根碰不了 cli,干干净净的权限拒绝。咱们再看 rflags=10212,第 9 位的 IF 是 1,从跳下去到被拒的这一路,中断始终是开着的。rsp=500FE8 落在咱们给它的那页栈里,就在离页顶不远的地方。五项对完了,当年第一遍在这里留下的验收标准逐项命中,一条特权指令在 ring3 被拒的这一下,恰恰证明了保护在工作。这一跤摔出来的就是成绩单。

咱们补一句为什么拿 cli 当探针。它的险处在于成功比失败可怕:ring3 要是真能关掉中断,随便哪个客人都能把整台机器的耳朵捂住,心跳、键盘、时钟一起聋掉了。所以它被拒,验的不只是一条指令的权限,是整个特权级的地基。不过反过来:跳之前哪一步没做对,摔相也各有各的样子,咱们一一对得出:锅没备好,ring3 来的头一个中断就换不了栈,等着它的就是双重错误。user 位漏了一级:缺页错误码 0x05。世界没画对:取第一条指令就断了路。真摔出来的这一下五项全对得上号,说明咱们排的次序一步都没白排。

中断能这么来来回回,靠的是座位扩容时备下的锅,和更早立的表。ring3 来了中断:CPU 从 TSS.rsp0 取新栈,把 ss、rsp、rflags、cs、rip 五件都压了进去。回去的路是 iretq,照着五件里的 ss 把客人送回原处。这套结构咱们只消把零件对上号:异常帧在会疼那一卷立的时候就写全了,ss 那个槽从第一天就占好了位。SYSRETQ 的选择子算术,座位扩容的时候就把 RPL 3 编进基值,也从第一天就是对的。所以这一跳真正的新东西只有一件:CPU 第一次以客人的身份,住进了低半区。

报告打完了,机器按异常的惯例停住,这一跳的验收到此为止:停得心安理得。Main 里那个键盘回显的主循环,今天咱们送它功成身退。自己的脸,自己的耳朵那一卷立它,验的是按键到屏幕的整条链。如今跳板一去不回:循环没了位置。能力不丢:机器里的键盘测试台兜着底,而真正的接棒者是第三块里的常客。眼下在场的客人,活着是它会的,被拒也是它会的,可它只会自言自语:三亿次是它一个人转的,被拒也是它一个人的事,它跟内核之间没有一条开口的路。写一行字、退个场都离不了开口。
