# 会说谎的证据链

这一章不添一行新的功能,咱们回头翻一桩旧案。案发在柜台施工的那几天,比上一节那桩寄存器的案子还要早,比柜台开张的头一行字也要早:第一次带着 SYSCALL 的镜像按下去,客人的第一句话还没落地,机器就倒在了门口。咱们给这桩案子单开一节。难修是谈不上的,修动的只是几个数字。可它把一件事摆到了咱们面前——观察全是真的,链条也是自洽的,断出来的话却是错的。

咱们按当时的顺序把证据摆出来,您看看冤枉出在哪一环。头一件:断点踩在 SyscallEntry 的第一条上,咱们单步跨过 swapgs,前一边读到的 gs base,还是面板上那个高半区的地址,后一边读到的,就只剩了 0。硬件是不说谎的:swapgs 确实把另一格换上来了,而另一格里装的确实是 0。然后咱们回头查了装家。GS 安家的那一章,咱们明明写了两笔,把两个 base 都指去了同一块。读回来的数也确实是漂亮的,面板上读得见的那笔,与咱们拿调试器直读出来的另一格,摆的是同一个数。咱们把两件证据一拼,判断几乎是自己跳出来的:swapgs 换上来的格子,写入是压根没生效的。可写入为什么无效?机器是虚拟的,疑心于是落到了虚拟化层的头上:是不是它把 MSR 写入,或 swapgs 的语义,走了一点样?这样的解释能盖住全部的证据。咱们差一点就把它写进了档案。

这一回的翻案没靠新实验:咱们把笔下的编号抄出来,跟编号的字典对:就是 MSR 那一章说过的,Linux 把全机 MSR 编成的那部索引。对上的那一刻,全明白了。咱们翻回字典里看:FS base、GS base、KERNEL_GSBASE 是连座的:起头的是 0xC0000100,后头连着的是 0xC0000101 与 0xC0000102。咱们要写的是后两格,笔下的两个号却各往前挪了一位——GS base 的那笔,写进了 FS base 的门牌。KERNEL_GSBASE 的那笔,写进了 GS base 的门牌。错位之后的世界是这样运转的:写进去的两笔,一笔进了 FS base,一笔进了 GS base,两格里都是有数的。读回的那两笔,读的又恰好是刚喂过的两格,所以读回来的数真有其格,真摆出了设计的模样。唯独 KERNEL_GSBASE 本尊的格子,写它的笔没有落过,读它的眼也没有扫过——格子从出生起存的就是 0,连看它一眼的人都没有。直到第一次 swapgs 真的把两格对调,零才上了位,门口的那一摔,摔的是货真价实的 0。最毒的还在后头:装家的设计本来就是两个 base 同指一块、两笔读回同数,错位了之后,读回来的还是同数。设计的目标态和病态,摆在读数上是一模一样的。

您把那两件证据再读一遍,会发现没有一件在撒谎:硬件真的把 0 换了上来,被换上来的格里存的真的是 0,两笔写入真的都落进了格子,面板读回的数也真有其格。观察是没有撒谎的,撒谎的是常数——咱们全程用错误的编号提问,证据就全程用真实的答案,替错误的判断作证。咱们愿意把教训说得重一点:常数抄错了而机制照常运转的时候,证据链是最有欺骗性的——每个环节都是诚实的,合起来却指向了一桩冤案。观察的真,不等于判断的真,中间隔着的,是提问用的那个号对不对。咱们差一点,就把冤案判给了虚拟化层。

修法本身没有什么可说的:三个号归了位,就修成了。真正的判决是处分:这一类的错,咱们不许它再有机会。于是有了您在 MSR 那一章见过的 msr.hpp——现在咱们可以交底了,它的出身就是这桩案子,判决下了,词汇表才生了下来。词汇表收的就是七个号,起名照的是 Linux 的索引。连座的三兄弟就排在里头,咱们一眼就能看出谁是邻居:

```cpp
inline constexpr unsigned int kFsBase = 0xC0000100;
inline constexpr unsigned int kGsBase = 0xC0000101;
inline constexpr unsigned int kKernelGsBase = 0xC0000102;
```

三个消费点一起换了血:GS 安家的两写两读,开快速系统调用的四笔,开机面板的读回。十六进制从此就不进新码了,要用号的话,拿的地方只有词汇表。您在前面几节里读到的那些名字,案发当时还是光秃秃的数。结案之后咱们给全树换了血,名字才各就了位。

咱们把词汇化跟下次小心放在一起比一比,高下是分得出来的。数抄错了,咱们手里没有一件工具验得出:隔壁那块门牌是合法的,全机的验法都拿它没办法。变成名字就两样了:名字是单源的,定义是只在一处的,引用却到了各处。再要错位的话,只能错在名字的词面上,把 GS base 的活派给 FS base 的名字,这样的句子写的人落笔时自己就看得见。防复发的手段分两等,一等靠的是人仔细,另一等靠的是结构堵路,这一回咱们选了后一等。

词汇表立好了,这一卷欠下的话也就能兑现了。客人眼下能开口办的事,咱们掰着指头也数得过来:只剩了写字与退场。它真正的头一桩需求是等——等一个还不存在的键。
