# 客人的出身

咱们今天新开一个 user/ 目录,客人的出身从这里起算。动工头一件要划的边界,是客人不能跟内核一个锅里吃饭:堆、断言、打印、种子柜这些内核的运行时,咱们一样都不许它碰。咱们不是小气,客人将来活在咱们够不着的世界里,眼下它跟内核之间其实连一条路都没有,谁也给不了它这些家当。于是客人的构建链自成一条,链接脚本到编译档的整套章法,咱们一页纸重新立。

咱们这就安家。链接脚本开篇就把地址写下,客人的家安在这儿:

```ld
USER_VMA = 0x400000;

SECTIONS
{
    . = USER_VMA;

    .text : ALIGN(4096) {
        *(.text.start)
        *(.text .text.*)
    }
```

0x400000 不是咱们发明的,这套机器上非 PIE 的可执行文件历来从 4MiB 起家,咱们沿用传统。真正硬的是另一半约束:编译档用 -mcmodel=small,小代码模型要求程序里的所有符号都落在低 2GiB 内,0x400000 远在圈内的深处。您拿内核的链接脚本一对照,对称就出来了:内核安在 0xFFFFFFFF80200000,编译档换成了 -mcmodel=kernel,约束是最高处的 2GiB。内核住进了头顶,客人住进了脚下,一份地址空间两头各安一家,谁也越不过自己的半边。

咱们再看编译档的其余几位,个个砍的都是依赖。-ffreestanding:声明的意思是没有标准库可依。-nostdlib 加 -static:缺省的库一个不链,链上的全是静态货。-fno-exceptions:异常展开的表整个不要,自由档的世界里没人接异常。-fno-pie 配 -no-pie:地址就是要写死。这一串里得单独说的是 -lgcc:把编译器自己的运行时档链进来。这档白得的东西比名字听上去多,64 位的乘除法、memcpy 与 memset 的真身都在里面,编译器生成代码的时候会悄悄调用它们,咱们不链它,这些调用就都成了断链。末了是嵌镜像:链接器产出 ELF,objcopy 把它抽成不带任何包装的纯二进制,再把这个二进制包成一个目标文件的独立段,嵌进了内核镜像。字库走的正是同一条路,客人又走了一遍。纯二进制还有个好处:ELF 的头、段表、对齐填充全被剥掉,剩下的头一个字节就是 .text 的头一个字节,起点符号在文件里的偏移是零,咱们把它整页映射到 0x400000:入口就正好落在页头。内核拿嵌进去的起点符号,能算出这段程序的物理身家,下一节跳的时候正要用它。

客人本身值得咱们说一说。咱们第一位客人叫 hello,名字本身就是句问好的话,干的活却是验收,它的一生只有两件事:三亿次 volatile 自增,末了一条 cli。自增为什么必须 volatile?咱们把“消失的那通 call”里教过的脾气反过来用,不加 volatile 的话,编译器看这三亿次什么都没观测到,整个循环连同它一起删了,咱们要的“活着”就没了。三亿次:每次花一拍上下的时间,算是几秒钟的活。百赫兹的心跳数下来是几百下。咱们的客人要在这几百拍里全程活着,每一拍都是一次从 ring3 进内核再回来的往返。它什么都不打印,省事其实还在其次,这一跳要验的东西,咱们在内核侧全都看得见,客人多说什么都是噪音。末了的 cli 是故意的:cli 是特权指令,ring3 碰它必被拒:咱们要的就是这一拒。拒了,保护才算真的在工作。hello 当的是验收员,验完了就交差退场,常客的名分留给往后住下来的客人。

这一路的磕绊有三件,件件值得咱们记下来。头一件最重:嵌进镜像的程序,起点符号的尾数是 98A0,而页界要求尾数 000。页表项收的只有帧号,低 12 位直接丢了,咱们以为把 0x400000 映到了程序头上,实际映到的是程序所在那页的页头,前头是别家的数据,跳进去取下来的第一条指令就是乱码,#UD 当场就到了。修的路走了三步:头一步在段内加对齐,没什么用,它还顶着别人的段名,通配符把它归进了大流,对齐怎么也落不到它头上。再把对齐挪到输出段自己的冒号后面,同样的因由,所以还是没用。末了给它换成谁也套不上的独立段名(真名就叫 usertext.user),链接脚本里单独立了一条 .user ALIGN(4096),这才稳稳落在尾数 A000 的页界上。长凳上验镜像尺寸的那个测试还顺手立了一功:空段也会推进位置计数,这个不起眼的毛病是它头一个抓出来的。

第二件小些:objcopy 偏偏吃绝对路径,生成的符号名会把整条路径拼进去,长得没了边,重命名的规则对不上号。咱们在字库上早遇过这事,解法是现成的,抄一个短名字的副本再喂给它。第三件其实与构建无关,却差点毁掉上一节的心血:批量排版的时候,跳板那段汇编被当成 C 文件重排了一通,五条指令的格式当场被毁。重写之后立下一条往后一直算数的纪律:汇编文件永不进排版的清单。

至此咱们把客人的出身办齐整了:家安在 0x400000,编译档立了自家的章法,程序嵌进了镜像,端端正正地坐在页界上。程序在镜像里了,下一节咱们跳。
