# 不出门的会客

门内的两位客人要用套接字说话,在此之前咱们只有一种信封:IP 加端口。信封上写的是网络坐标,信就得从网络的那扇门出去,在回环线上绕了一圈,再进另一位的收环,同一间屋里的对话,偏偏得让信出门跑一趟才到得了隔壁。这一章咱们在屋里开一扇新门,门牌写的是 AF_UNIX,家族字写的是一,人家给它起的名号是 Unix 域,给同一台机器里的进程会客用。UDP 与 socket 那一卷把套接字立成了家族,六张虚的脸:收、发、落座、指名、报自家、报对家,每张脸都是成员自己填的,如今家族里搬进的是一位新住客,六张脸还是照填的,填的全是屋里的名字。流式的听与收尾那些后来添的脸,跟 TCP 成员借的是一套,它也是一张缺的都没有。

socketpair 是生来成对的,是新住客带来的头一件家当。TCP 完备的那一卷里,这扇门后是空的,答的是不支持,空着的门总比挂一扇假门诚实,老话是这么留的,现在咱们把门后填上了。两只套接字一落地就连在一起了,bind 省了,敲门也省了,中间隔的是一条现成的信道,咱们把它整个挑出来看:

```cpp
struct Channel : base::RefCount<> {
    base::container::RingQueue<unsigned char, kLocalStreamBytes + 1> streams[2];
    base::container::RingQueue<Datagram, kLocalQueue + 1>            datagrams[2];
    bool                                                             closed[2]{};
    bool                                                             write_closed[2]{};
};
```

流式的每个方向一条字节环,深写的是 4097,用的是 4096,留的一格空着,所以满与空才分得开,家族里环的老讲究,咱们原样带了过来。数据报是两边各一排格子的,一格的位子装一封信,深写的是 9,用的是 8。写的人把字节推进对家的环,读的人从自己的环里弹,咱们给多少它就截多少,数据报是没有下半截的,老礼数是一条都没改的。

末尾的两对旗管的是告别。closed 说这一侧整个走了,write_closed 说的是这一侧封了笔,写是不写了,耳朵倒是还开着。半关闭的门道就住在这两行里:shutdown 送的是一,落的正是 write_closed,封笔的人不再写,但是他自己照样收得着。这对旗的名字,咱们到探针那段还会再见到。

没成对的客人,咱们给它们备了另一条路:走名字。bind 把名字登记进内核的一张表,名字最长的时候占一百零八字节,拿的是 sockaddr_un 里 sun_path 的尺寸,同时挂着的名字至多十六个,重了答的是 EADDRINUSE。流式的礼数跟 TCP 成员的一样:bind 落的是座,listen 换的是听票,connect 干的是敲门的活,accept 领的是人,候客座备了八个位子。差别是在握手上的,门内的敲门是当场办完的,connect 门里那七十五秒的软限一圈都不用等,敲门的人还没离开柜台,新套接字已经躺进听者的候客座。座满的时候敲门的人当场拿一声 EAGAIN 回来,门内是不设等待的队伍的。数据报的 connect 更省事,记的只是个名,跟 UDP 成员用的是同一个礼数,线是一根都不出的。

地址的形,门里现翻译的老讲究没变,译法多了新的一套。咱们看门里抄名字的十几行:

```cpp
    if (family == net::kAfUnix) {
        if (length > sizeof(family) + net::kLocalNameBytes || length == sizeof(family)) {
            return -kEinval;
        }
        out.family     = net::kAfUnix;
        out.name_bytes = length - sizeof(family);
        if (!uaccess::CopyFromUser(out.name, address + sizeof(family), out.name_bytes)) {
            return -kEfault;
        }
        if (out.name[0] != 0) {
            for (unsigned long index = 0; index < out.name_bytes; ++index) {
                if (out.name[index] == 0) {
                    out.name_bytes = index + 1;
                    break;
                }
            }
        }
        return 0;
    }
```

请您对着这十几行看两处。头一处看的是长度:族字后面的全是名字,只有族字、没有名字的,答的是 EINVAL,名字塞过一百零八字节的也是它。另一处是名字打头的那个零:打头的是零,长度就按客人递来的算,打头不是零的话,咱们抄到第一个零为止,零本身算名字的一部分,路名的老写法。族字不是一也不是二的,答的还是那句 EAFNOSUPPORT,咱们家没有那个家族的门。bind 与 connect 的门口另有一道对字:信封的家族字跟套接字对不上,答的照样是 EAFNOSUPPORT,两套礼数是不混用的。

> 探针里咱们挂的名字,用的就是打头带零的写法,零后面跟着的是 cinux-eco。Linux 给它起了名,叫的是抽象名字,名字住在内核的表里,不落到盘上的路径里。

地址结构还是同一个,咱们门里靠信封上的家族字分辨走哪套抄法。网络两卷的客人隔着真线说话,信封上写的是 IP 与端口,门内的客人写的全是屋里的名字,同一副套接字的身子,两边是通用的。SocketAddress 这个结构自己也长了身子,添的名字字段与 IP、端口并存。门定单件上限的时候,问的只是出生的类型:流式给的是一个最大段,数据报给的是一千四百七十二,门内的数据报跟 UDP 同一张表,格子借的就是一样的尺寸,超了答的是 EMSGSIZE。

poll 的问话也进了套接字自己的家。从前 poll 的眼睛认管道与普通文件,套接字借的是 readable 一只眼,答得上的是有没有货进门,答不出的是对家走没走,可写倒是永远报有。现在咱们再扫,见了套接字的描述符,问的是它自己的脸:听着的,候客座里坐了人,答的是可读。连着的,自己的环里有货、或者对家封了笔,答的也是可读,对家的环是有空位的,答的是可写。对家整个走了,答的是一声断,HUP 也挂了上去,封笔的自己可写不再报,客人不会对着封死的笔干等。等的圈子还是那四步,空收答的是 would-block,非阻塞的描述符答的是 EAGAIN,有信号候着答的是 EINTR,都不是的话就让位一圈,门是一行都没改的。

旗与错在这一章全是实打实的,咱们挨个念。MSG_DONTWAIT 管的是单次调用不陪等,描述符生来的阻塞位一个字不用动。MSG_NOSIGNAL 管的是断管的时候请安静。流式的对家整个走了之后再写,答出去的是 EPIPE,同一时刻十三号的信号 SIGPIPE 照递,除非客人递过了 MSG_NOSIGNAL。生面孔的旗答的是 EOPNOTSUPP,咱们不装懂。假文件与真终端那一卷里备着没挂的那对事件,errno 侧的 EPIPE 与信号侧的十三号,在套接字这扇门配成对落了地。管道那头没有这样的待遇,欠单上照旧挂着 EPIPE 与 SIGPIPE 的名。数据报寄给没人住的名字,答出去的是 ECONNREFUSED,不装成寄到了的样子。

名字跟着套接字的寿命,套接字一走的话,名字就从表上下来了,腾出来的位子给下一位,长凳上备了一案专考这个:听者走了,挂过这个名字的候补马上挂得上,原来领出来的人照样说话。盘上不会出现 socket 的文件,bind 过的名字在文件系统里照不出影子,您拿 ls 去盘里找,是找不到的,这不是咱们漏了,这一版本来就没把名字种进盘的打算,门内的名字住门内的表。SCM_RIGHTS 是没有的,那是隔着套接字把开着的描述符随信递给对家的本事。凭据的传递也没有,信上不自动署写信人的身份。欠单上记的就是这两样。

跑在机器里的探针,咱们让它把全套走了一遍。生来的对子上,空收答的是 EAGAIN,写下了五个字节,poll 应了一声可读,分两截读完了,封笔的一方读到零,另一方回写了一笔,封笔的照样收得着。挂名的听者从 bind 到 accept 走全,信从敲门的人手里递到领出来的新描述符。数据报的案子上放了两封隔界的信,读的格子只有一字节,头一封截剩的丢了,第二封照样送到了,界是没混的。长凳上另有一案玩的是真线程:两个真线程隔着一条生来的信道,一个按序发的是四千零九十六个字节,一个按序收齐了,这一案往后还要进带线程竞争检查的构建里跑,细节留给本卷的验收章点数。

咱们家里的设施齐了,客人、户口、布告栏、储物间、门内的传话,全都在了。可这满屋的家当,每一件都是手装的,该有一间作坊了,好让它们一条龙地装出来。
