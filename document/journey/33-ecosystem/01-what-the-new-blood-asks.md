# 头一件事:看新血要什么

盘上的世界要换血。这是上一卷收卷撂下的话,同一句里还揣着另外三件方向:动态的程序,一号进程的 init,一条命令从干净的树到 QEMU 里一台配得像样的系统。四件合到了一处,是把机器配成自己会长的系统。这一卷开了卷,咱们把单子对一遍,四件都得在这一卷里落地,排在头一件的就是换血。

为什么要换,动因是藏在下一卷的。再往后的路上,咱们要把编译器全家请进盘,让机器编自己的程序,而 GCC 全家喝的血是 glibc 的:这些现成的编译器,身子生在 glibc 的世界里,起手就得有 glibc 的解释器伺候。盘上如今的血统是 musl 一家,开门迎客那一卷请进来的静态 busybox,把后半场交给解释器那一卷跑通的 musl 动态程序,一直喝到了今天。血不对的话,客人就进不了门。所以换血排在头一件:盘上的 C 库血统从 musl 换成 glibc,解释器与 libc 是一起换的,musl 也就谢幕下盘了。

> 当年的板,笔者在这里交代一句。第一遍走到这一步的时候,拍的是三条:glibc 的兼容要改,工具链不是自己编的,musl 与 glibc 是在盘上共存的。重走的这一遍,前两条是照旧的,第三条换了,拍的是 glibc 统一,musl 是不带上盘的,换完了血之后盘上就只许剩一家。

咱们听着动静大,杠杆倒是早就埋下了。把后半场交给解释器那一卷立过一条中立:ELF 的程序头里有一栏 PT_INTERP,专门指名请的是哪位解释器,写的是谁,exec 装的就是谁,门是不挑客的。当年它给 musl 的解释器安了一个确定的家,如今同一扇门原样接待 glibc 的解释器,ld-linux 的名字直接写进 PT_INTERP。换血是不用改门的,这是咱们敢开工的底气。

动工之前咱们照例当一回侦察兵,把新血从头到尾地盘一遍,看它进门到底要什么。您八成会把嫌疑押在号位上,glibc 那么大一户人家,号位上要的菜怕是数不过来。真盘下来倒踏实了:号位面上真正缺座的,只有 pread64 这么一个,读的时候自带位置。要补的大头在四样。

头一样是落在情报桌上的。程序进门的时候,内核递到栈上的是一桌情报,把后半场交给解释器那一卷排了十四味,glibc 要在桌上见到它认的两味:AT_PLATFORM 报处理器平台的名字,AT_HWCAP 报硬件的本事。咱们那桌还停在十四味的老菜单上,该添了。

第二样在栈的户口上:栈要不要可执行,得由客人自己在程序头里申报了才算,申报用的栏就是 PT_GNU_STACK,咱们的 execve 至今不扫它,栈的执行位因此没有出处。glibc 那边按户口自报的章法来,没申报的按最严的办,栈默认是不可执行的,这栏户口咱们得学着接。

第三样是 brk 的上界。堆是往上长的,天花板画在哪儿就成了问题,glibc 的堆比 musl 那会儿长得高,当年为了它抬过一回,这一遍要不要抬的问题,到那一章咱们再交底。末一样是 vDSO:真内核会往每个程序的空间里映射自己的一小段代码,读钟一类的急事不用进门就能办。这层东西咱们登记不做,验收念欠单的时候,它的名字还在名单上。

吃法咱们也照例摸一遍。glibc 的动态程序进门要三件,您把桌面摆出来看:解释器 ld-linux-x86-64.so.2 住 /lib64,libc.so.6 住的是 /lib,再带上客人自己带来的二进制。座位跟当年 musl 的动态客人用的是同一张表,把后半场交给解释器那一卷排的座,礼数是照旧的,换的只是料。座还是老的那一批,坐上去的换成了 glibc 家的身子。

单子对完了,次序也排定了。走在头里的是内核的地基,exec 的装载、VMA 那本登记册、mmap 的语义,这些承重件得扛得住 glibc 的真实用法,后面几桩案子也都是从这一段里发的。地基夯实了是盘面,/lib 里剩下的就只有一家,客人挨个把考卷过了一遍,缺什么补什么。然后是一号座:内核直拉的壳退下去,init 的真身坐上来,咱们叫它当家的,开台办事照的是一张当班表。家里的设施跟在后头,盘的搬进搬出,两家共用的储物间,不出门的会客,咱们一样一样添。末了是作坊与开张,自家的一套组装脚本把内核、客人、盘一件件装齐,一条命令从干净的树到 QEMU 里一台可用系统,这一卷的收官大戏就是它。验收照旧殿后就是了。

新血的考卷发到咱们手里,发下来的一共是两份。头一份考情报桌的两味加栈的户口,下一章咱们交卷。第二份是压在后头的,考的是装库的 mmap 序列,解释器把库搬进内存的那一路手法,料是地基那一章备的。
