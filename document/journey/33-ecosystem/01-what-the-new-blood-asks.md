# 头一件事:看新血要什么

盘上的世界要换血。这是上一卷收卷撂下的话,同一句里还揣着另外三件方向:动态的程序,一号进程的 init,一条命令从干净的树到 QEMU 里一台配得像样的系统,合起来,是把机器配成自己会长的系统。这一卷开卷,咱们把单子对一遍,四件都得在这一卷里落地,排在头一件的就是换血。

为什么要换,动因藏在下一卷。再往后,咱们要把编译器全家请进盘,让机器编自己的程序,而 GCC 全家喝的血是 glibc 的:这些现成的编译器,身子生在 glibc 的世界里,起手就得有 glibc 的解释器伺候。盘上如今的血统是 musl 一家,开门迎客那一卷请进来的静态 busybox,把后半场交给解释器那一卷跑通的 musl 动态程序,一直喝到今天。血不对,客人就进不了门。所以换血排在头一件:盘上的 C 库血统从 musl 换成 glibc,解释器、libc 一起换,musl 谢幕下盘。

> 当年的板,笔者在这里交代一句。第一遍走到这一步,拍的是三条:glibc 的兼容要改,工具链不自己编,musl 与 glibc 在盘上共存。重走的这一遍,前两条照旧,第三条换了,glibc 统一,不带 musl,换完血盘上只许剩一家。

动静听着大,杠杆倒早就埋下了。把后半场交给解释器那一卷立过一条中立:ELF 的程序头里有一栏 PT_INTERP,专门指名请哪位解释器,写谁,exec 就装谁,门不挑客。当年它给 musl 的解释器安了一个确定的家,如今同一扇门原样接待 glibc 的解释器,ld-linux 的名字直接写进 PT_INTERP。换血不用改门,这是咱们敢开工的底气。

动工之前照例当一回侦察兵,咱们把新血从头到尾盘一遍,看它进门到底要什么。您八成会把嫌疑押在号位上,glibc 那么大一户人家,号位上要的菜怕是数不过来。真盘下来倒踏实了:号位面上真正缺座的,只有 pread64 一个,读的时候自带位置。要补的大头在四样。

头一样长在情报桌上。程序进门的时候,内核会往栈上递一桌情报,把后半场交给解释器那一卷排了十四味,glibc 要在桌上见到它认的两味:AT_PLATFORM 报处理器平台的名字,AT_HWCAP 报硬件的本事。咱们那桌还停在十四味的老菜单上,得添。

第二样在栈的户口上。栈要不要可执行,得由客人自己在程序头里申报,申报栏就是 PT_GNU_STACK,咱们的 execve 至今不扫它,栈的执行位因此没有出处。glibc 那边按户口自报的章法来,没申报的按最严的办,栈默认不可执行,这栏户口咱们得学着接。

第三样是 brk 的上界。堆往上长,天花板画在哪儿,glibc 的堆比 musl 那会儿长得高,当年为它抬过一回,这一遍要不要抬,到那一章再交底。末一样是 vDSO:真内核会往每个程序的空间里映射自己的一小段代码,读钟一类的急事不用进门就能办。这层东西咱们登记不做,验收念欠单的时候,它还在名单上。

吃法也照例摸一遍。glibc 的动态程序进门要三件,您把桌面摆出来看:解释器 ld-linux-x86-64.so.2 住 /lib64,libc.so.6 住 /lib,再带上客人自己那件二进制。座位跟当年 musl 的动态客人用的是同一张表,把后半场交给解释器那一卷排的座,礼数照旧,换的只是料。座还是那一批座,坐上去的换成了 glibc 家的身子。

单子对完,次序也排定了。走在头里的是内核的地基,exec 的装载、VMA 那本登记册、mmap 的语义,这些承重件得扛得住 glibc 的真实用法,后面几桩案子都从这一段里发。地基夯实了是盘面,/lib 里只剩一家,客人挨个点名,缺什么补什么。然后是一号座:内核直拉的壳退下去,init 的真身坐上来,咱们叫它当家的,开台照一张当班表办事。家里的设施跟在后头,盘的搬进搬出,两家共用的储物间,不出门的会客,一样一样添。末了是作坊与开张,自家的一套组装脚本把内核、客人、盘一件件装齐,一条命令从干净的树到 QEMU 里一台可用系统,这一卷的收官大戏就是它。验收照旧殿后。

新血的考卷发到咱们手里,一共两份。头一份考情报桌的两味加栈的户口,下一章交卷。第二份在后头,考的是装库的 mmap 序列,解释器把库搬进内存的那一路手法,地基那一章备料。
