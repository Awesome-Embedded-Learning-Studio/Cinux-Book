# 验收:换完的血与开好的张

收卷的章程照旧,面板、长凳、实弹、对单这四样的家底,咱们一样一样点,头一样就带着本卷的真新闻。面板的老几样照旧报着:两颗核是在线的,线是挂着的,回环是通着的,壳的提示符候着。行数咱们不逐一清点,这一卷的真新闻也不在行数上,在开机这出戏的戏本里。从前的开机,是内核直拉的一个壳。现在一号座上坐着当家的,按当班表开的台,开台那一声是当班表头一行说的,提示符是第二行拉起来的,兜底的是 respawn。Ctrl+C 把 sh 打断了,转眼提示符又回来了,就是当家的按表重拉了一回。倒了再起的戏码,这门兜底咱们这一卷头一回看见它真切地干活。监护人是守在旁边的,只保的是位子,家是不当的。

面板的新闻就一件,咱们报完了。

长凳四面咱们挨着面点。头一面 ELF 的画像案摆了十四案:auxv 那桌情报新添的两味各自在册,平台那味给的是 x86_64 字符串的指针,镜像里是没有它的,整味是不出场的,能力那味是恒出的,值给的是零。GNU 栈的两案进了门,执行位的户口是自报的,缺了头的镜像按默认不可执行守门。第二面 test_syscall_face:pread 的定位读,读完游标是不动的,负偏移是当场拒的。mmap 的 fixed 案也锚上了号位。第三面 test_vma 收的是二十七案:半覆盖的劈段留头留尾、堆里打洞后洞上的尾巴升格成自己的段,这两案是都在册的。第四面 test_vfs 收的是十三案,卸载的案在这一卷长齐。

首轮的完整验收,咱们照实报:宿主的四条线,普通、地址加泄漏的排查、线程竞争、内核检查构建,各七十九案全过了。机内的两套是普通构建与检查构建,二十一案里各过了二十。差的这一案在 test_vma,一桩旧断言还守着注销拒绝劈段的旧话,可注销早就能劈段了,断言写的却还是从前的老判法。您翻回占址重建那一章,能看见语义是在哪儿换的。断言按现在的真实行为改写,咱们复跑。

复跑下来的时候,两套各二十一案咱们看着它们全过了。

首轮那一遍不能记成整轮的通过,这一句咱们写在案上。顺带把章法点一句:咱们改断言不是放水,断言跟着真实的行为走。

实弹的排面,这一卷比往常的要厚,因为出的盘有三套:普通构建的是一套,检查构建的又是一套,第三套空了缓存,挪进了独立的空目录,从下载、校验到全量组装都从头走了一遍。三套演的是同一场戏,判据是一样的。glibc 的 hello 开口说话。用户 init 坐稳了一号座。十四位 applet 客人挨个点验了退出码,十四位是全过的。fstab 按表挂载了,tmpfs 的隔间搬进搬出,卸载的寿命连同延迟卸载与重挂一起验。储物间里的货跨过 fork 还在。门内的传话,流式与数据报的两型,连同 poll 也验了。RELRO 的收权也在判据里。三套是全过的。空缓存那一套最见成色:盘不是只在咱们自己的机器、自家的缓存里长得出来,换哪儿都开得了张。判据都是读者够得着的。作坊的那层薄壳,您敲 `bash user/rootfs/busybox/build.sh verify`,走的是非交互,判据到齐了才算过。全矩阵的老入口还是 `scripts/checks/acceptance.sh`。您把缓存清空、换个空目录再开一回张,走的就是那第三套的路。双核的实弹两套各来一遍:管道读到了收尾,两颗核上 fork 了九十六轮,盘上 busybox 的双核脚本压一场。键盘上 glibc 的冒烟也点了一行,是过的。

收尾的地方还有两件,只点的是数,是不展开成课的。头一件是 NVMe 的做实。这套与 AHCI 并列的盘协议,这一卷把它请了进门,做实到了什么份上,咱们点数:独立的一具控制器,namespace 是控制器底下划出的逻辑盘,admin 与 I/O 的两类队列,PRP 的散页清单,给 DMA 寻址用的,HPET 那口钟管的是超时,完成项是全字段校验的。当年第一遍在这儿留过一笔兜底:盘答的是 0x4080,LBA 出界加 DNR 置的是一,设备明说了这笔别再试,门里却把它当成功放过了。这一遍兜底踢掉了,负例来敲的时候,当场拒了它。二十轮的写读、队列绕回、还原、flush,三套镜像里各跑了一遍。练手的场子全在副库房那块 scratch 盘上,新协议是头一回上路的,货是不押真盘的,根盘还是 AHCI 的老司机。错误的身份或者超时,就把控制器隔离了,DMA 可能触及的页,一页是不释放的。另一件咱们叫它查岗的双眼。线程的那双眼是 TSan,专抓两个线程抢一处数据的竞态,考场设在门内传话的套接字上,宿主里两个真线程对传了四千零九十六字节,这一案是真跑的。内核的那双眼是 UBSan 加 lockdep,一个抓的是未定义行为,一个盯加锁的次序,一路是开着的。咱们把话说实,只宣称覆盖到的路径,不冒称完整的竞态检测器。验收的工具自己也修了两处,KVM 是串行跑的,遇了错就退,记了一笔就走。

然后咱们对单,这一卷照旧是对着两份来的。头一份是当年的:init 作一号座的旧话,划掉了。动态的 busybox,划掉了,咱们注一笔,当年笔者装上盘的那具动态身子,流的是 musl 的血,busybox 换 glibc 的血是重走这一遍多做的一步,单子按今天的口径还。批发式的内核面补全,划掉了,当年是几天连着打完的,这一遍摊成了一整卷按件消化。NVMe 的旧欠,划掉了,当年是兜底的,这一遍做的是真。第二份是上一卷收卷时撂的四件方向:盘上世界的换血,兑现了,/lib 里剩下的只有 glibc 一家。动态的程序,兑现了,glibc 的 hello 与整具 busybox 都上过桌。init 作一号进程的旧话,兑现了,一号座上坐的是真身。一条命令从干净的树到 QEMU 里一台配得像样的系统,兑现了,上一章开张那天验的。卷里自己挂的两笔也收了口:占址重建那一章撂的 protect 连坐观察项,收权学会劈段那一章还上了。/lib 只剩一家那一章留的两模式口径,作坊那一章把默认翻了过来。

续欠的名单咱们照旧念名,从大的起。PIE 与基址随机化的旧欠,位置无关的身子至今没有座,转给了下一卷,下一卷要用的进路,这一卷已经垫在作坊里了:烤 busybox 的配置中,编译与链接两面 PIE 的旗各立一行,开关都攥在了手里。任务睡进自己的上下文、拿令牌唤醒,还是照旧的。套接字的门把 EPIPE 落了地,管道那头的 EPIPE 与 SIGPIPE 照旧挂名。门内的传话没有跨门递描述符的 SCM_RIGHTS,凭据的传递也没有。储物间的管理动作只认 IPC_STAT 与 IPC_RMID 两样,容量是至多十六段、每段一 MiB 的教学尺寸。vDSO 是显式不做的。网络的旧欠是拥塞、v6、分片这三样,咱们照旧念名。欠的都挂在明处,一笔没有暗的。

收官的路,方向咱们点一下,是不展开的。机器如今会认人、会开机、也会自己烤出一张盘了,可还不会自己编自己的程序,也还没把自己的脸露出来。下一卷咱们把编译器全家请进作坊,机器编的是自己。收官那一卷咱们给机器一张脸,当班表上的行还要添,run_gui 门后上的是人。发版的那一摊,排在更后面的地方,一句话带过也就是了。验收的数字点完,咱们在这里收卷。
