# 验收:换完的血与开好的张

收卷的章程照旧,面板、长凳、实弹、对单,咱们一样一样点,头一样就带着本卷的真新闻。面板的老几样照旧报着:两颗核在线,线挂着,回环通着,壳的提示符候着。行数咱们不逐一清点,这一卷的真新闻也不在行数上,在开机这出戏的戏本里。从前开机,是内核直拉一个壳。现在一号座上坐着当家的,按当班表开台,开台那一声是当班表头一行说的,提示符是第二行拉起来的,respawn 兜底。Ctrl+C 把 sh 打断,转眼提示符又回来,就是当家的按表重拉了一回。倒了再起,这门兜底咱们这一卷头一回看见它真切地干活。监护人守在旁边,只保位子,不当家。

面板的新闻就一件,咱们报完了。

长凳四面,咱们挨着面点。头一面 ELF 的画像案,十四案:auxv 那桌情报新添的两味各自在册,平台那味给的是 x86_64 字符串的指针,镜像里没有它,整味不出场,能力那味恒出、值是零。GNU 栈两案进门,执行位户口自报,缺了头的镜像按默认不可执行守门。第二面 test_syscall_face:pread 的定位读,读完游标不动,负偏移当场拒。mmap 的 fixed 案也锚上了号位。第三面 test_vma 二十七案,半覆盖的劈段留头留尾、堆里打洞后洞上的尾巴升格成自己的段,两案都在册。第四面 test_vfs 十三案,卸载的案在这一卷长齐。

首轮完整验收,咱们照实报:宿主四条线,普通、地址加泄漏的排查、线程竞争、内核检查构建,各七十九案全过。机内两套,普通构建与检查构建,二十一案里各过了二十。差的这一案在 test_vma,一桩旧断言还守着注销拒绝劈段的旧话,可注销早就能劈段了,断言写的却还是从前的老判法。您翻回占址重建那一章,能看见语义是在哪儿换的。断言按现在的真实行为改写,复跑。

复跑下来,两套各二十一案,咱们看着它全过。

首轮那一遍不能记成整轮通过,这一句咱们写在案上。顺带把章法点一句:改断言不是放水,断言跟着真实的行为走。

实弹的排面,这一卷比往常厚,因为出的盘有三套:普通构建一套,检查构建一套,第三套空了缓存、挪进独立的空目录,从下载、校验到全量组装从头走一遍。三套同一场戏,判据一样。glibc 的 hello 开口说话。用户 init 坐稳一号座。十四位 applet 客人挨个点验退出码,十四位全过。fstab 按表挂载,tmpfs 的隔间搬进搬出,卸载的寿命连同延迟卸载与重挂一起验。储物间里的货跨过 fork 还在。门内的传话,流式与数据报两型,连同 poll。RELRO 的收权也在判据里。三套全过。空缓存那一套最见成色:盘不是只在咱们自己的机器、自家的缓存里长得出来,换哪儿都能重新开张。判据都是读者够得着的。作坊那层薄壳,敲 `bash user/rootfs/busybox/build.sh verify`,非交互,判据到齐才算过。全矩阵的老入口还是 `scripts/checks/acceptance.sh`。您把缓存清空、换个空目录再开一回张,走的就是那第三套的路。双核的实弹两套各来一遍:管道读到收尾,两颗核上 fork 九十六轮,盘上 busybox 的双核脚本压一场。键盘上 glibc 的冒烟也点一行,过。

收尾还有两件,只点数,不展开成课。头一件是 NVMe 做实。这套与 AHCI 并列的盘协议,这一卷把它请进门,做实到什么份上,咱们点数:独立控制器,namespace 是控制器底下划出的逻辑盘,admin 与 I/O 两类队列,PRP 的散页清单,DMA 寻址用,HPET 那口钟管超时,完成项全字段校验。当年第一遍在这儿留过一笔兜底:盘答 0x4080,LBA 出界加 DNR 置一,设备明说这笔别再试,门里却把它当成功放过了。这一遍兜底踢掉,负例来敲,当场拒。二十轮写读、队列绕回、还原、flush,三套镜像里各跑了一遍。练手的场子全在副库房那块 scratch 盘上,新协议头一回上路,货不押真盘,根盘还是 AHCI 的老司机。错误的身份或者超时,就把控制器隔离,DMA 可能触及的页,一页不释放。另一件咱们叫它查岗的双眼。线程那双眼是 TSan,专抓两个线程抢一处数据的竞态,考场设在门内传话的套接字上,宿主里两个真线程对传四千零九十六字节,这一案是真跑的。内核那双眼是 UBSan 加 lockdep,一个抓未定义行为,一个盯加锁的次序,一路开着。咱们把话说实,只宣称覆盖到的路径,不冒称完整的竞态检测器。验收的工具自己也修了两处,KVM 串行跑,遇错即退,记一笔就走。

然后对单,这一卷照旧对着两份来。头一份是当年的:init 作一号座,划掉。动态 busybox,划掉,注一笔,当年笔者装上盘的那具动态身子,流的是 musl 的血,busybox 换 glibc 的血是重走这一遍多做的一步,单子按今天的口径还。批发式的内核面补全,划掉,当年几天连着打完,这一遍摊成一整卷按件消化。NVMe,划掉,当年兜底,这一遍做真。第二份是上一卷收卷时撂的四件方向:盘上世界换血,兑现,/lib 里只剩 glibc 一家。动态的程序,兑现,glibc 的 hello 与整具 busybox 都上过桌。init 作一号进程,兑现,一号座上是真身。一条命令从干净的树到 QEMU 里一台配得像样的系统,兑现,上一章开张那天验的。卷里自己挂的两笔也收了口:占址重建那一章撂的 protect 连坐观察项,收权学会劈段那一章还上了。/lib 只剩一家那一章留的两模式口径,作坊那一章把默认翻了过来。

续欠的名单咱们照旧念名,从大的起。PIE 与基址随机化,位置无关的身子至今没有座,转给下一卷,下一卷要用的进路,这一卷已经垫在作坊里:烤 busybox 的配置中,编译与链接两面 PIE 的旗各立一行,开关都攥在手里。任务睡进自己的上下文、拿令牌唤醒,照旧。套接字的门把 EPIPE 落了地,管道那头 EPIPE 与 SIGPIPE 照旧挂名。门内的传话没有跨门递描述符的 SCM_RIGHTS,没有凭据传递。储物间的管理动作只认 IPC_STAT 与 IPC_RMID 两样,最多十六段、每段一 MiB,教学尺寸。vDSO 显式不做。网络的旧欠,拥塞、v6、分片,照旧念名。欠的都挂在明处,一笔没有暗的。

收官的路,方向点一下,不展开。机器如今会认人、会开机、会自己长出一张盘,可还不会自己编自己,也还没露出脸。下一卷把编译器全家请进作坊,机器编自己。收官那一卷给机器一张脸,当班表上添行,run_gui 门后上人。发版那一摊,排在更后面,一句话带过。验收的数字点完,咱们在这里收卷。
