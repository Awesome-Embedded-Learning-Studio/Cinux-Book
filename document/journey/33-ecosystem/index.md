# 盘上换血:一家 glibc、一号当家人与一条命令的开张(卷名草稿)

上一卷收卷的时候,话撂得具体:盘上的世界要换血,动态的程序要进门,init 要坐一号进程的座,还有一条要走的命令,要从干净的树一直走到 QEMU 里一台配得像样的系统。四件方向合到了一处,是把机器配成自己会长的系统。这一卷开了卷,咱们把单子对一遍,四件都得在这一卷里落地。网络四部在上一卷收了摊,收官前的路咱们分三卷走:这一卷把别人家的血与人口请进自家的盘,机器头一回由当家的自己开机。下一卷在自家的盘上装下工具链,机器编自己的程序。末一卷给机器一张自己的桌面。头一程走的是安家,不过家不安稳,后面两卷连落脚的地方都没有。

次序咱们照新血的脾气排。换血的事排在头一件,它的头一步却落在内核的地基里:glibc 进门的时候,也就到了给情报桌添味的时候,栈的户口要改成自报,装库的手法要换成替换语义,桩桩都是内核的活,后面几桩案子也都是从这一段里发的。地基夯实了才轮到盘面,盘面上 /lib 里剩下的就只有一家,客人挨个重考一遍当年的卷子。盘面齐了,一号座上换的是真身,当家的照一张当班表开台。当家的坐镇了,家里添的设施一共三件:搬进搬出是一件,共家的储物间是一件,门内的传话又是一件,咱们一样一样来。设施齐了,作坊也开了张,一条命令从干净的树直达开机的机器。验收照旧殿后就是了。

咱们照例盘家底。手里有的:网络四部攒下的整套,两颗核是在线的,线是挂着的,回环是通着的,壳的提示符也候着。把后半场交给解释器那一卷立的 ELF 动态整套,门对解释器是中立的,解释器有一个确定的家,情报桌已经齐了十四味。开门迎客那一卷请进来的 musl 客人,静态与动态两路都是能跑的。假文件与真终端那一卷立的描述符表与文件外衣还在,挂载表上摆了八座,ext2 占的是根,头三号是真的座。懒到家那一卷的登记册带齐了 mmap、munmap、mprotect、brk 四号,浮点的闸门也在,安全那一卷的写与执行分家也在,进程那些卷的 fork、exec 与收尸也在,线程那一卷的共享世界也在,双核是现成的,块层与请求队列也是齐的,ext2 的读写是通的,procfs 与 devfs 的骨架立着,TTY 的行规程在位,信号也备好了。缺的也一片一片数:glibc 的兼容面一件都没有,MAP_FIXED 的替换语义没有,注销的动作也只会整段连坐。盘上还没有 /etc 的家,户口本的影子也没有。一号座上还是内核自家的监护线程,壳是它直拉的孩子。mount 与 umount2 的号位还空着,tmpfs 还没有自己的座,SysV 的共享内存没有,AF_UNIX 的套接字也没有。造盘靠的是手敲一串命令,作坊是连影子都没有的。缺的件件都得这一卷自己补起来。

咱们进站时,机器的面板与上一卷出门时一个样:两颗核是在线的,泵是常摇着的,线是挂着的,回环是通着的,壳的提示符也候着。出站的时候,老几样报的数照旧,这一卷的真新闻得往开机这出戏的戏本里找:从前是内核直拉一个壳,现在一号座上坐着当家的,开台照的是当班表,开台那一声是表上头一行说的,提示符是第二行拉起来的,壳倒了有人按表再拉。报数报在长凳与实弹里:长凳摆了四面,宿主的四条线各七十九案,机内的两套各二十一案。实弹出了三套镜像,普通的一套、检查的一套、空缓存挪新目录的一套,判据是一样的,十四位客人挨个交了退出码,十四位都过了,空缓存的那套最见成色,换了哪儿都能重新开张。

这一卷的活,咱们摊开报数。开卷看的是血,动因是压在下一卷的,杠杆是门对解释器的中立,咱们侦察下来,号位上欠的只有 pread64 一个座,要补的大头在四样。头一份考卷跟着交:情报桌添到了十六味,一味的值是 x86_64 的指针,另一味的值恒是零,栈的户口改成自报,缺了头就默认不可执行,pread 读了不算走过。地基的重头是占址重建,三验过后出场的才是替换语义,注销学会了劈段,头尾都留了下来,文件偏移一字不差地随迁。新语义头一场冒烟就翻出案子:musl 往堆里砌的护页把堆尾砍得失管,打洞留段的修法结了案。glibc 的 hello 起动即死,rip 指着一条要整格的 movaps,入口栈对齐到了 0x200,自家的程序垫上 start.S,连着后继的 RUNPATH 与 mmap 两案,三修进了门。收权也学会了劈段,RELRO 的中段收权不再连坐,浮点的旧债同场销了案。地基夯实了轮到盘面:busybox 翻三个开关换了血,musl 就此谢了幕,盘从 16M 扩到了 64M。十四位客人拿当年的考卷重考,环境件也立了名,布告栏补齐 /proc 的 mounts 与 uptime,重考的这一遍全过了。然后就轮到一号座:当班表写的是两行,值夜的假铃恒答 EAGAIN 不入眠,用户态的 init 坐进一号,守在旁边的监护人只保位子,孤儿归当家的收。reboot 的旧案在实弹头一响里翻出。设施三件挨个开张:搬进搬出带着四间认门槛的临时隔间,真 glibc 的 umount 一敲就抓出读反的座次。共家的储物间钥匙与货分家,fork 共到的是同一张页。AF_UNIX 的门内传话不出门,socketpair 是生来成对的。末了是作坊与开张:三层货一本进料册,料不变的时候就不出新货,作坊进了构建图,三扇门认的是盘,一条命令从干净的树走到 QEMU 里一台可用的系统,盘上剩下的是 glibc 一家。验收照旧殿后就是了,案卷都收好了。

当年的旧话交代。当年的这一段,是几天里连着打完的:init、盘上的动态 busybox、批发式的内核面补全、NVMe,都挤在同一段日子里完成的,重走的这一遍把它摊成一整卷,一件一件地消化。有两笔咱们如实记下:当年装上盘的那具动态 busybox,流的是 musl 的血,busybox 换 glibc 的血是这一遍多做的一步,当年是还没有这笔判例的。开门迎客那一卷请进来的客人,身份是不变的,变的是血,那几卷的叙事一个字不改写。取舍还是老尺子:能解释今天手里这套机制的进正文,在它该在的那一章把来龙去脉摆开,只作反面教材的,收敛地讲。
