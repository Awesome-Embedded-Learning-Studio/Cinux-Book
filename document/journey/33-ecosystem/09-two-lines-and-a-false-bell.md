# 当班表两行与值夜的假铃

盘上 /etc 里躺着一粒一直没动过的种子:/etc/inittab。换血那天它跟着户口本一家一起上了盘,其实统共就两行,咱们今天开读,原样摆出来给大家看:

```text
::sysinit:/bin/echo Cinux up
console::respawn:/bin/sh
```

行话里的名字是 inittab,咱们这一卷叫它当班表:将来坐在一号座上的当家的照它开台,开机头一件事做什么,谁退了场谁负责再拉起来。一号座就是头一个进程的座位,这一卷报数里念了一路的位置。两行的形状不是新发明,当年第一遍开台的时候,笔者靠的就是它。咱们照着读。冒号把每行切成了几栏,要认三样:打头的前台,中间的动作,末尾跑什么。第一行的前台空着,什么都没挑,动作写的是 sysinit,开机头一回跑一遍就算完了,跑的是 echo,让机器开口报了一句 Cinux up。第二行的动作是 respawn,倒了再起:跑的是壳,壳哪天一口气没接住退了场,当家的再拉它一回,退了再拉,提示符底下永远有人候着您。打头那个 console 咱们单独记一笔:前台是谁由它说了算,当家的照它打开 /dev/console,壳的说话声走真控制台的代理。

读表的身子,盘上也已经备下了。烤盘的脚本把 busybox 写进 /bin 之后,又给它在 /sbin 里挂了一根硬链,init 这个名字与 /bin/busybox 挂的是同一个 inode,身子当然也是同一具。busybox 的本行就是一身多角:进门头一件事,看自己被叫成了什么名字。argv[0] 里写的是 /bin/sh,它演的就是壳,开门迎客那一卷咱们见识过这套老章法,那会儿它就靠读 argv[0] 认下自己的角色。哪天内核递出去的名字换成 /sbin/init,同一具身子转身就演当家的:开台、读表、拉壳、收孩子,全是它的活。当家的不请新程序,老熟人换个名字进场也就是了。咱们眼里它始终是同一个身子,演什么戏全看名字,一根硬链就够用了。

真开台了以后,当家的日常里有一半是守夜:孩子退了场要收,信号递进来了要接。它问话敲的门叫 rt_sigtimedwait,这一号在号位表上是从前没有的,这一卷咱们把它补上。号定的是 128。咱们头一回记岔了,记成了 280。好在咱们的北极星一直挂着。下楼开张那一卷立下的是三条:编号、寄存器、负 errno。头一条就是号照人家的表,当场拿系统的 SYS_rt_sigtimedwait 一对:人家表上是 128,咱们记的 280 对不上,咱们就照实测改。长凳上还留了一行断言替咱们看着:

```cpp
static_assert(static_cast<int>(cinux::syscall::SyscallNr::kRtSigtimedwait) == SYS_rt_sigtimedwait);
```

咱们要是哪天再记岔,长凳上的断言连编译都不给过。这一手还是跟人家学的,glibc 自己的头文件里就拿 static_assert 守着这个号,咱们的断言与它同一个意思。

门挂了号,答的法子才是正题。当年第一遍的时候,笔者在这儿立下的是防死锁的判例,这一遍原样继承了下来。处理函数的全部就这几行:

```cpp
long long HandleRtSigtimedwait(const SyscallFrame& /*frame*/) {
    return -kEagain;
}
```

参数是一个都不读的,谁来问都答的是同一句。kEagain 的值是 11,它的意思是现在没有,来问的回头再来就是了。号位表里给它配的英文批注就五个词:`answered try-again, never parked`,答了就走,其实从不留人过夜。咱们管这叫值夜人手里的假铃:摇就响,响完了就放人,能靠它睡过去的人到现在还没有。它是睡不得的。来问话的,是一号座上的当家人,机器里没爹的孩子全归它收,它要是睡进一扇没人看守的门,叫醒的路又还没修,开机的头一件事就成了全家干等一个人,死锁是这么来的。所以门只管答,答完了就请回,值夜的接着巡夜,收尸的活照干。真睡的手艺,机器欠到了现在:TCP 完备那一卷收卷时挂的名,任务睡进自己的上下文、令牌唤醒,咱们记的原样都在列。这扇门今天给不出咱们要的真等,给得出的是那声从当年第一遍响到今天的假铃。

长凳上咱们给这扇门立一案,案名起的就是一句判词:`sigtimedwait answers try-again without parking`。断言咱们只写一行:

```cpp
ASSERT_EQ(cinux::syscall::HandleRtSigtimedwait(kFrame), -11);
```

您贴着看这个负号。EAGAIN 的号就是 11,负号是北极星的第三条,错了就拿负数答。而编号与负 errno 是两条北极星,咱们让它们在同一行断言里各站一头,一条落在了号上,一条落在了答话的符号上。

当家的开台要的家什不止一扇门,好在剩下的全是旧相识,咱们只把名字报一遍:vfork,开门迎客那一卷挂的号,按普通 fork 的路数办,起孩子的老路照走。reboot 在认字那一卷就连同 getcwd、chdir 一起同了号,当家的关机走现成的门。收尸的家法,生与收那一卷立的,孩子退了场有人接。console 的前台,当班表第二行打头已经把它安顿好了。这些判例件前几卷都齐了,这一卷咱们不重做。

当班表躺在盘上的老地方,/sbin/init 的名字挂在硬链上,问话的门答得上话,判例件咱们点过了,一件缺的都没有。可一号座还是内核自家的监护线程,壳是它直拉的孩子,壳是不读当班表的,倒了再起的兜底也还没交到咱们手里。
