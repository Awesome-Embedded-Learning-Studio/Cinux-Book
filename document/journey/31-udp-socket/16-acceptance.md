# 验收:客人自己的成绩单

收卷的章程照旧,咱们点的还是面板、测试、实弹三样。面板这一卷有句实话:一行没动。进站时长什么样,出站时还长什么样,两颗核在线,壳的提示符候着。前头几卷的报数报在开机的面板上,这一卷的正主是客人,报数就活在壳的命令行上,敲一条,验一条。您开机进壳,这一卷的每一笔都能亲手重敲一遍。

实弹的清单咱们照收官那天的排面报。三幕大戏打头:三发 ping 两秒窗,回音行、总数行、提示符三样断言守住。一秒窗敲一个不应的地址,零收的数落屏。不限发数的 ping 一声 Ctrl+C,统计与提示符落屏。配角挨个过:终端的行读与伪终端的录案,管道的前后手,后台的睡眠与等待,/proc/net/dev 的两行十六个零,ifconfig 的五行户口,nslookup 的三行应答。压轴的是两颗核上的两场压测:一场跑自家的 smpstress,两颗核上 fork 九十六轮,管道读到收尾。一场拿盘上的 busybox 跑压测脚本。断言守的是两场的落款,外加全场的串口里没有一声事故的标记。宿主侧的长凳同一天也全过了:词书的门、端口表的座、环的纪律、门的翻译、钟的换算、表的原子、名册的答话,案案过。

验收的数字,咱们也照收官那天的记录报。四条配置线各跑各的:普通的一条,宿主侧交了七十六项,机器侧交了二十一项,合起来的九十七项全数过了。地址越界、未定义行为加泄漏三查的一条,过了七十六。线程竞争检查的一条,也过了七十六。内核侧锁序图加未定义的一条,过了七十六加二十一。静态检查的边界也照实写一笔:format 过了,tidy 的告警没有清零,剩的是工具链对标准库头的解析、命名上的取舍与复杂度的存量,运行的四条配置线全过,不等于静态的那一关也过。章程在,记录在,读者照着跑,得到的应当同款。

对卷首的承诺,咱们逐项过。客人摸清了,七位客人的吃法挨个记全,活分了四摞。号位生齐了,十四个一次挂上,门一行没改,四十六、四十七空着不装。UDP 入座了,词书补了条目,三重门立了,伪首部当了反码和分段累加的头一个主顾,算出零发全一落了地。端口表开张了,八个座,短命号码跟人家对齐。家族立了,环起了,借来的帧在锁内抄成自家的,满了丢客记一笔。sockaddr 的礼数立了,bind 三条,connect 只是记名,write 走记名的路,出参的出参两层交代。等的门道立了,一圈四步,EINTR 把超时与打断都接住。钟立了,三扇门,相位前移,错过的拍子并一声。表把座攥住了,引用计数进门,善后出锁,蹦床按 ABI 补了承诺。控制台自己活了,泵常驻,字节三有了来路。裸通道开了,哨位连头交货,回环上两份收货入了判例。大戏唱了,客人自己站着唱完。残案结了,入口的画面背对背,块读按页截短。名册答了话,字节序的案子屏幕自己卖了自己。答话人到了,UDP 全家当着真服务器的面验了成色。一件不落地交齐了。

边界咱们照旧挂明处,这一卷欠下的从大的念起。两笔从点亮网卡那一卷撂过来的防线,咱们这一卷还是没还上,如实地登记在案:头一笔还是头的声明对缓冲的核对,头说自己六十个字节、缓冲里只躺着二十的截断包,今天照样一路走到校验的那一步,校验和会读到界外的字。第二笔还是应答缓冲的入站边界,一千四百八十是自家出站的章法,线上来的消息可以更胖,回声的抄写差着那么几个字节。这两笔比上一卷又重了一层:上一卷线刚接上,这一卷线上的客货真的多起来了,ping 的应答、DNS 的回包,天天在路上走,防线没落的路,走的人越多越悬。别的欠照旧念一遍名字:IPv4 仍不分片,中断驱动仍是登记远期的,发送的回写仍不读。可打断的真睡、软超时、唤醒的令牌,整包排在下一卷。旋钮那排点头的,实数也排在往后。欠的都挂在明处,一笔没有暗的。

合卷点数咱们只报数:号位十四,errno 的新词十二,判案判例几桩,残案一桩,客人七位,验过成色的三位。往前的戏排在第四部,正主是 TCP 的完备:流式的成员坐进家族,SOCK_STREAM 从诚实拒变成真门,listen 与 accept 背后那套机制立起来,真睡与软超时同场开张。两笔防线,也该在那之前落地。验收的数字点完,咱们在这里收卷。
