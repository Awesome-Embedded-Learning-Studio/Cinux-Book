# 表攥住座,栈守住承诺

等的门道那一章立的门有个新姿势:任务会在里头坐很久。裸阻塞的 recvfrom,包不来一圈一圈地让位,一圈就是一段不短的光阴。这段光阴里,同进程的另一条路完全可能喊一声 close,或者拿 dup2 把这个座顶掉。表要是只借出不计数,座被撤的那一刻,背后那个套接字跟着析构,而门里的调用者还攥着它的指针在圈里转,收环没了,锁没了,下一圈 receive 踩的就是空地址。这笔欠在管道那些快的门上不显眼,阻塞的 socket 门一来,咱们就得还了。

表发的不是指针,是攥得住的引用。咱们把表进出的那套锁抄来看:

```cpp
void FileTable::TablePolicy::enter(State& state) {
    state.irq = arch::SaveAndDisableIrq();
    state.table.gate_.lock();
}

void FileTable::TablePolicy::exit(State& state) {
    state.table.gate_.unlock();
    arch::RestoreIrq(state.irq);
}
```

进门的章程是抢停加锁,一步到位,咱们看着临界区就放心:表是全进程共用的,任何核上都可能有人来动它,中断也挡在外面,临界区小,挡得起的。发引用的路口在这把锁里:按号找座,找着了,把座上的 Shared 拷一份递给调用者,拷贝就是计数,计数在锁内完成,出到锁外,对象的生命已经攥在调用者手里,表里那座撤与不撤,都动不了它。门的等待圈从头到尾攥着递出来的引用,套接字活着,环活着,收多少圈都踩不空。

撤座的那一路同样有讲究,咱们看 close_all:

```cpp
void FileTable::close_all() {
    base::Shared<OpenFile> held[kFileTableMax];
    {
        const TableGuard kGuard(*this);
        for (unsigned long descriptor = 0; descriptor < kFileTableMax; ++descriptor) {
            held[descriptor] = detach_locked(descriptor);
        }
    }
}
```

十六个座,一把锁,咱们一遍走完:每座把 Shared 挪进局部数组,座上清空,cloexec 的位顺手抹掉。锁一放,数组出作用域,引用一份一份落下去,该析构的析构,该放的放,善后全在锁外办。free 与 close_on_exec 同款:锁内只做挪,锁外才做放。alloc 反着来:查空座拿一把锁,真造 OpenFile 在锁外,造好了再拿锁落座,造对象可能慢,慢活不占着表的锁。dup2 的原子性在次序上:验源座在前,动目标在后,拿不到引用就答错,目标座一根毫毛不动。验过了才在同一把锁里换座,客人要么看到旧目标还好好的,要么看到新目标已经坐稳,中间态不存在。fork 的快照一遍走完:源表一把锁,逐座拷引用进新表,两个表从此各是各的,爹关爹的,儿子关儿子的。

两句诚实的话,咱们跟着入册。头一句,表锁是叶子锁:锁内不碰任何后端的锁,不问文件系统,不问设备,套接字的环锁也不在它的锁内碰。别的路径可以拿着后端的锁再来拿表锁,反着来没有。第二句,表自己这把锁走的是自家的一套锁法,不在锁序的册上登记,锁序图里看不见它,如实记下,留给往后的检查点。

这一卷的实弹还顺手清了另一笔旧欠,长在栈上。任务退场的时候,退出路径要走 close_all,close_all 要在退出栈上摆那个十六格的 Shared 数组。数组一摆,编译器生成的代码里出现了对齐的向量存取,movdqa,十六字节对齐差一点都不行。任务蹦床的栈,偏偏在那一刻没对齐,机器一口保护异常回绝了。根子不在数组,在蹦床的收尾:当年退出钩子用的是 jmp,蹦过去就没人回来了,钩子里调用的编译代码,都以为自己是被 call 叫进来的。机器的 ABI 在每次调用进门那一刻,对栈有一句对齐的承诺,调用指令压了返回地址,栈就差八个字节,编译器全指着这句承诺排布局部变量。jmp 不压返回地址,承诺从第一声起就是空的,只是多年没人摆对齐的数组,空承诺一直没被踩出来。修法咱们贴着原文抄,就两行:

```asm
TaskTrampoline:
    sti
    call *%r12
    call *%r13
    ud2
```

钩子改用 call 叫,承诺当场兑现,栈对齐了。钩子办完事本不该回来,真回来了一声 ud2 当场停机,不叫它带着糊涂栈往下走。这个修法有一股熟悉的味:用户入口的栈当年也为同一句承诺对齐过,那笔学费,生与收那一卷埋的,懒到家那一卷还的,交的就是这八字节。门的承诺要么兑现要么明说,拿编译开关把向量指令禁了糊过去,是咱们不取的路:伤好了一半,承诺还是空的,下一回别的对齐踩出来,又是从零查起。
