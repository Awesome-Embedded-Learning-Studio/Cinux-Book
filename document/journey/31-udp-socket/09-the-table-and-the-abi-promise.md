# 表攥住座,栈守住承诺

等的门道那一章立的门有个新姿势:任务会在里头坐很久。裸阻塞的 recvfrom,包不来一圈一圈地让位,一圈就是一段不短的光阴。这段光阴里同进程的另一条路完全可能喊一声 close,或者拿 dup2 把这个座顶掉的。表要是只借出而不计数,座被撤的那一刻,背后那个套接字就跟着析构了,而门里的调用者还攥着它的指针在圈里转,收环没了,锁没了,下一圈 receive 踩的就是空地址。这笔欠在管道那些快的门上不显眼,阻塞的 socket 门一来,咱们就得还了。

表发的不是指针,是攥得住的引用。咱们把表进出的那套锁抄来看:

```cpp
void FileTable::TablePolicy::enter(State& state) {
    state.irq = arch::SaveAndDisableIrq();
    state.table.gate_.lock();
}

void FileTable::TablePolicy::exit(State& state) {
    state.table.gate_.unlock();
    arch::RestoreIrq(state.irq);
}
```

进门的章程是抢停加锁,一步就到了位,咱们看着临界区就放心:表是全进程共用的,任何核上都可能有人来动它的,中断也是挡在外面的,临界区是小的,挡得起的。发引用的路口在这把锁里:按号找座,找着了,把座上的 Shared 拷一份递给调用者,拷贝的那一下就是计数,计数是在锁内完成的,出了锁,对象的生命已经攥在调用者手里,表里那座撤了还是不撤,都动不了它。门的等待圈从头到尾攥着递出来的引用,套接字是活着的,环也是活着的,收多少圈都是踩不空的。

撤座的那一路同样有讲究,咱们看 close_all:

```cpp
void FileTable::close_all() {
    base::Shared<OpenFile> held[kFileTableMax];
    {
        const TableGuard kGuard(*this);
        for (unsigned long descriptor = 0; descriptor < kFileTableMax; ++descriptor) {
            held[descriptor] = detach_locked(descriptor);
        }
    }
}
```

十六个座配的是一把锁,咱们一遍走完:每座把 Shared 挪进局部数组,座上就清空了,cloexec 的位顺手抹掉。锁一放数组就出了作用域,引用一份一份地落下去,该析构的析构,该放的放,善后是全在锁外办的。free 与 close_on_exec 走同款的章程:锁内做的只是挪,锁外做的才是放。alloc 是反着来的:查空座的时候拿一把锁,真造 OpenFile 是在锁外的,造好了再拿锁落座,造对象可能是慢的,慢活不占着表的锁。dup2 的原子性在次序上:验的是源座在前,动的是目标在后,拿不到引用的话就答错,目标座是一根毫毛都不动的。验过了才在同一把锁里换座,客人要么看到旧目标还好好的,要么看到新目标已经坐稳了,中间态是不存在的。fork 的快照一遍走完:源表一把锁,逐座地拷引用进新表,两个表从此各是各的,爹关爹的,儿子关儿子的。

两句诚实的话,咱们跟着入册。头一句咱们说表锁,表锁是叶子锁:锁内不碰任何后端的锁,咱们不问文件系统与设备,套接字的环锁也不在它的锁内碰。别的路径可以拿着后端的锁再来拿表锁,反着来的是没有的。第二句说的是登记,表自己这把锁走的是自家的一套锁法,不在锁序的册上登记,锁序图里是看不见它的,如实地记下,留给的是往后的检查点。

这一卷的实弹还顺手清了另一笔旧欠,是长在栈上的。任务退场的时候,退出的路径要走 close_all,close_all 要在退出栈上摆那个十六格的 Shared 数组。数组一摆编译器生成的代码里就出现了对齐的向量存取 movdqa,十六字节对齐是差一点都不行的。任务蹦床的栈,偏偏在那一刻没对齐,机器一口保护异常回绝了。根子不在数组而在蹦床的收尾:当年退出钩子用的是 jmp,蹦过去就没人回来了,钩子里调用的编译代码,都以为自己是被 call 叫进来的。机器的 ABI 在每次调用进门的那一刻,对栈有一句对齐的承诺,调用指令压了返回地址,栈就差了八个字节,编译器排的是局部变量,全指着的是这句承诺。jmp 是不压返回地址的,承诺从第一声起就是空的,只是多年没人摆对齐的数组,空承诺是一直没人踩出来的。修法咱们贴着原文抄,抄的就这两行:

```asm
TaskTrampoline:
    sti
    call *%r12
    call *%r13
    ud2
```

钩子改用 call 来叫了,承诺是当场兑现的,栈对齐了。钩子办完了事本不该回来,真回来的话一声 ud2 就当场停了机,咱们不叫它带着糊涂栈往下走。这个修法有一股熟悉的味:用户入口的栈当年也为同一句承诺对齐过,那笔学费是生与收那一卷埋的,懒到家那一卷还的,交的就是这八字节。门的承诺是要么兑现要么明说的,拿编译开关把向量指令禁了糊过去,是咱们不取的路:伤好了一半,承诺还是空的,下一回别的对齐踩出来的时候,又是要从零查起的。
