# 线那头的答话人

卷首立边界的时候咱们说过:当网关的服务没有 UDP 的 echo,所以大戏的角色是 ICMP 的 ping,UDP 的成色得等一位真的答话人。这句边界是有出处的,不是猜的。当年第一遍送 UDP 上真线的那天,笔记里记的原话,说的是 SLIRP 无 UDP echo 服务,答的是不期望 reply。那一发蹭的是 ping 刚验过的出门路,只证的是包能从真线出去,回音是没有等的。点亮网卡那一卷记下的边界,是它答 ARP、答 DHCP、答 ICMP 的回声,TCP 与 UDP 的 echo 服务没有,握手的应答没测过,是不替它说话的。这几样里 ARP 与 ICMP 的回声两样,点亮网卡那一卷是在真线上亲手验过的,DHCP 那一笔是当年的记录收进正文的,咱们没走过那道手续。可这一卷的实测添了新的一笔:同一位网关的后头,坐着一位答 UDP 的,说的就是 DNS,十点零点二点三的五十三口。它是这一卷实测出来的答话人,而不是替 echo 填空,UDP 等的这个人,这一章等到了。

家当是两份住在盘 /etc 里的种子文件。resolv.conf 的一行,写的是 nameserver 10.0.2.3。hosts 的两行,写的是 127.0.0.1 localhost 与 10.0.2.15 cinux。装进盘里的路是造盘脚本铺的:种子住在仓库的 scripts/ext2_seed 目录里,造盘的时候装进 /etc。读者重造一遍盘,两份就原样带上了,种下的每一行开机可验。咱们看,两份各有各的客:hosts 是给走 libc 解析的客人抄的近道,名字在本地是能对上号的。nslookup 偏偏不抄这个近道,它指名问的是服务器,resolv.conf 里写的是谁,它问的就是谁。

咱们把 nslookup localhost 一行敲下去,顺着包咱们走一遍。客人在用户态构好了查询,socket 要一个数据报的。sendto 把查询递了出来,目的地十点零点二点三的五十三口。套接字是没有 bind 过的,发送的路上悄悄领一个短命号码落座,回信是有处投递的。查询上了真线:路由看地址不在回环网,递给了网卡,ARP 的名册问一趟路,虚拟网络那一头应了门,帧出了门。应答往回走:e1000 的收环接住,泵排的水把它送进汇,汇判了两次,协议字判的是十七,UDP 的座接包。三重门一道一道地过,核对的是长度,折拢的是校验和连伪首部。端口表查到了短命号码,载荷连同回信地址落进了环里。壳里的 nslookup 此刻阻塞在 poll 加 read 的用户态循环上,read 落进套接字的 receive,环里把它弹了出来,答案到了手。这一路里内核是一行都没有为 DNS 加过的:poll、read、write、socket,全是这一卷与前头各卷立好的门,客人穿着文件的外衣把事办完,这正是卷首侦察时记下的那句,nslookup 是用户态自足的。

面板上落的,咱们断言守着三样:Server 的一行,写的是 10.0.2.3。Name 的一行,写的是 localhost。Address 的一行,写的是 127.0.0.1。名字问的是对面真服务器,答案也是从线上答回来的。回程的线还有一层意思值得点破:三发 ping 走的是裸套接字的直通道,是不穿词书的。这一包 DNS 应答走的是 UDP 的全套:词书、三重门、端口表、短命号码、环,是一件都不缺的。这一包应答进了环,UDP 的全套家当才算当面验过成色。客人名单上坐的是七位,验过成色的三位:ping 的裸通道,ifconfig 的名册,nslookup 的全程。剩下的几位客人,telnet 与 nc 要等流式的成员,netstat 要等的数还没立,ping6 问的是 v6 的路,那套栈是还没立的,名单是留着的,戏是排在后头的。
