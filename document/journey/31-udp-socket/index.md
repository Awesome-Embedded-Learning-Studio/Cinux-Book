# UDP 与 socket:一只环与客人自己的 ping(卷名草稿)

安全那一卷收卷的时候,把 socket 的号位撂给了门:要生在那扇门上,新出的号位一出生就在门内。点亮网卡那一卷收卷的时候又把路指到了这一卷:第三部的正主是 socket,UDP 与用户态的 ping 都坐这一程,四层的座是他们的凳子,门也早就立好了。咱们这一卷就是第三部。它的位置在四部里这样摆:第一部立的纯逻辑栈,第二部接的生产与真线,这一部把栈的活摆到客人面前:号位、套接字、端口、钟、打断,一件一件立了起来。收官的那天,壳里的客人自己敲 ping,发是它自己发的,收是它自己收的,超时了是它自己的事,被打断了也是它自己接的。UDP 是这一卷的正主之一,可它一个人撑不起一部戏:客人的吃法要什么,咱们就立什么,所以这一卷的行李格外杂,不过杂得有章法。

咱们照例盘家底。手里有的:校验与回环栈那一卷攒下的整套栈,词书、端口表、类型字的座、四层的座、判两次、反码和,长凳上全验过了。点亮网卡那一卷的世界、泵、真线与第一声 ping。听得懂喊声那一卷立的送信与投递,安全那一卷补上的信号返回,外加那扇每一个指针都走检查的 uaccess 门。管道与假文件那两卷立的描述符表与文件的外衣,stat 的身份号、引用的计数,都是现成的,拿到咱们手里就能用。进程那几卷的让位与调度。USB 的键盘管输入,ext2 的盘管的是种子。缺的咱们也一片一片数:socket 的号位一个没有,UDP 的座空着,定时器的门一扇都没有,裸通道也没有现成的,接口的名册没有,DNS 的种子没下,控制台还拴在读者的路上,表的引用还有一笔到期没还的欠。缺的清单长,可每一件的地基都是现成的,这是三部攒下来的福气。

咱们进站时,机器的面板与点亮网卡那一卷出门时一个样:两颗核在线,泵在后台常驻地摇,线是挂着的,回环也是通着的,壳的提示符候着。出站的时候,面板上的字一个都没动,这一卷的报数不报在开机的面板上,报在壳的命令行上:三发 ping 三声回音,一秒窗的零收一行,Ctrl+C 之后落屏的统计,ifconfig 的五行户口,nslookup 的三行应答,一行行都是客人自己敲出来的。宿主侧的长凳全过,判案判例记了几桩,残案也破了一桩。

这一卷的活,咱们摊开报数。头一件摸了客人,七位网络客人的吃法挨个记全,活分成了四摞,次序也定了下来。第二件生了号位,十四个号位一次挂齐了,门的代码一行没改,socket 穿文件的外衣坐进描述符表,门卫只认的是外衣,判例立了一桩。第三件给 UDP 坐了座,词书补了条目,三重门立了起来,两笔旧话也兑了现:伪首部当了反码和分段累加的头一个主顾,算出零发全一落了地。第四件开了端口表,开出来的是八个座,bind 把满与重都验了才落笔,短命号码跟人家内核的默认对齐,发路就一气写完了。第五件立了家族与环,六张虚的脸,身份号出自开机一份的计数器,环深九用的是八,借来的帧锁内抄走,满了丢客记一笔。第六件立了 sockaddr 的礼数,进出的方向都当场翻译,bind 的讲究有三条,connect 要做的只是记名,write 走记名的路。第七件立了等的门道,一圈四步的让位,EINTR 把超时与打断都接住了,真睡的边界如实划清。第八件备了钟,备的是三扇门,相位也往前移了,错过的拍子并一声,明写 SIG_IGN 的不吵。第九件把表攥住了,引用进门就计了数,善后的事出锁再办,dup2 验源的时机在替换之前,蹦床的 jmp 改 call,ABI 的栈承诺也补上了。第十件把控制台救活了,常驻的泵摇着终端,前台组存的是原子量,信号送组的事出锁再办,USB 的控制字节补齐了来路。第十一件开了裸通道,十六座的观察哨,判完头两次就连头交了货,回环上两份收货入了判例。第十二件唱了大戏,壳里的 ping 全程自己走,三幕都唱齐活了。第十三件破了残案,入口的画面背对背,块读按页的大小截短,三根新不变量写进了测试。第十四件答了名册,纯值的快照,枚举的判例立了,字节序的案子屏幕自己卖的,/proc/net/dev 里的零是诚实的。第十五件会了答话人,盘里也下了种,nslookup 全程走 UDP 的家当,DNS 的应答进了环。末一件收尾走的还是验收。

当年的旧话咱们也照例交代。当年网络的后半段也是这么一串:UDP 几天里连着打完,socket 起手立的是七个号位,后来盘上的客人多起来,配生态的时候一次补齐到十四个对齐。ping 起手走的是内核自家的号位,后来轮到的才是 SOCK_RAW。Ctrl+C 当年踩的是一对耦合的 bug,等待的循环不看名册,信号帧的栈没对齐,重走的这一遍,这两课分别在门圈的第一步与蹦床的收尾里各自兑现,教的还是同一门学问。入口画面的残案是这一遍新破的,当年没有这样的案子,案子是重走的路自己带来的,也由重走的路自己结。取舍还是老尺子:能解释今天手里这套机制的,进得了正文,在它该在的那一章把来龙去脉摆开。只作反面教材的,收敛地讲。
