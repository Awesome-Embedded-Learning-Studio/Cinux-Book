# 被自家栈吃掉的字符串

大戏唱完了,咱们来讲这一卷实弹里追的最深一案。现象是不长眼的:壳里跑着跑着就出了事,ash 一旦调用得深了,报错信息的前缀成了一撮残渣,两个孤零零的字符,写的是 r 九。咱们头一眼只当是壳的一笔小毛病,记下了待查,没料到后头牵出来的是入口的画面。残渣是 commandname 与 PATH 的尸首:壳报错要把命令的名字打出来,名字没了,打出来的是被写花之后的字节。名字在哪坏的?不在壳的手里,壳是一个字节都没碰过它的。

户口的画法咱们回头讲一笔。开门迎客那一卷立过入口的画面:程序进用户态之前,内核在入口的栈页上画一幅画,argc、argv 的指针表、字符串本尊、envp 全套,末了辅助向量收的是一个裸的 AT_NULL,一层一层地摆下来,这是程序落地时的全部家当。辅助向量的真条目,是把后半场交给解释器那一卷才摆齐的。老布局是这样画的:初始 RSP 挨着页顶,指针表画在 RSP 的上方,字符串是从页底起步向上长的。画完的那一刻什么都是对的,检验也都过了。问题藏在两个方向里:调用栈的生长方向是向下,从 RSP 往低了压。字符串偏偏住在 RSP 下方的低处。程序一起跑的时候,函数一层一层地调,栈也一层一层地压,压着压着就压进了字符串的地界,每一笔写入都是栈自己的合法写入,野指针是没有的,可户口本就这么一页一页被自家的栈吃了。浅的程序吃不着,深的一口咬中:ash 的词法解析栈深,正中的是要害。

复现这一段的事值得单独记,它是反面教材的缘故。咱们换了四样姿势:换键盘的源,换整行的标准输入,一个字一个字放慢了敲,压上六十轮的强度,四样是全空手的。空手之后回头看才明白:这些姿势变的都是时序,而案子不认时序,认的是栈深。时序类的疑心撒完,剩下的诊断就不再靠试运气了:顺着布局的方向一推,栈是向下的,字符串是在下的,深栈是必中的,一推就对了。这一案的教训入册:复现姿势要对着病灶的变量去设计,栈深的案子,拿时序去腌是腌不出来的,推布局是比撞运气快的。

修法是把画面的方向整个翻过来,几个数咱们摆在这儿:

```cpp
const unsigned long kPageBase = entry_rsp - (entry_rsp % kSize);
PicturePlane        plane{
    .page       = stack_page,
    .page_base  = kPageBase,
    .strings_at = kSize,
    .words_at   = entry_rsp - kPageBase,
};
```

咱们让字符串的游标从页顶起向下排。指针表的游标从 RSP 起向上排。两游标相遇的时候,中间还留十六字节的地界为界,挤到界上就答画不下了,入口的画面宁可拒画不硬画。RSP 的落点改从页基起算,画面整体住在 RSP 的上方,RSP 的下方从此是整页空白:栈向下长,页内是有一段余量的,余量用尽了,下方本来就是栈的 VMA,缺了页就补页,是天经地义的。RSP 的落点在页内挪了家,没动的是 0x208 这个数与余八的形态,当年对齐的学费也一分没退,生与收那一卷埋的,懒到家那一卷还清了。

翻过来的第二天,连带的一处缝自己浮出来了。字符串如今是贴着页顶住的,而 exec 暂存与路径抄写两处,收字是六十四字节一块一块收的:块要是骑在页顶上,前半块是在页内的,后半块出了页,越了顶就是过界,一声 EFAULT 就回绝了。老布局里这个缝也是有的,只是越界的方向朝着栈的生长区,那片地界恰好是都映射着的,错了也是无声的。新布局把缝转到了亮处。修法是不绕的:每块开读前算一遍页内余量,块的大小按余量截短,咱们把路径抄写里改的这一段摆出来:

```cpp
const unsigned long kInPage =
    cinux::arch::page::kSize - ((source + done) % cinux::arch::page::kSize);
const unsigned long kChunk = std::min({kChunkBytes, cap - done, kInPage});
```

exec 那边的暂存是同款的,各加了一钳。两案 live 的实证跟着记下:一案的 envp[1],环境串里的第二条,贴在页内偏移四千零六十九的位置,越顶的那块读当场拒了。另一案里 script 开的是 /dev/null,报的是 Bad address。搁在从前两个客人的下场是无声的错,如今是有声的拒。咱们给测试新立了三根不变量:画面里每一个字符串的指针,都必须落在初始 RSP 的上方。拿 0xAA 的洪水把 RSP 下方的页灌满,字符串是一根毫毛都不动的。五十九条一百三十字节的长串把页塞满,画面答的是零,咱们拒画。方向对齐了,两个游标背对背地长,谁也进不了谁的地界,案就结了。
