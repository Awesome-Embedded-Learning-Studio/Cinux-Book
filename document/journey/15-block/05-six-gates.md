# 六道准入

引擎空转着,现在咱们填本卷的头一封命令信:操作码 `0xEC`,IDENTIFY DEVICE,盘的身份问答卷。信发出去,盘要回 512 字节的材料过来——256 个 16 位词,从它姓甚名谁,到它会什么本事,到它有多少个扇区,全在这 256 个词里。发送的路数上一节认过了,这里只说收货前咱们备的一手:

```cpp
cinux::base::SetBytes(cinux::base::PtrAt<void>(mm::DirectMapVirt(data_page_.raw)), 0xA5,
                      kSectorBytes);
```

中转的弹跳页,咱们发命令之前,把要用的 512 字节全填上 `0xA5` 当底色。盘要是没把材料搬来,这 512 字节就还是满眼的 `0xA5`,搬来了,底色被盖掉多少、盖成什么样,一眼可见。盘交货还有一张回执:命令头里的字节数域,规范说搬完由控制器填,咱们读出来跟 512 对数,对上才算收货。

材料到手,咱们挑两样念给您听。头一样,容量:48 位的扇区数躺在 100 到 103 号四个词里,低对低、高对高,拼成一个 64 位数——咱们这块盘报上来 2048,正好是 1 MiB。第二样,型号:27 到 46 号这 20 个词是盘的铭牌,可字不能直接读——盘把两个字符装进一个词时,是反着装的,高位放头一个字母。咱们边读边把高低字节换回来:

```cpp
model[(2 * index)]     = static_cast<char>(cinux::base::bit::HighByte(kPair));
model[(2 * index) + 1] = static_cast<char>(cinux::base::bit::LowByte(kPair));
```

读出来就是面板上那行 `QEMU HARDDISK`——名字后面拖着的一长串空格也是铭牌的原文,20 个词装 40 个字节,名字短,后头就拿空格垫。咱们照原样转写,不替盘修剪。

不过材料念得再顺,也不能照单全收。本节的主角是准入:盘得证明自己是咱们伺候得了的那类盘,才准注册进门。六道门槛,一道道数:

头一道和第二道都在 0 号词里。bit 15 立着的,是 CFA 盘—— CompactFlash 那门方言,命令集有出入,咱们不伺候。bit 2 立着的,是自报词表不全的盘,材料都交不齐,咱们不收:

```cpp
if ((words[0] & kWord0Cfa) != 0 || (words[0] & kWord0Incomplete) != 0) {
    return false;
}
```

第三道查铭牌:40 个字节,个个得是能打印的字符(空格到波浪号之间),而且不能全是空格——名字都没有的盘,咱们往后拿什么称呼它?第四道查本事。83 号词的高两位是规范留的验真暗号:bit 15 必须是 0、bit 14 必须是 1,这词才算数。词算数了,才轮到看 bit 10——48 位寻址的旗子。咱们的读写命令全是 48 位的,盘要是不会这个,后头的路全堵死:

```cpp
if ((words[83] & kWord83Invalid) != kWord83Valid || (words[83] & kWord83Lba48) == 0) {
    return false;
}
```

第五道查家底:刚才拼出来的扇区数,得落在 1 到 2 的 48 次方减一之间——零个扇区的盘没法用,超出的,那是数字本身坏了。第六道是道防伪:255 号词的低字节要是写着 `0xA5`,意思是“本材料附校验和”,那咱们就得把 256 个词的所有字节加起来,按 256 取余,结果必须为零。盘没写 `0xA5`,这一道自动放行:

```cpp
unsigned sum = 0;
for (const uint16_t kWord : words) {
    sum = (sum + cinux::base::bit::LowByte(kWord) + cinux::base::bit::HighByte(kWord)) & 0xFF;
}
return sum == 0;
```

六道都过了,盘就名正言顺地住了进来:容量进字段,铭牌进字段,面板报出 `ahci QEMU HARDDISK, 2048 sectors`,块世界的第一个真家伙落了户。哪道拦下了,也不悄悄退回:面板把铭牌、0 号词、83 号词一起打出来,您顺着读数就知道盘卡在哪一道。

> 说句如实的闲话:AHCI 的口寄存器里有个签名域 PxSIG,江湖上不少教程教人认盘,头一件事就是看它读出 `0x101`,说这是 SATA 盘的暗号。暗号是人家找盂数的路数,咱们没跟——签名域在结构体里躺着,代码一处都没引用它。门是拿证件守的,不是拿门牌守的:上面六道查的全是盘自己交上来的词表,材料对不上,门牌再漂亮也不放行。

还差一样没说:发信之后,咱们拿什么等盘回话?这一卷把等待做成了两套手艺。下一节铺中断的路,再下一节,两套等待摆开。
