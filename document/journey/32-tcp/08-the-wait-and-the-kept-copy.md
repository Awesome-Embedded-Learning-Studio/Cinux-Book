# 等不着的回答,留下的底稿

钟立好了,咱们还单子上最重的一笔:重传。这笔债的来历,放在头里说清。IP 层是个不回执的搬运工,包丢了它不吭声,UDP 摊摊手,丢了就丢了,散件的生意,下一发另起炉灶。TCP 答应过的事不一样:客人交给它一个字节,它负责把这个字节送到,送到两个字怎么讲,拿到对端的 ACK 才算送到。于是每一个发出去的字节,在拿到回执之前,都不能算完事。它得留在手里,这就是这一章的第一件家当:底稿环。

环是上一卷的老朋友,这一回方向反了过来。上一卷 UDP 的环收的是别人的货,等待主人来取。轮到 TCP 的环,存的是自家的底稿,深四千零九十七格用四千零九十六格,留一格空,满与空分家的老道理。send 的时候,每一段发出去的字节顺手压进环里。ACK 滑过来,认了几个号,环就弹出几个字节,底稿与在途字节始终一字不差地镜像。镜像图什么?咱们看重传的时候:模块想再发一遍最老的那段,字节数它记得,内容呢?环里没有,只能干瞪眼。底稿环就是重传的全部本钱。

重发只补最老的一段,一段的长度取三个数的下限:在途的字节数,一个最大段的体量,环里实有的字节数。取完不新发,是照着底稿重念。这里头藏着一桩真病灶,值得单独讲。发送与重传走的是同一个 transmit_segment,起手的版本里,序列号在这个函数里写死了笔尖的号。新发的段用笔尖,没错。重发的段该用最老未认的号,写死的笔尖把重传段的名头安到了还没发的字节上,对端一比号,这是一段没头没脑的乱序货。这病咱们是在长凳上抓的:测试憋着不回 ACK,等钟到点逼出一笔重传,断言重传段的序列号,当场对不上。修法是把序列号提成显式的参数,新发传笔尖,重传传最老的号,一个函数两条路,名头各归各。

等多久,这是估算的活,章程写在 RFC 6298 里,咱们用整数照办。采样的代码不长,整段在这儿:

```cpp
    if (connection.srtt_ns == 0) {
        connection.srtt_ns   = kSample;
        connection.rttvar_ns = kSample / 2;
    } else {
        const unsigned long long kDiff = connection.srtt_ns > kSample
                                             ? connection.srtt_ns - kSample
                                             : kSample - connection.srtt_ns;
        connection.rttvar_ns           = ((3 * connection.rttvar_ns) + kDiff) / 4;
        connection.srtt_ns             = ((7 * connection.srtt_ns) + kSample) / 8;
    }
```

头一个样品,平滑值就取它,方差取半,家底薄,只好信第一手。往后的样品按三七与七八的两档滚动:平滑值八份里占一份新样品,方差四份里占一份新偏差。样品是什么时候采的,咱们记着两个时刻:最老的一笔货离开家的时刻,与回执推进到笔尖的时刻,一减就是一趟来回。等待的算法是平滑值加四倍方差,再垫一个十分之一秒的粒度下限,免得快得发糊。封顶六十四秒。头一笔货还没有任何样品,等待从保守的一秒起。

可这里有个鸡生蛋、蛋生鸡的纠缠:样品的时间差,前提是回执认的就是那一笔出发的货。重传过一次之后,回执来了,它认的是头一笔还是第二笔?分不清。把分不清的差当样品,回执总认的是头一笔的话,样品被第二笔的出发时间拉长,估算越采越歪。人家的名字叫 Karn,正解是重传过的段不采样。咱们取简化版:连接上立一面旗,重传一发生就升起来,旗升着不采样,直到 ACK 把窗口推着走了,旗落下去,采样恢复。粗,但方向不会歪。

五次重传的花销花满,放弃,座释放,报给自家客人的是不可达,不是被拒。放弃时一个段都不发,这一手咱们要单独说一句:对门连五次重传一声都没应,它听不见,RST 发给谁?喊一个听不见的人,徒增网上的噪音。这个五,咱们把口径立准:数的是连续的沉默。只要 ACK 把窗口推着走了,哪怕只认一个字节,重传的计数当场清零,从头再数。所以五次不是一条连接的终身额度,是对门连续不吭声的额度,断断续续还应声的连接,这笔数花不满,连续哑了五回的,才落到放弃与不可达那一步。五次之内,每次到点重发一笔、等待翻一倍、钟重租一座:一秒起,二、四、八、十六,长凳上按合成时钟一步一步逼,六笔火候排下来是一、三、七、十五、三十一、六十三秒,断言就按这个表验。还有一案专考道别的:客人在还有字节没被认的时候就道别,告别信排在底稿后头,重传把没认的字节补完,信才轮得上路。重传,当年单子上最重的名目,到这儿还清了。
