# TCP 完备:一张旧单与到点叫人的钟(卷名草稿)

上一卷收卷的时候,话撂了两串。一串近的:流式的真门、listen 与 accept 背后那套机制、两笔从点亮网卡那一卷一路挂过来的防线,都点名排在紧后头。一串远的:可打断的真睡、软超时、唤醒的令牌,整包排在下一卷。这一卷就是那个下一卷,也是网络第四部的正主:TCP 完备。它的位置咱们这样摆:第一部立的纯逻辑栈,第二部接的生产与真线,第三部把栈摆到客人面前,这一部把当年欠下的控制还清。丢、淹、乱、断,四样灾,四样接法,收官那天,壳里的 nc 当着真网卡的面自己连自己,一条流走完全程。

这一卷的发动机,咱们从一张旧单子里请出来。当年第一遍收官那天的笔记,重传、往返估算、滑动窗口、乱序重组、道别之后多守一程的 TIME_WAIT,一笔笔明记在案,好几笔的原因栏写着同一句话:需要内核的定时唤醒基建,当年没有。所以咱们还单的次序是倒着还的:单子上头一件还的是那句原因,十六个座的钟。然后重传与底稿环,快速重传与修包座,两扇窗,道别的完备与多留的一程,风暴全家,末了流式的成员进门,nc 上桌。

咱们照例盘家底。手里有的:上一卷立好的全部,十四个号位,套接字的家族,文件的外衣,让位的圈与 EINTR,三扇钟门,攥住座的表,活着的控制台,裸通道,观察哨。校验与回环栈那一卷的词书与反码和,四层的座,判两次,端口表。点亮网卡那一卷的世界、泵、真线、路由的名册。进程那些卷的调度与让位,时钟家里现成的单调钟。缺的也数得出:TCP 在四层的座上还没有座,定时唤醒的基建没有,重传、估算、窗口、重组、守程,一件都没有,流式的成员不在家族里。缺的件件都在单子上,单子就是施工图。

进站时,机器的面板与上一卷出门时一个样:两颗核在线,泵常摇,线挂着,回环通着,壳的提示符候着。出站的时候面板还是一字未动,咱们盘这一卷的收获,盘在别处:长凳上二十二案加六案加十七案,机内四案,实弹一场双端退出码零,残案两桩告破,当年的欠单划掉五笔,没划的两笔挂在明处。

当年的旧话交代。当年 TCP 的骨架几天立完,立完的当天就把欠单明记在案,这是那一遍最体面的一笔:没还的债写清楚为什么没还。重走的这一遍,单子照收,利息也认:确定性递增的起始号当年是为测试可复现,这一卷换成大步的黄金比例,可确定还是确定,随机化续欠。真睡的三样上一卷许给这一卷,这一卷兑现一半,剩一半接着写在明处。取舍,咱们还是用老尺子量:能解释今天手里这套机制的进正文,在它该在的那一章摆开来龙去脉。只作反面教材的,收敛地讲。

合卷的时候咱们再点一遍手里的新话:一张旧单亮在开头,五笔还清,没划的两笔挂在明处。十六个座的钟立了,清座在调用之前,票烧过就作废。底稿环镜像每一个在途字节,估算按整数版滚,三声一样的应答不等钟,四座修包,两扇窗,道别之后多守两个寿命,新 SYN 让位。两笔旧防线赶在头里还清,截断包死在词书,胖回声死在门口。流式的成员坐进家族,门后不再是诚实拒,accept 没有期限地等,connect 的门里软限开了一回张,睡与令牌接着写在明处。挂线后回环断案的根子按目的地取源地址,十四 KiB 的临时改成就地新生,两案都结。nc 当着真网卡的面自己连自己,双端退出码零。这一卷咱们就收在这里。
