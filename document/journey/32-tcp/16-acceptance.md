# 验收:还完的单子与续期的欠

收卷的章程照旧,咱们点的还是面板、长凳、实弹三样。面板是放在头里说的,还是那句老实话:一行是没有动的。进站时长什么样,出站时还长什么样,两颗核是在线的,泵在后台常驻地摇,线是挂着的,回环是通着的,壳的提示符候着。这一卷的正主住在协议层与门后,报数不报在开机的面板上,报在长凳的案子里与脚本的落款上,您跑一遍,得到的应当同款。

长凳上是四面的案子。头一面 TCP 的二十二案,咱们按行为串:词书的三拒与坏校验和的专名死守门厅。握手的响铃、闭口回 RST、第九连接的专名拒,守的是开场。迟段乱段是各有名目的,越窗的是不入座的,越界的应答丢,守的是边界。沉默逼的是重传,道别前补完的是字节,五次花满了就放弃。三声一样的应答即发,补缺是连着收割的,守的是重传与修包。对端的窗缩放与重开,守的是流量。守满的是两个寿命,守程中让位的是新 SYN,挨了 RST 即释放,守的是道别。风暴三场加全链四泵收了尾。第二面钟的六案:到点一响,退租的哑,烧过的票作废,回调里自续了租,满座答的是专名拒,一趟是按座序连响的。第三面套接字的十七案,流式的新进三案:回环的会话穿过 accept,挂线之后回环是照旧的,写的人早走,替他守着的是货与尽头。第四面是在机器里的,备的是四案,含真等两个最大段寿命的那一案,机内的钟走的是真时间,不是合成的步进。验收的矩阵绿过,其中双核争锁的一案头一回抖了一回时序,复跑就绿了,不是代码的事:多核的案子偶发一回,复跑了一遍再下判断,您别急着改码,这一回章法是用上了的。实弹排的是上一章的 nc:双核挂线的排面,双向的会话,双端的退出码零。

然后咱们对单,这一卷的对单要对着两份来。头一份是当年的:重传,划掉了。往返的估算与超时,划掉了。滑动的窗口,划掉了。乱序的重组、重复的应答、快速的重传,划掉了。TIME_WAIT 的那一笔,划掉了。当年原因栏里的那一句需要定时唤醒基建,如今是十六个座的钟,是立着的。没划的两笔念名字:拥塞控制,登记的是不做,完备两个字咱们按传输可靠性的口径数,对外的礼让另立门户,是不混在这卷里冒充的。ISN 的随机化,这一卷的号仍是确定性的大步递增,防的是幽灵,防不了有心的对门,续了欠。第二份是上一卷撂的:流式的真门,兑现了,协议字是点六或留空的。listen 与 accept 背后的那套机制,兑现了,accept 是没有期限的,旗归的是新描述符。防线的两笔,兑现了,截断包死在了词书,胖回声死在了门口。真睡的三样,兑现了一半:到点叫人的钟立了,connect 门里的软限开了一回张,任务睡进自己的上下文、令牌唤醒,续了欠,挂在了明处。别的旧欠照旧念名:IPv4 分片不做,中断驱动登记在远期的那一栏,发送的回写不读,旋钮点头的实数排在往后。

网络这一路走完了四部,咱们给它一个说法。第一部立纯逻辑的栈,词书、算术、判两次的门道,字节在 host 的长凳上学会守则。第二部接的是生产与真线,守则上了真正有泵、网卡、第一声 ping 的机器。第三部把栈摆到了客人面前,门、套接字、钟、打断的全套,壳里的客人自己开口。第四部是这一卷的事,把当年欠下的控制还清,字节从散件攒成了会话。从字节到会话的这一程,是全的。它当然不是终点:拥塞的礼让、v6 的另一条路、分片的远期,都在名册的那一页上,哪一笔是该还的,还的时候站在哪一卷,咱们到时候再排。

下一卷的地界,咱们只点一下方向,不展开:机器如今认得自己的字节、自己的客人,可客人吃的还是自家土造的干粮,盘上的世界要换血,动态的程序、一号进程的 init、一条命令从干净的树到 QEMU 里一台配得像样的系统,都留在了那边。验收的数字点完,咱们在这里收卷。
