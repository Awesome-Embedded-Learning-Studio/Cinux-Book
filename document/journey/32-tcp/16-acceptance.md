# 验收:还完的单子与续期的欠

收卷的章程照旧,咱们点的还是面板、长凳、实弹三样。面板放在头里说,还是那句实话:一行没动。进站时长什么样,出站时还长什么样,两颗核在线,泵在后台常驻地摇,线挂着,回环通着,壳的提示符候着。这一卷的正主住在协议层与门后,报数不报在开机的面板上,报在长凳的案子里与脚本的落款上,您跑一遍,得到的应当同款。

长凳四面。头一面 TCP 的二十二案,咱们按行为串:词书的三拒与坏校验和的专名死守门厅。握手响铃、闭口回 RST、第九连接专名拒,守开场。迟段乱段各有名,越窗不入座,越界的应答丢,守边界。沉默逼重传,道别前补完字节,五次花满放弃。三声一样的应答即发,补缺连着收割,守的是重传与修包。对端的窗缩放与重开,守流量。守满两个寿命,守程中新 SYN 让位,RST 即释放,守道别。风暴三场加全链四泵收尾。第二面钟的六案:到点一响,退租的哑,烧过的票作废,回调里自续租,满座专名拒,一趟按座序连响。第三面套接字的十七案,流式的新进三案:回环的会话穿过 accept,挂线之后回环照旧,写的人早走,货与尽头替他守着。第四面在机器里,四案,含真等两个最大段寿命的那一案,机内的钟走真时间,不是合成步进。验收的矩阵绿过,其中双核争锁的一案头一回抖了一回时序,复跑即绿,不是代码的事:多核的案子偶发一回,复跑一遍再下判断,别急着改码,这一回章法用上了。实弹一场,上一章的 nc,双核挂线的排面,双向会话,双端退出码零。

然后是对单,这一卷的对单要对着两份来。头一份是当年的:重传,划掉。往返估算与超时,划掉。滑动窗口,划掉。乱序重组、重复应答、快速重传,划掉。TIME_WAIT,划掉。当年原因栏里那一句需要定时唤醒基建,如今是十六个座的钟,立着。没划的两笔念名字:拥塞控制,登记不做,完备两个字咱们按传输可靠性的口径数,对外的礼让另立门户,不混在这卷里冒充。ISN 随机化,这一卷的号仍是确定性的大步递增,防的是幽灵,防不了有心的对门,续欠。第二份是上一卷撂的:流式的真门,兑现,协议字点六或留空。listen 与 accept 背后那套机制,兑现,accept 没有期限,旗归新描述符。两笔防线,兑现,截断包死在词书,胖回声死在门口。真睡的三样,兑现一半:到点叫人的钟立了,connect 门里的软限开了一回张,任务睡进自己的上下文、令牌唤醒,续欠,挂在明处。别的旧欠照旧念名:IPv4 分片不做,中断驱动登记远期,发送的回写不读,旋钮点头的实数排在往后。

网络这一路,四部走完,咱们给它一个说法。第一部立纯逻辑的栈,词书、算术、判两次,字节在 host 的长凳上学会守则。第二部接生产与真线,泵、网卡、第一声 ping,守则上了真正的机器。第三部把栈摆到客人面前,门、套接字、钟、打断,壳里的客人自己开口。第四部这一卷,把当年欠下的控制还清,字节从散件长成了会话。从字节到会话,这一程是全的。它当然不是终点:拥塞的礼让、v6 的另一条路、分片的远期,都在名册上,哪一笔该还,还的时候站在哪一卷,咱们到时候再排。

下一卷的地界,方向点一下,不展开:机器如今认得自己的字节、自己的客人,可客人吃的还是自家土造的干粮,盘上的世界要换血,动态的程序、一号进程的 init、一条命令从干净的树到 QEMU 里一台配得像样的系统,活在那边。验收的数字点完,咱们在这里收卷。
