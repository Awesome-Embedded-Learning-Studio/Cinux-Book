# 两笔旧欠,进门就还

还单之前咱们把两笔不在单子上的旧欠还掉。上一卷收卷的时候,边界挂在明处念过两笔:两笔从点亮网卡那一卷撂过来的防线,当时说这两笔比线刚接上那会儿又重了一层,线上的客货天天在路上走,走的人越多越悬。这一卷开了工,头一件还的就是这两笔旧欠。TCP 的戏开锣之前,咱们把门口扫干净。

头一笔是截断的包。IPv4 的头有一个字说自己有多长:第一字节的低半是头占几四个字节的字,说的是五字到十五字、二十字节到六十字节的范围。这一项从前是词书判的,判的只有它撒不撒谎,不查缓冲里实际躺着的字节盖不盖得住它。于是咱们看着这样一个包一路过关:头声明的是十五个字、六十字节的身量,缓冲里其实只躺了二十个字节。过关之后两处都遭了殃。校验和照着头声明的范围折,折到第二十一个字节就已经出了界,读的是别人的内存。更深一处的减法更狠:载荷的长度拿有效的字节减头长,有效的字节数是拿声明的总长与实到的长度取小得的,得到的是二十减六十,无符号的数倒着减,下溢出来的就是一个天文数字,交给四层的座,座上的人拿它当长度使,后果是不堪设想的。修法是这样的:

```cpp
    const auto kHeaderBytes = static_cast<unsigned char>(kHeaderWords * sizeof(uint32_t));
    if (length < kHeaderBytes) {
        return Ipv4Error::kDatagramTooShort;
    }
```

实际缓冲盖不过头自己声明的头长,词书当场答一个专名的拒:数据报太短。这一道检查咱们加在查完谎、读总长之前,恰好把后来两处遭殃的路都拦在门里:门都进不来的话,折校验和的事谈不上,减载荷的事更谈不上。判词咱们沿用现成的名字:短就是短,新词是不添的。

第二笔是胖的回声。ICMP 的回声应答,从前的章法是来多大抄多大,可回声的缓冲是按自家出站的章法备的,备下的是一千四百八十字节。线上的消息不由咱们定章法,对门送来一个一千四百八十四字节的回声请求,抄写的循环拿进来的长度当上界,四个字节越出缓冲的尾部,写的又是别人的地界。修法是在门口立了一个上限:

```cpp
    if (length > kMaxIcmpEchoBytes) {
        ++stats_.refused_oversized;
        return;
    }
```

超了一千四百八十,专名的计数器记一笔,人客气地送走。答不上来的就明说答不上来,这比硬抄越界是诚实的,咱们认这个章法。这一回的判词是咱们新起的 refused_oversized,从此名册上多了一口计数。

两笔都还了,咱们把这笔生意的性质说清。这两道门守的都不是 TCP,一道守在 IPv4 的词书里,一道守在 ICMP 的门口,它们是入界的门,赶在一切传输的生意之前就存在。之所以排在还单的最前头,理由上一卷就写过:线上的客货天天在路上走,ping 的应答、DNS 的回包,往后还要加 TCP 的段,防线不落的路,走的人越多越悬。上一卷收卷时念的原话是头说自己六十个字节、缓冲里只躺着二十的截断包,今天照样一路走到校验的那一步。这一句现在可以划掉了:截断的包死在词书里,胖的回声死在门口,长凳上守着的各有一案,一案的断言是专名的拒词,一案的断言是那口新计数器从零走到一。旧欠清完了,咱们回头看正主:十态的状态机,和它身后整张待还的单子。
