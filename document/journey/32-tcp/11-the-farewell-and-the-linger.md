# 四次道别与多留一程

道别在 TCP 这里是一桩正式的手续,UDP 无所谓道别,散件嘛,发完两清。可流是双向的,两头各有一半的话要收尾,咱们把这套手续一件一件办清。close 递出自家的告别信:FIN 立着,占一个号,自家笔尖加一。信不是想走就走的,它排在底稿的后头,前面还有没被认的字节,重传把字节补完,信才轮得上路,底稿环那一章的长凳考过这一手。信递出去,状态从通行走到一等。对端认了,走到二等。

二等是一个值得停一停的状态,因为半闭是这一卷真给的:close 关掉的是发送的路,收的路还开着。咱们看这笔生意怎么做:客户端把告别信递了,服务端还有半车货没发完,接着发,客户端照收,收完了自己也递信。所以道别是两笔独立的告别信,四个手:一方 FIN,一方 ACK,一方 FIN,一方 ACK。为什么不能像握手那样三手并两手,因为两笔信各走各的时辰,中间隔着随便多少数据,硬并就要么丢半车货,要么逼着没说完的一方把话掐了。

咱们看对端的信到了怎么办:absorb_bytes 把期待号推过 FIN 占的那一号,自家最后一手 ACK 递出去。到这儿,被动道别的一方对完最后一手就下台,座位释放。主动道别的一方不,它再多守一程:

守多长,两个最大段寿命。教学值一秒,守两秒,长凳上一秒的演示刚好活得完。真实栈在这一栏填的是三十秒,咱们照实标注,不改口。这一程守的有两层意思。头一层在自家:最后一手 ACK 也是段,也会丢,丢了,对端以为信没送到,重发告别信,此刻要是座位已经撤了,没人应,对端干等到钟花满、不可达、狼狈收场。守着,重发的信一来,重申一声现状,对端安心走人。第二层在号码带:旧段在海上漂,同四元组的下一个连接兴许已经在路上,守的这一程是给海上的幽灵留的寿数,漂着的段寿尽了,新连接的号才干净。

守着期间,来段一律重申现状,期待号一个纯应答回去,咱们让状态一步不动。可有一条特别的路:同四元组的新 SYN 进了门。这不是幽灵,幽灵是旧号的段,这是新号的新握手,守在门口的老连接不该挡路。判法在进门的头一层就办了:连接在多留的状态,段立着 SYN 没立 ACK,老座位静默释放,告别的铃不重响,新握手按没主的 SYN 走门规。长凳一案专演这出:守程中一个新 SYN 进来,出门的是带着新起始号的 SYN 加 ACK,计数器里没主的记录一笔没动,旧票当场作废。让位,让得干净。

RST 是另一种道别,撕破脸的那一类,两型。头一型答没人听的口:SYN 进了门,口上没有听客,或者连接座满了,回 RST 加 ACK,应答值取对方的序列号加段的占号长,把对方的手数完再拒,对端一看便知门没开。第二型答游离的 ACK:一个不认任何连接的纯应答飘进门来,回一个光杆 RST,序列号取对方的应答值,不带 ACK 旗。两型各答各的场合,长凳上闭口的案子与建连被拒的案子各立一案。RST 落到活连接头上,那就没有商量:咱们记一笔收到,座位当场释放,报给客人的是被拒。自家这头销毁套接字也有章法:连接还开着的,析构走道别的路递告别信。握手还没成的,座直接撤,一声不出,别让对端干等一个没开张的连接。

这一章收尾还留着一课,是手摇的世界教的。多留一程的钟,基点取在检修趟的当前时刻上。手摇的世界要是从头到尾没喂过时间,当前时刻是零,道别信递出去,在途的计时起点落在零上,而零在这一卷的词汇里是没有什么在途的意思,检修趟不给它挂重传的座,信丢了就真丢了。长凳的写法是道别之前喂一口非零的时刻,时刻对了,座挂上了,一切照章。教学的机器小,可零这个数从握手到道别背着两三个意思,咱们一路用,一路当心。
