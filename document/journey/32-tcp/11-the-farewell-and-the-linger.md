# 四次道别与多留一程

道别在 TCP 这里是一桩正式的手续,UDP 是无所谓道别的,散件嘛,发完了就两清。可流是双向的,两头各有一半的话要收尾,咱们把这套手续一件一件办清。close 递出自家的告别信:FIN 立着,占的是一个号,自家的笔尖加一。信不是想走就走的,它排在底稿的后头,前面还有没被认的字节,重传把字节补完了,信才轮得上出门的路,底稿环那一章的长凳考过这一手。信递了出去,状态从通行走到了一等。对端认了,状态就走到了二等。

二等是一个值得停一停的状态,因为半闭是这一卷真给的:close 关掉的是发送的路,收的路还开着。咱们看这笔生意怎么做:客户端把告别信递了,服务端的半车货还没发完,货是接着发的,客户端也是照收的,收完了自己也递信。所以道别是两笔独立的告别信,合起来是四个手:一方递了 FIN,一方回了 ACK,对面递了 FIN,这边回了 ACK。为什么不能像握手那样三手并两手,因为两笔信各走各的时辰,中间隔着的是随便多少数据,硬并就要么丢半车货,要么逼着没说完的一方把话掐了。

咱们看对端的信到了怎么办:absorb_bytes 把期待号推过 FIN 占的那一号,自家最后一手 ACK 也递了出去。到了这儿,被动道别的一方对完最后一手就下台,座位也释放了。主动道别的一方不,它偏偏要多守一程:

守的是多长?守的是两个最大段寿命。教学的值是一秒,守的是两秒,长凳上一秒的演示刚好活得完。真实栈在这一栏填的是三十秒,咱们照实标注,口是不改的。这一程守的有两层意思。头一层在自家:最后一手的 ACK 也是段,也是会丢的,丢了,对端以为信是没有送到的,重发的是告别信,此刻要是座位已经撤了,是没人应的,对端干等到钟花满、不可达、狼狈收了场。守着的话,重发的信一来,重申的是一声现状,对端就安心走人了。第二层看的是号码带:旧段在海上漂,同四元组的下一个连接兴许已经在路上,守的这一程是给海上的幽灵留的寿数,漂着的段寿尽了,新连接的号才干净。

守着的期间,来的段一律重申现状,回一个期待号的纯应答,咱们让状态一步不动。可有一条特别的路:同四元组的新 SYN 进了门。这不是什么幽灵,幽灵是旧号的段,这是新号的新握手,守在门口的老连接不该挡路。判法在进门的头一层就办了:连接在多留的状态,段立的是 SYN 没立 ACK,老座位静默地释放,告别的铃不重响,新握手按没主的 SYN 走门规。长凳一案专演这出:守程中一个新 SYN 进了门,出门的是带着新起始号的 SYN 加 ACK,计数器里没主的记录一笔没动,旧票当场作了废。位让了,而且让得干净。

RST 是道别的另一种,撕破脸的那一类,分的是两型。头一型答没人听的口:SYN 进了门,口上是没有听客的,或者连接座满了,回的是 RST 加 ACK,应答值取对方的序列号加段的占号长,把对方的手数完再拒,对端一看就知道门是没开的。第二型答游离的 ACK:一个不认任何连接的纯应答飘进门来,回的是一个光杆 RST,序列号取对方的应答值,ACK 旗是不带的。两型各答各的场合,长凳上闭口的案子与建连被拒的案子各立一案。RST 落到了活连接头上,那就没有商量:咱们记一笔收到,座位当场就释放了,报给客人的是被拒。自家这头销毁套接字也有章法:连接还开着的,析构走道别的路递告别信。握手还没成的,座就直接撤了,是一声不出的,别让对端干等一个没开张的连接。

这一章的收尾还留着一课,是手摇的世界教的。多留一程的钟,基点取在检修趟的当前时刻上。手摇的世界要是从头到尾没喂过时间,当前的时刻是零,道别信递了出去,在途的计时起点落在零上,而零在这一卷的词汇里是没有什么在途的意思,检修趟不给它挂重传的座,信丢了就真丢了。长凳的写法是道别之前喂一口非零的时刻,时刻对了,座挂上了,一切是照章的。教学的机器小,可零这个数从握手到道别背的是两三个意思,这个数咱们一路在用,咱们也一路在当心。
