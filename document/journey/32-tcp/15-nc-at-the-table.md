# nc 上桌

残案结了,咱们唱大戏。排面是特意挑的:两颗核在线,真网卡是挂着的,戏是在回环口上唱的。为什么非这么挑,上一章刚结的案就是理由:挂线之后回环还能不能握手,恰好是最容易被手摇的世界盖住的一条缝。大戏是站在缝上唱的,翻过案的地界,以后每一遍开锣都是在替这一案站岗的。

大戏由宿主侧的一台脚本提机器,您一条命令跑全程:

```sh
python3 scripts/test_net_tcp.py
```

脚本进门头一件事是验镜像:把编译出来的内核文件读出来,盘里第三十二个扇区起的地方逐字节比对,对不上的话,当场就喊了停,叫人把盘重造了再跑。这一步不是摆样子的,上一章的那笔疑云,启动行的尺寸跟文件是对不上的,差点把整个排查带进了沟里。疑云结了案,教训进了章程:镜像与文件的比对,从此跑在了每一场大戏的头里,您跑到哪一遍,它都在头里等着您。

然后咱们把机器开起来,等壳的提示符。第一场演的是服务端,一条后台的命令:

```text
/ # (busybox nc -n -v -w 2 -l -p 4410 </dev/null; echo TCP_SERVER-$?) &
```

nc 听的是四千四百一十口,标准输入一头接的是空的。咱们这么接有讲究:nc 的脾气是输入读到尽头就把 EOF 送过线去,stdin 是一起头就到尽头的,服务端一上来就备好了道别的半边。断言等的是一行,listening 打头的听口行。第二场演的是客户端:

```text
/ # echo hi | busybox nc -n -v -w 2 127.0.0.1 4410; rc=$?; busybox sleep 1; echo TCP_CLIENT-$rc
```

echo 把一行 hi 喂给了 nc,nc 连上了门,连完把退出码存了下来,睡了一秒,落一行带退出码的落款,咱们就在这行落款上等结果。

咱们的断言有六样,咱们一样都不掺水。听口的那一行,证明 listen 与 accept 的门后真有人。

串口上落下的那一行 hi,咱们认它是全场最要紧的一笔。

咱们跟着它走一遍:hi 从客户端的壳里进 nc,穿 connect 的握手、发送的窗、回环的线、服务端的收件箱、accept 落下的连接、nc 的读,最后落到了串口上,一条流的全链,一个环节断了这一行就没了。客户端的退出码零,服务端的退出码零,两头的落款各验各的。最后 wait 把后台的这一场收干净,再落一行收场的落款,提示符就回来了。第六样是全场兜底的一道:全程串口里没有一声事故的标记,脚本把认识的坏事标记挨个查过,一个都是不许见的。

有一处写法咱们要单独交代:退出码的断言写得宽,落款的字母之间夹进几个外来的字符,也算过了。两颗核是开着的,两个任务是同时往串口写字的,字符级的交错是真的会发生,一行 TCP_CLIENT 落款被另一个任务的几个字咬上一口,机器是没有错的,输出也是没有错的,是终端那把锁的缝。断言按宽的写,缝记在了名册上,哪一卷把终端的锁补齐,哪一卷就是来收窄断言的。全场的 PASS 一行是这么打的:双核,线是挂着的,载荷上了串口,双端的退出码零。一头一个的两个零,是两头各自挣下的,是谁也没替谁作保的。

散了戏,咱们把客人名单再点一遍。上一卷验过成色的三位:ping 的裸通道,ifconfig 的名册,nslookup 的全程。这一卷 nc 上了桌,流式的会话当着真网卡的面走完,它是名单上第四位验过成色的。telnet 是还坐在门外的,它要的伪终端交互还没立。netstat 的数没立,ping6 的路没修。名单是不撕的,往后一卷一卷地清。戏唱完了,咱们收卷。
