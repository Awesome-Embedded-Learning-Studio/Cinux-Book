# 客人换了,欠单还在

第三部的收官大戏,壳里的客人自己敲 ping,自己收,自己被打断,咱们在旁边看着,戏算是唱完了。第四部开门,客人换了主位:这一卷的正主是 TCP,而它伺候的头一位客人,上一卷点名等过它,就是 nc。侦察的活儿照老章程办在头里,咱们把它的吃法挨条记下。

nc 的吃法是这样的。socket 要流式的,上一卷这扇门还答着 ESOCKTNOSUPPORT,这一卷的门后得站着真东西。服务端的路数:bind 一个口,listen 把门挂出去,然后 accept 坐下来等人上门,等到了,两头之间就是一条双向的字节流,一头写进去的,另一头读得着。客户端的路数短一截:connect 直接头一个地址加一个口,通了就是同一条流。还有两样脾气,咱们得记下:它读输入读到文件结束,要把这个结束送到对端去,流式的世界里这叫 EOF,半闭着嘴也要把话说完。它给自己备了两秒的读超时,到了点没等到下文就收摊。这两样脾气,一头牵着道别的完备,一头牵着连接的死活,后面各有一章的戏。

配角也照实数。telnet 还坐在门外,它要的伪终端那一套交互,这一卷不给。netstat 要问的是每个连接的近况,数还没立,它问不出来,咱们不装。ping6 问的是 v6 的路,栈都没立。名单记下,戏不冒领。

客人摸完,咱们把这一卷真正的发动机请出来。它不是新客人,是一张旧单子。当年第一遍走到 TCP 收官的那天,笔记里立了一张表,标题写的是诚实标注,一笔一笔明记在案。重传,重传等待的时长 RTO,滑动窗口,拥塞控制,登记的是同一句原因,需要内核的定时唤醒基建,当年没有。道别之后多守一程的 TIME_WAIT,同一句原因。起始序列号的随机化,笔记里写作 ISN 随机化,写明当年用的是确定性递增的计数器,为的是测试可复现。乱序重组、重复应答、快速重传,当年最小可用的选择是乱序直接丢,不缓存。一笔笔记下的是施工单:当年把协议的骨架立起来了,线上的字节能按严格的次序从这头流到那头,握手四次道别都走得通,可线一断、包一丢、次序一乱,骨架上没有一件东西接得住。传输控制协议里的控制二字,当年欠着的就是它的全部本钱。

重走的这一遍,单子照还,次序是笔者拍的板,有讲究。垫底盘的活排在动手之前:把当年最小可用的那副骨架重立起来,状态机、握手、按序交付、四次道别,这是当年的长凳上一案一案验过的东西,这一卷在自家的新底子上复刻齐整。垫底盘不算还单,界线是笔者划的:底盘是旧物复刻,单上本来没有它的名目。真正还单的头一件是定时器件,当年整张单子上出现最多的就是那句原因,基建没有,什么都谈不上,所以笔者把它排在正主前头,立在时钟的家里,后面的每一件都踩在它上头。往后依次是超时重传与往返的估算、三声重复应答触发的快速重传与乱序的修包座、收发两扇窗、道别的完备与多留的一程、全家的对抗负测,最后把流式的成员送进套接字的家族,nc 上桌唱收官的大戏。您拿到这一卷的时候,单子上除了两笔,别的都划掉了。

边界的话,卷首要挂,挂在明处。头一条是老话:当网关的服务没有 TCP 的 echo。这句的出处当年笔记里记的是原话:SLIRP 无 TCP echo,不期望 reply(TX-only,诚实同 UDP)。当年那一发蹭的是 ping 验过的出门路,只证 TCP 的段能从真线上出去,没等回音,握手的应答当年没测过,咱们不替它说话。所以这一卷的实弹全在自家地界里唱:回环口上一台机器自己连自己,双颗核,两头都是自家栈。另一条是取舍:拥塞控制这一卷不做,登记在案。单子上重传那一批还的是可靠,不还的是对外的礼让,完备两个字按传输可靠性的口径数,不吹。末一条是续期:上一卷收卷时撂过,可打断的真睡、软超时、唤醒的令牌,整包排在下一卷。这一卷立起了到点叫人的钟,内核侧的等待吃上了它,可任务睡进自己上下文、有人拿令牌来唤醒的那两样,还没立,咱们在这里把话续上,不冒充还清。

当年的旧话还剩一句要交代:TCP 的骨架当年是怎么验的。当年 host 的长凳上,握手、字节、道别一案一案过,机内的回环口上跑过完整的生命周期,真线那边做过一次出门的烟测。重走的这一遍,这些底子一件件重新立在新底子上,立的时候多还了一批当年明记的债。所以这一卷讲当年的旧事,讲的都是当年为什么不做。这一遍做的东西,一件件算这一遍的新工。两下不混,咱们开工。
