# 没有再犯的五处

后见之明这个词说起来倒是轻巧,咱们把它放到第一幕的战果上称一称。当年踩过的雷区,咱们这一遍走到收卷,有五处旧病是没有再犯的。躲开靠的不全是运气,每一处都说得出凭什么,凭的东西统共两样:一样是代码的版式,版式把错误的路堵死,咱们想走都走不进去。另一样是手里的案卷,当年一桩一桩记下的笔记和修补就是案卷,里头摆着的全是答案,咱们照着对的路走。咱们一处一处数。

头一处的旧病是孩子的返回值。当年 fork 落地那一天,一天之内 fork、execve、wait 全写完了,近四千行的改动,孩子那一半却是个半成品:孩子从父亲被切走的地方续跑,一次调用、两次返回的承诺,偏偏没有人替它兑现,孩子手里没有一个干干净净的零。咱们这一遍,返回尾的镜像一立,末拍把 rax 清了零,孩子生下来头一句话就说对了。咱们把那几拍旧码原文引来给您回个眼。fork 本体那一篇贴过全的,机器倒是连一个字节都没动:

```asm
ForkChildEntry:
    movq 32(%rsp), %rdi
    # —— 中间十拍,和返回段一样,一件一件弹回来 ——
    movq (%rsp), %rsp
    xorq %rax, %rax
    swapgs
    sysretq
```

孩子头一回被请上 CPU 的时候,rip 就落在这一段的开头,一拍一拍把自己的帧弹回寄存器,走的路和父亲的返回段一模一样,镜像说的就是这个。承重的是 xorq 那一行:父亲的 rax,装的是 C++ 那侧算好的孩子 pid,孩子的 rax 没有人替它算,这一拍清了零,当年那个没人兑现的零,在这儿补上了。而且后日谈里咱们把当年的三部曲讲全了,帧指针的糊涂、写穿的栈、末了的公认定式,那三幕是后日谈自己的私房分法,跟咱们这一卷说的两幕不是一回事。三部曲留给咱们的,是每一幕的病因和终局的形状,病因是认得的,形状是现成的,咱们照着搭,就搭对了。

当年的头一遍,写时复制做了,引用计数没做:一帧映射进了几个世界,数的人一个也没有。父亲退了场,帧还了池子,孩子还在读的,是已经被人领走的页,谁退谁留的事,全凭一时的运气。复制什么的那一篇里,咱们把当年那版当反面教材讲过。这一遍咱们拍过板,一次性做对:物理内存每帧一个字节的计数,多来一个映射的世界,咱们给它加一,拆掉了一个世界,咱们给它减一,减到零了,帧才回自己的池子。它凭的算不上新知识,当年的那道坎,知识是够的,卡住的是拍板。

还有一桩当年炸得吓人的:调度器换任务不保存 GS 的两个基址,任务在内核里睡了过去,醒来基址已经不是自己的,下一条系统调用一头栽进零地址,报丧都叠成了双重故障。咱们这一遍躲得干净,却不是靠修:咱们的两个 GS 基址至今同值,swapgs 换的是相等的量,配对怎么乱都乱不了。fork 本体那一篇咱们说过,躲开的干净是结构自带的免疫:病在咱们的形状里压根没有生过,自然也就谈不上修好了。免疫是有期限的,等讲线程的那一卷,用户态有了自己的基址,它就到期了,那天的事那天办。眼下它是真的:当年那一声巨响,在咱们的版式里没有引线。

装载的活当年也出过事。装载循环没把页内偏移算进自己的步进,文件字节全铺去了第一页,第二页起读到的全是零,桌面上的 shell 只回显、不执行,换行进了管道变成零字节,一路查到装载器头上才破了案。咱们这一遍,装载的每一步都是页的纪律:领一帧,整页清了零,文件字节从头铺到自己的份上为止。越界写花邻居的那个病灶,在新版式里没有落脚的地方,咱们说的没犯,说的就是它。同一门页内偏移的算术,这一遍其实是换了衣裳又来了一遍:初版循环把页数当字节步进使,超过一页的段从第二页起根本没映出去,装载器那一章记了案,咱们照实转写。旧病灶没了土壤,可字节和页混着算的这门学费,前后照缴了两回。一回是当年的装载器,把偏移漏在了步进的外头。一回是咱们初版的循环,把页数当了字节步进。

第五处的旧病是往中断里塞重活。当年的桌面亮起来之后,画面的合成有一阵跑在时钟中断的回调里。中断是全机最急的差事,谁在里面多待那么一刻,全机的活都得排队等着,窗口冻住了、画面不动了,一整类毛病的根都在这儿。工程线后来把这个形状翻了过来:中断只递事件,干活的另有其人。咱们这一遍,轮流当家那一卷立了家规:心跳只数自己的拍,应答走自己的路,该不该换人的事,问在返回前的那一拍。中断的处理从头到尾不干活,这句家规在桌面出生之前就立下了。将来咱们的桌面亮起来,画图这件事生来就是任务的活,连进中断的门都找不到。

五处数完了,您看出共性了吗。躲开靠的两样东西,堵路的是版式,引路的是案卷,都不是什么玄学。可这两样东西也有够不着的地方:咱们明知道当年的故事,还是绕了三处弯。那一章倒是比这一章还要紧。
