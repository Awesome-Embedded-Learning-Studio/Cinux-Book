# 验收,和卡住的日子

咱们照例在 host 这头数一数家底。清单数到了十三件:e820、format、framework、result、vesa、bits、gdt、layout、page、image、bitmap、pmm、kernel_image,十三件全都过了。本卷添的是三件:bitmap 和 pmm 围着册子转,kernel_image 看住取尾的算术。咱们拿 test_pmm 打头,它的套路是喂假图:咱们在正常电脑上自己编几张小的 E820 图谱,看册子在各种处境下的表现。头一桩就把名册登记的方向全拴住了:

```cpp
TEST("pmm: low megabyte stays out of the ledger") {
    cinux::boot::E820Entry const kMap[] = {
        make_entry(0, 128_KiB, 1), make_entry(128_KiB, 896_KiB, 2), make_entry(1_MiB, 4_MiB, 1)};
    Pmm pmm{};
    ASSERT_TRUE(pmm.init(kMap, 3, PhysAddr{2_MiB}, 8_KiB));
    ASSERT_TRUE(pmm.managed_page_count() == 1024);
    ASSERT_TRUE(pmm.free_page_count() == 1022);
    ASSERT_TRUE(pmm.allocate_page() == PhysAddr{1_MiB});
}
```

咱们拿假图人工读一遍:低 1MiB 里塞了半截 usable、半截保留,上头才是 4MiB 干净的 usable。册子怎么记?低 1MiB 是一刀全不放行的,4MiB 进了册,合的是 1024 页。内核报的家在 2MiB、地界 8KiB,标走了 2 页,剩了 1022 页空闲。咱们伸手要一页,拿到的是 1MiB——低 1MiB 保留,内核占的是 2MiB 往上,头一个空页可不就落在中间的 1MiB 上。三行断言把方向、切法、标占一项不漏地全验了。后头几桩更狠:有一桩把整个小世界的页循环分光,数出来的正好是 1022——一页不多、一页不少、一页不重。有一桩要 512 页的连续大块,看分配避开内核的洞落到该落的地方,还回去之后册子就回了原样。test_bitmap 的十桩则是给位图词汇本身站岗:字的尾巴怎么算,重复的登记算不算两遍,跨字的洞找不找得着。

面板的那一头,咱们把这卷最要紧的一行单独请出来核对:

```text
[kern] pmm: 32350 pages free (probe 100000 ok)
```

32350 是怎么来的?咱们拿真图算一遍。QEMU 给了 128MiB 内存,图谱里 1MiB 之上的 usable 就一条,0x7EE0000 字节的长度除以 4KiB,合出来的正是 32480 页。内核从 0x200000 起家、地界 0x810C0,向上取整占了 130 页。拿 32480 减去 130 得到的正是 32350。probe 那个 100000 也是同一本册:内核开工后伸手要了头一页,分到的是 0x100000——低 1MiB 整块保留,内核住的是 2MiB,头一个空页自然落在 1MiB 的地界上。要完看了一眼,又原样还了回去,所以面板报的空闲数,还是还完之后的 32350。您看,这一行字里没有一个数是拍脑袋的,全部能从单子上的图谱和鞋盒上的身世推出来。

咱们也把尺寸报一下:MBR 是 512 个字节,多出来的一个都没有。stage2 长到了 13068 个字节、26 个扇区,还在预算的范围之内。内核盘上躺的是 3740 个字节,内存里 528576 个字节的地界——差值您已经知道了,几乎全是躺在 .bss 里的那半兆册子。胖是胖了些,进出倒是平的。

咱们验收到这儿,本卷的活儿齐了。收尾之前咱们去考古箱里翻一段日子,这一回咱们不翻代码、专门翻日历。当年第一遍的这本位图记完的时候,笔记停在了三月二十六。再落笔的时候已经是四月十八,中间空了整整二十三天——一步没走。歇完这二十三天再动的工是描述符表、中断表和异常,活像一场复健的操练。您把日历跟当时的速度对照着看会更感慨:当年头几天倒是另一副样子,串口、格式化打印、内存管理、成套的测试一气呵成,笔记是一天能写几百行的。紧接着的就是那二十三天。第一遍的教程,笔者后来挨过读者一句评语——太陡峭、跟不上。可当年的真实日历里,本来就躺着走不动的日子。

咱们把旧事摆完就回自己的卷。本卷只上了两道菜,掂量过了才上的:串口的一道、位图的一道,每个数都验到了底,咱们连一样多余的都没塞——描述符表、中断、盘,全留在了门外。当年能把一堆东西挤在几天里赶完的底气,是因为有第一遍的后见之明托底。您现在走的这一遍,咱们希望您每一站都能消化完再上路。这也是第一遍的读者用一句“跟不上”换来的。

内核眼下会什么了?咱们的话,说在真正的机器也认的串口上,册子也记在了自己名下的位图里。分一页的能耐有了,还一页的能耐也有了,出事的早上照样喊一声 rip。上一卷收尾时咱们点过的那几件活,这卷咱们清一笔:内存的家底——兑现了,就是面板末尾的那一行。剩下的几件里,中断的表是下一卷的正主:五桩极早的异常还守在自己的岗上,而全量表、时钟、键盘都跟在后面。盘驱动、还有把鞋盒从自家格式换成 ELF 的那一小刀,眼下它们的号还没叫到。倒不是忘了,而是它们的出场得等各自的动机到了,到那天您会认得它们为什么来。

机器安安静静地停在 Halt 里,串口线上的最后一个字节也送完了——下一卷,咱们教内核搭一张被打扰的表,到了那时候,它才真正算学会了听。
