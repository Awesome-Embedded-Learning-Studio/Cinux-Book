# 为什么教进程分身

听得懂喊声那一卷收卷的时候,咱们把幕间的名单又念了一遍,念到了线程,当时还补了一句:一个进程的身子要住进好几条执行流,世界是共享的,栈是各抱各的。今天咱们就来办这件事。动工之前咱们照老章程,把缺的东西盘清楚。

咱们手里现在的家什,生与收那一卷置办得齐全:造孩子的是 fork,换身子的是 exec,收尸连同退出码的交割,都清清楚楚地归了 wait。可您细看 fork 造出来的东西,它是一个整整齐齐的进程:世界是克隆的,写时复制让它省了一半的力气,可省的只是力气,分的决心一点没少——父子的册子是两本,文件表是分开的两张,谁也看不见谁的内存。有些活这样办正合适:孩子干孩子的,父亲干父亲的。可有些活天生不是这个形状:画面的流一边算一边刷,算的和刷的要看同一块内存,服务的流一边收活一边回话,收的和回的要数同一个计数。您说这好办,一个进程里多写几个循环就是了。可循环是排队办的,手头的事没办完,下一件就得等它交了差,咱们到现在为止,一个进程在 CPU 上跑的只有一条执行流,它是进程的全部,也是进程的唯一。

想给一个进程添执行流的时候,缺的就露出来了,咱们一件一件数。缺的头一件,是世界没有半分半合的路子。fork 的世界里只有全分:世界整个克隆,贵是贵了些,但是胜在干净。咱们没有一件家什能照着清单办事,说这句:地址空间是共用的,文件表也是共用的,栈是各拿各的。缺的第二件,是词上的等待。挤在同一个世界里的几条流,总要在同一个词上碰头:这个词的值没变,你就睡,值变了,有人叫你。信号的嗓子是喊任务的粗嗓子,线程之间一个词一个数的细握手,它是唱不来的。缺的第三件,是名分不够用:执行流要各自的号牌,这样在调度器的眼里才分得清谁是谁,可它们又要共一个进程的名字,因为它们对外的身份是一个人。今天咱们的号册是一人一名一名一人,执行流要的双重身份它不认。

这三件缺的,合成的是同一个词:线程。咱们不打算发明它,这话在柜台那一卷就说过了:将来装库跑别人的程序,人家编译好的二进制认的就是 Linux 的约定,咱们一个字都不能自创。线程序列要的那几样,名册上都有现成的名字:造线程走 clone,旗标里写明了哪些共用哪些各持,等待走的是 futex:一个用户词就是一间等候室,各流自己的家当靠 FS 基址指路,musl 在咱们的机器上就是这么用它的。咱们照单全收,一样一样地立。

当年的旧话也得交代。工程线上那二十来个小时连发的六件,到上一卷为止咱们消化了四件,本卷领走的是线程,六件里块头最大的一件,当年从傍晚干到了后半夜,一卷里塞了五个大活。第一遍的读者被它喷得最惨,幕间为密度立的家法,冲的就是这样的日子。咱们这一遍的走法您在本卷的目录里看得见:基址、词、描述、clone、送行的字,五件事摆出五个不同的样子,一件一节地消化,验收之外咱们还要断两桩案中案。最大的一块,配最慢的牙口。

顺序上咱们照着依赖走。基址咱们赶在最前头,它是各抱各的那一半的地基,顺带把号册的双重身份立起来。词上的等待第二,它是几条流碰头的章程。第三件把家当的地基打好,描述层立了起来,clone 才有现成的共用件可指。第四件的主角是 clone 本尊,分家的清单拿在调用人手里。末一件是送行的字,线程怎么退场、等它的人怎么知道,外加名册上一枚安静的雷。下一节咱们动基址,生与收那一卷挂了许久的那句远话,也到兑的时候了。
