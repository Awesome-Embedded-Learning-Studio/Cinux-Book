# clone,商量着分家

家当地基都齐了,本节咱们请主角进门。fork 的世界观,咱们从头到尾管它叫分家:世界是克隆的,表是新开的,册子是新造的,一分到底的性子。clone 要办的事,是把一刀切改成了商量:调用人手里拿一张清单,清单上写明了哪几样共用、哪几样各持,内核办事照的是单。号位照的是 Linux:五十六。清单指的就是旗标,咱们认的七位摆开:共世界、共表、入组、装基址,四面都是分家的正戏,另有三面小旗专管 tid 词的落笔,留给讲送行的字的那一篇细说。清单之外冒出来的任何一位,咱们整个拒掉,答的是 EINVAL,半份的忙咱们不帮——旗标里混着看不懂的位,最老实的回答就是不干,猜着办的下场是把命运交给运气。

四面正戏咱们一面一面说。共世界的旗是 CLONE_VM:孩子的地址空间和登记册最终指父亲的,持有者的计数加一。这里咱们把实话交代在前面:共不是跳过分家,clone 的走法是把 fork 的全套原样走一遍,再按旗把分来的世界退掉、换指父亲的,几百行的手艺一行没省,底细咱们放到下一段细说。共表的旗是 CLONE_FILES:孩子的文件表指父亲的表,全家用的是一张,上一节说的第二层共用。入组的旗是 CLONE_THREAD:孩子坐上席以后,名册上的组号改成组长的,从此 getpid 报的是同一个进程,对外的时候它就是一个人。装基址的旗是 CLONE_SETTLS:孩子还没跑用户态的第一条指令,FS 基址就已经指好了,库进门要找的 TLS,生下来就落在了原位。四面都不设的 clone,答出来的就是又一个 fork,只有一样不同:栈照旧得由调用的人递,user_rsp 的补丁照打不误。这样的用法咱们留着,也给将来的库留的,人家有各种稀奇古怪的玩法。

底子您别担心重复造。BuildCloneChild 头一件事还是把 fork 的孩子整个造出来:新内核栈,帧原样地拷来,写时复制的世界一路不省。造完再按旗标覆写:共世界的,把克隆出来的世界退掉,换指父亲的世界,退掉的世界随持有归零当场散掉:一行不浪费。所以不共的各持与 fork 一个模样,共的改成引用,这个次序保证了每个孩子都从一份完整的底子起身,然后咱们再按旗给它改道。

门前的检查咱们报一遍:孩子栈的地址要界内非零,装基址的值要规范,tid 词必须是可写的。都过了,才轮到本节最妙的一笔,子帧的补丁。您还记得 fork 的孩子是怎么醒的吗:内核栈顶摆着父亲帧的原样拷贝,回家路上 rip 从帧里的 rcx 槽取,孩子落在与父亲相同的位置上,跑的是同一条指令,只是 rax 归了零。clone 的孩子走的是同一趟,帧是整张拷来的,rcx 槽里躺着的本来就是 syscall 的回家地址:一个字都不用改。要补的只有一格:user_rsp。fork 的孩子醒来站的还是父亲的用户栈,那是因为世界是克隆的,栈也克隆了一份,站的就是自己家的。clone 的孩子不一样,世界多半是共用的,栈是调用人另递的,孩子的 user_rsp 必须改成递来的那个栈顶,不然它醒来一脚就踩在父亲的栈上,父亲正在那上面干自己的活。机内的案子里有一条断言,断的就是这两件事:孩子帧的 rcx 与父亲的回家地址同值,user_rsp 是递来的新栈顶。

内核这边改完了,用户的那边还得有人把栈递进来,把分岔的路演出来。咱们把演示用的包装抄上来,一段汇编演的是两面,您一句一句看:

```cpp
    __asm__ volatile(
        "syscall\n\t"
        "testl %%eax, %%eax\n\t"
        "jnz 1f\n\t"
        "xorl %%ebp, %%ebp\n\t"
        "movq %%r9, %%rax\n\t"
        "movq %%r15, %%rdi\n\t"
        "andq $-16, %%rsp\n\t"
        "call *%%rax\n\t"
        "ud2\n"
        "1:\n"
        : "=a"(ret)
        : "a"(static_cast<unsigned long long>(cinux::syscall::SyscallNr::kClone)), "D"(flags),
          "S"(child_stack), "d"(parent_tid), "r"(kChildTid), "r"(kTls), "r"(kEntry), "r"(kArg)
        : "rcx", "r11", "memory");
```

syscall 响了一声,同一个指令上回来的就是两种人。做父亲的拿到的是孩子的号:正数,一测就跳去了标签一,顺路交回的还有答案,函数就返回了。孩子那边的 rax 是零,测试的分支不跳,顺着往下走的第一步是 ebp 清零,这是新执行流的老章程,r9 里存的入口函数归位到 rax,r15 里存的参数归位到 rdi,栈按的是十六字节对齐,call 进的是入口函数。入口函数收尾的地方调的是 Exit,它是不回来的,真要回来了,底下候着的 ud2 当场清清楚楚地响。参数坐的位子也交代一下:栈在 rsi,tid 词占的是 rdx 和 r10,这些都是 Linux 定下的座次:库照座次递话,咱们照座次收,入口和参数走的是 r9 与 r15,是因为内核的帧把通用寄存器几乎全数存档,唯独 rax 是孩子的零,咱们就借 r9 与 r15 两条现成的车把两样东西捎给孩子。

入组之后的名分,讲基址的那一篇立过,咱们这里再点一句:每条流自家一枚号牌,上面写的是 tid,组长号咱们只发一个,getpid 问的是组长号,gettid 问的是自家号牌。组里的成员退场也不走进程的老路,咱们留到下一节再说,那里有一枚安静的雷等着咱们。

最后的一件是护栏,立的地点在造孩子的门口,管的是父亲。造孩子的那串调用,是在父亲的内核栈上走的:克隆世界、抄帧、填册,一层压一层地叠上去。父亲自己的栈要是已经用得很深,叠上去的这几层就可能探底,造孩子的活还没收尾,父亲折在了半路。所以 BuildForkChild 进门头一件事是量栈:用掉的部分过了四分之三,响亮地拒绝,panic 报的是 spawn refused。开工之前的一拒,好过半路的一死,fork 与 clone 过的是同一道量法。至于内核栈自己的守卫页,咱们在懒到家那一卷记过一笔,说它归讲线程栈的这一卷。咱们如实交底:页这一层,这一卷是没有立的,当年栈底的那句魔数哨兵还在岗,量栈的深度闸顶上了岗哨的一半,那一半咱们接着挂,不装作办了。

clone 落了地,孩子的生与回都齐了,可它刚落地那几天,咱们的演示程序在 shell 里跑出了一桩怪事,怪到一个数字说不清自己的身份。下一节咱们查那桩案子。
