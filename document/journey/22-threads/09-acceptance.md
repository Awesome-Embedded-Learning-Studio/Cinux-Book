# 验收:几条流唱一台戏

收卷的章程照旧,看的是三样:面板、测试、实弹。面板这一回的安静,和听得懂喊声那一卷的脾气一样:两枚基址握在切换器手里,桶表是内核静态的家当,词躺在用户的世界里,线程的全部家当没有一件会在开机的面板上留行,新行是一行没有的,咱们也就不抄旧读数了。测试和实弹才是这一卷的正戏。

宿主的长凳上,新添的一件叫 thread_exit,四案装的是清词唤醒、不可写的词一字不动、组员出圈不答 wait、正经子照常交收据,案子的来历前面那一篇讲过,咱们记名不重数。老件里添案的两处:文件表添两条共享案,认领之后两张表的游标一起动,一方销了票,另一方还活得好好的。上下文那件添了两条,规范检查收下两个合法的半边,又把天洞里的值一个一个拒出去。宿主从五十件长到了五十一件,普通线、地址排查线、数据竞争线、内核检查线,四条配置全数绿了。普通线咱们另在开了 KVM 的机器上走了一遍,地址排查线照旧把泄漏的检查开着,长凳的家法听得懂喊声那一卷立过,这一卷咱们照办。整条 ctest 数下来六十四件全过:宿主占了五十一件,机内占的是十三台,口径照旧是串行的。

机内的十三台,台子还是原来的台子,长的只有案数,咱们把新案点一遍。调度的一台从二十四案长到了三十案,添的六案咱们按名点。克隆占两案:头一案断共有的肢体,断言一根根比的是世界、登记册、文件表,孩子指的都得与父亲是同一个对象,基址落的是递来的值,帧也搬了家,咱们要孩子的 rcx 与父亲的回家地址同值,user_rsp 要落在递来的新栈顶。第二案断不设旗的克隆,它就是换了栈的 fork,各持的另起一份。futex 占三案:词动了,等的人拒绝泊车。没人等的词,咱们喊了也只答零。桶里要是睡的是人,咱们只叫醒词对得上的。末一案是线程组的成员:直落回收,wait 来问了,咱们只答没有,孩子链咱们断到归零。咱们把六案排开,机制的每一面都有人看着。链进 ctest 的接线也顺手理了一遍:调度的八个宿主目标都补挂了 futex 和登记册的编译件,thread_exit 单立了一件,这些是构建的家务,咱们记一笔就走。

然后是实弹的戏。盘上的 /bin 里住进了 threaddemo 和 tlsdemo 两位新住户,驾驶的小抄还是那一句:它们是盘上的程序,要 run 加了全路径才请得动。头一出的戏是 threaddemo,它的戏码是:报身份,开了一份文件,生了两条线程,各报各的身份、各干各的活、各退各的场,主线程等完了两个 join,问了问 wait,点一点共用的家当,谢了幕。咱们把会话抄上来:

```text
cinux> run /bin/threaddemo
[thr] main pid=3 tid=3
[thr] motd descriptor=3
[thr] clone answered a=4 b=5
[thr] tid words after clone: a=4 b=5
[thr a] tid=4 getpid=3 fs:0=659918
[thr a] borrowed 8 bytes through the shared descriptor
[thr b] tid=5 getpid=3 fs:0=723717
[thr] joined a: wait=0 word=0 code=65
[thr] joined b: wait=0 word=0 code=34
[thr] wait4 on a thread answers -10 (a thread is not a waitable child)
[thr] counter=255 letterbox[0]=97
[thr] main read 8 bytes from the shared descriptor after the join: ys hello
[3] exited with 0
cinux>
```

这一屏咱们照例念三遍。头一遍看的是身份:主线程是三号,这也是它的 tid,组长自家的号牌与组长号同号。clone 答了四和五,两张 tid 词落下的也是四和五,给孩子落票的旗是活的。两条线程各报各的,tid 是各的,getpid 报的都是三,共用的是一个组长号。fs:0 的两个数最值得看,两条线程的 FS 基址指着共享世界里两格不同的家当,读回来的是六五九九一八,另一个读的是七二三七一七,基址是按执行流隔离的,这是第一件地基的实证。第二遍看字:join 两个都答了 wait=0 word=0,零是被唤醒的回话,词被死亡侧清了零,送行的字全链走穿。code 的六十五和三十四,走的是共享内存里的一格,收据是不走的。wait4 朝线程递了过去,答的是负十,没有这样的孩子,线程的退场与进程分得清清楚楚。第三遍看的是家当:counter 是二百五十五,两条流的加法落进了同一个词,letterbox 开头的九十七,是一条流写进去的字母。最妙的是末一行,线程 a 从三号描述符借读了头八个字节,join 完了主线程再读同一个描述符,读上来的是 ys hello,开机问候的头八个字节早被借走了,游标就停在了第八个字节上,后来的人接着往下读。游标用的是一支,接力的是两处,第二件地基的实证就在八个字节里。末行 [3] 交了零谢幕,组里的成员走尽,主进程得了善终。

第二出的戏是 tlsdemo,演的是第二节的机制:往返与拒绝。咱们把要紧的两行抄来:

```text
[tls] arch_prctl(SET_FS, non-canonical) answers -22 (negative: the base was refused)
[tls] arch_prctl(SET_GS + GET_GS) answers 0/0 base=140737488351192
```

咱们看第一行,SET_FS 递的是天洞里的值,答的是负二十二,门口的规范检查把不规范的基址拦在了 wrmsr 以前,CPU 没有机会发它的脾气。您再看第二行,SET_GS 与 GET_GS 打了一个来回,答的是零零,读回的基址一字不差,那一长串数折成十六进制是规范的用户地址,正是它栈上登记的那个词。老住户 hello 也重跑了一遍,退出码还是当年的四十二,几条流上上下下地跑,咱们没惊动一位老房客。

最后对卷首的承诺。三件的缺,咱们说都齐了:世界可以按清单共用,clone 拿着旗标把家分了,共与不共各走各的门。词上咱们能等也能叫,futex 的桶里没有睡丢的人。号册认下了双重身份,tid 与组长号各司各的职。外加一笔当初没敢承诺的收获:两笔挂了几个卷的旧话在这一卷到头,GS 双值的简化作了废,dup 要的描述层立了户。欠着的也照旧挂明处:跨类的次序这一卷也没动,看得见的内核那一卷记下的这笔,接着留给真要裁它的日子。信号打断睡眠的事没做。内核栈的守卫页没立,魔数的哨兵还在岗。futex 的超时没抓。

幕间的名单,今天咱们勾掉第二项。机器如今一个身子里住得进好几条执行流了:基址各抱各的,世界指的是同一份,等的地点在词上,走的时候留一个清零的字。名单上只剩最后一件了:装库,跑别人编好的程序。客人自带的是一整箱家什,clone 的旗标、futex 的词、FS 指的 TLS,每一样咱们都要用上。下一卷咱们把门开大些,迎它进咱们的门。
