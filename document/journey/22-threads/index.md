# 22 · 同一副身家,各一条栈:线程、futex 与送行的字

听得懂喊声那一卷收卷的时候,名单上排定的下一项咱们没有含糊:一个进程的身子要住进好几条执行流,世界是共享的,栈是各抱各的。这一卷就是来办这件事的。办完了这一卷,一个进程再也不是一条执行流的另一个名字了。

咱们照例盘一盘手里有什么,缺的就露出来了。生与收那一卷教了 fork:造一个孩子,世界整个克隆了一份,贵是贵了些,但是胜在干净,父子从此各过各的。可有些活天生的形状是几条执行流挤在同一个世界里干:一条流算它的数,一条流画它的屏,手里的册子只有一本,谁也舍不得再抄一本新的。今天的机器给不出这个形状——fork 的分家是全分,咱们手里没有一件家什能说这句:这几样是共用的,那几样是各持的。再有挤在一个世界里的几条流,碰头的地点总在同一个词上,一个流等它的,一个流唤它的,这样的等待咱们也没有词。第三件是名分:执行流要各自的号牌,又要共一个进程的名字,号册今天还不认执行流要的双重身份。

所以这一卷的活,咱们摊开报数。头一件办的是基址:两枚段基址记进任务的家册,切换的时候随人走,这是各抱各的那一半的地基,生与收那一卷留的那句 GS 的远话,在这里到了头。第二件立的是词上的等待:一个用户词、一个期望值,内核当的是停车场,收拢队伍的是二百五十六只桶,丢唤醒的老窗口从结构上关死。第三件搬的是家当:打开的文件从格子里搬出来,自立一份带引用计数的描述,fork 改走的是认领,当年留给讲线程这一卷的那笔 dup 旧话,在这里兑现了。第四件是 clone 本尊:分家的清单拿在调用人的手里,哪样共用、哪样各持的安排,旗标说了算。末一件立的是送行的字:线程退场的时候清一个词,等在词上的人就知道了,外加一桩收尸名册上的真案。收尾照旧走的是验收,外加两桩案中案:一个来历不明的三十八,一扇学会自己找地方的窗。

当年的旧话也照例交代。工程线上六月十八到十九那二十来个小时连发的六件家当,咱们一卷一卷地消化,已经数过了四件:可观测和调度类合住在看得见的内核那一卷,信号和进程组这对搭档住在听得懂喊声的那一卷。本卷领走的是线程,六件里块头最大的一件,当年一个白天连着夜里就咽了下去,第一遍的读者就是被这样的密度喷倒的。咱们给它整整一卷,一件一件地办,幕间立下的家法,这一卷的兑现最彻底。

合卷的时候咱们再点一遍手里的新话:两枚基址随任务走,能等人也能叫人的是一个词,家当指着的是同一份持有,clone 分家按的是清单,线程退场时留下一个清零的词。当年六件里最大的一块,到今天消化完了。欠的也照旧挂在明处:跨类的次序没动,信号打断睡眠的事没做,内核栈的守卫页没立,futex 的超时没抓。幕间的名单只剩最后一件了:装库,跑别人编好的程序。客人自带的是一整箱家什,咱们这一卷立下的每一样它都要用。下一卷咱们开门迎客。
