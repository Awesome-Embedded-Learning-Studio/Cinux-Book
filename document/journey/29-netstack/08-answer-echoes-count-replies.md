# 应答与记分

三件套的最后一件是 ICMP,干的活只有一件:回声。回声请求来了当场就答,一拍都不带等的。答案的形状是镜子:类型从请求的八换成应答的零,代码照的是零,配对的标识与排序的序号原样带回,这一对字是问答双方对暗号用的,带错了,对面就认不出这是自己那一句的回音。载荷一个字节一个字节地跟着抄,人家问了什么,咱们一字不改地顶回去。校验和按的是老章法:字段铺了零,整段加了一遍,答案写了回去。

答案往哪送:交给递进来的那个汇,接线的人把它瞄向 IPv4 的 send。要答的人写在头的源地址里,所以件的手上得有头,这正是上一章座上连 Ipv4View 一起传的理由。应答的缓冲是件自己的成员,按数据报的上限一千五百减头的二十备好,得的是一千四百八十,自备的缓冲自己管。这个尺寸管得住的只是自家出的站:自家构的数据报,载荷过了线,send 当场把它拒了。入站没有这道闸:以太帧的载荷区装得下一千五百零四,减掉头的二十,线上来的消息可以到一千四百八十四,比自备的缓冲还多四个字节。这一卷的回环上,来往的都是自家构的包,尺寸全在自家的手里,所以安全。真网卡进了门,线上来什么咱们管不了,这道边界也记在欠的那一页上,收紧的日子等真网卡进了门再定。缓冲在件的肚子里,件的个头有多大,机内那一章咱们再量一次。

回声应答咱们不处理,咱们观察。请求是自己发的,应答回来了,该记的记:答了几声,见了几声,最后一声的标识,最后一声的序号。四个数就是 ping 的整面记分牌。用户态的 ping 还在很后面,今天的记分牌就立在协议层,长凳上读的是它,机内读的也是它,收官的验收,读的也是记分牌。

坏消息的死也有计数,这一件的纪律与全栈一致,长凳上验它的法子就是咱们亲手把坏字节塞进回环,摇了一轮 poll,回头读它的计数。八字节都不到的,refused_short 的计数加一。校验和折不到零的,refused_checksum 的计数也加一。坏包死了,留下的只有计数。

造请求的词也立了:BuildEchoRequest,往调用者的缓冲里写一只完整的请求。标识与序号递了进来,载荷按索引的花样填,校验和照的是老章法,算好了写回去。发不发的事,什么时候发,都是调用者的事。这件词今天是没有主顾的:长凳上与机内的案子,填请求全是手搓的,连第一个字节都是自己铺的。咱们这么干,是考卷的章法:考题要是拿被考的件现构,构包的手错了,他自己也认得自己的手笔,考就白考了。断言跑起来的时候,咱们看的就是记分牌上的四个数,答了几声,见了几声,最后一声的标识与序号,自己铺的字节有没有铺对,记分牌说了算。它的第一个主顾排在第二部,到真线上连发几声 ping 的时候,用的就是它。

三个协议件到此立齐了:记名的 ARP,判验的 IPv4,回声的 ICMP。头文件的依赖单向一条线:ARP 的头认的是设备门面与配置,词书只在 ARP 的件里被认,ARP 的头是不认词书的。IPv4 的头认词书,ICMP 的头认 IPv4 的出站结构,IPv4 的那头从不回头认 ICMP,回程走的是擦了类型的座与汇,谁也不存谁的成员。整条的链,碰硬件的一行没有,碰操作系统的一行也没有。链立齐了,咱们接上电试试。
