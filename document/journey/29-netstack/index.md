# 校验与回环栈:长凳、词书与一轮 poll(卷名草稿)

安全那一卷收卷的时候,话撂在了两处:socket 的号位要生在那扇门上,还有一套当年内核里开着中断跑长活的死法,现场都排在网络的名下。咱们这一卷就走进网络了。不过网络这一摊,咱们拆成了四部走,各有各的主题。头一部立的是协议栈的纯逻辑层:校验和的算术、头的词书、协议的座与预算制的搬运,整条的链不碰硬件,不碰操作系统的任何一件家当,缓冲是从外面递进来的,时钟也是从外面递的。死法那套戏码咱们看过病灶了,它长在泵的身上,长在异步的等待上,不长在协议的字里,所以它排在第二部的开场,这一部是一句不抢的。比上一卷撂话的时候又细了一层:上一卷只说现场排在网络的开场,这一卷把开场落到了第二部的泵上。号位的事也还早,socket 是排在第三部的,这一部只把它脚下的地基立好,给四层协议的落座备下凳子,四层说的是 IP 之上按协议号落座的那一层,ICMP 与往后的 UDP、TCP 都坐那边。所以这一卷的名字,咱们暂且叫它校验与回环栈:校验说的是反码和那一门算术,回环说的是一台没有网线也听得见回声的设备,它上一卷进了网络册当首住户,这一卷整个是它的主场。

咱们照例盘家底。手里有的:驱动基本框架那一卷立的设备门房与三本册子,网络册的首住户回环,发即入队、读才出队的脾气,四帧的队列答满答超长都诚实,不带地址也不带以太头,这些话那一卷都立下了。消费者握的只是端口,设备是不认的。端口的那层皮,驱动基本框架那一卷立的是手法,件名 NetPort 倒是头一回露面:concept 查一遍、擦一次类型,查有没有硬件地址、查地址、查有没有以太头、报帧上限、收一帧、发三层载荷,六张嘴原样地传。base 的家底厚实:位词汇、比特掩码、字节的读词写词一应俱全,只是字词序的旧词从盘和固件学来的是小端,大的那一头还没有词。测试场的家法也在:宿主与内核一份声明两张实现,长凳上跑得快的跑在前头,机内的世界只留它盖不住的那几件。缺的咱们也一片一片数:kernel/net 这个目录还不存在,协议栈是一行都没有的,ARP、IPv4、ICMP 的头一个词都不认识,校验和的件 base 里一个字都没有,全树的检索命中的只有几台设备的识别码,那是另一家的算术。坏包来了,走的是崩溃的老路。

咱们进站时,机器是一台听不见网络的机器:网络册上挂着回环一个住户,跟它说话的人没有,栈、词书、校验一概是没有的。出站的时候,回环上 ping 127.0.0.1 一轮 poll 跑完了完整的来回,请求答了,回声看见了,记分牌上的标识与序号对得上。机器面这么算:全链的证据交在宿主的长凳上,机内的两案随第二部的检查点进树。坏包六类进了门,死得各有各的计数,没有一个是冤枉的。开机面板是一个新字都没有的,栈还没接进开机的世界,生产的那一摊咱们没动,接线的活连着泵一起排在第二部,这个边界咱们挂在明处。

这一卷的活,咱们摊开报数。头一件摆的是长凳,立的是章法:纯逻辑层是不碰硬件不碰操作系统的,家族的事实簿随目录一起立,双向的禁令交给机器把守。第二件把算术立进了 base:立的是反码和一件,字节配对、进位绕回、取反的三步,六个案子在长凳上考过了。第三件补大端的读写词,判例也顺手收下:构包的手顺了小端写词,头一轮就红了。第四件写的是词书:四张解析的脸,以太、ARP、IPv4、ICMP 的回声,每张脸要么给字段、要么给一个有名字的拒因。第五件搭栈:端口表、按类型字注册的协议座、预算制的 poll,无头的口直送 IPv4 的座。第六件给 ARP 立的是名册,学会、查问、造请求的三张脸,查不着的事不当错误。第七件立的是 IPv4:判了两次再派发,出站的数据报整只构好交给汇,汇是出站字节递出去的那个口,第七章说它的形状。第八件立的是 ICMP,管的是应答与记分。第九件在回环上跑通一轮 poll 的完整来回,预算当缰绳的案也一并立下。第十件是坏包的负测全家福,逐类断言了死因。第十一件进机内立纪律:16 KB 的栈上大对象住文件作用域,两案的进树随第二部的检查点。末一件收尾走的还是验收。

当年的旧话咱们也照例交代。当年网络的那一段,抽象、ARP 与 IPv4 与 ICMP 的三件套加回环、真网卡,三笔是一天里连着打完的,重走的这一遍摊成四部,一步一步地验证。取舍还是原来的老样子,一条家法:能解释今天手里这套机制的,进得了正文,在它该在的那一章把来龙去脉摆开。当年为什么从回环上跑 ping 起步,理由今天原样成立:模拟器里那个用户网络的回包是异步投递的,什么时候到不作准,而回环是纯内存的队列,一轮 poll 确定性地排干,时序攥在咱们自己手里。当年留下的几条判例,这一卷一一兑了现:三个模块互相需要,谁也不存谁的成员,构造期是没有环的。ARP 查不着的事不当错误,这一轮发了请求,下一轮再来问就是了。大对象住的是文件作用域,不住 16 KB 的栈。还有处理函数里往外发的重入,预算就是它的缰绳。只作反面教材的,收敛地讲。

合卷的时候咱们再点一遍手里的新话:base 里有了反码和的件,大小端的读写词齐了,词书会具名地拒绝,协议按类型字落了座,预算管住了循环,ARP 学会了异步地等,IPv4 判了两次再派发,ICMP 的应答与记分立住了,回环上一轮 poll 跑完了 ping 的来回,坏包六类死得是有计数的,机内的纪律也立了。欠的还挂在明处:栈没接进开机的世界,面板上是连新行都没有的,ARP 造的请求今天只有长凳上的案在用,反码和分段累加的本事在栈内还没有主顾,无头的口派发一律当 IPv4,IPv4 是不分片的。戏也照旧往前排:第二部把泵立了起来,内核的线程常驻地摇它,真网卡进了门,第一声真线的 ping,连同当年开着中断跑长活的那套死法,开讲的地方都在那边,NetStack 的生产接线也归那边一起上。socket 的号位生在门上的事,是要排在第三部的,这一卷立下的四层座,就是往后 UDP 与 TCP 落座的凳子。这一卷咱们就收在这里。

卷名咱们暂记作《校验与回环栈:长凳、词书与一轮 poll》。候选的名字另有三个:《坏包死得有计数》《回环里的第一声回声》《判两次再说话》,连同定名的活,都留给咱们日后慢慢挑。
