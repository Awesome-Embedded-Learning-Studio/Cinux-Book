# 开工头一件事,摆长凳

网络这一摊的活,跟前几卷有个不一样的地方:前几卷的产物长在机器里,开了机就看得见,这一部的产物是纯逻辑,不开机也能把它全验了。所以协议的事往后放一放,咱们开工的头一件事是摆长凳。咱们把整条协议栈写成一层没有操作系统耦合的东西。这一层不认的东西有三样:设备、中断、调度。缓冲是从外面递的,时钟也是从外面递的,栈自己的手里只有词书、座与计数。这样的一层,宿主的测试场原样跑得动,机内的世界原样跑得动,咱们写到一半就能按住验一段,不用等网卡进了门再回头补课。

咱们摆出这个姿态,图的不是省事,是被网络的两头天性逼出来的。一头是坏包:网线上来的字节咱们半个都不能信,校验与拒因是这一层的正课,而正课最好搬在没有硬件噪音的桌上上,咱们把电平毛刺与时序怪相留给驱动那一层,不该混进协议的考卷。另一头是异步:回包什么时候到不由咱们说了算,等是往后泵分内的事,这一层把等字从字典里划掉了,查不着了就记一笔,下一轮再来问就是了。这两头划清楚了,协议的字才立得干净,验的时候才有确定性可言。

目录随需要出生的家法,这一卷轮到的是 kernel/net。头一件进目录的是家族的事实簿:以太头十四字节,类型字 0x0800 说的是 IPv4、0x0806 说的是 ARP,ARP 的包定长二十八字节,IPv4 的头最小二十最大六十,协议号也进了簿:ICMP 是一、TCP 是六、UDP 是十七,ICMP 的回声头八个字节,回声请求的类型八字、应答的类型零,回环的地址 127.0.0.1,用户网络里自家的地址 10.0.2.15 与要喊话的对端 10.0.2.2。这些编号是协议家族的户口,咱们一个家就收齐了,往后代码里不许再出现裸的数字。连主顾还没到的词也备进了家:回声消息十二字节的身材,应答等待的一秒二,用的都是第二部的事,词比主顾早进了门。设备那一侧的事实,地址六字节、帧的上限一千五百一十八,住在设备家族自己的事实簿里,协议侧用 using 把以太头长度这个词借了过来,为的是复用而不是另写一遍,两个家各管各的事实。

容量咱们也当事实记进簿:一张栈同时侍候两口,类型字的座四个,四层的座也四个,一次 poll 的预算十六帧,构出的数据报顶到一千五百,ARP 的名册四条,出门的生存时间六十四。这些数字是配置而不是教条,要改的时候改的只是簿子,逻辑是一行都不用动的。往后线接上了哪个不够用,改的也是这一页。

姿态立了,不然写着写着手就伸向硬件了,所以总得有人守。咱们把禁令写成脚本交给机器:kernel/net 里不许出现 PCI、USB、MSI 那些驱动主题件的头,也不许出现任何网卡的名字,协议栈的手够不着硬件,立的是头一条。设备家族 kernel/driver/net 也不许倒过来把 kernel/net 的头 include 进来,爬进协议栈的设备,犯的也是另一条。一正一反的两条禁令,咱们都交给脚本逐行去检索,命中了就报 FAIL,连同命中的那一行一起喊出来。当年第一遍守这道闸用的是四条检索的老判例,重走的这一遍把门立成双向的,往后每一卷进网络的新件进门就得过这道闸。

这一部不做什么,咱们也交代清楚。立泵的活落在第二部,它是那边的正主。咱们不开中断也不点网卡,socket 的号位一个不生。栈立好了,长凳上验完了再进机内跑一遍,这一部就算收了,接线的活连着泵一起排在第二部。所以卷首把话撂明白:这一卷收工的时候,机器开机的样子与上一卷分毫不差,新的东西全在长凳上、在测试的镜像里。咱们从最底下那门算术开始。
