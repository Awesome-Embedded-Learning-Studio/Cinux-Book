# 判两次,再落座

IPv4 的件是这一卷最厚的一件,咱们给它的职责就一句话:进来的判两次,出去的整只构好。判的第一次交给词书,头合不合自己说的话,四个拒因各归各的计数:短一项的进 refused_short,版本一错的进 refused_version,头长一谎的进 refused_header_words,总长一亏的进 refused_total_length,死的时候都留名。第二次是算术:头自身声明的那些字节,连校验和的字段一起,反码和是一定要折到零的,折不到零的案子,refused_checksum 的计数加一,包也就死了。两次都过了才轮到派发。两次判的是两样东西:词书判格式,而算术判内容,一道拦说谎的头,一道拦算错的和。

派发交给四层的座。这一层的座与栈那一层的座同构,只是登记的钥匙从类型字换成了协议号,ICMP 占的是一号,往后的 UDP 十七、TCP 六号,来了就坐。落座递载荷的时候多带一样东西:Ipv4View,解析出来的头。为什么连头一起递,因为回信要答问话的人。ICMP 收到了回声请求,是要回的,而回给谁,得看头的源地址,咱们要是在座上不传头,回信就成了没头苍蝇。

头里声明的总长,与包实际到达的长度,谁说了算,咱们在这里接词书撂下的那一棒。模块取小:声明的总长与缓冲的真长,短的那个说了算,减去了头长,就是交给座的载荷长。线上多给的以太填充不下货,声明超出缓冲的也不越界去拿,拿得到多少就老老实实地交多少。载荷这边有取小的法子护着,头的声明对缓冲的核对,词书与模块这一卷都还没做:头说自己六十个字节、缓冲里只躺着二十的截断包,照样能走到校验的那一步。这笔挂在欠的那一页上,真网卡进门的日子再补。哪一部接走?到时候再定也不迟。欠着的后果得摆开:头说六十、缓冲只有二十,校验那一步读到的是缓冲外面的字,长凳的紧数组上这是未定义行为,机内的帧缓冲宽一些,读到的是界外的陈旧字节,算出来的和是正是邪全凭运气,包死得不明不白的。就算越界的和碰巧折到了零,后头载荷的减法还藏着一柄无符号下溢的刃,二十减六十会给座递上天文数字的长度。上一卷咱们刚给客人的指针立了门,自家进门的包,界内的字才作数,这笔债的分量就在这里。

出站的活是 send。调用者递一个 OutboundDatagram:去的是哪,走的是什么协议,载荷放在什么地方,长度占的是多少,四样事实收在一个结构里递了进来。件里构一只完整的五字头:版本四,头长写的是五个字,总长写上了,标识与分片的字全零。咱们不分片,超长的载荷进门就拒,一千五百减二十是它的上限,如实地交代,分片的活远期登记。生存时间写的是六十四。校验和按的是老章法:字段铺了零,整头加了一遍,答案写了回去。源地址写自己的,目标地址写要去的地方。构完了连头带载荷整只交给汇。

汇 DatagramSink 是这一卷接口上的新词,咱们要的形状就两样:一个不透明的上下文指针加一个函数指针,问过了 assigned,接没接线就都知道了。
树里定好了形状,咱们把两个字段表照原样摆出来:

```cpp
struct OutboundDatagram {
    uint32_t             destination = 0;
    unsigned char        protocol    = 0;
    const unsigned char* payload     = nullptr;
    size_t               length      = 0;
};

struct DatagramSink {
    void* context                                                 = nullptr;
    void (*send)(void* context, const OutboundDatagram& datagram) = nullptr;

    [[nodiscard]] bool assigned() const { return context != nullptr && send != nullptr; }
};
```
件不知道汇的那头是谁,接往回环的也好,接往真网卡的也好,接线的人来瞄。这个形状是有两层来历的。一层是当年的老判例,发送的路径不该被固定在件里,借用而不拥有。另一层是这一卷立下的参数家法:函数的参数,咱们过了四就收成结构体。递载荷要的是四样事实,收成了 OutboundDatagram,汇占的是两样,也收成了结构,函数的嘴上永远干干净净,调用的人一眼看得全。

init 与重瞄分了两张脸,这是给开机留的活口。init 是从头来的:计数清了零,座也全下了,汇与自家地址定死。aim 只换汇与地址,计数与座是原样活着的,起步跑的是回环的世界,线来了重瞄一次,旧数是一笔不清的。这个活口今天还没有用上它的人,第二部接线的那天它就是正主,脸咱们现在就留好。

互相需要的死结,咱们这一卷也解了。ICMP 的回信要经 IPv4 构头,IPv4 收到的载荷要交 ICMP,引用是互相的。当年第一遍在这里的教训是互相存成员,构造期就打成了环,结果谁也生不出来。这一遍的解法两头下:IPv4 不认 ICMP 的类型,只认擦了类型的四层座。ICMP 不认 IPv4 的脸,只认的也是一个汇。接线的人在两个件都活了之后才把线接上,构造期谁也不欠谁什么。这个解法不是这一卷的专利,往后的 UDP 与 TCP 进门,坐的都是同一张凳子。
