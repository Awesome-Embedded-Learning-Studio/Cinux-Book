# 桌面客人上桌:带来源,定版本

上一章收尾咱们数过家底,链的那一头从桌面报到从机、再从从机喊到前台组,一路是通的,单缺一位真会开窗、真会报尺寸的客人。这一章咱们办的就是请它上桌这件事。客人是有名有姓的,桌面程序叫的是 vesper,家在 GitHub 的公开仓 `Awesome-Embedded-Learning-Studio/vesper`,您想看就能去看,您想克隆也就能克隆走,它自家的说明就住在那儿。它脚下踩着的图形核心又是另一位客人,版本同样让 vesper 给定死了,一环扣一环地传下去,谁都是不浮动的。前几卷请 busybox、请 GCC 全家是什么姿态,请它就是什么姿态,来源是带上的,版本是定好的,号是对得上的。

请客人的纪律,咱们顺势立在这儿。客人的源码按子模块进咱们的树,就定在这一卷所带的版本上,版本定在什么地方,树里是记着的,一查就明白了,盘上跑的就是公开仓里的同一版。里子是一概不改的,客人家里缺什么、哪儿要修,去改去收的事都到客人家里办,咱们这边只跟着升版本。咱们这么较真,为的是来源不断线。您想,一份被偷偷改过的客人,跟公开的正本就对不上号了,您按公开仓去读,读到的跟盘上跑着的两样,教程就两头不接气了。

客人怎么上盘,咱们看着它走一遍。构建是不另起炉灶的,走咱们自己的构建树,出一份静态链接的桌面,glibc 的血统,整个装在了一个二点八兆的文件里,落进盘上的 /bin,名字起的就是 vesper。生态那一卷把盘上的血换成 glibc 一家,接的就是这一路客人,如今连桌面也进了门。上盘的路出过一案。客人是要在多种宿主上安家的桌面,构建里除了走帧缓冲的通道,还带着伺候显示服务器的通道,那一系的库把依赖公开声明在链接行上,谁链了它,谁就把显示服务器的几串动态库整串继承了下去。静态链接的门口见了动态库,拒答是当场的,链接就断在了那儿。咱们顺着链接行找回去,根子在两条通道的家当没分家,修法是把桌面壳连着它的画布单独立成一座库,帧缓冲的通道从此只背自己的家当。改完了,静态桌面顺顺当当地出来了,出来的就是 /bin 里那二点八兆。改动落在了客人家里,改的是 vesper 自家的构建文件,收尾的事也由客人家里收,咱们这边只升了版本号。

桌面上盘了,谁去拉它?生态那一卷是交过班的,一号座上坐着当家的 init,开台照 /etc/inittab 里的当班表,行上带 respawn 记号的,谁退了场它按样重拉。点火的头一版,咱们就照这个章法来,当班表里添一行带 respawn 记号的座,桌面倒了,重拉的事归当家人,跟当年壳的兜底一个待遇。

后来盘统一了,开机的门收敛成三扇,名号叫的是 run、run_debug、run_gui,生态那一卷立门的时候说过,门后是暂时无人的。三扇门共用的是同一张盘,麻烦也跟着来了,咱们上手一进图形门就发现不对,桌面是没了着落的,您不手敲 vesper 它就不亮,统一盘之前的自动桌面,成了回归。补回来的办法,咱们补在会话上。run_gui 起机器的时候,经模拟器的固件配置器递一张条子进机器。固件配置器是模拟器往机器里塞数据的正经入口,开机以前就把数据放了进去,内核在开机路上是读得着的。条子上的话是,本次会话是图形的。条子原样交到一号座上当家人的手里,当班表里那行服务只在条子写着图形会话的时候动手跑一遍,切到普通用户的身份,exec 盘上的桌面。条子要是没递的话,run 与 run_debug 的会话里那行服务就不起,您得到的是干干净净的串口会话,登录提示符等着您,桌面的一行代码都不跑。三扇门进的是同一家,一张盘装的是同一家当,差的只是一张条子的事。

> 当家人头一回跑那行服务的时候,还栽了一个小跟头。服务的身子是一份脚本,咱们 exec 那扇门只认 ELF,当场就把咱们拒了,报的号也文不对题。正路是把脚本开头的解释器行认进内核,咱们没扩张到那一步,当班表里明写的是由 /bin/sh 来执行,路照样是通的。

图形那扇门的参数,这一卷又配了两样,另有一件小事您上手就知道,咱们一并交代。头一样是把 USB 的键盘鼠标一对摘掉,输入只剩 PS/2 的一路,键盘鼠标还是各走各的两股流。为什么摘得这么干净,下一节的实弹里判例自己会现身。第二样办的是显示窗口,窗口是开着的,画面按窗口的大小整体缩放,咱们如实交代,缩的只是画面,机器里头的图形模式还是开机定死的那一档,不跟着窗口走的。小事是 PS/2 的鼠标,要您在窗口里点一下才捕获进来,键与指针这才归了机器管,想拿回来的话,您就按 Ctrl+Alt+G。

火点着了,旧话咱们翻出来对一眼,这一段笔者来念。第一幕的桌面,是编译开关请进内核的自家人,开关一打开的时候,整座桌面就住在内核里了,连终端都是在内核态跑的。这一遍的客人住在外头,盘上的 /bin 里一个文件,拉它的是当家人,内核从开工到收官的全程,没见过它的一行源码。机器点起来的时候,咱们从 run_gui 那扇门进去,您还没敲下头一条命令,桌面已经亮在屏上了。亮得真不真的问题,下一节咱们一条判据一条判据地验,亮不亮的事,咱们让像素说话。
