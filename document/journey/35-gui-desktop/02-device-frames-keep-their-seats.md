# 设备帧的座:映进来,不还回去

上一节撂下的话,现在来兑现:地基的头一件,安的是设备帧的座。安座之前咱们把要请进门的客人看清楚。桌面程序要往屏幕上落一个像素的话,您想,这个像素写到了哪儿?落在显卡自己带的一片存储里,行话叫的是帧缓冲,压根不在咱们插的内存条上。程序要往里落笔的话,就得把这片存储映进自己的虚拟地址,像用一段普通的内存那样用它。

偏偏麻烦就出在这个像字上。懒到家那一卷立的登记册,开张到今天收的每一段,垫在底下的都是咱们自家的帧:匿名的,底下垫的是池子。文件的,底下是盘上的字节。家法就是照这个前提立的。如今头一回来了位新客人,背后站着的是设备。它要进门的话,老的家法就不能原样沿用了,册子的家族,就得给它添一个新的门类。

座添在了门类上。每一段往册上落的时候,记的是从哪到哪、许做什么,出身也一并记着:匿名的补零,文件的读缓存,栈的向下长。设备区间跟兄弟们坐在了同一本册上,差别只在背后站着的是谁。至于程序怎么把这样一段立上册,开哪扇门、递什么凭证,那是下一节像素正门的戏。三处的章程咱们挨个走,都是册子收下它之后的事。

头一处改在了补页上。咱们把老路复习一遍,再走新的。程序头一回碰一个还没映的地址,缺页来了,裁决者照懒到家那一卷立的路查册、问权限,认出段的出身,按各自的出身补页。匿名的路子咱们熟:从池子里领一帧,整页清了零,画上了页表。而文件的多一道手续,把盘上的字节读进帧里再画。两条路有个共同的地方,您看:帧,都是从咱们家的池子里领出去的。

设备座是两条老路都不吃的。缺页还是照旧地来,裁决者照旧查它的册,认出的是设备区间,补页就拐进了一条新岔,岔里的池子根本不出场。咱们拿一页真的走一遍。裁决者算出页在段内的偏移,拿这段偏移去问设备:落在你哪一枚帧上?设备按自己的地界答出一个帧号。页表就照答出来的帧号画,写位照册子给的权限给。帧是一枚都不领的,零也是一点不清的,盘也不用咱们读,内容本来就住在设备自己的家里,映过去了,像素就在那儿了。

所以物理内存的名册上,从头到尾都找不见它的影子。设备的帧不是内存的家当。后面的两处章程,盯的都是这一句。判据咱们配了三案,都立在了机内。直映的一案,问的是一枚,答的也是一枚,页表里画进去的,正是设备自己报出来的那枚帧。偏移要是问出了段外,设备就把这问话拒了,缺页立着不补就是了,越界的照越界办。连答帧的座都没装的设备,回的也是同一声拒,倒是一点也不含糊。

第二处改在了还帧上。借了要还,这是内存世界的老礼数:拆映射、任务退场的时候,拆下来的叶表项要是带着现在位,帧计数的那道手续就得走上一遍,数减到了零,帧就回了池子。可设备帧是走不得的。咱们把灾难演一遍,您就看清了。假设某个任务退了场,名下那枚设备帧照老路回了池子。池子是不知情的,转手就把它发给了下一个任务。新主人往里写自家的数据,一笔一笔地写,每一笔都落在了屏幕上。把别人的屏幕当空闲页卖,这样的事,咱们一步都不许有。

所以还帧的路上立了一道闸,闸的背后是一张登记表。咱们把它跟任务名下的登记册分清楚,那是两份不同的册子:登记册随任务生灭,登记表一开机就立在内核这边了,管的是帧的归属。设备节点上桌之前咱们走布线的手续,把自家帧的地界报进来,物理的起点按页对齐,张数也是按页凑整的,报的是一整段。表里装得下的至多是四段,而一段只认一个设备,重叠的段拒收,一帧认的主人也只有一个。段进去了就不挪窝,表是只添不减的。

还帧的手续走到闸口,咱们拿帧号在表里过一遍。落在段里的,咱们放行,不数也不还:它是帧池外边的座,池子从来是管不着它的。落在段外的,照旧走帧计数的路,该还的还。设备的帧从进系统的头一天起,归属就写明白了,它是设备的,谁也不许当它是没人要的。

第三处改在 fork 的分家。生与收那一卷立的法子,咱们还记着:父子合用一份帧,两边的页表都画成只读,打上写时复制的记号,谁写了谁挨缺页,裁决者接了案,分家的抄一份自家的,独享的把写位复权。设备区间是不吃这一套的。fork 克隆页表的时候,孩子名下直接画进的也是同一枚帧,写位照册子给足了,是直通可写的,共享的记号一个不打。

道理是不绕的,咱们顺一遍就通。写时复制护的是内存里的内容,怕的是落笔写脏了别人也要用的那一页。设备帧上落笔的话,笔笔都落在了设备自己身上,父子俩写的本来就是同一扇屏,各抄一份这回事是没有的,谁的内容也弄不脏。生态那一卷立共家的储物间时,共家房同样不走写时复制的路,不过那边给共享票加了一票,设备帧是连票都不给的。票是替还帧数数用的,它的还帧之路压根不存在,数它做什么。

地基的头一件为什么立的是座?往后的戏全压在它上头:下一节的共享映射,映的就是设备区间,桌面自己的绘图家当,也是从这扇门进的。当年的第一遍没有这一步,笔者把那桩旧案照实念给您听。当年的头一张画布,是一块三兆字节的内存,一次分配了下去,三层地基债一齐炸了出来。

头一层炸在了堆上。当年的堆没有上限,三兆字节的画布一开口,它就一路长了上去,长进了设备内存与栈的地界。第二层炸在了门牌上。那块物理地址,直接映射是盖不到的,内核拿物理地址换虚拟门牌的那一步,换门牌的人自己吃了缺页。第三层是最隐蔽的,咱们多看两眼:把关 GUI 的编译开关一开,测试过的就不全了,开关一关就又全过了。病就被挡在了门外,发作的样子谁也没见过,盲区就是这么来的。

这一遍三层的根都除了,咱们一对一对过去。堆住自己的窗,长是按页往上长的,头顶的门牌管够。设备的地址也不跟内存条挤直接映射,内存当家的那一卷起,屏幕走的就是自己的设备窗。至于当年的盲区,三案判例都立在了机内,哪道编译开关也不能再把病挡到门外了。而 GUI 对内存布局,是一场货真价实的压力测试。当年一遍就炸穿了三层,这一遍的压力照样来,接招的座已经立好了。
