# 队列、钟与摇泵的人

鼠标上了电,字节也解得成样本了,上一节收尾撂下的是两句问话,12 号线门口谁来接、两股流在什么地方合。头一句咱们从门里答起,接货的就是中断处理自己。12 号线一进了门,处理把上一节单独成件的解码器交出来的样本接住,当场翻成事件的记录,哪一路动了,动了多少,是按下的一笔还是抬起的一笔,再请钟把时间戳打上了,一条一条地递进流里。键盘那边的 1 号线早就在这么干了,翻好的键号进了门就递。发布的这一步住在中断里,活是掐得很短的,盖一枚时间戳的工夫,递进环就出了门,别的东西咱们一概不碰。

咱们顺着往下问,就问到队列的配法。如今机器上的生产者有两位。省事的配法是开一条大队列,谁来了都往里塞,取的活归另一头的读者,咱们偏不这么配。跟客人对上的口径,说的是一条流单生产单消费。这句话说的是流两侧的身份:写的那一头是永远只有一位的。读的那一头,也是永远只有一位的。身份干净了,次序就不用谁来主持了。键盘和鼠标共用一条队列的话,写的那头就有了两位,这句话当场就破了。拿守卫来补行不行?写以前关掉本核的中断,单核上是真挡得住的,可咱们的机器是两颗核的,关得住本核的闸,关不住另一颗的门。所以咱们不在一条队列上赌,键盘的记录进键盘的环,鼠标的进鼠标的环,一人一条流地分开,生产的算生产的,消费的算消费的,两头就都数得清了。环的深浅是六十四条,外头搭着一把自旋的小锁,那是内核自家的谨慎,本钱是身份的,不是锁的。环要是真灌满了,内核把环清了,丢的那一笔也记下,下一趟读开的头一条,就是丢了东西的口信,还按着的键一律补报抬起,免得桌面以为还有没松开的手指。

门外的这一半,读的礼数三件。头一件是整记录地读,一条的分量是二十四字节,装得下几条咱们就给几条,半条是从来不过线的,上一节立过的老礼,咱们门里照办。第二件说的是空了不硬撑,环里是一条都没有的,流回给的是一句 would-block。第三件说的是,等的礼貌不住在流里,照旧是住在门上的。描述符生来带非阻塞位的,门答的是 EAGAIN,眼下是没有东西可读的,说完这一句就走了。没带的,门里备着的是一只圈,收着了,抄出去答的是字数,有信号候着的话,答的就是 EINTR,出了门,都不是的话,就让出一圈的位,把处理器交到别人的手里,下一圈轮回来了,咱们再收。这个圈您见过,UDP 与 socket 那一卷的门上,一模一样的四步,同一位老师教出来的。

圈是转起来了,总得有人一圈一圈地摇。摇泵的人是谁?这一卷的答案跟前几卷不一样,咱们数数家谱。泵是咱们的老词了,点亮网卡那一卷里咱们给排水立过一具泵,UDP 与 socket 那一卷里咱们给控制台收字又立过一具,两具都是常驻的内核任务,过的是摇一圈让一圈的日子。这一卷的泵住的不是内核。内核到收官的那天一行 GUI 代码都没有,自然也不会养 GUI 的泵,摇把子头一回换了主人,从咱们的手里交到客人手里。桌面的主循环就是这具泵,它把两个节点的描述符攥在手里,一趟一趟地读,键盘的记录,鼠标的记录,到了它手里才照面。两股流在内核里是从头到尾没见过面的,合流的这一步,内核是压根不掺和的。前几卷撂过的是引擎归引擎、调用者归调用者这句话,这一卷把它挪进了用户态。引擎是内核的环和门,摇引擎的,是别人家的主循环。

当年的这一口,恰是栽得最疼的一口,笔者把案卷摊开讲。当年的 GUI 住在内核里,泵也跟着住了进去,还挑中了最不该挑的住处,时钟中断的回调。机器的心跳一秒一百下,每一下进的都是回调,回调里干的是三样活,事件泵摇了一遍,画面合成跑了一遍,终端轮询转了一遍。中断上下文是什么地方,打断别人进门、放下东西就该走的客座,让一具常驻的泵住进去,门就被长活占了。桌面的活一忙,回调的活就干不完,下一次的心跳也进不来,调度器是收不到让位的,整台机器陪着桌面一起僵住了,画面是冻着的,键也是不应的。这桩病当年拖着走完了收官,第二幕花了一整段功夫,才把 GUI 从中断里解了出来,搬进了用户态。这一遍咱们谈不上修它,这病从结构上就生不出来了:内核里没有 GUI,泵想搬进时钟中断的话,连门都是找不着的,它生下来认的门就只有一扇,那是客人自己的主循环。

接线的活拢共四口,像素的正门,输入的两股流,摇泵的人,末一口给的是钟。这一口是最薄的。函数指针表的上头,问钟的那一项,要的只是此刻,走的路数是不回头,后一次的问话,不会比前一次问出来的小。这样的钟,咱们手里早就有两座,心跳那一座是一百赫兹的,开机起就在跳了,细针那一座是块高精度的事件定时器,跑别人的程序那一卷请进来的,专管两次心跳之间的刻度。问钟的那一号也早就挂上了号,单调的那一问,答的是开机以来走过的工夫,事件记录头两笔的时间戳,打的也是这同一口钟。这一口没有要干的新活,门是开着的,钟是走着的,客人伸手问一声就是了。

走到了这儿,家当与边界咱们一起挂明。咱们讲的始终是兑现,环怎么排,等待怎么答,钟怎么走。事件的词汇,记录里每个字段的含义,表上究竟要什么,正本写在客人自家的说明里,咱们不在这儿重述。咱们要是凭记忆背写一份,写岔了一个字段,读者手里就攥着两份对不上的正本,照哪一份做都是错的。重述是必然漂移的,漂移的说明,是比没有说明还要坏的。

像素的正门,输入的两股流,摇泵的人,末口的钟,四口接齐了。桌面是画得出了,也听得见了,钟点也掐得住了。可它上头坐着的终端,是一扇一扇拖得动的窗,窗一改了大小,里头的壳就该听见一声。到了下一节,咱们去量窗口。
