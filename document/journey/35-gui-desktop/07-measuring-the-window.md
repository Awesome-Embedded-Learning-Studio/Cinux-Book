# 量窗口:从端换尺寸与 28 号信号

像素的正门立起来了,两股流也接上了,桌面是画得出了,也听得见了。可上一节收尾咱们撂过一句,桌面上坐着的终端,是一扇一扇拖得动的窗。咱们就在脑子里拖一回。您捏住窗的边框往右一带,窗宽了,一行装得下的字跟着变多。窗里的 ash 却不知道。它手里的行列还是开窗那会儿的数,折行照旧折在窄时候的列数上,字断的位置跟窗对不上,您看着就别扭。它也是冤的,通知它的人一个都没有。控制台的那块文本屏从来没这桩事,行数列数开机就定了,谁都是改不动的,里外都认的是这个数。桌面上的窗不一样,量是随时会变的。窗口的量变了,里头的人是得听见的,这是终端跟外面世界的一门基本礼数。这一篇咱们就把这门礼数立进内核。

礼数要落的那个家,咱们盘一遍家当来找。窗口是终端的家当,这一卷里会开窗的终端,又全是伪终端一路的。那一对东西是现成的,假文件与真终端那一卷早就铸好了,ptmx 一开出来的就是一对,主机握在程序的手里,从机是一台全须全尾的终端,行规程、开关、问话门都是齐的。前台组也是那一卷立的,^C 该翻给的是哪一组,在真客人身上是走通过的。窗口的事,那一卷只办了一半。您翻回去看从机重新接线的重置清单,咱们能看见这么一句,窗口也是清了的。清是清了,量却是从来没人量的。问窗的话,从机的问话门上没有号,窗变了要喊的那一声,在信号名册上也还没有这个人的位子。

咱们把窗口的量说具体。一台终端的窗口,四个短整就装下了,拢共占的是八个字节,装的是几行、几列,再带横竖两个像素的数。量不出来的,就老老实实地记零,咱们不装懂。控制台的窗咱们手里有,内核是照着文本屏幕量的,行与列是都量得出的,横竖的像素对文本屏没有意义,记的就是零。

伪终端的从机,咱们接着看,屏幕它是压根没有的,内核想替它量的话,也是找不着对象的。替它量尺寸的,只能是握着主机的人,放到这一卷的地界里就是桌面。可从机是不能生下来两眼一抹黑的。每铸一对新的,从机的窗照着控制台抄一份打底,ash 头一回坐进去的时候,折行、画提示符的活,手里就有数了。抄来的尺寸只是个底,真尺寸是要听桌面报的。报的路,Linux 定的是两句问话,都挂在从机的问话门上,量窗的一问答现成的数,名号叫的是 TIOCGWINSZ,设窗的一问把新量好的行列交进来,名号叫的是 TIOCSWINSZ。

设窗的一问进来,咱们看着从机办两件事。头一件是把带来的行列像素记下来,往后谁再问量窗的话,答的就是新记下的数。第二件是抬头看一眼自家的前台组。组里是有人的,就朝整组投一个二十八号的信号,组还空着的话,咱们就不打扰。为什么朝组喊,不朝单独哪一位喊?窗跟键是一个道理,是整台终端的公产,坐在台前的就听得见,^C 翻出来走的就是同一条路。投递的路也不用新修,听得懂喊声那一卷早把发送与投递两段都走通了,今天不过是请一位新住户走了回老路。组空着的时候干脆不喊,喊了也没有耳朵,这一嗓也就省下了。

二十八号要进门的话,名册就得跟着添了。听得懂喊声那一卷立号表的时候交过底,一到二十二号照的是 Linux 原样,范围停的正是二十二,当年工程线裁的就是这一段,咱们重走,当年的裁法就不再来了。可新住户的座次,轮不到咱们排。Linux 把窗口的变化定在二十八号上,客人们编译好的二进制认的就是这个号,咱们要是图省事,给新人另编一个二十三的号,人家进门就找错了人。所以要按真座次进门,名册的尽头就得是二十八,二十三到二十七的几位一并上册。眼下喊它们的还没有人,座位就暂且空着了。宿主的长凳上还有一处随手的跟进,信号的那门功课,考的就是号出没出界,名册宽到了二十八,考题里的界外号跟着改成了二十九。

新住户进了门,咱们照 Linux 的表办事,给它的默认处置是忽略。同一间屋子里住着的十七号孩子,它的死讯早就是这个待遇,来了默认是不吵的,选择权是留给客人的。满屏画表格、拿行列算版式的程序,自个装上了句柄,窗是一听见就重新问的,画也照新的尺寸重画。不在意的,信号来了就地蒸发,跟没来过是一样的。喊话投的是组,组里每一位各自过一遍各自的处置,装没装句柄的事,就各随各便了。一扇窗里的动静,别的窗半个字节都不沾。

到了桌面那一头,咱们把整条链接起来走一遍。开一扇新的终端窗,桌面调 forkpty 起了会话,铸出了一对伪终端,busybox ash 摆到从机上落了座,主机那头留在桌面的手里当转播。窗画定了,桌面就拿设窗的一问,把按字位量出来的行列报给从机。往后窗一改了尺寸,桌面就把改的那一回原样报了回去。从机记下了新形状,朝前台组喊了一声,组里装了句柄的,回头再把窗问了一遍。从桌面到从机的头,从从机到前台组的尾,这么一接链就通了。

走到了这儿,多终端就不用另起炉灶了。咱们开一扇窗就铸一对,窗开到三扇的时候,三对也就铸齐了。各管各的环,各管各的前台组,谁也不串谁家的门,谁家的窗变,听声的也是谁家。当年第一遍的收官站,笔者是拿手工 new 出来的管道把终端和壳接通的,fd0 和 fd1 塞的是伪 inode 的座。壳一眼就看穿了自己坐的不是终端,isatty 是立不住的,只能降级求活了。窗口尺寸的那会儿,就更没人问得起了。后来第一幕自己换成了伪终端,这笔才算有了个了结。这一遍倒好了,伪终端从头走的就是正门,量窗的礼数跟着门一起立。成群的 busybox ash 各坐各的从机,当年要等到收官才见得着的画面,如今是这个家族的日常。

链通了,机制到这儿也就齐了。现在缺的,是一位真会开窗、真会报尺寸的客人,把整条链当真地跑起来,跑给您看。请它上桌的事,是下一篇咱们要办的。
