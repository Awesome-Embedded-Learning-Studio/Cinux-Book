# 量窗口:从端换尺寸与 28 号信号

像素的正门立起来了,两股流也接上了,桌面画得出,也听得见了。可上一节收尾咱们撂过一句,桌面上坐着的终端,是一扇一扇拖得动的窗。咱们就在脑子里拖一回。您捏住窗的边框往右一带,窗宽了,一行装得下的字跟着变多。窗里的 ash 却不知道。它手里的行列还是开窗那会儿的数,折行照旧折在窄时候的列数上,字断的位置跟窗对不上,您看着就别扭。它也冤,没有谁通知过它。控制台那块文本屏从来没这桩事,行数列数开机就定了,谁也改不动,里外都认这个数。桌面上的窗不一样,量是随时会变的。窗口的量变了,里头的人得听见,这是终端跟外面世界的一门基本礼数。这一篇,咱们就把这门礼数立进内核。

礼数落在谁家,咱们盘一遍家当。窗口是终端的家当,这一卷里会开窗的终端,又全是伪终端。那一对东西,假文件与真终端那一卷早铸好了,ptmx 一开就是一对,主机握在程序手里,从机是一台全须全尾的终端,行规程、开关、问话门都齐。前台组也是那一卷立的,^C 该翻给哪一组,在真客人身上走通过。窗口这件事,那一卷只办了一半。您翻回去看从机重新接线的重置清单,里头有这么一句,窗口也清了。清是清了,量却一直没人量。问窗的话,从机的问话门上没有号,窗变了要喊的那一声,信号名册上也还没这个人。

咱们把窗口的量说具体。一台终端的窗口,四个短整就装下了,拢共八个字节,几行,几列,再带横竖两个像素数。量不出来的,老老实实记零,不装懂。控制台的窗咱们手里有,内核照着文本屏幕量,行与列都量得出,横竖的像素对文本屏没有意义,记零。

伪终端的从机,咱们接着看,它压根没有屏幕,内核想替它量,也找不着对象。替它量尺寸的,只能是握着主机的人,放到这一卷,就是桌面。可从机不能生下来两眼一抹黑。每铸一对,从机的窗照着控制台抄一份打底,ash 头一回坐进去,折行、画提示符,手里就有数了。抄来的尺寸只是个底,真尺寸,听桌面报。报的路,Linux 定的是两句问话,都挂在从机的问话门上,量窗的一问答现成的数,名号叫 TIOCGWINSZ,设窗的一问把新量好的行列交进来,名号叫 TIOCSWINSZ。

设窗的一问进来,咱们看着从机办两件事。头一件,把带来的行列像素记下,往后谁再问量窗,答的就是新记下的数。第二件,抬头看一眼自家的前台组。组里有人,就朝整组投一个二十八号,组还空着,就不打扰。为什么朝组喊,不朝单独哪一位喊?窗跟键一个道理,是整台终端的公产,谁在台前谁听得见,^C 翻出来走的就是同一条路。投递的路也不用新修,听得懂喊声那一卷早把发送与投递两段都走通了,今天不过是请一位新住户走了回老路。组空着的时候干脆不喊,喊了也没有耳朵,省这一嗓。

二十八号要进门,名册得跟着长。听得懂喊声那一卷立号表的时候交过底,一到二十二号照 Linux 原样,范围停在二十二,当年工程线裁的就是这一段,重走不重裁。可新住户的座次,轮不到咱们排。Linux 把窗口的变化定在二十八号上,客人们编译好的二进制认的就是这个号,咱们要是图省事,给新人另编一个二十三,人家进门就找错了人。所以要按真座次进门,名册就得一路长到二十八,二十三到二十七几位一并上册。眼下没人喊它们,座位暂且空着。宿主的长凳上还有一处随手的跟进,信号那门功课,考的就是号出没出界,名册宽到二十八,考题里的界外号跟着改成了二十九。

新住户进门,咱们照 Linux 的表办事,给它的默认处置是忽略。同一间屋子里,十七号孩子的死讯早就是这个待遇,来了默认不吵,把选择权留给客人。满屏画表格、拿行列算版式的程序,自个装上句柄,听见一声就把窗重新问一遍,照新尺寸重画。不在意的,信号来了就地蒸发,跟没来过一样。喊话投的是组,组里每一位各自过一遍各自的处置,装没装句柄,各随各便。一扇窗里的动静,别的窗半个字节都不沾。

桌面那一头,咱们把整条链接起来走一遍。开一扇终端窗,桌面调 forkpty 起会话,铸出一对伪终端,busybox ash 摆到从机上落座,主机那头留在桌面手里当转播。窗画定了,桌面就拿设窗的一问,把按字位量出来的行列报给从机。往后窗一改尺寸,改一回,报一回。从机记下新形状,朝前台组喊一声,组里装了句柄的,回头再把窗问一遍。从桌面到从机,从从机到前台组,头尾这么一接,链就通了。

到这儿,多终端不用另起炉灶。开一扇窗,铸一对,开三扇,就是三对。各管各的环,各管各的前台组,互不串门,谁家的窗变,谁家听声。当年第一遍的收官站,笔者是拿手工 new 出来的管道把终端和壳接通的,fd0 和 fd1 塞的是伪 inode 的座。壳一眼就看穿自己不在终端上,isatty 立不住,只能降级求活。窗口尺寸那会儿,更是没人问得起。后来第一幕自己换成伪终端,这笔才了结。这一遍倒好,伪终端从头就是正门,量窗的礼数跟着门一起立。成群的 busybox ash 各坐各的从机,当年要等到收官才见得着的画面,如今是这个家族的日常。

链通了,机制到这儿也就齐了。现在缺的,是一位真会开窗、真会报尺寸的客人,把整条链当真跑起来给您看。请它上桌,是下一篇咱们要办的事。
