# 验收:收官的点数

上一篇收尾咱们撂过一句,判据过了,手感是还没过的,毛边一处一处地冒头,咱们看看它们长什么样,要怎么补,下一篇咱们接着办。这一篇就是咱们说的那下一篇。咱们把毛边补完,再照收卷的章程,把这一卷的点数摊开念。这是全教程的最后一篇验收,咱们念完它,三部曲就合龙了。

毛边的头一批是长在输入上的。您把手放上去,头一个觉出的是鼠标,您拖着拖着,包就乱了。根子是在应答字节上的,鼠标是偶尔回话的,0xFA 与 0xFE 这两声答话混在位移的字节流里,解码的那头一律当应答收走了,合法的负位移跟着丢了,三字节的包就对不上齐了。修法是把收应答的活限定在初始化的问答里,运行期的字节全数交给包解码器,判据里添了含应答数值的微小位移往返,乱过的路咱们再走一遍,包对齐了就算回了家。

再的一批是长在看的方面的。光标原来没有自己的画法,箭头的样子也不对,咱们给它立了单独的覆盖层,移动的时候登记新旧两块地方,收尾的时候一并重绘,箭头按真正的像素图画全。桌面原来把宽高写死了,屏宽过了六百四十,右边的就一直黑着,现在按帧缓冲的实际尺寸铺满,六百四十往上的,咱们宽到四千零九十六都接。窗口的显示也放开了,宿主的窗口缩到多大,画面是整体跟着缩的,咱们如实交代一句,缩的是画面,机器里头的图形模式还是开机定死的那一档。

键盘上的毛边也有两处。您按 Tab 的时候,从前被桌面的焦点遍历半路截走,伪终端就收不着了,补全就断了。现在的次序是终端排在头里接,终端有焦点的时候,Tab 的按下与抬起都直进伪终端,没了焦点才轮得到遍历。修饰键的问题更隐蔽,Shift 的键号是四十二,落在字符区里就被当成了星号,您敲 cmake 的参数,行里就凭空多出星号来了。修法是把落在字符区的非文本键挪进不翻译的那一区,核心的命名键与空格照旧特判,星号就不再凭空冒头了。

最后的一批毛边埋得最深,是持久化的根子。您在桌面终端里编着译着,一切都是正常的,关掉了窗口再开机,盘上的东西时好时坏。咱们把病挖到了底:写回缓存里的脏数据,是等到被淘汰或者显式刷新才写进盘的,直接终止了模拟器,剩下的脏数据就断送在半路,盘上就新旧混杂了。补的法子分三层。sync 这一声号令也接上了,号令是它喊的,完整的元数据序列持锁刷净。关机改了次序,授权过了就同步,同步不成的时候答错误,电是不切的。当家人等关机请求的那一声也换了真的,从前那个等信号的问话是个假返回,现按指定的信号真等,超时与打断各有各的答。这三层落定了,正常关机走的是 poweroff,断电的场面就直接关窗口,两者的分别,您现在知道了。

毛边补完了,咱们现在点数。四棵构建的树,咱们一棵一棵报名字。普通的一棵。开着地址越界与未定义行为排查的一棵,连内存泄漏一起都抓了。线程竞争那双眼单独跑的是又一棵。第四棵是内核本体的树,未定义行为的检查与锁次序的检查一路开着。宿主的长凳在每一棵树上都是八十二案全过,进了 KVM 之后,普通与检查两版是各二十二案全过的。文件系统那门功课是长到六十二案了,输入的那门也添到了八案,照常是全过的。检查的开关,咱们一个没关。

老章程咱们照旧,边界也跟着念了一遍。线程竞争的那双眼跑在宿主里,罩不到硬件中断与汇编的切换。代码的那头,提交前的四道闸也过了一遍,排版的、头文件注释的、静态检查的,还有不许拿强转成 void 装看不见的那道。全都过了。

实弹咱们分几摊念。GUI 的这一套,普通与检查两版是各打了一遍的,四条判据是一条都不少的,桌面的底亮着,界外是一片黑的,双击就开出了终端窗,sendkey 的回显落屏而串口零漏字,拖窗是跟着走的。补过的毛边各有各的判据,光标动过了,旧的地方就复原,窗口缩放的两档实测过了,Tab 的补全在机器里走,考的是 cd 加两个字母,咱们把补全一敲,落脚的目录名就逐字对上了,双 Tab 的候选列出,Ctrl-U 一敲就清了行,后续的输入照常进。

持久化的这一套,咱们跑了普通两轮,检查版的自动桌面两轮。每一轮的活都一样,进了系统,编了程序,写了文件,sync 过了,关了机,fsck 验了盘,冷启动回来的时候,上一轮写的数据重读一遍,上一轮编出的程序照跑一遍。轮轮是全过的,fsck 回来都是干净的。从前的时好时坏,根子挖掉了,病就再没回来过了。

机内构建的这一摊,咱们单独念。空的构建目录,用的就两条命令,cmake 的配置加 cmake 的编译,整个项目二百九十一个动作就这么从零编了出来,引导器、内核、用户程序、启动镜像一样不缺地全在里头。没有变化的时候就不重编,改了一行源码,只重编该重编的,产物过了哈希,提取了出来就重启,机器是活着的,探针也过了,桌面终端里又编出了一只 hello。这一轮的冷构建全程一百六十秒上下,量的是墙钟。另有一只独立的小示例,两个源文件进了 HOME 复制出来,同样的两条命令编出来跑通了,普通与检查版各在自动桌面里走了一遍。

口径的边界,收卷咱们念明白。权限的这一块,这一卷只做到了用户与身份,默认用户有自己的号与家目录,管理员是换不成的,越权的换身答不许。可文件的属主面没有接线,新建文件记下的属主还是零,谁家的文件谁可读,内核眼下是不问的,这一块咱们不能冒称做了。USB tablet 的光标同步开着头,离开窗口再回来的这一手没验完,没验完的不记通过。缩放缩的是画面,前头交待过了,这儿咱们再记上一笔。

卷首咱们摊开报过的数,现在咱们一件一件点回来。设备帧的座立了,补页是直映的,还帧的路上有闸,fork 是直通的。fb0 的两问答清了,共享映射只对答得出帧的设备放行,让屏收屏是各归各位的。两股流立了,键盘的两张脸都在,鼠标走的是三字节包,解码器是单独成件的。环各配各的,泵换了主人。量窗的两问挂上从机,二十八号进了名册,成群的壳各坐各的窗。客人把来源带进了盘,版本是固定的,三扇门用的是一张盘,图形会话走的是一张条子。四条判据全过了,毛边也补齐了,持久化的根子落了地,机内两条命令就编出了整个项目,桌面终端里自家的 gcc 编出了 hello。您对着卷首那页数,一件一件都是能对上的。

欠的咱们照旧念名,一篇咱们都不藏。文件的属主面、目录的逐级许可、创建掩码这三样,还有改名与信号的身份边界,这一整块咱们都没做,留给往后独立的一轮。USB tablet 的光标重入,是开着头的,是不算数的。readlinkat 那一行 unserved 的杂音,客人的库在起会话的路上问的,是不挡路的,补服务还是记下了,这个咱们留给作者裁。缩放的深度,客体模式是不变的,咱们如实挂着。名单念完了,欠的都挂在明处。

点完了数,咱们把整个旅程收个尾。第一幕走的是手搓,从一枚扇区搓到了内核完整,第二幕走的是爆发,进程、内存、驱动、网络一路铺了开来,收官的三程走的是安家、自养、收官,如今桌面亮了,工具链也在盘上了,机器在自家的桌面上编自家的程序。火把递到了这一卷,烧到头了,剩下的路,是您自己的。这一卷咱们就收在这里。
