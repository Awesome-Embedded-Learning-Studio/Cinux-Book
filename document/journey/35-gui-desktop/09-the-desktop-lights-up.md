# 桌面亮起:四条判据与三条判例

火点上了。上一篇咱们把客人送上了桌:生态那一卷铺出来的盘上世界,编译自己那一卷装进去的工具链,如今全垫在了客人的脚底下。inittab 里的 respawn 一声令下,桌面就跟着开机自己爬了起来,不用您守在旁边敲命令。机器是转起来了,可有一句要紧的话,咱们谁也别急着替它说,眼前的屏,到底亮不亮?

这一章咱们打实弹,章法是只有一条的:亮了没有,咱们让像素来答。咱们截一张屏下来,断言是拿像素来写的,该亮的地方得见着像素,该黑的地方一个亮点都不许有。判据是立在头里的,过了就是过了,没过的就是没过,咱们不跟自己客气,屏幕的场也是不替它圆的。这一套并不是咱们跟自己过不去,实弹是要一回一回重跑的,人坐在屏幕前是用眼睛看的,看一回是客气一回的,机器看的是像素,回回是一样的。

判据是有四条的,咱们一条一条地过。

头一条看的是没人动的桌面。判据说的是桌面的底上亮着像素,六百四十列之外的地方,一片是黑的。屏比桌面的地界宽,界外的那一片,理应是一个亮点都不漏的。前半句考的是全链,设备帧是映射进了门的,客人把画面从像素的正门递上来,哪一环断了,像素都是亮不成的。后半句守的是地界,您别看它只是黑,内核的报数早就改走了串口,屏上是不该再有别人落笔的,谁的手伸过了界,断言是当场翻脸的。黑得干净的话,同样也是算过的。

下一条看的是双击。桌面的图标上印着 TERMINAL,判据要求的是双击下去,真的开出一扇终端窗来。这一下咱们拿它当全礼数走:积分出来的坐标落在图标身上,算的是命中。您两下按得够近,桌面这才认下了一次双击。认下了就去消费,铸的是一对伪终端,把 busybox ash 摆进去落了座。开出来的是一扇窗,窗里坐的是真终端真进程,不是画给您看的假样子。

双击的这一下,照出的是一面当年的镜子。当年第一遍收官的时候,笔者走的桌面也是这三步,图标的注册、命中、消费,三件套是一样不少的,只是当年整套是住在内核里的,这一遍整个搬去了用户态,内核出的只是设备接口。门里门外换了主人,礼数还是原来的那三步。

> 当年的桌上还摆过一位计算器。双击是开得出来的,里头却是没有任何消费者的,这一层当年就如实交代了,占位的就是占位。是什么就写什么,这样的写法,咱们到今天还照着学。

往下要开跑的话,咱们得把子弹上膛。实弹既然是要机器代跑的,咱们的手就只能待在宿主这边,够不着机器里的键盘。好在监控通道是模拟器自带的,咱们隔着它就能发令。sendkey 替咱们按下键。mouse_move 替咱们挪鼠标。这一场的子弹,全是从这儿上膛的。

再下的一条,是四条里走得最远的一条。sendkey 替咱们把 echo hi 这一行敲进去,判据要求的是窗里见得着回显,busybox ash 把 hi 回了出来,而且串口那头,一个字都是不许漏的。您跟着一笔键走一遍全程。它是从 PS/2 那扇门进来的,翻成键号进了事件流。桌面的泵收着,拼回的是字节,喂进了伪终端。ash 在从机上听见了,回出的是一声 hi,再从伪终端的那头折回来,落进了窗里。hi 是挺短的,走过的路可不短,咱们这一卷接过的口子,它一笔全过了一遍。串口的零漏字也不是顺带的。抓座要是没立住的话,字符腿还是开着的,这些字是会顺着老路漏去串口的。回显算的是成绩,零漏字交的是证据,证据在咱们手里,咱们才认成绩。

末一条看的是拖窗。您按住标题栏,把窗挪了地方,判据看的是窗真的跟着走了。它考的是鼠标那股流,按下的要收得住,挪动的要跟得上,松手的要放得下,字节解成了样本,样本变成桌面手里的坐标,坐标再落到了窗上。至于这里头的路怎么个走法,它埋着的是后头的两桩案子,咱们到案子那儿细说。

四条判据到这儿是立完了的。可把它们跑通的路,本身又判出了三桩案子,一桩落在了键上,一桩落在了坐标上,一桩落在了节奏上。咱们一桩一桩地过。

头一桩是出在键上的。sendkey 的键,模拟器头一个喂的是 USB 键盘,USB 键盘是在位的,PS/2 那股事件流里是一个键都收不着的,sendkey 敲得再欢的话,桌面也是聋的。所以 GUI 通道咱们要的是纯 PS/2 输入,启动的时候就不带 USB 的人机设备对。普通通道照旧带着 USB 的一对,两边的键各走各的门,是互不碍事的。实弹里的 echo hi,键全是从 PS/2 进来的,靠的就是这个安排。

另一桩是出在坐标上的。监控命令的 mouse_move,报的是相对位移,挪了多少,它一笔一笔告诉您,挪到了哪儿,它是不吭声的。可点中标题栏要的是绝对坐标,这活儿没有别人替咱们干,宿主这边是自己积分的,从最初的起点起,一笔一笔地往上累。鼠标上电的收尾撂过一句旧话,相对位移怎么积分成绝对坐标,这话如今就到期了,拖窗的判据,拿的就是积分出来的坐标。当年双光标的那桩“不是毛病的毛病”,根子还是这两套坐标的对不拢,倒是同一个根子,当年画出来的是两个光标,这一遍演成的是一道积分题。

末一桩是出在节奏上的。双击是桌面认出来的,看的是两按隔得多近,间隔一松的话,它只当两回不相干的单击,窗就开不出来了。所以发令的节奏,咱们得收紧,两按的间隔压进五百毫秒里,双击的判据才认得成。

四条判据是全过了的,咱们一条一条地走,全走下来了。按理这儿是能松口气的,可判据过了,手感却是还没过的。判据问的是有没有,手感问的是顺不顺,等您真把手放上去,毛边是一处一处冒头的。它们长什么样,怎么补,下一篇咱们接着办。
