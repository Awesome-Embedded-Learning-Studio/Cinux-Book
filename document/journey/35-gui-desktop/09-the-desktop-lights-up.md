# 桌面亮起:四条判据与三条判例

火点上了。上一篇咱们把客人送上了桌:生态那一卷铺出来的盘上世界,编译自己那一卷装进去的工具链,如今全垫在客人脚底下。inittab 里的 respawn 一声令下,桌面跟着开机自己爬起来,不用谁守在旁边敲命令。机器是转起来了,可有一句话,谁也别急着替它说,眼前的屏,到底亮不亮?

这一章打实弹,章法只有一条,亮不亮,让像素说话。咱们截一张屏下来,配上一句像素断言,该亮的地方得见着像素,该黑的地方一个亮点都不许有。判据立在头里,过了就是过了,没过就是没过,咱们不跟自己客气,也不替屏幕圆场。这一套不是跟自己过不去,实弹是要一回一回重跑的,人坐在屏幕前用眼睛看,看一回客气一回,机器看像素,回回一样。

四条判据,咱们一条一条过。

头一条,看没人动的桌面。判据是,桌面的底上亮着像素,六百四十列之外,一片黑。屏比桌面的地界宽,界外那一片,理应一个亮点都不漏。前半句考的是全链,设备帧映射进门,客人把画面从像素的正门递上来,哪一环断了,像素都亮不成。后半句守的是地界,您别看它只是黑,内核的报数早就改走了串口,屏上不该再有别人落笔,谁的手伸过了界,断言当场翻脸。黑得干净,同样算过。

下一条,看双击。桌面的图标上印着 TERMINAL,判据要求双击下去,真开出一扇终端窗。这一下咱们拿它当全礼数走:积分出来的坐标落在图标身上,算命中。两按隔得够近,桌面才认这是一次双击。认下了就去消费,铸一对伪终端,把 busybox ash 摆进去落座。开出来的是一扇窗,窗里坐的是真终端真进程,不是画给您看的假样子。

双击这一下,还照出一面当年的镜子。当年第一遍收官,笔者走的桌面也是这三步,图标注册,命中,消费,三件套一样不少,只是当年整套住在内核里,这一遍整个搬去了用户态,内核只出设备接口。门里门外换了主人,礼数还是那三步。

> 当年的桌上,还摆过一位计算器。双击开得出来,里头却没有任何消费者,这一层当年就如实交代了,占位就是占位。是什么就写什么,这笔写法,咱们到今天还照着学。

往下开跑以前,得把子弹上膛。实弹既然要机器代跑,咱们的手就只能待在宿主这边,够不着机器里的键盘。好在模拟器自带一条监控通道,隔着它就能发令。sendkey 一声,替咱们按下键。mouse_move 一声,替咱们挪鼠标。这一场的子弹,全从这儿上膛。

再下一条,是四条里走得最远的一条。sendkey 替咱们把 echo hi 这一行敲进去,判据要求窗里见得着回显,busybox ash 把 hi 回出来,而且串口那头,一个字都不许漏。您跟着一笔键走一遍全程。它从 PS/2 那扇门进来,翻成键号进了事件流。桌面的泵收着,拼回字节,喂进伪终端。ash 在从机上听见,回一声 hi,再从伪终端那头折回来,落进窗里。hi 挺短,走过的路可不短,咱们这一卷接过的口子,它一笔全过了一遍。串口的零漏字也不是顺带的。抓座要是没立住,字符腿还开着,这些字就会顺着老路漏去串口。回显是成绩,零漏字是证据,证据在手,咱们才认成绩。

末一条,拖窗。按住标题栏,把窗挪个地方,判据看窗真的跟着走了。它考的是鼠标那股流,按下要收得住,挪动要跟得上,松手要放得下,字节解成样本,样本变成桌面手里的坐标,坐标再落到窗上。至于这条路怎么个走法,它埋着后头两桩案子,咱们到案子那儿细说。

四条判据,到这儿立完了。可把它们跑通的路,本身又判出三桩案子,一桩在键上,一桩在坐标上,一桩在节奏上。咱们一桩一桩过。

头一桩在键上。sendkey 的键,模拟器头一个喂的是 USB 键盘,USB 键盘在位,PS/2 那股事件流里一个键都收不着,sendkey 敲得再欢,桌面也是聋的。所以 GUI 通道咱们要的是纯 PS/2 输入,启动的时候就不带 USB 的人机设备对。普通通道照旧带着 USB 对,两边的键各走各的门,互不碍事。实弹里的 echo hi,键全从 PS/2 进来,靠的就是这个安排。

另一桩在坐标上。监控命令的 mouse_move,报的是相对位移,挪了多少,它一笔一笔告诉您,挪到了哪儿,它不吭声。可点中标题栏要的是绝对坐标,这活儿没有别人替咱们干,宿主这边自己积分,从起点起,一笔一笔往上累。鼠标上电收尾时撂过一句旧话,相对位移怎么积分成绝对坐标,如今到期,拖窗的判据,拿的就是积分出来的坐标。当年双光标那桩“不是毛病的毛病”,根子也是这两套坐标对不拢,同一个根子,当年长成两个光标,这一遍长成一道积分题。

末一桩在节奏上。桌面认双击,看的是两按隔得多近,间隔一松,它只当两回不相干的单击,窗就开不出来。所以发令的节奏,咱们得收紧,两按的间隔压进五百毫秒里,双击的判据才认得成。

四条判据,一条一条,全过了。按理这儿能松口气,可判据过了,手感还没过。判据问的是有没有,手感问的是顺不顺,等您真把手放上去,毛边一处一处冒头。它们长什么样,怎么补,下一篇咱们接着办。
