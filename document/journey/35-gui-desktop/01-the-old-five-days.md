# 当年五天的桌面,这一遍的第一天

编译自己那一卷收卷的时候,火把递到了咱们手里。您回想那时的机器,自家的 gcc 在串口里当场把 hello 编出来,盘上常驻着整套工具链,可一切都是一行一行的字,机器连一屏属于自己的画面都没有,它还没有脸。收卷撂下的话咱们原样接住:下一卷,给系统一张脸。

位置咱们开卷摆正。生态那一卷接过网络四部撂下的总纲,把余下的路排成三程,安家、自养、收官,前两程走完了,脚下是合龙的末程。这里又是全教程的最后一卷,三部曲的收官与整个旅程的收官,叠在同一卷里。份量心里有数,活,还是一件一件干。

现在把旧案翻开,这一段笔者来讲。第一幕的收官,恰恰是桌面。画布、窗口管理、原生终端、位图、桌面,五件活,三天,五枚 tag 打完。隔了一天,多终端殿后,第一幕落幕。这样的密度您当史料看就好,第一遍被读者说过太陡,幕间还为密度立了家法,重走不复制当年的冲刺。

更要紧的是当年的住法,笔者讲细一点。当年的 GUI 整个住在内核里,画布是内核的画布,窗口管理是内核的件,连终端都在内核态跑,靠一道编译开关住进来。事件泵、画面合成、终端轮询,三样活全塞在时钟中断的回调里。中断上下文本该是打断别人进门、干完就走的客人,却让它常驻门里干长活。桌面一忙,回调干不完,下一次滴答进不来,机器就僵在那儿,画面冻着,键也不应。第二幕后来花了一整段功夫解耦,GUI 这才搬去用户态。

这一遍,咱们不等那场搬家。开工头一天,形态就是终态:GUI 本体是一位用户程序,从公开仓请来的客人,版本固定,对得上号。内核到收官那天,一行 GUI 代码都不会有,出的家什只有两样,设备的接口,终端的复用,桌面上的终端成群开,靠的是它。当年的终点,就是这一遍的起点,这句话整卷只念一回。

当年的案卷摊开,能对上四处,咱们各点一句,后头只在机制露面的地方回还。形态方才讲过了,当年住内核,这一遍在用户态。戏也对得上,当年双击桌面图标弹出壳,这一遍双击 TERMINAL 图标,开的是终端窗口,窗里坐着 busybox 的壳。地基也照面,当年画布起步那一炸,炸出了三层地基债,这一遍头一件立的,就是替设备帧安座的地基。缝也有一处,当年终端与壳之间靠内核里手工造的管道接通,壳问一句自己是不是接在终端上,管道答不上来,这一遍由假文件与真终端那一卷铸好的伪终端顶上。

另有一笔年差,咱们交代在开卷。当年的多终端,是跟进程的生与收挤在同一段收官冲刺里的,那会儿生与收的活还是半成品,前后脚落地,攒下的排错笔记五篇、六百二十八行,第一幕里数得着的厚。这一遍顺序倒过来了,进程的生与收早就走完,多终端独自殿后。为什么倒着排,幕间交过底:终态在用户态的东西,得等家什置办齐了才进得来。

这一卷的教学主线,就是那道缝。GUI 本体与操作系统之间,把边界摊开来,是一张函数指针表,核心要什么,表上就列什么,填表的是用户程序,内核自始至终不知道桌面的存在。表上每一项的语义,正本写在 GUI 本体自家的说明里,您要查全表,到那边去,咱们这边讲的是交了什么、验了什么。请客人的姿态,跟前几卷一个样:用,直说,指路。

表的方向,开卷就得立界,这里请您打起精神。当年解耦出来的旧表里,有一项 render_frame,方向是宿主把场景画进核心,画笔握在宿主手里,核心只收成型的画面。这一遍请来的客人,表整个反了过来,核心产出像素,宿主只收提交、给输入、给时钟,画笔回到核心手里,一笔都不画。两张表看着像亲戚,箭头是反的,您要是拿旧表的形状当这一遍的预期,后头每一节都会读反。

开胃菜照样板端上来,当年画布起步的那一炸,笔者慢慢讲。画布要一块三兆字节的背面缓冲,画好了整帧翻上去,免得闪。三兆字节一次性分配下去,地基的麻烦全冒了头,咱们一层一层看。头一层,堆没有上限,分配器只管给,不问头顶还剩多少地,画布一路长上去,顶进了设备内存和栈的地界。第二层,直接映射盖不到那片物理地址,内核拿物理地址换虚拟门牌,换的人自己吃了缺页。第三层最隐蔽,图形的编译开关一开,测试过不全,开关一关,全过,病被挡在门外,发作的样子谁也没见过,绿绿的测试照样给笔者涨着信心。

这一遍,咱们三处都不欠:堆按页住自己的窗,设备的地址走 ioremap 的正路,盲区的判例立在机内,没有哪道编译开关能把病再挡到门外。GUI 对内存布局,就是一场现成的压力测试,当年一遍炸穿三层,这一遍压力照样来,只是座位早就备下了。

所以头一件要立的地基,不在屏幕上,在内存的座位表里。设备的帧要映进来,映进来还不还回去,它压根就不是内存的家当。这座地基立稳了,像素的正门、输入的两股流、终端量窗的礼数,后头一样一样才接得上。下一节,咱们就从给设备帧安座起工。
