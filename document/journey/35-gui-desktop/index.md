# 桌面亮起:给系统一张脸(卷名草稿)

编译自己那一卷收卷的时候,火把递到了咱们手里。盘上常驻着自家的 gcc 与 g++,串口壳里的话音清楚,机器已经样样都会了,唯独缺一屏属于自己的画面,它还没有自己的脸。收卷撂下的话咱们原样接住,下一卷咱们就给系统一张脸。位置咱们开卷摆正,生态那一卷把收官前的路排成安家、自养、收官三程,前两程都走完了,脚下是合龙的末程。这一卷又是全教程的最后一卷,三部曲的收官与整个旅程的收官,叠在了同一卷里。份量咱们心里有数,活还是一件一件地干。

这一卷的戏,咱们开卷报一遍,次序就是施工的次序。头一层是地基,设备帧的座,显存的帧要映进来,而且映进来就不还回去,这是往后所有的戏全压着的一件。第二层开的是门面,像素的正门,/dev/fb0 两问答清了尺寸,共享映射把显存递到客人的手里。第三层立的是两股流,键盘走的是一股,鼠标走的是另一股,键盘添了键号的第二张脸,鼠标从 8042 的辅助通道带上电。第四口把队列、钟与摇泵的人接齐,泵这一回头一次不住进内核了,而是住进客人自己的主循环。礼数跟着立了起来,窗口的量变了,里头的壳要听得见一声。然后咱们请客人上桌,来源是带上的,版本是固定的,火一点了,咱们的实弹就开打,亮不亮的问题,咱们让像素说话。坡度是前缓后紧的,地基缓缓地起,实弹是收到顶上的,验收殿后就是了。

咱们照例盘家底。手里有的,假文件与真终端那一卷铸好的伪终端,一对一对都是现成的,行规程与问话门都是齐的,前台组的路也走通过。懒到家那一卷立的登记册,匿名的、文件的、栈的,它都收了,家法是现成的。听得懂喊声那一卷的信号名册与投递路,生与收那一卷的分家法子,自己的脸那一卷带电的键盘与它的翻译机,配屏那一卷趁 BIOS 应话问回来的屏参数,都候在那儿了。盘上世界是生态那一卷铺的,工具链是编译自己那一卷装的,客人的脚底下什么都有。缺的也数得清:设备帧的座还没有,输入的事件节点一个都没有,鼠标整条是黑的,量窗的礼数悬着,会开窗的客人还没请。

咱们进站时,机器的面板与上一卷出门时一个样,两颗核是在线的,线是挂着的,回环是通着的,一号座上坐着当家的,壳的提示符候着,盘上的工具链是齐全的。出站的时候,老几样是照旧的,真新闻是不在串口上的,它就在屏上:桌面是亮着的,光标是随着鼠标走的,双击 TERMINAL 的图标,窗就开出来了,窗里坐着自己的壳,三扇窗各跑各的,窗改了大小,里头的折行就跟着变了。您想亲眼看看,run_gui 那扇门您一进去,您还没敲头一条命令,桌面就已经亮了。咱们再往深里走一步,您在桌面终端里敲下 gcc,hello 当场就编出来了,这一卷收官的实弹,考的就是它。

这一卷的活,咱们摊开报数。设备帧进了登记册的新门类,补页是直映的,不领帧、不清零这两样就是它跟普通补页分家的地方,还帧的路上立着闸,fork 的分家对它直通可写。fb0 住进了设备表,虚屏与定屏的两问答清了,版式照 glibc 的头文件逐字段对齐,共享映射只对答得出帧的设备放行,谁持有帧缓冲的描述符,谁就拥有整块的屏幕。键盘立了键号的第二张脸,0xE0 扩展组十七个键入了座,您一把抓座落下去,字符的腿就归了桌面。鼠标从 8042 的辅助通道带上了电,三字节的包按签名解,解码器单独成了一件,长凳上不开机就考得了它。两股流各配各的环,泵换了主人,住进桌面的主循环,当年中断里摇泵的旧案,这一遍从结构上就生不出来了。量窗的两问挂上从机,二十八号的新住户进了门,朝前台组喊了一嗓子,成群的壳各坐各的从机。客人 vesper 带着公开仓的来源进盘,静态链接的门口出过一案,桌面壳立了一座库才根治,三扇门共用的是一张盘,图形会话的条子递了进去,桌面就跟着开机自己爬起来了。实弹的四条判据全过了,毛边一处一处地补齐,写回缓存接上了 sync,关机把盘刷新了才断电,机内的空目录,两条命令就编出了整个项目,桌面终端里自家的 gcc 编出了 hello,收官的实弹落了地。

当年的旧话交代。当年第一幕的收官,恰恰是桌面的那五天,画布、窗口管理、原生终端、位图、桌面的五件活,三天就打了五枚 tag。当年的多终端,是跟进程的生与收挤在同一段收官冲刺里的,这一遍倒是倒过来了,进程的生与收早就走完了,多终端倒是独自殿后了。为什么倒着排,幕间是交过底的,终态在用户态的东西,得等家什置办齐了才进得来。更要紧的是当年的住法,GUI 是整个住在内核里的,泵挑中了最不该挑的住处,时钟中断的回调,桌面的活一忙,整台机器也就跟着僵了,第二幕花了一整段功夫才把 GUI 搬去用户态。这一遍不等那一场搬家了,开工头一天的形态就是终态。取舍还是咱们那把老尺子,能解释今天手里这套机制的进正文,当年只作反面教材的,收敛地讲。
