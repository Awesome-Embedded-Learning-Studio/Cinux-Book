# 验收,和没有笔记的日子

咱们的发货链还是老命令:`cmake -B build && cmake --build build --target run`。开出来的面板,kern 的部分如今是十行,咱们一行一行地对:

```text
[kern] 64-bit C++ world alive
[kern] gdt+idt self-owned, sse on
[kern] bootinfo: 8 e820 entries, fb 1024*768*32
[kern] screen console 128 cols 48 rows
[kern] kernel at 200000 size 8C780 entry 200670
[kern] pmm: 32339 pages free (probe 100000 ok)
[kern] vmm: address space up, magic 114514
[kern] heap: new/delete live (probe 114514)
[kern] irq on, tick 100Hz
[kern] keyboard on, type to echo
```

十行里的六行,咱们看着还是老样子,格子里的数一个都没变。数字变了的是 pmm 和 kernel at 两行,新面孔就是 vmm 和 heap 的两行,咱们对着变动一笔一笔说。头一笔说 kernel at:那行报的 size 涨到了 0x8C780,这一卷内核长了个子,堆和页表的代码进了盘,16KiB 的栈从低位的 0x90000 搬进了镜像,还要在 .bss 里多躺一份交接单的归档副本。0x8C780 折成十进制的 575360 个字节,向上取整占了 141 页,entry 的门牌也跟着挪了窝。第二笔说 pmm:那行从上一卷的 32345 落到 32339,名册那一卷立的算法没变,1MiB 之上的 usable 一共 32480 页,减去内核占的 141 页,得的就是 32339。比上一卷少的 6 页,正是搬进镜像的栈 4 页、对齐搭上的 1 页,加上镜像长个多占的 1 页,咱们一笔一笔都对得上。probe 落的还是 0x100000:种子柜圈的地在低 1MiB 里,那是名册一刀圈走的保留区,没有一页是从 usable 里扣的,老册子倒是一笔没乱。第三笔是 vmm 的那行,magic 114514 是经直接映射读回的,它的来历在拆城一节里已经说全。第四笔是 heap 的那行,probe 的数也是 114514,开机一发 new 的实弹。至于截屏的验收,十行全都亮了,键入的字符顺着键盘的线原样回显——屏幕走的是 ioremap 的门,低半边的旧门打接管那一拍起就已经死了,能回显本身就是新布局活着的证词。

长凳的那头,mm 家族在这一卷新添了三件:mm_layout、vmm、heap,收到的总数 22 件。机器里的那头,test_kernel 的台子从三台涨到六台:selfcheck、tick、keyboard,加上本卷的 vmm、heap、aspace,每台开机的工夫在零点三秒上下,红绿的结果由退出码报给构建。六台里头有一台咱们想单独点一句:aspace 台上的第三案,咱们让 activate 切出去、写、读,最后回家——干这件事的是一台测试内核,活生生地走进一个新世界,又活生生地走了回来,这零点三秒里 CPU 换过的页表有两副。

尺寸咱们照例报。镜像还是 1MiB 的老样子,一格的位置都没动。咱们量了盘上的内核:27424 个字节。面板上报的 size 是另一回事,那是内存里的地界 0x8C780,折成十进制的 575360 个字节,盘上比内存里小了 54 万多:半兆的位图名册躺在 .bss,占盘的字节一个没有。栈的属性是 NOLOAD,16KiB 的栈内存里占着自己的地界,咱们没在盘上为它花一个字节。

收尾之前咱们再翻考古箱,这一卷的日子有点特别:咱们翻到的不是某一天卡住了,而是整整一段日子是空的。当年的四月二十,单日挤了九站,页表管理、堆、地址空间这三件,旧编年里紧挨着的三个里程碑,全挤在了同一天里,加起来近五千行的增删,一口气写完了,一口气跑绿了。可您翻那一段的笔记,一个字都没有:那段日子的笔记是空白的,今天咱们能找到的第一手材料,只剩当年书上各章末尾的调试现场。没有笔记意味着什么,写过代码的人都懂:那些天里每一个决策为什么这么定、每一次红灯怎么灭的,全都沉没在当天了。咱们这一卷能把这些机制重新讲一遍,靠的是两样还留着的东西:代码还在,当年的调试现场还在。被当映射的残留页表、没撕干净的旧条目、切出去忘了回家的地址空间,留下的那几篇调试现场,是空白期仅有的目击证词。这一遍咱们把它翻过来:每一步的来路、每一次被问倒的现场、每一个判别法,都写进了它该在的家。当年一天的路,今天走了一卷,连带着把当年的沉默也补上了。

三件活交割:页表归了内核,堆开了张,世界成了能造能换的。可这三件如今在咱们手里都还缺一个身份——使用者。走查在等新的映射需求,堆在等自己的进程对象,new 出来的第一件家具还没主。地址空间在等调度,能进能出的世界,得有人住进去才算成了家。下一卷进程来了,进程切换的那一响,换页表的一拍头一回不为验收,为的是让两个世界轮流活着。这一卷咱们把地基打到了这个份上:城里水电全通,就等住户了。
