# 验收,和一针 ud2

咱们照例头一步在 host 这头数家底。测试清单从十三件添到了十四件:新进的是 test_idt,五根哨兵第三节数过了,是一根都没有少的。test_gdt 也厚了:内核侧新添的哨兵,把三槽的身量、选择子紧跟 null 的 `0x08` 和 `0x10`、位词汇组合出来对上金位、L=1 配 D=0 的硬关系,一样一样全拴住了。十四件全过了,clang-tidy 是全零的,构建也是零错误的。QEMU 那头咱们照旧 -accel kvm 开机,面板打出了五行,咱们逐字抄在这儿:

```text
[kern] 64-bit C++ world alive
[kern] gdt+idt self-owned, sse on
[kern] bootinfo: 8 e820 entries, fb 1024*768*32
[kern] kernel at 200000 size 83C00 entry 200330
[kern] pmm: 32348 pages free (probe 100000 ok)
```

第二行是新添的,报告的是本卷办下的活。数咱们要一对一对地过。size 从上一卷的 810C0 涨到了 83C00:多出来的地界里,4KiB 是二百五十六格的表,整张都住进了 .bss,盘上是一个字节不花的,其余的近 7KB 是实料,描述符的家当、三十二个名字、三十二座桩,加上转储的代码。盘上的 kernel.bin 实测 11208 个字节,是从上一卷的 3740 涨上来的。镜像长了,入口的地址也跟着挪了位:上一卷 entry 还在 200296,这一卷排到了 200330。pmm 从 32350 变了 32348:32480 还是老数,128MiB 的机器,1MiB 之上那片 usable 的页数,上一卷咱们对过。内核的地界涨过了 4KiB 的格子线,名册是向上取整的,登记也就从 130 页变到了 132 页,咱们拿 32480 减 132,得出的数目是自洽的。前头的件是一个都没动的:MBR 还是 512 个字节的身量,stage2 也还是 13068 个字节、26 个扇区的块头。

面板报了平安,还不算验收的完。本卷的正主是疼,咱们要真枪实弹地验一回。咱们临时往内核代码里,塞了一条 ud2——x86 特意留下的未定义指令,生来就是两个字节、专门干这个的:谁执行了它,CPU 报的就是 #6 Invalid Opcode。开了机,机器一路走到了肇事的地方,面板稳稳打出了两行:

```text
[kern] exception #6 Invalid Opcode
[kern]  rip=FFFFFFFF802000EC cs=8 rflags=10016 rsp=8FEE0 err=0
```

六件咱们一件一件对。名字和号都对上了,来的正是 #6 Invalid Opcode,ud2 的正主。rip 给的是 FFFFFFFF802000EC——头上的一串 F,是内核在高半的家,出生那一卷开的那两扇门。这个数就是塞进 ud2 的指令本身的地址——第五节讲过的压栈章法,在这儿兑了现。cs 报的是 8,咱们自己表里的代码选择子。这一件还另有一层的分量:段表换没换成真的,它就是一份现成的证词。要是还踩着 boot 的表,这儿报的就该是 0x18 了。rflags 报的是 10016,咱们只认一粒位:第九位的 IF 是零。中断的门从保护模式的那一卷关到现在,到了这一卷也没开,本卷开的是疼,而听的功课,还留给了下一卷。rsp 报的是 8FEE0,栈顶立的是 0x90000,往下长的落点是正常的。err 报的是 0,#6 是不带错误码的,这个零是桩递的,递得干干净净的。验完了,咱们把 ud2 撤掉,重建出干净的镜像:疼这件事,验过一回咱们就撤,留下的得是干净的家底。

咱们去考古箱里翻日历,本卷该翻到的是四月二十。那一天算不得这一卷自己的日子,它是拿来对照的一面。当年大内核的 GDT、IDT 落在四月十九,到了第二天的四月二十,中断、时钟、屏幕、键盘一气冲了九站,全挤在了一天之内。那是第一遍密度原罪的亲历现场:后来读者那句“太陡峭、跟不上”,根子上就有那一天的影子,九站的活压在一天里灌完,跟不上的读者就掉了队。九站攒下的活,这一遍把它摊成了一站一件:一张表就讲一张表、验收就一针一针地对数,读者的步子,也就跟得上了。

咱们收工盘点:内核眼下会什么了?段表是自己的,三槽的身量,选择子落在了 `0x08`。异常表也是自己的,二百五十六格都齐了,三十二桩也都上了岗。疼喊得出名字了,六件现场一件都不缺的。SIMD 也在门内安了家,17 处 xmm 是真在干活的。可中断的门还关得死死的,时钟的线也还没接上,键盘的活儿躺在了再下一卷。上一卷结尾咱们许的愿,这一卷兑现了前半句:表,搭起来了。后半句是下一卷的事,外线的芯片、时钟的第一声嗒、头一回 sti,都是从那儿来的。机器停在了 Halt 里,睡得踏实——这回的疼是有名字的,现场也是六件齐全的。
