# 驱动基本框架:门房、册子与门铃(卷名草稿)

请第二颗脑子上线那一卷收卷的时候,咱们把话撂在了明处:散装进门的设备,该立一座统一的门房了,中断的消息新路,也定在了那时铺。这一卷就是来兑现这两句的。兑现的路上又请进一位重客:USB 的主机控制器。门房为它而立,新路也为它而铺,它进了门,键盘从一条崭新的线路上走进控制台。所以这一卷的名字,咱们暂且叫它驱动基本框架,立的是框架,请的是首客,两件事就这么咬在一起。

咱们照例盘家底。手里有的:认门找盘那一卷把 PCI 总线走了一遍,当年七台设备进了表,这一卷挂上了 USB 才凑成第八台,BAR 窗口的解码词也备下了。会听那一卷立的中立中断桌,座位与门分了家,芯片换了人桌子不动,第二颗脑子上线那一卷又给它换上了两片 APIC 的后端。假文件与真终端那一卷造好了 /dev 与 /proc,设备坐进了名字,进程的事实照进了镜子。块设备的五方法块脸、等待的完成件、显式设备窗的映射路数、PS/2 键盘的老线、busybox 这个真客人,一样倒是都在。缺的咱们也一片一片数:设备虽有几件,却是各开各的门,null 自己注册了,console 自己注册了,盘那边一台控制器带一块盘自己管自己的事,内核说不出自己有几台设备的家底,各自走的是哪条总线、归哪个驱动管。上一卷撂下的消息新路一步没铺,线中断的座位表管的是引脚,消息要的是向量的座。配置空间里设备的能力清单,咱们一页没翻过。USB 的这道墙,咱们连一块砖都没摸过。还有一笔假文件与真终端那一卷收官后冒出来的活:script 的会话收不回尾,内层退出之后外层的死等,咱们记着,这一卷收了它。

咱们进站时,机器是一台设备各管各的机器:注册各自为政,线是中断的唯一门路,USB 的窗口黑着。出站的时候,busybox 在提示符下敲的那一行 cat,三节名册照了出来,字符、块、网络三本册子各念各的住户。script 的会话能收尾了,内层退出了,外层的提示符回来,回显与 ^C 也都活了回来。消息向量有了自己的池子,池子的起点定在 0x40,避开线桩、本地定时器、调度广播与假中断四家在住的,外加 sigreturn 那一号空着的旧门牌。USB 的门铃响了,键盘的报告边沿翻成字符,汇进控制台的第三席。咱们在完整 USB 参数的机器上连着打字,引号分号长串的 echo,三轮全过了。

这一卷的活,咱们摊开报数。头一件给设备立门房:名字、册类、总线与驱动的记名,一座名册管全机的设备。第二件三本册子开张了:字符、块、网络,既有件各归了各位,一座只读的观测座把名册照给 /proc。第三件收 script 的旧活:伪终端学会挂断,两端学会了数人头,读尽答的是零,再写答的是错。第四件翻配置空间的活页:能力链一张单链表,读函数注入的活,宿主的长凳与真总线测的是同一份代码。第五件把两种消息方言解码成词:MSI 的窄宽两式,MSI-X 的表形与窗口。第六件铺消息新路:向量的池、座与派发,武装的四步协议。第七件请 xHCI 进了门,识别、开窗、四区寄存器的现读,停稳了再复位。第八件三只环与一枚门铃都立好了,TRB 每枚占的是十六字节,生产者与消费者靠控制字一位的翻转认新旧,门铃一摇的功夫,控制器就去看自己的环。第九件走枚举链:复位测速、领槽位、写上下文、置地址、读描述符、配端点。第十件破一案:一条模拟器没学过的指令,寄存器的读法跟着改,编译也跟着进了岛。第十一件是分层与回调的活:主机层瘦了身,设备层带上了模板,回调一次性的自解除,键盘汇成了第三席。第十二件再破连环的案:四道坎挨个地取证,外加一场看错屏幕的乌龙,方法论顺手做了更正。末一件收尾照旧走的是验收。

当年的旧话咱们也照例交代。当年的工程线上,驱动、安全与网络这一段当年是挤在一处连着打的,重走的这一遍,咱们按主题分了三卷,这一卷只管驱动的活,页表的执行位与客人指针的检查归后面安全那一卷,网卡与协议栈归后面的网络那几卷,咱们一句不越界。当年第一遍的 xHCI,是五笔活连着干完的。咱们按一条家法取舍:能解释今天手里这套机制的,进得了正文,在它该在的那一章把来龙去脉摆开。能力发现、控制器起转、置地址的状态机、键盘跑通,前四笔正是今天枚举链的骨架,咱们分章重讲。第五笔的绝对鼠标,今天只有一个在场的平板没有消费它的人,咱们登记在案,冒充的事不做。还有当年测试的一道暗门:默认入口不挂 USB 设备,用例早退仍然报了绿,重走的这一遍,设备参数直接进了主跑面,不再另设一条带设备的测试跑法。

合卷的时候咱们再点一遍手里的新话:设备有了一座名册,三本册子各念各的住户,伪终端认了挂断,配置空间的活页会翻了,两种消息方言解成了词,消息向量有了池子,主机控制器立了三只环与一枚门铃,枚举链走通了,USB 键盘的字从第三席流进控制台,回调有了自己的值类型,五桩案的卷宗归档。欠的照旧挂在明处:消息真送达在咱们的模拟器下不可靠,武装是静态度的证明,扛货的活归了排空,tablet 在场而消费的人还没来,热插拔与 USB 类驱动的扩展登记远期,键盘的睡等还没换成完成件,名册的父子与挂树、计数的激活,都等的是第一个消费者进门再立。戏也照旧往前排:客人递进来的指针,内核向来当真话信了就抄,页表里执行权限的位也还没立,这两摊活排到了下一卷,咱们在这里把话撂下,这一卷就收了。

卷名咱们暂记作《驱动基本框架:门房、册子与门铃》。候选的名字另有三个:《给设备立户口》《三本册子一位门铃人》《散件归册》,连同定名的活,都留给咱们日后慢慢挑。
