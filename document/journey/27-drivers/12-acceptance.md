# 验收:名册、向量与门铃的成绩单

咱们收卷的章程照旧,看的是三样:面板、测试、实弹。面板这一回添了三行新相,都长在盘的自检与多核上线之间,咱们把串口原文逐字抄来:

```text
[kern] xhci 100 ports 8 slots 64 running
[kern] xhci msix entry stayed masked, the drain carries the cargo
[kern] usb keyboard seated, config 1 ep 81 max 8 interval 7
```

第一行是控制器自报家门:0x0100 的版本,报了八个口、六十四个槽位的家底,咱们启用其中八个,跑起来了。第二行是消息中断的诚实边界:表项按协议留在屏蔽,货由排空来扛的分工,说的全是大实话。第三行是枚举链收尾的那句话,配置、端点、包长、间隔的事,一行里都带上了。这三行的上头,还是那段八台设备的走线报数,串行总线上报 1B36 的客人,如今是咱们亲手伺候的了。这几处的新相之外,面板没添多余的一行,咱们如实报。

测试的长凳上,咱们报数字:宿主六十六件,四条配置线各跑一遍全部过了,普通的一遍,地址越界、未定义行为加泄漏三查的一遍,线程竞争检查的一遍,内核侧锁序图加未定义的一遍。机内的十九台,普通与检查的两个镜像各一遍。这一卷添进名单的新住户,咱们点齐案名:名册本身的登记、查重、坏形状、满表、越界,回环设备的回放、次序、诚实答非与擦除表双设备,配置空间走查的命中、自环、保留位,两种消息方言的窄宽式与窗口落位,消息座位的拒座、入座、静默、答满,环协议的绕回与握手,异步回调的触发、自解除与重武装,伪终端挂断的整段生命周期,再加机内那个强制断言的控制器用例,设备不在的话就红,不给跳的路。假文件与真终端那一卷挂下的 script 疑点,如今在名单里也有了一整排证人。

实弹打了三场。头一场是开机的面板,上面已经逐字抄过了。第二场是三节的名册,busybox 在提示符下敲的那一行 cat,七行住户与名册的记录一台不差,咱们在开册那一章已经整表抄录,这一章就不再重复了,只补一句当时的报话:四十号系统调用没人接,是客人打头探了 sendfile 的新门、退回 read 的旧路,输出的字一个不差。第三场是打字的回显,这场咱们打得最朴素,盘上不带 cat 的裸名,客人敲 cat 吃了一个 not found,然后一个字一个字地敲 echo,串口原文咱们逐字抄来:

```text
/ # cat /proc/devices
/bin/sh: cat: not found
/ # echo usb-ready
usb-ready
/ # 
```

字敲进了控制台,行规程回显了出来,该答的答,该回的回。加上送键桥那边的连续输入与三轮长串 echo,一动一静两个 hello 的回归,普通与检查的两个镜像各跑一遍全套,全数过了。咱们实弹收证据,走的都是上一章立的次序,这一章的每一行证据,都从串口里逐字地抄来。

对卷首的承诺,咱们逐项过。门房立了,三本册子开张了,散件各归了各位。script 的会话能收尾了。配置空间的活页会翻了,注入的读函数喂着两个世界。两种消息方言解成了词,消息向量有了池子、座位与桩,武装四步带着静态度证明立在真硬件那侧的门口。控制器进了门,窗开了,四个区的起点现读,停稳了再复位,六十四位的寄存器低半打底。三只环与一枚门铃转起来了,枚举链走通了,USB 不发 SET_ADDRESS 的那道沟咱们蹚过了。一条模拟器没学过的指令立了两条防御与一座岛,机内也添了不许跳的强制用例。回调有了值类型,键盘汇成了第三席,四道坎与一块像素的卷宗归档。一十二章的活,一件不少地交齐了。

边界咱们照旧挂明处,这一卷欠下的从最大的念起。消息中断的真送达,在咱们的模拟器加 KVM 的组合下不可靠,回读就是不上钩的,咱们保持屏蔽,排空承载的格局,武装链留作静态度的证明,换到真硬件就绪的那天即通。tablet 平板在场而未消费,它的光标消费端属于后面的卷,咱们给它留了动机,代码倒是没给它留。热插拔与 USB 类驱动的扩展登记远期,存储类、全协议人机接口设备、hub 各自的名字,都在那页的名单上。MMIO 统一窗口的分配件顺延,今天一个 BAR 消费者还撞不了车,第二个消费者出现的时候再立。键盘的等待是读路径轮询,睡等的完成件形态登记在案。伪终端的座位仍只铸不还,名册的父子与挂树、计数的激活,等的是第一个消费者。逐核的消息路由不做,今天与外面的路由芯片一样,投递认准的是引导核。机器上的网络控制器,八台设备里的 0:3:0,咱们这一卷一眼没多看,网卡与协议栈整个属于后面的网络那几卷的戏。每核一队、偷活、票锁那一页明确不做的,咱们照旧不动。前几卷挂下的老欠,这一卷没碰的照样念一遍名字:跨核的速查表冲刷仍是最大的一笔,信号位的共同协议、共享文件表的竞争、文本控制台的一把粗锁、两核同读一台终端的护栏、词上二百五十六桶共用一闸、多片 IOAPIC 拒收,一笔不少地挂在原处。堆的扩张不查重叠、符号链接的形态不认、ash 的作业控制面没添,欠下的也都还在。本卷实弹里那声 cat 的 not found,咱们把话说准:busybox 一家在盘上只落了两个名字,/bin/busybox 的本尊与 /bin/sh,四百多个命令的联动链接一条没烤,cat 这个名字在盘上其实根本不存在,裸名敲下去答的找不到,说的是实话,不是什么病,要读文件得敲 busybox cat 的全名。符号链接的形态不认,是前几卷在册的欠,咱们独立登记在这里,不算在这场实弹的头上,哪天盘上真造出了链接,它才是拦路的那一道。

合卷的时候咱们回头看这一卷的骨相:门房为散件而立,向量为消息而立,可真正的重头是带动了一整条新总线的客人,门铃摇了七环才把键盘请进门,进门之后还有四道坎与一场看错屏幕的乌龙等着。咱们的机器从几件各管各的散件,变成了名册上三节可数的住户,键盘的字从一条崭新的线路流进行规程。欠的照旧挂在明处。往前的戏也排好了:客人递进来的指针,内核向来当真话信了就抄,页表里执行权限的位也还没立,这两摊活是下一卷的开场。验收的数字点完,咱们在这里收卷。
