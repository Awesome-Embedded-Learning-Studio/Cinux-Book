# 三个会挪的座位

布局的确定性是一份白送的礼,咱们一直没收。今天的机器,同一个程序两次开机落在同一个地址,栈顶的位置永远在同一高,堆的种子永远在同低,匿名映射的狩猎场永远是同一片天花板。调试的时候它是恩人,对想猜地址的人这也是恩人,猜一次就管了一辈子。咱们机器上今天没有那样的对手,可把确定性白送了出去,章法上说不过去。这一章咱们给三个座位装上抖动:栈顶、堆的种子、匿名映射的天花板。

抖动是三把掩码的活,咱们一把一把看。栈顶的掩码是 0x7FF000,最多挪的也是八个兆。堆的种子 0xFFF000,给的是十六个兆。映射天花板的掩码最大:0x3FFFFF000,十六个吉的量级,天花板往下压了一头,后面的映射跟着整体下移。三把掩码的尾巴上都挂着三个零,页的倍数。尾巴上的零不是白挂的:进程入口处的栈指针模十六必须是八,这是调用约定的老章法,挪动量是页的倍数,模十六的余数就一分不动,对齐的纪律不破。

文本段的座位不挪,咱们把死路登记在案。咱们的用户程序不随位置走,链接时定了型,小内存模型把全局数据的地址当立即数烤进指令里,那一片的位置要活,得整套换成相对寻址的形态,那是完完整整的另一场工程,收益在本卷的场景里看不见。生产系统里那些不随位置走的程序,同样享受文本段固定的待遇,咱们与它们站在同一边。还有一笔在册的欠要说明:把后半场交给解释器那一卷,撂下过解释器基址与位置无关形态的随机化,咱们这一卷没有接,挂上欠的清单,留给后面的卷。

随机的源头,咱们分了两层。算法层坐的是 xoshiro256 的双星变体,名字里的两个星号说的就是它,四字的状态,住进了 base,播种的时候用 SplitMix64 把一个字摊成四份。它干的活是纯算术,所以哪个世界都编得动,宿主的长凳直接考。种子层在架构层混的是四样东西:rdrand 两把,处理器的硬件源,CPUID 问过了才拿。周期计数器自复位以来自由地跑,两次开机读到的天然不同。再加内核自己的落点,编译器选的座,两次构建的结果也少有相同。混完了喂给发生器。定位咱们说清:这套熵图的是两次开机不一样,不是面对一个研究你输出的对手。要面对对手的场合,自己的硬件源自己带。栈上的那枚 AT_RANDOM,是把后半场交给解释器那一卷摆成一桌真的时种下的,走的就一直是 rdrand,而 rdrand 的接线本身,倒是开门迎客那一卷接 getrandom 时接上的。

种子的时机在开机序列里排在保护开位之前,没种之前抽到的都是零,布局停在编译期的座位上,降了级,但是诚实,不是什么陷阱。实弹咱们请 aslrdemo,连跑了两遍,三处座位各报的是自己的数,串口原文咱们逐字抄来:

```text
/ # /bin/aslrdemo
[aslrdemo] rsp=0x00007FFFFFCD6DF0 brk=0x0000000000620000 mmap=0x00007F7C29313000 uid=0x0000000000000000
/ # /bin/aslrdemo
[aslrdemo] rsp=0x00007FFFFFF8ADF0 brk=0x0000000000C45000 mmap=0x00007F7EA9290000 uid=0x0000000000000000
/ # 
```

咱们把两遍对看:栈顶差着两个多兆,堆的种子差着六个兆出头,映射的地基差得更远。uid 的那一栏两遍都是零,身份的戏份咱们记在这里,立身份的那一章再开演。三把座位都会动了,可故事没有这么顺,当天夜里就出了一桩悬案,下一章咱们破它。
