# 还一笔旧债

开工的章法,咱们照旧,欠的赶在动工前还清。这笔欠的来得安静:行动结构,就是听得懂喊声与开门迎客那两卷里叫过动作记录的那件东西,在开门迎客那一卷照 musl 的词序重排成了四词的形状,restorer 的格子从那天起就在,咱们收下了客人的字,却偏偏从来没有人读它。投递信号的时候,咱们把 handler 的返回地址一律写成内核 trampoline 页的地址,客人明明说了收尾走谁家的门,咱们不认,自己另指了一条路。功能上倒是没坏,musl 的客人走咱们的页也收得了尾。可欠就是欠:接口收了话,该办的事一件没办,这笔欠的活这一卷开头才摆上桌面。

返回的路怎么走,咱们把机制摆平。投递的时候,咱们在用户栈上给 handler 铺一幅回家的图:寄存器的现场、被挡掉的信号罩、原来的栈顶,一层一层地码好,图的上面压一个返回槽。handler 干完了活,ret 的那一下落在返回槽上,槽里写的地址决定收尾走谁家。收尾的活只有一句:发十五号系统调用 rt_sigreturn,内核按图把现场一层层地还原。所以债的收法小得可怜:写返回槽的时候看一眼旗。客人把 SA_RESTORER 立了,槽里就写客人指定的 restorer 地址,没立就照旧写咱们的内核页。十五号本身当然一个字不动,铺好的图也不动,动的只是门牌一格。

两条路各是什么模样,咱们挨个看。musl 自带的 restorer,是客人可执行页里的一小段代码,尾巴上就是一条编号十五的 syscall 指令,它跑起来与咱们内核页里的七个字节干的是同一件事。咱们自己的内核页,是听得懂喊声那一卷立的:一张独立的页,可读可执行而不可写,顶在匿名映射天花板的上一页,页里的七个字节,一条是把 15 搬进 eax 的 mov,另一条是收尾的 syscall。它为什么天然不怕后面要开的执行位闸:它本来就是按可执行登记的独立页,而不必寄人篱下。

当年第一遍这笔债可没有这么轻,咱们把旧结摊开。当年的用户态是手搓的 freestanding,连 libc 的影子都没有,也没有给客人供 restorer 的人,投递的收尾代码只能内核自己写,而且当年是直接写进用户的栈里:一小段以 int 0x80 收尾的指令铺在栈上,handler 返回跳的就是它。咱们一开 NX,栈就不可执行了,这段代码就死了,信号的收尾全死,所以当年必须赶在开 NX 之前把 trampoline 挪出栈,这是开闸的前置。为什么当年走 int 0x80 不走 syscall:当年的系统调用帧太精简,R12 到 R15 的现场不进帧,而收尾要还原的是完整现场。重走的这一遍,两条前提都不在了:trampoline 住在独立页里,帧是听得懂喊声那一卷扩完整的一百二十八字,musl 的客人自带 restorer。债从拦路的降成了体面的,顺序也就自由了,咱们把它放在开工头一件,图的是心里干净。

宿主的长凳上配两案:带旗的,落点必须是客人给的 restorer 地址。不带旗的,哪怕行动结构里 restorer 的格子写了字,落点也必须是咱们的内核页。旗说了算,字段自己说了不算。实弹咱们打两条路。自家的新客人 sigcatch,装 handler 的时候不设 restorer,自己给自己发了一号用户信号,handler 里记了数,串口原文咱们逐字抄来:

```text
/ # /bin/sigcatch
[sigcatch] handler armed without a restorer, kernel trampoline owns the return
[sigcatch] caught 1 after 0 spins
/ # 
```

caught 后面跟的是一,自旋的圈数是零,一来一回都算上了。错误的返回路永远回不到记数那一行,这个一就是整条往返的回执。另一条路在 musl 那边:提示符下用 trap 挂一号用户信号的 handler,kill 给自己发了一发,handler 里 echo 的空行照常回显,shell 活得好好的,收尾走的是客人自家的 restorer。两条路都过了,债清了,咱们去干这一卷的正事:台阶上的三个位。
