# 第六十三位进了页表

咱们这就上第一级台阶:NX。开位本身一口气的事:快速系统调用使能的那一步,EFER 一笔写进系统调用使能与不可执行使能的两位,写完了回读,断言的是位十一亮着。第二颗核从蹦床里抄引导核的 EFER,新开的位跟着一起继承。面板每核一行的观测里,EFER 报的是 d01,咱们把这个字逐位看:位零是系统调用使能,位八与位十是长模式的使能与激活,位十一就是咱们今天种的不可执行使能。三位老住户带了一位新住户,字面上清清楚楚交代了谁刚搬来。

位开了,页表的词条得跟上来。咱们给用户半的每片叶子立了一个组词的小函数:拿用户页打底,登记册说可写的,添上了写位,登记册说不可执行的,添上了六十三位。从此用户半每一片叶子的权限,都从懒到家那一卷立的登记册三个字段现组。这些字段以前只是登记册上的话,补页的时候按它们填,查问的时候按它们答,可页表偏偏不认执行这一件事。从这一章起咱们让页表开始当真。

落线的路有五条,咱们一处一处数。加载器一路:ELF 段旗里带执行位的段,组词的时候执行照给,不带执行位的数据段不给。补页一路:缺页补页按登记册的字段组词,与加载器走的是同一个函数。开机头一个 shell 的栈,显式地组词,可写而不可执行。写时复制一路:共享叶按原叶的样子重新组词,私有叶拷贝的时候也照原叶,原叶带六十三位的话孩子当然带,爹娘没有的话孩子也不凭空有。trampoline 页的那一路,还旧债的那一章说过,可读可执行而不可写,本来就没欠什么。词法通了,mmap 的脸也通:PROT_EXEC 的旗一路通到登记册,客人要执行的新页,登记册记了一笔,补页组词的时候给执行。于是用户半的章法成形:代码页是只读的,数据页与栈是不可执行的,写与执行分了家。W^X 这串字母说的就是这个:写异或执行,而两样不并立。

内核半咱们不装,怎么登记的就怎么说。内核半今天是引导时铺的一吉字节大页,整片都是可执行的,咱们一个位都没落。要给它落位的话,咱们得把大页拆成小页逐片登记,工作量是真的,收益却要等到内核自己的代码段想防窜写的那天。当年第一遍就是这么登记的,重走的这一遍沿用同一条边界,拆页挂在远期的清单上。

头一次跑机内测试的时候,两个案子报了双红,咱们把破案的原话记下。症状报的是保留位页错误,错误码的位三亮着,说的是你写进页表的位,这颗处理器偏偏不认。怪就怪在词其实没有错,词表里的六十三位明明白白。看现场才明白:机内测试的世界,自己那架开机初始化的梯子铺地址空间时,没有开 EFER 的不可执行使能。位没开的时候,六十三位在页表里的身份就是保留位,叶子一带它就翻了脸。咱们给这架梯子补上那一句 OR,转绿了。这一课咱们记成家法:机器事实必须每个世界都立一遍。测试世界怎么说也是个世界,它自己的 EFER、自己的页表约定,一样都少不了,不然测出来的绿是另一个世界的绿。

机内补了两案,数据叶带上了六十三位,而代码叶不带,写时复制的案子看着六十三位穿越共享与私有两段,想要什么位全走表驱动。实弹咱们请一位新客人 nxdemo 出场,它在可写的数据段里放了一枚裸的返回指令,十六字节数组的头一个字节 0xC3,而后把它当函数调。串口原文咱们逐字抄来:

```text
/ # /bin/nxdemo
[nxdemo] about to call into writable data
Segmentation fault
/ # 
```

程序预告了要跳,跳下去就没有了第三行,页表答了段错误,shell 倒是还在提示符上等着下一个命令。要是咱们没落六十三位,这一跳会真的执行,数组的字节当指令跑,程序会打出一行数据页仍在执行的告白,然后正常地退场。第一级台阶上完了,可机器还欠一样东西:内核现在依然当真话信着客人的指针,立门的活这就开工。
