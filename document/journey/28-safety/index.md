# 安全:三道闸与一扇门(卷名草稿)

驱动基本框架那一卷收卷的时候,咱们把话撂在了明处:客人递进来的指针,内核向来当真话信了就抄,页表里执行权限的位也还没立,这两摊活排到了下一卷。这一卷就是来兑现这两句的。兑现的过程里,活又自己长了几样:给指令配上道歉的路,给栈帧配上了哨兵,给布局装上了抖动,给进程记上了身份。所以这一卷的名字,咱们暂且叫它安全,立的是三道闸,修的是一扇门,两件事咬在了一起,闸防的是机器外面的手,门管的是机器里面伸出去的手。

咱们照例盘家底。手里有的:懒到家那一卷立的读、写、执行三字段,连 mprotect 都备齐了,只是页表其实一直没认执行这件事。请第二颗脑子那一卷给的每核地基与机制回读的脸,双核的机器,位是每核一份的这个常识,咱们在那一卷讲同步的几章里交过学费了。听得懂喊声那一卷把系统调用帧扩成了一百二十八字,还有独立可执行的 trampoline 页。开门迎客那一卷请来的 busybox,还有它给 getrandom 接上的 rdrand 线,把后半场交给解释器那一卷又用 rdrand 给客人栈上种了真的 AT_RANDOM,那一卷的加载器段旗也在手里。词表里备着没人用的 EFER 不可执行常量。缺的咱们也一片一片数:页表词条没有六十三位的词,CR4 连张自己的读写脸都没有,stac 与 clac 的痕迹全树为零,例外表的底子是零,ring0 的页错误未解就是一路走到挂。exec 的布局常量全固定,代码里的注释自己写着有意为之。任务结构里没有身份的四个数,而编译器没给栈帧种过哨兵。restorer 的格子,开门迎客那一卷照 musl 的词序重排行动结构时收了进来,从进来那天起就没有读者。

咱们进站时,机器是一台信客人话的机器:指针照单全抄,错一个字的下场是内核陪葬,布局两次开机的样子一样,而栈帧不设防,收尾的门牌客人说了不算。出站的时候,面板上的报数是 cr4 300620,两颗核的字一模一样,三位全开了。门立在了每一个号位上,坏指针答的是负十四,内核到了第二天照常开机。数据段里当函数调的那一跳死在半路,客人跳向内核正文的那一跳也死在半路。栈帧里有了哨兵,三个座位两次开机的排布不再重样,身份四个数入了册,id 出了数,sigcatch 一来一回的 caught 记了一。

这一卷的活,咱们摊开报数。开工的头一件是收旧债,返回槽的选路按旗,客人的 restorer 与内核的页各走各的路,咱们没动十五号一个字。词汇与台阶排在第二:页表的六十三位,CR4 的读写脸,CPUID 的问句,位断言右移取位的判例。第三件上的是第一级台阶,不可执行位随快速系统调用的一笔写入,AP 的继承靠抄送,落线的有五路,写与执行分了家,机内世界补课的破案一并记下。门立的是第四件,两起两落走了一遭,考过试才接的线,跨方向的往返案,几十个号位走的全是门,futex 拆成了两层,窗口纪律配上当年的反面判例。第五件教的是指令道歉,例外表配上链接器的新段,修完了页才轮到问表,坏指针答的是 EFAULT。第六件把闸开了,SMEP 与 SMAP 落了位,处理器直通进了主跑面,开闸后的验证逮住的是两处漏网,顺手划掉了信号位共同协议那一笔。第七件给栈帧种了金丝雀,全局哨兵的形态,老笔记原样地搬来,失败走的是 panic。第八件挪了座位,栈、堆、映射天花板的三把掩码,熵的四源混种,文本段的死路如实登记。第九件破了悬案,一宗 exit 十七的案子,病根一桩带出了四桩,修法落了五件,两笔误判入了册。第十件记下身份的四个数,号位排了六张,setuid 的两规则,记号笔画的是身份,篱笆的桩还没立。末一件收尾照旧走的是验收。

当年的旧话咱们也照例交代。当年这一段是单日打完的一弧,从收尾债到身份一天走完了,重走的这一遍摊成了一卷,一步一步地验证。取舍照旧一条家法:能解释今天手里这套机制的,进得了正文,在它该在的那一章把来龙去脉摆开。当年全局开窗的弯路,讲成了窗口纪律的反面判例,一个每核一份的标志位,教会人的是什么叫上下文。当年在跳向用户态的路上裸写用户内存的侥幸,讲成了开闸那天的注脚,而伸手就死,不再靠什么运气。当年收尾代码写在用户栈上、逼得执行位必须等收尾的旧结,讲成了这一卷开头那笔债轻重的对照。负测选址的假绿判例,讲进了例外表那一章,换了根子照旧要防。只作反面教材的,收敛地讲。还有一套当年内核里开着中断跑长活的死法,它的现场在网络上,咱们一句不抢,排在后面的网络那几卷开场再讲。

合卷的时候咱们再点一遍手里的新话:执行位落了线,写与执行分了家,主管的两位开了闸,门立在了每一个入口上,指令学会了道歉,栈帧有了哨兵,座位能挪了,身份入了册,信号收尾的旧债清了,exit 十七的悬案破了。欠的照旧挂在明处:内核半整片可执行,又写又执行的页没有否决的闸,文本段的座位不挪,咱们的熵不面对对手,creds 有记号而没有盘查,组清单的问话没人接。咱们的戏也照旧往前排:后面网络那几卷,socket 的号位生在这门上,那边的开场还有一套关于中断与长活的故事等着咱们,这一卷咱们就收在这里。

卷名咱们暂记作《安全:三道闸与一扇门》。候选的名字另有三个:《指针的门》《修好了再开闸》《六十三位与一只金丝雀》,连同定名的活,都留给咱们日后慢慢挑。
