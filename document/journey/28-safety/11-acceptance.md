# 验收:三道闸与一扇门的成绩单

收卷的章程照旧,点的还是面板、测试、实弹三样。面板这一回的新话有两处,都在开机的头一程,咱们逐字抄来:

```text
[kern] cr4 300620 after core protections
[cpu 0] APIC 0 online, LSTAR ffffffff8022b656, EFER d01, CR4 300620
[cpu 1] APIC 1 online, LSTAR ffffffff8022b656, EFER d01, CR4 300620
```

第一行是保护开位的自报,拆字的那一章干过。后两行是每一颗核上线的报数,EFER 与 CR4 报的字一模一样,一颗写点全核生效的凭据,就在这两行的相同里。这几行之外的地方,面板没添一个多余的字,咱们如实报。

测试的数字:四条配置线,宿主的七十件,普通的一条,地址越界、未定义行为加泄漏三查的一条,线程竞争检查的一条,内核侧锁序图加未定义的一条,各跑各的全过。机内的二十台,普通与检查的两个镜像各一遍。新住户咱们挨个报名:处理器位词的六案,宿主的门方向五案与机内的门件八案,例外表的排序与二分,随机件的播种与推进,补页执行位的两案,写时复制穿越的一案,收尾落路的两案,再加调度测试里改走纯内核引擎的三处。这一卷还把验收本身的跑法提速了一截:四棵树并行地跑,机内测试上了快照,咱们别让多台机器同写一张盘,热缓存里的全矩阵十秒出头交卷。

这一回的实弹打得比往常都厚,因为这一卷的活天生要实弹证明:三道保险各请一位客人递死法,布局的抖动要两遍对看,收尾的旧债要一来一回。开机面板之外咱们把六位角色的串口原文整段抄来。其中 aslrdemo 的两行,咱们单独起了第二次开机来采,与前一章的那一场对看,三个座位又换了一整套数:

```text
/ # /bin/nxdemo
[nxdemo] about to call into writable data
Segmentation fault
/ # /bin/aslrdemo
[aslrdemo] rsp=0x00007FFFFF8F6DF0 brk=0x0000000001134000 mmap=0x00007F7D3CD85000 uid=0x0000000000000000
/ # /bin/aslrdemo
[aslrdemo] rsp=0x00007FFFFFBE0DF0 brk=0x00000000011AC000 mmap=0x00007F7DFA7F6000 uid=0x0000000000000000
/ # /bin/smepdemo
[smepdemo] about to call into kernel text
Segmentation fault
/ # /bin/efaulter
[efaulter] writing four bytes at the hole address
[efaulter] write answered -14 (14 is EFAULT, the door apologized)

[sigcatch] handler armed without a restorer, kernel trampoline owns the return
[sigcatch] caught 1 after 0 spins
```

收尾还跑了一轮回旧:十次冷启动,三十次的 exec,伪终端的会话往返,全数过了。对卷首的承诺,咱们逐项过。旧债收了,返回槽的选路按旗,两条收尾的路都实测过。台阶上了三级,次序上的一级没换,每一级要的那件东西都摆在了明处。六十三位进了页表,五路落齐了,写与执行分了家,数据段里那一跳死在了半路。门立起来了,起了两回落了两回,考过试才接的线,几十个号位走的全是门,后端再不见客人的地址。指令会道歉了,修完了页才轮到问表,坏指针答的是负十四,内核原样地活着。闸开了,镜子里逮住的是两处漏网,补齐了,三保险的实弹全命中。栈帧里种上了金丝雀,全局哨兵的形态,老笔记原样地搬来。三个座位会挪了,悬案破了,掩码开了闸。身份四个数立了,记号笔入了册。一十一章的活,咱们一件不落交齐。

咱们把边界照旧挂在明处,这一卷欠下的从最大的念起。内核半整片是可执行的,一吉字节的大页没拆,拆页的工作量是真的,所以登记远期。一张又写又执行的页,mmap 的词法上给得出,两面旗并要的页照样给,咱们没有立否决的闸,如实登记了。文本段的座位不挪,它的死路登记在案,连着解释器基址与位置无关形态的随机化,把后半场交给解释器那一卷撂下的,其实这一卷也没接,一并挂在欠的清单上。咱们的熵不面对对手,面对对手的场合自带硬件源。creds 有记号而没有盘查,所有进程的身份仍是 root,setuid 的文件不做。组清单的那一问,号数写的是一百一十五,桌上还没这道菜的身影。特性不在的机器,门走不带窗的路,面板报的是实情。收掉的也在这里记收:读用户区间只查界不查映射这笔,听得懂喊声的那一卷最早提过一句,假文件与真终端那一卷把它单独立了项,请第二颗脑子那一卷挂上了欠的清单,这一卷的门加例外表把它收掉了,名单上信号位共同协议那一笔也划了去。剩下的老欠,咱们照着上一卷的名单逐项重念:跨核的速查表冲刷仍是最大的一笔,共享文件表的竞争,文本控制台的一把粗锁,两核同读一台终端的护栏,词上的二百五十六桶共用一闸,多片 IOAPIC 进不了门,伪终端的座位只铸不还,堆的扩张不查重叠,符号链接的形态不认,ash 的作业控制面没添,都还挂在了原处。

合卷的时候咱们回头看这一卷的骨相:三个位是三道闸,门是全机当差最勤的那一扇,例外表是门后的道歉,金丝雀与抖动是添的两道暗锁。分量都在顺序里:修好了再开闸,闸开了验覆盖。往前的戏也排好了:指针的门立好了,后面网络那几卷要开的 socket 号位,直接生在了这门上,新号位出生的时候就在门内,不用写了再改。咱们手里还有一套故事,当年内核里开着中断跑长活怎么个死法,那套戏码排在网络的开场。验收的数字点完,咱们在这里收卷。
