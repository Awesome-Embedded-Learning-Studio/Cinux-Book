# 编译自己:师傅进门与一只新内核(卷名草稿)

上一卷收卷的时候,话撂得是实在的:下一卷要把编译器全家请进作坊,机器要编自己的程序,盘的尺寸还要再扩,位置无关的身子的留白,也记在了它名下。这一卷开了卷,咱们把话原样接过来。收官前的路排成三程,上一卷安好了家,收官的那一卷给机器一张脸,咱们脚下走的,是中间请师傅进门的一程:机器要从跑别人编好的程序,走到自己造自己的这一步。

大戏一共是三层的,咱们开卷报一遍,次序就是施工的次序。头一层的戏在串口壳里唱,盘上自家的工具链把 hello 编了出来,当场跑了起来,这门本事的名字叫自举。再往上的一层,g++ 上了桌,编出的是真 C++ 程序,STL 与异常是要过堂的。压轴的一层,才对得上编译自己四个字的全部意思,咱们在自家盘上,从一个空的对象目录起,编出一只完整的新内核,把机器重启了,再让它给咱们编一遍 hello。坡度是前松后紧的,缓坡是头一程的路,主轴是中间的一程,加冕与压轴都留在了后头,验收走在最后就是了。

咱们照例盘家底。手里有的:生态的那一卷,书里的题名叫《盘上换血》,它留下的作坊烤得出盘,进料是有指纹管着的,glibc 一家的座位摆在那儿,师傅进门喝的就是 glibc 家的血。懒到家的那一卷立过 VMA 的登记册,缺页来了怎么诊,家法是现成的。生与收那一卷立的装载与入口,程序进门怎么装,栈上怎么铺,路也都是现成的。线程那一卷的 clone 与 futex,师傅起孩子的时候正好用得上。跑别人的程序那一卷铺的号位面,空号被敲就报一声 unserved 的探针,门上站着的还是它。缺的咱们也一片一片数:exec 侧的惰性装载是真缺口,大胖子进门的懒办法还没有。位置无关的身子有个行话叫 PIE,咱们还没给它排座,上一卷收卷念欠单时把它转了过来。

咱们进站时,机器的面板与上一卷出门时一个样,两颗核是在线的,线是挂着的,回环是通着的,一号座上坐着当家的,壳的提示符候着。出站的时候,老几样是照旧的。这一卷的真新闻在开机面板上找不着,报数报在了壳里:两位老师傅在盘上链出的 hello 一声开口,Hello from GCC! 头一回响了起来。咱们拿 od 读字节,三位产物的 e_type 都是 3。SPAWN_FAIL_1 与 SENDFILE_PROBE_PASS 的两行记号,是失败路径与改判号位的回执。四棵构建树是各七十九案的,机内的两套各二十一案,咱们在门上一声装聋都没听着。压轴的报数最响,新内核自己开了机,自家 gcc 当场编出了 reborn,Hello from GCC! 又响了一回。您想亲眼看看,开机之后您自己敲一遍,数就在您的串口上。

这一卷的活,咱们摊开报数。师傅进了门,行李由 ldd 一件件报了名,合起来才算成了闭包,crt 祖传的家什随行,解释器坐在分毫不差的 /lib64 门牌下,断链案立了判例。两位老师傅交了头一件活,串口壳里 hello 链出了开口,lseek 的三锚立了起来。座位认得了 ET_DYN,位置无关的动态形态进了主程序的座,地板定在了 512MiB,再摇不超一 MiB 的滑动。cc1 改成了惰性装载,段分成了三截,四十七兆的胖子进门只递一张名片。问询打了九十声,答法落成了三种:头一样翻的是案卷,第二样明说的不办,第三样就真办了,装聋清了零。spawn 的合约立住,起手探的是 clone3,听见了 ENOSYS 就退到 vfork,失败时旧世界是原样保留的。exec 的交接按正本重立,预算是算出来的,上限是明文的,次序也排定了,全是照 Linux 来的。sendfile 从明说不办改判成了真办,offset 两种语义分了家。C++ 的家当上桌,STL 与异常都立了双断言,三个 PIE 是拿 od 读字节核出来的。空缓存挪了新目录,从头又走了一遍,判据还是原来的那套。造一只新的自己,目标五步全在机内走完了。真实负载揪出的洞,文件系统的洞一摞,内存边界的洞一摞,号码与寿命的洞又一摞,三摞都补齐了。炉子通了风,块缓存按空闲内存的三十二分之一生长,CLOCK 二次机会转了起来,链接器挤爆的文件表换成了分块生长的动态骨架,整只内核花了一百八十八次编译加两轮链接,编出 590656 字节的身子,墙钟走了 369.811 秒。重启的证明,带进场的内核对象数是零,哈希对出来是逐字一致的,自家的产物开了机,当场就编了 hello。验收殿后就是了,出师的成绩单念完,案卷都留在了案上。

当年的旧话交代。当年这一段的密度极高,工具链上了盘,号位是一路追着赶的,机内连整内核的编译都排了进去,全挤在很短的日子里连着打完,重走的这一遍把它摊成一整卷,咱们按件消化。判例是件件有来处的。不自编工具链的板照旧有效。当年 8 MiB 的老盘一步扩到 128 MiB。ld 崩在了四层案里,咱们学走的是分层破案的手艺。stdc-predef 那桩隐式包含的案子,遗产直接写在今天的指纹里。cc1 从停 22 秒走到了停零,是当年的口径,这一遍不拿它当自己的测量。musl 与 glibc 共存的老路已翻篇。取舍还是老尺子:能解释今天手里这套机制的进正文,只作反面教材的,收敛地讲。
