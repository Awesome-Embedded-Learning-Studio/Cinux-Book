# 验收:出师的成绩单

新内核自己开机、自己编 hello 的那一场,记在重启的证明那一章。戏唱到这儿,这一卷的活干完了,出师得有一张成绩单。咱们照收卷的章程,从四棵树点起。

四棵构建的树,咱们一棵一棵报名字。普通的一棵。开着地址越界与未定义行为排查的一棵,连内存泄漏也一起抓。线程竞争那双眼单独跑的,又是一棵。第四棵是内核本体的树,未定义行为的检查与锁次序的检查一路开着。

每棵树上,宿主的长凳七十九案全过。进了 KVM,普通与检查两版各二十一案全过。宿主这个七十九,您在生态那一卷的收卷里见过一面,数没变。检查的开关,咱们一个没关。

线程竞争那双眼的边界,收卷咱们再念一遍。它跑在宿主里,罩不到硬件中断与汇编的切换,锁次序的检查罩着的也只是自旋锁。

代码那头,提交前的四道闸也过了一遍。排版的、头文件注释的、静态检查的,第四道不许拿强转成 void 装看不见,请咱们改用 `[[maybe_unused]]` 或者干脆裸着调用。四道全过。

实弹是两套的,咱们普通与检查两版各打一遍。生态那套,glibc 的 hello 开了口,一号座上坐着当家的,十四位 applet 挨个点验,fstab 按表挂载,tmpfs 的隔间照旧,储物间、门内传话与 poll 都在判据里,全过。自举这套,两位老师傅的手链在册,gcc 与 g++ 的全链走通,三个 PIE,STL 与异常的双断言,sendfile、execprobe 与 spawn 的失败回收,全过。这一卷亲手立的探针也都在场,freestanding 案子里的最小程序真跑过,execprobe 报到的行里,fd_growth_rlimit 与 brk_exact_shrink_zero 两个名字逐字落屏,考的正是文件表的增长限额与断点的字节精确。

咱们看着两版跑完,门上零装聋,unserved 的报数是零,内核异常也是零。

整只内核的自编译,跑在普通的内核配置上。检查版过的是四棵树的必验与两套实弹,咱们没让检查版把整只内核再编一遍,成绩单上也就不写它没干过的活。中间失败的那几轮,日志都留着,失败轮不冒称通过。

当年的欠,按当年的口径念。当年笔者第一遍,办完一件活就记一个递增的号,收官对号,074 与 076 两件因为 fork 路线上一记没根治的 #GP 没办成,号缺在那里。两个号这一遍不补,咱们不替当年圆场。

卷首咱们摊开报过的数,现在一件一件点回来,您对着卷首那页数,一件都没有少。师傅进了门,全家老小一个不落,门牌一字不差。两位老师傅交了头一件活。座位认得了 ET_DYN,师傅摆成 PIE 的活也上得了桌。cc1 惰性装载,四十七兆上下的胖子不再整只进屋。九十声点名,三种答法,装聋清零。spawn 的合约,失败的路也照约走。exec 的交接按正本。sendfile 从明说不办改判真办。

后头的咱们接着点。C++ 的家当上了桌,STL 与异常双断言,三个 PIE。空了缓存、挪进空目录,从头组装再走一遍,判据不变。在自己肚子里造一只新的自己,目标五步全在机内走完。

压轴的几件,咱们也点齐。真实负载揪出来的一串洞,文件系统、内存的边界、号码与寿命,三摞都补上了。炉子通了风,块缓存按空闲内存的三十二分之一生长,CLOCK 的二次机会转起来。文件表也甩掉六十四个描述符的旧上限,长成按需生长的动态表。整只内核在机内编出来,一百八十八次编译(算上生成的 kallsyms)加两轮链接,产物 590656 字节,369.811 秒。口径跟炉子通了风那一章同一套,Debug 配置、512 MiB 内存、两颗核、串行,量的是全程的墙钟。重启的证明,带进场的内核对象数是零,哈希逐字一致,自家的产物开机、编 hello。

还欠着的,咱们照旧念名。共享文件页的缓存,目录项与 inode 的缓存,大块的 read 与 write,vfork 的路径,并行构建,五件没做,都留给往后独立测量。加上当年缺的号,名单念完,欠的都挂在明处。

点完数,咱们把火把递出去。工具链在串口壳里验过成色,盘上常驻着自家的 gcc 与 g++。下一卷给系统一张脸,桌面亮起来,终端成群,终章的实弹,就是桌面终端里用自家的 gcc 当场编一只 hello。
