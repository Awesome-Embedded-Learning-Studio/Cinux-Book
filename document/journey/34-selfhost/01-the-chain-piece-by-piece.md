# 师傅的班子,一层层看

机器如今会认人、会开机、会自己长出一张盘,可还不会自己编自己。生态那一卷验收收卷的时候,这句话咱们原样撂在了案上。您看盘上如今躺着的程序:busybox、glibc 的 hello、坐一号座的当家的,个个能用,可每一个的身子,都是在咱们开发它的电脑上编出来的,拷进盘里才上的桌。机器会跑别人编好的程序,自己一个字还造不出来。这一卷,咱们就把这个还不会,办成会。

收官前的路,生态那一卷开卷就排成了三程:头一程它把家安好,末一程收官,给机器一张脸。咱们脚下走的,是中间这一程:请一位师傅进门。它在中间承重,没有它,收官那一卷亮起来的,还是一台只会跑别人编好的程序的机器。

请进门的是 GCC 工具链一家。生态那一卷往盘上请的是客人,客人进门,是被咱们伺候的一方。这一卷请的是师傅,师傅进门是来干活的。收官的大戏,开卷报一遍:三层,层层加码,次序就是施工的次序。头一层的戏在串口壳里唱:盘上自家的工具链,把 hello 编出来,当场跑。用自家的家伙,在自家门里,造出自家的程序,这门本事有个名字,叫自举,咱们后头也爱说,这是机器把自己举了起来。再上一层,C++ 也要成色:g++ 上桌,编出真 C++ 程序,跑通。压轴的一层,才对得上编译自己四个字的全部意思:在自家盘上,从一个空的对象目录起,编出一只完整的新内核,造一只新的自己。编出来的新内核怎么验成色,咱们留到压轴那里再唱。

师傅的班子长什么样,咱们从您敲熟的那行命令看起。在咱们开发它的电脑上,您把 gcc 敲了不知多少回,应门的从来是 driver,班子里的领班。它自己几乎不动手,把参数拼好,把孩子一站一站往外派。头一站是 cpp,预处理,把 include 进来的头文件摊开,宏换成真身。摊出来的文本交给 cc1,编译器本体,班里干重活的匠人,把 C 翻成汇编。C++ 的活另有一位匠人,cc1plus,等 C++ 上桌那一章再出场。汇编文本交给 as,老师傅,收成目标文件。末一站 ld,也是老师傅,把目标文件和库连成可执行文件。两位资历最老,干的都是硬活,开工的头一件活就由他们交。班子里另有 collect2 和各路家什,到 C++ 那一摊再当面认。

链是这么走的,可五站吃起内核的饭来,吃法各不相同,咱们一路一路看。领班派孩子,进程怎么起是头一桩:师傅起孩子自有章法,跟咱们至今伺候过的客人都不一样,起不好,整条链开不了工。老师傅干活,文件的游标得会回头:ld 写目标文件,有的字节写出去还得补写,游标要是只会一路往前拱,活就卡住了。匠人进场,内存要给得起:cc1 的块头,当年量过,一身约 47MB,咱们至今伺候过的客人,还没有谁到过这个块头,整只搬进屋要出事,得有懒办法。末了看门上,号位的面要够宽:全链一开工,号位挨个点名,点到的名,都得有人应。

四样的吃法,咱们看下来,活就排成了队,施工图自己浮出来。

师傅本人,直接从咱们开发它的电脑上请:跟盘上客人喝的同一种血,同一个版本,同一个目标平台,连同它随身度日的库与家什,一起搬上盘。在盘上从源码重新长出一位师傅,是另一条长得多的路,这一卷不走它,这一卷的大戏,是机器拿起工具链造东西。

> 当年的板,笔者照例交代。当年那一遍拍过三条:glibc 的兼容要改,工具链不自己编,musl 与 glibc 在盘上共存。整块板,生态那一卷给 busybox 换血的那一章《/lib 里只剩一家》交代过,这里只重提跟师傅有关的一条:工具链不自己编,这一遍照办。musl 与 glibc 共存那一条已经翻篇,glibc 统一在生态那一卷办完,师傅进门,认的全是 glibc 的路数。

动工之前,照例把家底盘一遍,有的和缺的,咱们一片一片数。生态那一卷留下的最厚:作坊烤得出盘,进料有指纹管着,一条命令能把一台系统从干净的树组装出来,glibc 一家的座位也摆在那儿,师傅进门,喝的就是 glibc 家的血。再往早数,懒到家那一卷立过 VMA 的登记册,缺页来了怎么诊,咱们手上有现成的家法。生与收那一卷立的装载与入口,程序进门怎么装、栈上怎么铺,是现成的路。线程那一卷的 clone 与 futex,师傅起孩子正好用得上。缺的呢,真缺口就一处:exec 侧的惰性装载,大胖子进门的懒办法还没有,当年那一桩判例的正主场就在这里。另有一笔转来的欠单:位置无关的身子,PIE,至今没有座,生态那一卷收卷念欠单时,点名转给了这一卷。

路线排定,缓坡在前,压轴在最后:在自家肚子里,从空的对象目录,编出整只内核。师傅的班子拆完了,下一节,咱们把师傅请进门。
