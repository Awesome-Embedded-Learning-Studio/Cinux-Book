# 师傅的班子,一层层看

如今的机器会认人、会开机,盘也能自己组装出一张来了,不过自己还不会编自己。生态那一卷验收收卷的时候,这句话咱们原样撂在了案上。您看盘上如今躺着的程序:busybox、glibc 的 hello、坐一号座的当家的,个个都是能用的,可每一个的身子,都是在咱们开发它的电脑上编出来的,拷进盘里才上的桌。机器会跑别人编好的程序,自己的一个字还造不出来。这一卷的活,咱们就把这个还不会办成会。

收官前的路,生态那一卷开卷就排成了三程:头一程它把家安顿好了,末一程轮到的是收官,给机器添的是一张脸。咱们脚下走的,是中间请师傅进门的这一程。中间承重的是它,缺了它,收官那一卷亮起来的,还是一台只会跑别人编好的程序的机器。

请进门的是 GCC 工具链一家。生态那一卷往盘上请的是客人,客人进了门,是被咱们伺候的一方。这一卷请的是师傅,师傅进门是来干活的。收官的大戏,咱们开卷报一遍:三层,码是一层层加上去的,次序就是施工的次序。头一层的戏在串口壳里唱:盘上自家的工具链,把 hello 编了出来,当场就跑了起来。用自家的家伙,在自家的门里,造出自家的程序,这门本事的名字叫自举,咱们后头也爱说,这是机器把自己举了起来。再往上的一层,C++ 的成色也要:g++ 上了桌,编出的是真 C++ 程序,跑通了。压轴的一层,才对得上编译自己四个字的全部意思:在自家的盘上,从一个空的对象目录起,编出一只完整的新内核,造一只新的自己。编出来的新内核怎么验成色,咱们留到压轴那里再唱。

师傅的班子长什么样,咱们从您敲熟的那行命令看起。在咱们开发它的电脑上,您把 gcc 敲了不知多少回,应门的从来是 driver,班子里的领班。动手的活它自己几乎不干,把参数拼好了,把孩子一站一站地往外派。头一站的活是 cpp,干的是预处理,把 include 进来的头文件摊开,宏换成了真身。摊出来的文本交给 cc1 这个编译器本体,班里干重活的匠人,把 C 翻成了汇编。C++ 的活另有一位叫 cc1plus 的匠人,要等到 C++ 上桌的那一章再出场。汇编文本交给了老师傅 as,收成的是目标文件。末一站的 ld 也是老师傅,把目标文件和库连成了可执行文件。两位的资历最老,干的都是硬活,开工的头一件活就由他们交。班子里另有的是 collect2 和各路家什,到了 C++ 那一摊再当面认。

链是这么走的,不过五站吃起内核的饭来,吃法是各不相同的,咱们一路一路看。领班派出去的是孩子,进程怎么起是头一桩:师傅起孩子自有章法,跟咱们至今伺候过的客人都不一样,起得不好的话,整条链开不了工。老师傅干活的时候,文件的游标得会回头:ld 写的是目标文件,有的字节写出去还得补写,游标要是只会一路往前地拱,活就卡住了。匠人进场的时候,内存要给得起:cc1 的块头,当年咱们量过,一身的块头约 47MB,咱们至今伺候过的客人,还没有谁到过这么个块头,整只搬进屋是要出事的,就得有懒的办法。末了看的是门上,号位的面要够宽:全链一开工,门号挨个问了一遍,问到的名,都得有人应了才放行。

四样的吃法,咱们看下来,活就排成了队,施工图自己就浮了出来。

师傅是直接从咱们开发它的电脑上请的:跟盘上客人喝的同一种血,用的是同一个版本,用的是同一个目标平台,连同它随身度日的库与家什,一起搬上了盘。咱们在盘上从源码重新立起一位师傅,是另一条长得多的路,这一卷绕开了它,这一卷的大戏,演的是机器拿起工具链造东西。

> 当年的板,笔者照例交代。当年那一遍拍过三条:glibc 的兼容要改,工具链不由咱们自己编,musl 与 glibc 在盘上是共存的。整块的板,生态那一卷给 busybox 换血的那一章《/lib 里只剩一家》交代过,这里只重提跟师傅有关的一条:工具链不自己编,这一遍照办了。musl 与 glibc 共存的旧话已经翻篇,glibc 统一在生态那一卷办完了,师傅进了门,认的全是 glibc 的路数。

动工之前咱们照例把家底盘一遍,有的和缺的,咱们一片一片数。生态那一卷留下的最厚:作坊烤得出盘,进料是有指纹管着的,一条命令能把一台系统从干净的树组装出来,glibc 一家的座位也摆在那儿,师傅进门喝的就是 glibc 家的血。再往早了数,懒到家那一卷立过 VMA 的登记册,缺页来了怎么诊,咱们手上有现成的家法。生与收那一卷立的装载与入口,程序进门怎么装、栈上怎么铺,是现成的路。线程那一卷的 clone 与 futex,师傅起孩子的时候正好用得上。缺的呢,真缺口就一处:exec 侧的惰性装载,大胖子进门的懒办法还没有,当年那一桩判例的正主场就在这里。另有一笔转来的欠单:位置无关的身子,行话里的 PIE,咱们还没给它排座,生态那一卷收卷念欠单的时候,把它转给了这一卷。

路线排定了,缓坡是排在前头的,压轴收在最后:在自家的肚子里,从空的对象目录,编出的是整只内核。师傅的班子拆完了,下一节咱们把师傅请进门。
