# 头一件活:两位老师傅上工

两位老师傅上工头一天,活是咱们替他们挑的:hello,最朴素的一只。生态那一卷领进门的第一位 glibc 客人也叫 hello,不过那回端上桌的,是在咱们开发它的电脑上编好的现成身子。这回给老师傅的是生料,一段同样在电脑上按 -fno-pie 预编好的 hello.s,跟 hello.c 一起躺在盘上。班子里干编译本体的匠人 cc1 还没进门,头一件活轮不到他,咱们从汇编起手,汇成 .o,链成能跑的身子,两位老师傅一人一场,手艺各自过一遍。

活分三步:as 把 /hello.s 汇成 /hello.o,ld 把 /hello.o 连成 /hello,然后跑它。三步连成一串,咱们叫它手链。麻烦出在 ld 那一步的命令行上。链接一环要的东西多,crt 家族那几件祖传的家什、咱们刚汇出的 /hello.o、要找的库,一样一样排上去,长长一列。可串口那行缓冲,约百个字符就封顶,再往后敲,后半截直接丢,老师傅收到的会是句残话。办法是响应文件:链接要的参数一行一件,写进盘上的 /hello.ldargs,ld 见了 @ 打头的名目,就去文件里把参数一条条读出来。于是串口上敲的主干是三行,每行末尾其实还缀着一句报退出码的记号,咱们省去不抄:

```
/ # as /hello.s -o /hello.o
/ # ld @/hello.ldargs
/ # /hello
Hello from GCC!
```

Hello from GCC!,咱们听着盘上头一只在屋里链出来的程序开了口。

烙进 /hello 的门牌,咱们看着眼熟,就是 /lib64/ld-linux-x86-64.so.2。生态那一卷给第一位 glibc 客人烙的,正是同一条。ld 把它写进产物的 PT_INTERP,开机装载照精确路径去请解释器,路径一个字都差不得。请师傅进门那一章立下的话,在咱们链出的产物上原样适用。

老师傅交活,门上跟着开了一座新号位,这座是实测当场点出来的。as 写 /hello.o,ld 写 /hello,肚子里使的都是 BFD,Binary File Descriptor,GNU 家管二进制格式的那套老库。BFD 写文件的路数有来有回:写 .o 的时候,段头常常是回头补的,数据落了盘,游标搬回去,把段头里的地址与尺寸填实。搬游标的号位是 8 号 lseek,咱们门上原来没有这一座。开工前的单子上写着,盘烤好了就不动内核。冒烟头一轮,这句就被划掉了。师傅的活要点什么,门里当场就缺什么,实测说了算。

游标的旧话,门里原本有底。生态那一卷 pread64 那道小题立过分寸:游标住在打开的描述里,定位读拿参数当地址,读完了游标一动不动,读了不算走过。真把游标搬来搬去的号位,lseek 是头一个。搬法照内核 ABI 定的三个锚:0 号锚在文件头,1 号锚在当前游标,2 号锚在文件末尾。前两个锚门里自己答得出,2 号锚的答案在文件总长,得问后端。三锚落在 anchor 一个字上,您顺着这段看:

```cpp
    auto* const kFile  = kSlot.value().get();
    long long   anchor = 0;
    if (frame.rdx == kSeekCur) {
        anchor = static_cast<long long>(kFile->offset);
    } else if (frame.rdx == kSeekEnd) {
        if (kFile->ops->stat == nullptr) {
            return -kEspipe;
        }
        fs::FsStat probed{};
        if (!kFile->ops->stat(kFile->backend, kFile->node, probed).ok()) {
            return -kEio;
        }
        anchor = static_cast<long long>(probed.size);
    }
```

anchor 起手的那个零,咱们认得,就是 0 号锚,谁也不用问。1 号锚取的是自家描述里那枚游标。2 号锚进门就查后端的 stat 面,查不到,当场回 ESPIPE。锚定了,落点就是锚加偏移,加出来是负数,游标要退到文件头之前,EINVAL 拒。锚码出了 0 到 2 的范围,同样 EINVAL。描述符不在桌上,EBADF。搬的正是打开描述里那枚游标,往后定位读、普通读,看的都是同一枚。答不出的只有一种情形,对一股流问总长,问题本身就不成立。errno 词表里跟着添的新词,29 号:

```cpp
inline constexpr int kEspipe          = 29;   ///< The open is a stream; it has no cursor to move.
```

注释替咱们把话说尽了:这次打开是股流,没有游标可搬。

手链跑起来,门上的 unserved 探针跟着上了工。那枚探针是跑别人的程序那一卷立的,空号被敲,案上就记一笔。这一回记下的头一笔,是 98 号 getrusage,客人叫了,门里没人应。号位被人叫到门上,咱们叫它点名。叫了没人应,连办不办都不说,咱们叫它装聋。装聋没碍事,glibc 不较真,活照干,路没被挡。跟着记下的还有 273 与 334 两个号位,一样被叫,一样没人应,一样没人计较。三笔都记在案,不在这儿销,后头点名单的那一章,getrusage 转成明说的不办,门里显式回一句 ENOSYS,有人应了,应的是不办,客人拿这句回话自己找退路。装聋与明说在验收里是两码事,留到那一章再算。

交活验收,咱们报三面。冒烟一面,两位老师傅在座,/hello 链得出、跑得起,Hello from GCC! 报得干脆。全量的老验收一面,四条线,普通构建、地址加泄漏的排查、线程竞争、内核检查构建,全过。回归一面,生态那一卷的全套实弹照跑一遍,过。ET_EXEC 老路上的客人,一位都没受惊。这一章门里添的是号位,没动老客人的路。

当年第一遍,同样的头一件活,笔者交得远没有这么体面:ld 一上手就崩,段错误。破案用的法子是分层。崩在哪儿,就只查哪儿的那一层,把这一层的嫌疑一项项排干净,修掉,再跑一遍。要是还崩,说明底下压着另一层,让它自己冒头,接着剥。四层 bug 就是这么剥出来的,修掉一层,露出一层,层层见底,没有一层是一眼望穿的。这门手艺您记走,崩哪儿查哪儿,修完再跑,让下一层自己站出来。

两位老师傅的头一件活,交了。盘上头一只在屋里链出来的程序,咱们看着它跑了起来。可有一件事跟着摆上了桌。hello.s 的生料是按 -fno-pie 备的,链出来的是老形态的身子,主程序的座照老样子收下了它。等班子在盘上凑齐,师傅亲手编出来的东西,默认摆的都是 PIE 的形态,位置无关的身子——主程序的座,还不认。
