# execve 换世界

execve 和 fork 是天生的一对,咱们把手法摆在一起看:fork 给孩子造的是一张新帧,让孩子从返回尾进了场。execve 不造什么新任务,它改旧帧——就在当前真实的帧上动笔,改完借着正常的 syscall 返回,把同一个进程送进一个全新的程序。PID 和身份都留在原地,世界整个换了。这就是 fork 加 execve 这对组合的精髓:造一个临时进程,再让它顶替成盘上的程序。

fork 那边咱们列过一张三行的单子,execve 这儿咱们也照着列一张,您两边对仗着读:

```text
换          地址空间(整棵世界重装)、用户栈(新的一页)、入口(rip 改指新程序)
不换        pid、fd 册、cwd、名字
```

换的三样,四步走里您都见过了:新地址空间连同段和栈是第三步装的,入口是帧上 rcx 里改的。不换的四样,咱们把 HandleExecve 从头翻到尾,它一行都没碰——pid 和家族的亲缘都留着,文件册是原封不动的,cwd 也还在原地躺着。这个不换往后有实际的分量:hello 进场头一件事是往 fd 1 写问候,fd 1 是柜台那层的固定座,不是文件册里的座,文件册里 fork 继承来的那些座,也一样原样留给了新程序。

四步的走法,咱们看代码:

```cpp
kSelf->space     = fresh.release();
kSelf->user_root = kSelf->space->root();
kSelf->space->activate();
delete kOldWorld;
auto* const kFrame = PtrAt<SyscallFrame>(PerCpu::self().syscall_frame);
kFrame->user_rsp = proc::kUserProgramStackTop - 16;
kFrame->rcx      = entry;
kFrame->r11      = kUserFlags;
kFrame->rax      = 0;
return 0;
```

头一步的活是折路,内核栈上抄下客人递的路径,FoldUserPath 的老手艺。第二步整读:fs 层新升格的 ReadWholeFile,把盘上整个文件读进一块 Own 持有的缓冲,短读一律拒绝——盘说给了十个字节就是十个字节,少了哪一个都算事故,回了 kEio,这个词这一卷新进了 errno 表。第三步搭的是新世界:领一张新地址空间,LoadElfIntoSpace 把段铺了进去,顶上再添一页用户栈的映射,栈顶定在了 0x501000。第四步是旧世界的拆除——注意代码里的次序,咱们是挂新、切表、后拆旧。

这一次的次序值得单讲。头一版是拆了旧世界再切表,拆完到 LoadCr3 之间的那几拍,CPU 取指用的还是旧 CR3,而旧世界的页表已经进了池子,随时可能被别人领走重用——每一步都踩在已释放的内存上取指。咱们当时跑它,靠的全是侥幸。回头自查那一遍把这里拎了出来,delete 挪到了 activate 之后:新世界挂上身、CR3 切过去,旧的这才安心拆,期间机器的任何一拍取指,脚下都是完整的页表。哦对了,activate 的这一拍本身,也是一桩实弹案子的修法,下一节咱们看它缺席时闹出的怪数字。

咱们顺手收一桩小案,就出在栈顶这个词上:execve 里用的 0x501000,头一版用的是个匿名常数,注释里叫的是 user stack top,可地址空间那一侧早有一个同名的词,值是用户半区的顶,两个词同名而值不同,读代码的人早晚掉进去。收法是立一个正经的单词:proc_config 里新立 kUserProgramStackTop,教学程序的栈顶专用,两个消费者都改挂了它,顺手把 4096 的裸数字换成 page::kSize。词立了,常数收进了同一个家,重名异值的口子就此关上了。

帧上改的四个字,咱们逐个念给您听。rcx 装程序的入口,SYSRET 从 rcx 里取返回地址。r11 装的是 0x202,SYSRET 从 r11 里恢复的是 rflags。0x202 里装的是 IF 位,加那个永远为一的保留位,新程序进了场,中断是开着的。user_rsp 挪到了栈顶往下十六字节,十六字节的对齐不破。rax 清了零,execve 成功的返回值是 0,新程序的第一拍要是回头问上一句的答案,拿到的答案是 0。

这一卷还留了一处白,咱们照实说:argv 和 envp 不支持。execve 只收路径这么一个参数,新程序是没有命令行的,环境也是没有的。当年头一遍也是这么留的,咱们要等装库那一卷,等真有 C 库要初始化、真有程序要读 argv 的那天,这块的活才轮得到动。

Own 这个名字在本节里已经出现了几回,咱们补两句:它是咱们在 base 新立的一类指针伞,持有的东西出界即 delete,转移只有显式的两路。execve 里的那块文件缓冲、那方新世界,举着的都是它,错误路径上咱们一路提前 return,手里的东西自动还回去。Own 一家的来历和全家的名册,收官那篇咱们细讲。走到了这里,一个进程不换身份就能换掉自己的整个世界——帧上四个字改完,门里门外都是新程序了。不过通上电之前,谁也不知道这几段代码会在真正的机器上演出什么——下一节咱们通电,三案挨个地破。
