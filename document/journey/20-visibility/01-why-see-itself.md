# 为什么教内核看得见自己

懒到家那一卷收卷的时候,咱们撂过一句话:偷懒教完了,下一卷咱们教内核看得见自己。这一卷就是来兑现的。可看得见自己的许诺,咱们不能空喊,把机器今天出事的样子端出来,您自己判断它缺了什么。

断言死了,串口上落下的是一行遗言:文件名、行号、函数名、那句话,打完机器就停了。异常的一路没人接,报出来的是向量号和一排寄存器,尾巴上还跟着一条裸地址的回溯。就这些了。当时是谁在 CPU 上?咱们不知道。内存的家底还剩多少?咱们也不知道。回溯里那一串十六进制的地址,您得自己抱着源码一个个地对,翻了好一阵子才对得上是谁。这句苦经咱们念过一遍了:懒到家那一卷给锁报名号的时候,说的就是拿着地址翻源码的滋味。锁的名字当年补上了,可地址的名字还欠着。

其实名字服务的钩子,机器里早就埋下了。轮流当家那一卷穿护具的时候,回溯件就立在了调试的地基里,头文件的门口留着一句英文承诺,咱们把原话抄来:`turning them into names ... keeps a symbol table out of the shipped kernel until the station that actually needs one`。把地址翻成名字,当年定的是离线的活,内核的镜像里不背符号表,一直背到真需要它的那一天。咱们现在告诉您:那一天就是今天,符号表该进门了。

这一卷的活,咱们摊开报数,分的是两半。头一半教的是机器说话,占的是三件。名字簿的查找那一半:表装了进去,地址问得出名字。遗言的一站式:崩了之后,原因、回溯、当时在跑的谁、内存剩下的多少,一张脸就说完了。第三件做的是真符号注入:nm 从链接好的镜像里把真名字抄进表,名字不再是手造的。后一半教的是机器排队,干的活是调度类。谁下一个上 CPU 的问题,今天说了算的是就绪队列的弹出,主见长在了队列的身上,想换也换不了。咱们给它开一个插口,让换主见的事变成插拔。

当年的旧话也交代在卷首。这批活在当年的工程线上,是六月十八到十九的二十来个小时里连发的六件:可观测、信号、线程、进程组、调度类、工具加固,一件压着一件地铺。第六件工具加固的分量,咱们照实分了家。最大的单项是真符号注入,它跟着名字簿的第三件进了本卷。锁的名册那一块,懒到家那一卷吃过了,分量还比当年的厚。余下的检查基建,是咱们自家的老底。第一遍的教程就是被这样的密度喷的,幕间为密度立下的家法咱们记得,当年一口气咽下去的,这一遍一口一口地吃:本卷拿的是可观测和调度类两样,信号与线程各归后面的卷,一件就是一个卷的饭量。

顺路还有一笔当年交过的学费,咱们这一遍不用再交。当年的工程线到可观测这一件,才头一回把全部测试在 -O2 下跑了一遍,而当年笔记里留了句原话:增量的构建绿了不算数。咱们的机器从 SSE 开禁那一卷起,-O2 就驻在了旗组里,天天都在它的眼皮底下过日子,所以这笔学费,后来的咱们生来就免了。

顺序上咱们照着依赖走。查找的那一半头一件立:手造的几行就能测,真表还不存在的时候也不碍事。第二件立的是遗言一站式,它有了表就报出名字,没了表就报出裸地址,两头的日子都过得下去。真符号注入落在了第三件,把真名字送进了门,前三件就合了龙。收尾的是调度类,它是这一卷另一半的主角。下一节咱们动身立名字簿。
