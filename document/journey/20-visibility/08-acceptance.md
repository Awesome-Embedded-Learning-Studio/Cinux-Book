# 验收:看得见的机器

收卷照旧看的是面板、测试和实弹。面板咱们实跑了一趟,有数的几行抄上来:

```text
[kern] kernel at 200000 size 4A8A80 entry 200040
[kern] pmm: 31264 pages free (probe 116000 ok)
[kern] kernel_init: root mounted, launching shell from the volume
cinux shell - type 'help'
```

报上来的数,咱们跟懒到家那一卷对。size 报的是装机后内存影像的跨度,从 4A0840 长到了 4A8A80,多出的是三万三千三百四十四个字节,按页的边界一凑,多占的是八页。咱们再看 pmm,空闲页从 31272 走到了 31264,恰好少了八页,一来一回都算完了,八页对的是八页,是对得上的。涨出来的分量里,新代码占了一截,而从来没背过的客人是注入表:名字簿跟着镜像进了门,每一台内核都背起了自己的一份。盘还是那一卷的四 MiB,多出来的扇区一个都没有。

宿主的长凳上,这一卷新添了两件。名字簿的一件,七案:没表的答没有,缺表的安静,精确命中报的是零偏移,腹地报了深度,低于头一个的没名字,重装换了表,空装了之后照样诚实,边界一把考全了。调度类的一件,八案:注册表重复来时安静地算无操作,到达的次序交人,挑最小的权重、平局认的是早晚,满行老实地拒,片长到了点才说够,名字的拼写按住,倒序的咨询,接手的人拿整片。数的单位照旧是件,宿主从四十七件长到了四十九件,普通线、地址排查线、数据竞争线、内核检查线,四条的配置全数通过。普通线咱们另在开了 KVM 的机器上走了一遍,地址排查线这一回把泄漏的检查也开着,都交了满分。咱们把整条 ctest 数下来,六十二件全过:宿主占了四十九件,机内占的是十三台。

机内的十三台测试内核,台子还是原来的台子,长的只有案数。调度的一台从二十一案长到了二十二案,添的就是权重类的发牌案:主流程把权重一与权重九两个任务发进来,次序必须是一的在头里,压的是真实内核栈,走的是真实切换。会疼的自证,会听那一卷立下的老台子,它添的端到端一案就是本卷的实弹,咱们把它的戏份单独说一段。

这出没有演员表的戏,演的就是它自己。机器通了电,主流程进门头一件事就装了表,装的是它自己的两段链接生成的表。您看,全套的工序都在它的身世里:生成器、nm、弱符号、二分,缺的一样也没有。然后跑着的测试问了一句:KallsymsLookup 这个函数,住在哪里?名字簿答了:就叫这个名字,偏移答的是零。手造的表答得出这一问不算本事,自己链接出来的表答出了自己,全链走穿了才算数。十三台的机器,每一台的表都是这么来的,这一案在两条线里各跑了一遍,回回答的都是零。

这一卷的收成,咱们对一对卷首的承诺。教内核看得见自己的事,教到了这样的份上:一个地址,有名字了,进了函数多深都报得出。一场崩溃的收尾,一张脸就说完了,当时在跑的谁、内存剩下的多少,漏的一句也没有。名字不是手造的,构建线自己生成了它,乱了序还会拒绝出货。另一半的收成是排队:谁上 CPU 的事,主见从队列的形状里搬了出来,住进了可插拔的类里,换主见的事不必再动调度器,接手的人也不再背前任的旧拍数。两个绿得侥幸的案子顺手翻掉,平凡析构的前提不再是藏着的事。

幕间立过的名单,咱们往前看:信号、线程、装库跑别人的程序。打头的就是信号——进程得听得懂别人喊它的意思,停得下来的本事和醒得过来的本事,它缺了哪样都不行,进程组和停走唤醒的戏,都挂在它的身上。看得见的内核立住了,下一卷咱们教进程听懂信号。
