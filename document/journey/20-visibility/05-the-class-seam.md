# 给决策面开插口

这一卷的另一半是调度。轮流当家那一卷给调度器立过的形,咱们对一遍家底:它把决策和动手分开了,语义坐在了 Scheduler 里,碰机器现实的切换走的是注入的 SwitchSink,四个动词配着类型擦除的手续。这个分离咱们一路用得很顺。可有一件事它没有分到:谁下一个上 CPU 的决定权。就绪的队列是一个环,取人的动作是弹出,弹出来的是谁就是谁,主见长在了队列的形状上,想换一种挑人的法子,就只能改调度器自己的代码。执行面开了口,决策面还是死铁的一块。

咱们这一件活,就是给决策面开的插口。虚的基类咱们新立了一个,它的名字叫 SchedulingClass,中文里念的是调度类。类的自家家当是一条就绪的队,调度器问它的话只有四句,咱们把头文件里的四句原样抄来:

```cpp
[[nodiscard]] virtual const char* name() const = 0;
virtual bool enqueue(Task& task) = 0;
[[nodiscard]] virtual Task* pick() = 0;
[[nodiscard]] virtual bool wants_rotate(unsigned int slice_ticks) const = 0;
```

一句一句地念。问名字的 name,答出来的拼写是给将来的转储行预备的自称。问收留的 enqueue,一个任务要排进你的队,满了就老实地拒。问给谁的 pick,交出你想送上 CPU 的下一个人,队里没了人就交空手。问片长的 wants_rotate,当前这个任务跑了几拍,按你的章程,是不是该换了。四问之外的事,调度器不看进类的内部——队怎么排、挑人怎么挑,都是类自己的事。

这里咱们要停一拍,还一笔老判词的旧话。会听那一卷给心跳挑后端的脸时立过判词:虚表要的是 vptr,vptr 的初始化要走动态,零构造的纪律容不下,所以选了 concept。本卷是全教程头一回在内核里立虚的基类,这笔旧话咱们得当面还清,还清的路有三拍。头一拍的道理在缝:这道缝要的就是运行时的可插拔加按注册序的问询,静态的 concept 给不了这个活。第二拍的维度不撞车:管机器动作的 SwitchSink 还是老样子,SchedulingClass 管的是决策,两张脸各说各的话。第三拍的 vptr 落座没有走动态:两个类的实例是函数内 static constinit 的单例,构造是隐式的 constexpr,vptr 在常量初始化里就定了座,零构造的纪律一分都没有破。

队的形状咱们随手就有:一个定容的数组,次序是保住的。来的追尾,满员了拒绝,抽走了一格,后面的往前挪着补位,谁也不越过谁的位子。每一类管自己的一行,行长是十六——这个数您认得,当年全局就绪环的容量就是它,如今不再是一口全局的锅,一类一行地各吃各的。

调度器那边瘦了下来,咱们只给它留一张注册表。来了一个类,重复注册的是安静的无操作,所以启动的路径不用设防。表满了四个就响亮地拒绝,丢了一个类比崩了更难查,这样的事必须大声。取人的路只有一条:按注册的次序挨个地问,头一个交得出人的赢,后面的类今天没人问过。落座的时候还有一条归宿:没指名类的任务,坐的是头一个注册的类,指过名的,指的类就必须在册,指了一个没注册的类,响亮地拒绝。

两个类咱们当场落户。头一个落户的叫 fifo,脾气是到达的次序:来了一个就排进去一个,取的时候从头上取,您在轮流当家那一卷过的就是这样的日子。第二个落户的叫 priority,咱们叫它权重类,将来的转储行里它自报的就是 priority 这个拼写,脾气是挑最小的权重:扫全行,数最小的人上,数一样小的,来得早的在前。任务的建造器为此添了两个旋钮,一个指名要坐的类,一个设权重——权重是任务身上的一个字节,数越小的事越急,读它的只有权重类,别的类看都不看。饿死的事咱们不遮掩,如实地说:严格地按权重,没有老化和提升的手腕,权重一的活要是源源不断,权重九的一直排在队里,这就是严格权重制的正经下场。当年手推过一个三个任务的序列,推出来的结果里有一个人永远轮不上,推演的判断当年直接写进了断言。咱们照这路数办事,平局的规则也写成了案。防饿死的那类算法,留给往后的年月,眼下的诚实是:会饿,而且咱们明说了。

跨类的边界同样如实。注册的次序就是问询的次序,fifo 注册在了头里,它不清空的时候,priority 就没人问过了。无类的任务源源不断地来,权重类就得一直等着——今天的仲裁就是这样,咱们不装。要紧的消费者还没来:能把任务停下来的信号在后面的卷里,到了那一天,类的队列要学会摘人,跨类的次序也要重新裁过,咱们把它记在了明处,等它的日子。

启动的注册序,主流程里就两行:默认的 fifo 头一个落座,权重类跟着落了座。您注意这里有一笔向后兼容的实打实:现存的任务一个都没改,全都没指名要坐的类,全坐了 fifo,行为与从前的一字不差。这样的安稳靠的是设计的约束,巧合帮不上忙——当年工程线吃过名存实亡的亏,咱们下一节把这个案发了,再做时间片的功课。
