# 查找的那一半

名字簿长什么样,咱们把一条条目端出来看。条目是一个装着两个字段的结构体,整本簿子就是它排成的数组,定义咱们原样地抄在下面:

```cpp
struct KallsymEntry {
    unsigned long long addr;  ///< The symbol's linked address.
    const char*        name;  ///< The symbol as the linker spelled it.
};
```

两个字段您都看见了,一个放的是地址,另一个放的是名字。addr 的类型是 unsigned long long,咱们跑的是六十四位的线,它的宽度是八个字节,链接出来的任何地址都装得下。承重的行是 name,它是 const char* 的指针,不是内嵌的字符数组——字符串本体由链接器放进了镜像的只读数据,表里握着的只是指向它们的指针。查表的手递出去的就是指针的原样,连复制都省了,簿子全身上下没有一块自己的内存,后面要说的零分配,根子就扎在了 name 那一行上。整本簿子再按地址升了序,查找走的是二分。这个形状是当年工程线定下的,咱们原样地继承,因为查找那一半有一个当年就立下的好性质:它不知道表从哪来。装表是一根独立的缝,宿主的测试递的是手造的小表,真的镜像递的是自带的段,查找的代码一个字都不用改。凭着这样的解耦,当年把注入拖到了最后一件才补,查找照样立得住了,咱们这一遍照用。

查找的语义,咱们拿四种问法把它考全。您问的地址恰好是某个符号的家,答的是它的名字,报的偏移是零。您问的地址落在一个函数的腹地里,答的还是它,偏移报的是您进了它多深——崩溃现场最想说的恰恰就是这句:死在哪个函数里不稀奇,死进去了多深才值钱。您问的地址比簿子里头一个符号还低,咱们老实地回答没有,它不在任何符号的名下,递邻居来充数是会骗人的,报出来的名字和深度就都是假话了。您问的地址越过了最后一个符号,回答的仍然归最后一个符号。缺的那一环在取法上——二分挑的从来是不大于所问地址的最近一个条目,地址高过了表尾,挑出来的自然就是末一个。这一挑其实也不冤,道理在布局上:数据的地址排在代码的上方,越过最后一个函数的那一截,归的都是它。

名字照链接器的拼写报。C++ 的符号带着名字修饰,长长的下划线串,咱们不做还原,原样地端出来。这样的选择,图的是诚实:名字簿报的是链接器眼里的世界,咱们拿修饰名去对符号表一字就能命中,还原的活留给看的人手边的工具。

注入的脸咱们立在公告头里,放的是一对弱符号,原样地抄在下面:

```cpp
extern "C" {
extern const KallsymEntry       kBuiltInKallsyms[] __attribute__((weak));
extern const unsigned long long kBuiltInKallsymsCount __attribute__((weak));
}
```

弱在哪、为什么弱,咱们把它说明白。没带表的镜像,链接器把两个符号的地址填成了空,查表的世界安静地过自己的日子。启动的时候有一句装表的调用,判空的活就落在它的身上,而判空的写法有讲究,咱们把守卫原样抄来:

```cpp
void KallsymsInstallBuiltIn() {
    if (&kBuiltInKallsyms == nullptr || kBuiltInKallsymsCount == 0) {
        return;
    }
    KallsymsInstall(kBuiltInKallsyms, kBuiltInKallsymsCount);
}
```

您看判空的那半句:比的是数组的地址,不是数组里的内容。未定义的弱符号,地址是零,取它的值就是从零地址往里读,这一步咱们不能走。计数的读是敢做的,靠的是次序:数组已经验明在册,计数跟着也就在了,生在同一份生成文件里的它们,过的是同生同死的日子。这一行的写法因此定死了:地址的判断在前,取值的判断在后,座次是换不得的。

装表的那根缝就是 KallsymsInstall,装了两次就是换表,什么都不分配。零分配是命定的:跑在崩溃现场上的就是它,那时候堆世界是什么样谁都不敢打包票,查找敢依赖的只有手里的表和打印。宿主的七案把边界考全了:没装表的时候问谁都答没有,缺表的镜像装内置表时安静不动,精确命中报了零偏移,腹地报了深度,低于头一个的没名字,重装换了表,空装了之后照样诚实。升序是表的必须,这是二分立命的前提。这道前提咱们不写在注释里祝愿,生成器那边立了一道闸,乱了的表它拒绝出货,真名字进门的那一篇里您能看到它拒绝的样子。眼下的簿子还空着,可遗言已经能够体面起来了,下一节咱们把崩溃的现场收成一张脸。
