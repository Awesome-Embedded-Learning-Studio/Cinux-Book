# 真名字,两段链接

查找的那一半立好了,本节咱们给簿子进真货。真名字的家在链接器那里:一个镜像链完了,nm 能把它肚里每个符号的地址和拼写都列出来。咱们要做的,是在构建线上加的一道工序,把整份清单翻译成一份 C++ 的编译件,定义上一节立的那对弱符号,再让它跟着链进了镜像。听起来是一句话的事,里面却有一道鸡生蛋的题:表想进镜像,可那时的镜像还没链完,nm 读的去处在哪里?

当年的解法是链完了再补一遍,咱们把这一遍换成两段链接,把蛋的题正面解掉。头一段的工序里,核心的源码全部编成一个对象库,加上入口、字模、行李这几样的家当,链出一个不带表件的镜像,它是专门供 nm 去读的。生成器照着它写出的是表件。到了第二段,同一个对象库原封不动地用,把表件加了进去再链一遍,这一回出来的才是出货的镜像。两段用的是同一批对象,这是一个字都不敢含糊的地方,含糊了后面的话就全塌了。

第二段加了东西,函数的地址为什么不挪?咱们把布局摊开看。链接脚本里的 .text 在前,.rodata 是自己独立的输出段,排在了它的后面。表件里的内容,咱们用段属性整个送进了一个叫 .rodata.kallsyms 的输入段,落点就在 .rodata 的里面。两段链接的 .text 是一模一样的,表加了进去,动的是 .rodata 往后的长度,函数住的那一带连门牌都没挪动过。当年工程线的布局里 .rodata 嵌在 .text 输出段的内部,也是排在所有函数的后头,性质同源——表自己的大小,影响不到函数的地址。这个办法当年叫的是单趟法,一趟的 nm 就够,迭代着猜的功夫都省了。咱们换了布局,性质咱们得重新验,把两段链接各跑出的符号表逐条对过,函数的地址零漂移,验了两轮才定案。

表件进了镜像,还有一道 gc 的关。咱们把链接的扫无主段选项开着,表里的内容没有任何代码挨个地引用它,弱符号的那点含情脉脉,扫帚是不认的。解法是老朋友:链接脚本里圈定保留的名单,本来住着四户——镜像头、字模、用户文段(usertext.user)、测试的案卷,如今添了第五户:

```text
.rodata : ALIGN(16) {
    KEEP(*(.rodata.font))
    KEEP(*(.rodata.kallsyms))
    *(.rodata*)
}
```

生成器本身是一条 Python 的脚本,干的是三件事,件件都有它的讲究。头一件挑的是符号:nm 按地址列清单,咱们只留代码符号,也就是类型是 T 和 t 的行,点开头的链接器私标丢掉,同一个地址挂着好几个名字的,留下的只是头一个。留头一个其实不是偏心,同址的几条在二分的眼里没有分别,给谁的都是同一个名字加零偏移,留哪一条查出来的话都一样。而要是全留下,相邻的两条地址相等,相等也算坏了升序,表就过不了马上要亮的那道闸。nm 的行长的是三段:地址、类型的字母、名字,大写的 T 是全局的代码,小写的 t 是局部的代码,D、B、R 一类数据的符号不在收编之列。只收代码的理由在消费人:名字簿伺候的是回溯,递进来的地址全是代码的地址,收了数据的符号,越过最后一个仍归它答的口径就得重裁——数据排在代码的上方,可上方没有最后一户的数据可指。武器库那一卷就用过 nm 与 c++filt 了,咱们是老熟人。第二件是咱们这一遍新立的闸,上一节卖过的关子,现在咱们把它亮出来:

```python
for (previous, _), (current, _) in zip(kept, kept[1:]):
    if current <= previous:
        raise SystemExit(
            f"{image_path}: nm listing is not strictly ascending "
            f"at 0x{current:x}; the lookup binary search needs an ordered table")
```

nm 本来就是按地址排的,所以这道闸平常一行都不拦。可二分立命的前提是有序表,前提写在注释里的只是祝愿,写进了闸里的才是保证:哪天 nm 的输出出了意料之外的形状,生成器就拒绝了出货,报的是镜像名和出事的地址,坏表一张都别想混进镜像去骗咱们的二分。第三件干的活是写文件,纪律只有一条:内容变了才写。不变也重写的话,文件的时间戳刷新了,下一趟的构建看见新时间戳就再链一遍,链完了时间戳又刷新,构建就进了死循环。所以写之前咱们把旧件读出来比一遍,一字都不差的话,咱们就一个字节也不动。

整套的工序都跑在构建线上,每一台内核都有自己的表:发货的镜像有一份,机内的每一台测试内核各有一份,各自的两段链接各自生成。验证咱们做到了端到端:机内会疼的自证,自证用的老测试内核,添了一案,把整条链都走穿了——

```cpp
TEST("kallsyms: the running image answers for its own functions") {
    const auto         kSite  = reinterpret_cast<unsigned long long>(&cinux::debug::KallsymsLookup);
    unsigned long long offset = 12345;
    const char* const  kName  = cinux::debug::KallsymsLookup(kSite, offset);
    ASSERT_NOT_NULL(kName);
    ASSERT_EQ(offset, 0ULL);
    ASSERT_TRUE(kName[0] != '\0');
}
```

跑在机器肚子里的代码,拿着自己身上一个函数的地址,去问自己链进来的名字簿,答回来的必须是这个名字,报的偏移也必须是零。表从它自己的镜像里生成,手造的成分一点没有,这一问问的是全套的工序:生成器、两段链接、弱符号、装表、二分,哪一环掉了都不行。发货的那一侧,主流程进门头一件事就是装内置的表,早到连启动路上头一个断言要是死了,遗言里都已经带上了名字。名字的事到此齐了,这一卷的另一半还等着,咱们去给调度器开插口。
