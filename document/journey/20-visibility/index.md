# 20 · 看得见的内核:叫什么,崩在哪,轮到谁

懒到家那一卷收卷的时候,咱们撂下过一句话:偷懒教完了,下一卷咱们教内核看得见自己。话音落了没几天,这一卷就来了。

咱们把机器今天出事的样子再盘一遍,您就知道这话说得多不及时。断言碎了,串口上留下的是一行遗言,打完就停了机。异常的一路没人接,报的是向量号和一排寄存器,尾巴上还跟着一条裸地址的回溯。当时在 CPU 上的是谁、内存的家底还剩了多少,这两样咱们一样都答不上来,那一串地址,您得自己抱着源码一个个地对。机器天天干着它的活,可它疼的时候说不出来疼在了哪,这就是哑巴内核的日子。其实解药的方子在护具那一篇就留了言:回溯件的门口写着,符号表不进镜像的约定,一直等到真需要它的那一天。这一天到了。

活分的是两半,咱们一件件报。头一半教的是机器说话,占的是三件:名字簿的查找那一半,配的是升序的表加二分,四种问法把边界考全了。遗言的一站式,崩了之后回溯带着名字、当前任务自报家门、内存的概览有什么报什么,一张脸就说完了。真符号注入的一件,nm 从链接好的镜像里抄来真名字,两段链接解开的是鸡生蛋,生成器还立了一道乱序就拒绝出货的闸。后一半教的是机器排队,干的活是调度类。谁下一个上 CPU 的主见,从一个环形队列的弹出里搬了出来,交给可插拔的类,四问——叫什么、收不收、给谁、片够没够——定下的是界面,注册表定下的是次序,顺手还修了一处接手的人背前任旧拍数的错。路上另有两件翻案:虚析构占了其一,物理寄存器占了其二,都是绿了很久靠运气撑着的测试,这一卷被开着插桩检查的构建配置照了出来。

当年的旧话照旧交代,整段的话留在卷首。那批活是二十来个小时里连发的六件,一件咬着一件地铺,本卷拿的是可观测和调度类两样,信号与线程各归后面的卷,-O2 的学费这一遍也免了。第一遍的教程被这样的密度喷过,幕间立下的家法咱们记得,当年一口气咽的,这一遍一口一口地吃。

合卷的时候,第二幕的第二卷交了。机器还是原来的机器,可它现在答得出三句话:这个地址叫什么,崩的时候发生了什么,下一个轮到的是谁。地址有了名字,崩溃有了整场的口供,排队的章程从队列的形状里搬进了可插拔的类里。当年挤在二十来个小时里的六件,咱们这一卷消掉了两样,幕间名单上的信号排在下一个:进程得听得懂别人喊它的意思,该停的停,该醒的醒,进程组的戏也从它开演。
