# 教科书 · 跟着正文往深处看

> 前置卷里咱们把家什备齐,正文里咱们把系统一行一行搓出来,这一层是咱们往深处看的地方:同一个机制,真实系统怎么做、代价是什么、咱们为什么不做。它跟着正文的进度长,咱们眼下能给的还是一张没写过一个字的目录。

## 将来有什么

- **第 0 部 导言** — 为什么亲手做一个操作系统,这本书怎么读
- **第 1 部 机器** — 一条指令的一生、字节寄存器与栈、上电、保护模式与长模式、与设备打交道、DMA 与中断、存储层次、ELF 与裸镜像
- **第 2 部 总论** — 内核态与用户态、中断与异常、系统调用、进程与上下文、文件系统抽象
- **第 3 部 内存** — 地址空间、分页与 TLB、缺页与按需分页、物理内存管理、内核地址布局、Page Cache 与写回
- **第 4 部 并发** — 竞态与临界区、锁的实现、死锁与锁序、条件等待、信号、内存序与缓存一致性
- **第 5 部 持久化与使用侧** — 文件与目录、文件系统实现、崩溃一致性与日志、块设备与驱动、TTY、Unix 进程语义全景、VFS 与 socket

## 怎么长

这一层不抢正文的节奏。正文推进到哪儿、咱们攒下的东西够写成一章了,这边就落一章:咱们把概念讲明白,再带着您按执行顺序读 Cinux 当下的真实代码,顺手对照 xv6 和 Linux 在同一件事上的做法。您现在进来想找点读的,您去[前置卷](../primer/)或者[正文](../journey/)转转都行,等这边有了第一批章,您再回来,咱们接着往深处走。
