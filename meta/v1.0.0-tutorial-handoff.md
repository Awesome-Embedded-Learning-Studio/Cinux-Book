## 1. ⚠️ 方法论铁律(上一轮踩的坑)

**教程 = 验证点,不是可选装饰。** 上一轮做了大 wholesale 把源码对齐 v1.0.0,但**只倒源码没写教程** = 跳过了验证 = 错。作者原话:「教程作为一个验证点看看代码行不行」。

正确做法:每个 brought-in 弧必须有配套教程,**写章过程就是逼自己读源码、核对锚点、确认它端到端可用**(不只编译过)。tmpfs 章就是这么验证的(确认 boot 真挂 /tmp + test PASS + syscall 级真挂测)。

**别再做大 wholesale 式的「只搬源码」。** 剩下的弧:源码已在树里(wholesale 带进来了),要补的是**教程**(核实 + 教学),不是源码。
